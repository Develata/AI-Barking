 [#pagemantle-company-dataset]

 PageMantle Company Dataset

PageMantle is a fictional company that sells software for building and hosting websites. This synthetic dataset by Deepnote [https://deepnote.com] contains its conversations, documents, customer records, billing and analytics.

The dataset imitates the data found in services such as Slack, Notion and Stripe. You work with local files, without connecting to the real services.

Use it to study how AI agents find and connect information across company tools. For example, an agent could investigate a customer problem using Slack, Linear and Notion.

 [https://deepnote.com/workspace/Deepnote-8b0ebf6d-5672-4a8b-a488-2dd220383dd3/project/PageMantle-Company-Dataset-Demo-3e19a2db-8452-47ad-bb10-3a297cfc4b9e/notebook/PageMantle-Company-Dataset-Demo-207eeefac0634046b8e97df389733d5f?utm_source=share-modal&utm_medium=product-shared-content&utm_campaign=notebook&utm_content=3e19a2db-8452-47ad-bb10-3a297cfc4b9e]

Explore a customer handoff across Slack, Linear and Notion in Deepnote, with the sample data, code and results already included.

 [#whats-included]

 What's included

Records are saved as of September 30, 2026, including September activity and older business records from eleven services:

Work: Slack, Linear (issue tracking), Notion and Google Calendar.

Customers and billing: HubSpot and Stripe.

Analytics: PostHog, Google Analytics, Google Search Console, BigQuery and Snowflake.

Formats include SQLite, Parquet, Markdown, JSON and PDF. The data guide [/datasets/deepnote/pagemantle-company-dataset/blob/main/DATA_GUIDE.md] explains the files and how to open them.

Size: 5.97 GB compressed, 10.11 GB extracted, 101,337 files.

 [#start-small]

 Start small

To run the example locally, use sample/ and examples/ from the release ZIP and open the quickstart notebook [/datasets/deepnote/pagemantle-company-dataset/blob/main/examples/quickstart.ipynb]. These folders contain about 1.3 MB. See the setup instructions [/datasets/deepnote/pagemantle-company-dataset/blob/main/examples/README.md].

Or explore Linear directly with these four files from the release, arranged as shown:

download/
├── data/
│ └── linear.tar.gz # Linear data, 344 KB
├── manifest.json # Archive verification details
├── file-index.jsonl.gz # Individual file checks
└── tools/
 └── verify.py # Checks your download

With Python 3 installed, run these commands in a terminal from download/ to check and extract the archive:

python3 tools/verify.py --service linear
mkdir -p unpacked
tar -xzf data/linear.tar.gz -C unpacked

Show five issue identifiers and titles with Python 3. No extra packages are needed:

python3 - <<'PY'
import sqlite3

with sqlite3.connect("file:unpacked/linear/linear.sqlite?mode=ro", uri=True) as db:
 for row in db.execute("SELECT identifier, title FROM issues ORDER BY identifier LIMIT 5"):
 print(*row, sep=": ")
PY

For all services, use the eleven archives in data/, run python3 tools/verify.py, and extract each into unpacked/. See the verification guide [/datasets/deepnote/pagemantle-company-dataset/blob/main/tools/README.md] for other check options.
