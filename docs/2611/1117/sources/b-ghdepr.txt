Upcoming deprecation of MAI-Code-1.1-Flash in December

With the launch of MAI Code 2 Flash, we will deprecate MAI-Code-1.1-Flash across all GitHub Copilot experiences on December 18, 2026:

Model
Deprecation date
Suggested alternative

MAI-Code-1.1-Flash
2026-12-18
Latest MAI Code Flash model

Please update your workflows and integrations to use the new model before December 18. Copilot Enterprise administrators may need to enable access to the alternative model through their model policies in Copilot settings. As an administrator, you can verify availability by checking your individual Copilot settings and confirming that the policy is enabled for the specific model.

Once enabled, you’ll see the model in the Copilot Chat model selector in supported GitHub Copilot experiences. No action is required to remove the older model once it has been deprecated.

GitHub Enterprise customers with questions or concerns are encouraged to reach out to their account manager for further assistance.

Share your feedback [#share-your-feedback]

To learn more about the models available in Copilot, see our documentation on models [https://docs.github.com/copilot/reference/ai-models/supported-models?utm_source=model-release-announcement&utm_medium=changelog&utm_campaign=newmodels] and get started with Copilot today.

Join the GitHub Community Discussion [https://github.com/orgs/community/discussions/213300?utm_source=model-release-announcement&utm_medium=changelog&utm_campaign=newmodels] to share your feedback.
