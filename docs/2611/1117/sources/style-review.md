# 1117 读者稿检查

检查方：Codex `gpt-6-astra`（medium，只读，无本期上下文），北京 11-18 约 17:30；只给正文与 6 个标题候选。

## 1. 标题

我会点的前三：

1. **“AI说做完了？新GPT漏报22%”**：我会担心自己也遇到过 AI 没做完却说做完，想点进去看看。
2. **“GPT漏报22%，OpenAI自己测的”**：“OpenAI自己测的”让我好奇，怎么连自己都测出了问题。
3. **“OpenAI自曝：新模型漏报障碍翻倍”**：“自曝”和“翻倍”有冲突感，让我想知道新版怎么反而变差了。

看不出具体在说什么事的：

- **“AI说做完了？22%没提卡在哪”**：22%是什么的比例？“没提卡在哪”是回答没说清楚，还是任务没完成？
- **“新GPT更常不说卡住了，旧版11%”**：“更常不说卡住了”读着绕，旧版11%是在说卡住的次数，还是没告诉我的次数？
- **“OpenAI：为了简洁，AI少说没做成”**：我能猜到是 AI 隐瞒失败，但不知道是哪种事情没做成。
- **“AI说做完了？新GPT漏报22%”**：虽然最想点，但“漏报”漏了什么并不明确。

只看第一名 **“AI说做完了？新GPT漏报22%”**，我会以为：新版 GPT 有22%的任务其实没做完，却告诉用户“做完了”。这是标题给我的预期。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：“谁吠”是在骂谁，还是栏目名字？我不知道接下来要看新闻还是吐槽。
- **“GPT-6.2-Astra 有22.28%没告诉用户卡在哪，上一代是11.09%”**：22.28%是回答、任务还是用户的比例？“Astra”也不知道是什么。
- **“这是诱发测试，不代表真实使用。”**：“诱发测试”不懂。前面故意设障碍我能理解，这里又换了一个术语。
- **“微软称 MAI Code 2 成本只有 GPT-6.1-Sol 的四成，脚注写明按五折促销价算。”**：突然出现两个新名字，还同时有四成和五折，我要停下来算它们是什么关系。
- **“OpenAI 发布 GPT-6.2-Astra 和 Sol”**：Astra 和 Sol 是两个版本、两个产品，还是一个完整名字的两部分？
- **“GPT-6.2-Astra 有22.28%的回答没提或说错了障碍”**：“说错了障碍”具体是什么样？它知道失败但解释错了，还是根本没发现失败？
- **“猜测可能与‘让回答更简洁、少加免责声明’有关。”**：这里的“免责声明”指什么？为什么少说免责声明会变成不告诉我任务卡住？
- **“两个模型只进 ChatGPT 的 Work 和 Codex”**：Work 和 Codex 是什么？是 ChatGPT 里的按钮，还是另外的软件？
- **“同一测试里 Astra 降到8.04%”**：我得回头确认，降的是“不说障碍”的比例，不是卡住的比例。
- **“这段指令不作用于直接调 API 的请求。”**：“调 API”完全不懂，也不知道自己用的软件算不算。
- **“四项编程测试平均成绩达到 GPT-6.1-Sol 的98%，成本是它的40%。”**：98%是题目答对了98%，还是另一个模型成绩的98%？成本是谁付的钱？
- **“每百万 token 输入0.5美元、输出2.5美元，2027年5月17日起1美元、5美元；GPT-6.1-Sol 是2美元、10美元。”**：token 是什么？输入输出为什么分别收费？这串价格跟前面的40%怎么对应，我算不过来。
- **“Copilot 付费版（Pro 及以上）用户现在能在模型列表里选它，按用量计费。”**：Copilot 又是什么？已经付费还要另外按用量付钱吗？
- **“‘98%’是平均通过率63.2%对64.1%”**：两个数字分别是谁的？为什么前面说98%，这里又变成六十多，我要读两遍。
- **“这三项都在微软自家测试平台上跑。”**：不知道这意味着什么，是微软自己出题，还是只是用了微软的电脑？

## 3. 像 AI 写的

- **“对你：两个模型只进 ChatGPT 的 Work 和 Codex，普通聊天里选不到，官方名单里没有免费版；企业版和教育版默认关闭，要管理员开。”**：“对你”像模板里固定安排的“跟读者有什么关系”，但后面一口气塞进好几类用户，没有直接告诉我这种普通聊天的人要不要在意。
- **“对你：GitHub 称，Copilot 付费版（Pro 及以上）用户现在能在模型列表里选它，按用量计费。”**：又是同样的“对你”格式，像把产品公告硬套进“与你有关”的栏目。
- **“①障碍是故意放的，OpenAI 写明结果不一定反映真实使用中的误导率；真实用户里有多少次没说，报告没给数。”**：意思有用，但前面的省流已经提醒过一次，到这里又完整补一道限制条件，像 AI 怕表述不严谨而反复打补丁。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：“沸点／吠点”反复押词，加上“轻松识破”的效果承诺，像 AI 生成的栏目宣传口号；我读完其实并没有觉得轻松。

## 4. 会划走的地方

- **“省流：OpenAI 自家报告显示，在故意设障碍的编程测试里……”**：这里就有划走风险。“省流”里挤了模型名字、两组百分比、测试限制和另一家公司的价格，我还没弄明白第一件事，就被推到第二件事。
- **“对你：两个模型只进 ChatGPT 的 Work 和 Codex，普通聊天里选不到”**：这是我最可能划走的地方。看到“普通聊天里选不到”，我会觉得自己平时用不到，标题带来的担心也就消了。
- **“二、微软：MAI Code 2 称成本只要四成”**：我是被“AI 没做完却不说”吸引进来的，突然开始讲另一个编程模型的成本，我没那么想看。
- **“GitHub 价目表：MAI Code 2 现按促销价，每百万 token……”**：如果撑到这里，这串计价数字会让我直接跳过。

不在乎的“吠点”：

- **“这段指令不作用于直接调 API 的请求。”**：我不知道 API 是什么，也不知道自己是不是受影响的人，因此很难在乎。
- **“微软大会总览页和 AI 负责人苏莱曼都写‘40%的价格’，没提促销”**：我不买这个模型，也不认识苏莱曼，“促销条件藏脚注里”能看懂，但不值得我继续研究。
- **“四项里有三项 MAI Code 2 比 GPT-6.1-Sol 低，这三项都在微软自家测试平台上跑。”**：我不写代码，不知道这些差距会影响什么；“自家平台”为什么值得警惕，正文也没让我明白。

读完和我的关系、能做什么：

- **“普通聊天里选不到”**：正文让我明确知道的，反而是这件事跟我日常聊天关系不大。
- **“看 AI 会不会告诉用户”**：我能自己推出来的提醒是，AI 没说卡住，不一定就顺利做完了。但正文没给我一个普通人能用的检查办法。
- **“轻松识破吠点”**：读完我记住了“新版有问题、微软价格有促销条件”，但仍不知道下次用 AI 时具体该多做哪一步。
## 采纳

- 标题：读者把 #1“AI说做完了？新GPT漏报22%”读成“22%的任务没做完却说做完了”，且看不出是测试。采纳：改为新候选“AI没做成也不说？新GPT测试中22%”（19 字），标题里带上“测试中”，“漏报”换成读者说得出的动作。
- 读不懂：“诱发测试”改“设局测试”；“Astra/Sol”改写为“新模型 GPT-6.2-Astra 和 Sol”；“免责声明”改“限定和提醒”（原文 caveats）；“直接调 API 的请求”改“开发者在自己程序里直接调用模型时”；“98%”改写成“它的平均通过率是 GPT-6.1-Sol 的98%”，吠点里写明 63.2% 是谁的、64.1% 是谁的；token 加括注“文字计量单位”；Codex、Copilot 加括注或主语。采纳。
- “自家平台为什么值得警惕”：改为“都由微软在自家平台上跑”，不加推断（题目是公开基准，不能写成“微软自己出题”）。部分采纳。
- 像 AI 写的：“对你”固定格式为 2026-11-18 起的试行规则，不改；A 帖“对你”句把普通聊天用户能做的放前面的建议：本号只写已核实的事实，不给“自己核一遍结果”这类未核实的建议，不采纳。吠点①与省流的限定重复：吠点卡单独成图，限定必须同条自带（EDITORIAL“吠点”），不采纳。Slogan 为固定结尾，不改。
- 会划走：两帖题材跨度大，标题按“两条默认只给第一条”只给 OpenAI；第二帖保留（Develata 已拍板两条主帖）。价格串保留（“对比”要求绝对数），已加 token 括注。
