 一文看尽微软Ignite大会：模型7连发，狙击Jev，Copilot成5000万智能体管家

智东西11月18日消息，今日凌晨，微软在Ignite 2026大会上一口气扔出五款新模型及两款模型新进展，其编程模型MAI Code 2在四项编程基准测试中，综合成绩达到GPT-6.1 Sol约98%的水平，测试成本约为其40%。

5款本次发布的新模型及升级版本：面向编程的MAI Code 2和MAI Code 2 Flash、面向网络安全的MAI Cyber 2 Flash、实时语音对话模型MAI Realtime 1，以及决策模型Microsoft-Decision-1.1。

2款此前已发布模型的新进展：今年10月27日发布的图像模型MAI Image 2.7，在Artificial Analysis图像编辑榜单上从第二升至第一，微软此次还推出了MAI Image 2.7 Flash；基于今年9月发布的MAI Transcribe 2构建的医疗语音转录功能Dragon Copilot Transcribe，已用于微软医疗AI产品Dragon Copilot，每月覆盖约1000万次患者就诊，多语言转录错误率降低约50%。

除了MAI Code 2，其他几款模型性能也接近甚至超过主流竞品。微软称，网络安全模型MAI Cyber 2 Flash在漏洞检测测试中的表现与GPT-6 Astra相当，单项任务计算成本不到后者的2%；图像模型MAI Image 2.7登顶Artificial Analysis图像编辑榜单，领先GPT Image 2.6 Sunburst Max 4分，价格约为后者的1/5。

微软董事长兼CEO萨提亚·纳德拉（Satya Nadella）在X上发文称，微软希望通过此次Ignite大会发布的一系列技术和产品更新，将技术进步转化为实际成果，让个人、企业和整个社会从中受益。

▲Satya Nadella发布推文（图源：X）

除了模型之外，此次更新依然高度聚焦企业AI智能体，微软公布了多项Copilot更新：能调度多个AI智能体合作干活、能主动从邮件中发现待办工作等。

用户可以让Autopilot持续跟进项目、安排会议和催办任务，也能在Workspaces中与AI共同修改文档、完成项目。企业也能通过Agent 365统一管理OpenAI、Anthropic等平台的智能体，查看Agent完成的任务、估算业务收益。微软披露，自今年5月推出以来，已有超过5000万个智能体在Agent 365累计登记。

此外，微软重点升级了企业知识管理平台Microsoft IQ。该平台整合Work IQ、Fabric IQ、Foundry IQ、Web IQ等能力，提供超过350个第三方连接器，帮助不同Agent调用企业知识、业务数据和操作工具。微软还推出Business Plugins，使企业可以将自己的业务规则、专业知识和操作能力封装起来，供不同Agent重复使用。

一、微软模型七连发！编程成绩逼近GPT、Claude，测试成本最低仅为竞品5%

微软此次亮出了五款新模型及两款模型新进展。其中，两款编程模型与决策模型已正式上线，前者已接入GitHub Copilot，后者在Cowork中为Auto提供支持。

MAI Code 2和MAI Code 2 Flash主要面向软件开发。前者能够完成复杂代码调试、跨文件修改等任务。据微软披露，在四项编程基准测试中，MAI Code 2综合成绩达到GPT-6.1 Sol约98%的水平，测试成本约为其40%；与Claude Opus 5.5相比，达到其约96%的成绩，测试成本约为其5%。

MAI Code 2 Flash主要用于代码解释、局部修改和日常错误修复。微软称，在三项日常编程基准测试中，该模型的表现与GPT-6 Luna、Claude Haiku 5.5相当，按促销价计算的测试成本分别约为两者的65%和20%。这两款模型均已接入GitHub Copilot，MAI Code 2 Flash还在Microsoft Foundry开放了限量预览。

▲MAI Code 2综合成绩及测试成本（图源：微软）

在网络安全领域，MAI Cyber 2 Flash可以协助发现软件漏洞、分析威胁并提出修复建议。在CyberGym-E2E测试中，该模型的任务成功率达到92.3%，略高于GPT-6 Astra的91.5%，单项任务计算成本不到后者的2%。微软计划从今年12月中旬开始，将该模型通过安全扫描工具MDASH逐步提供给符合条件的客户。

▲MAI Cyber 2 Flash官方技术博客评测（图源：微软）

图像模型MAI Image 2.7已于10月27日发布，主要用于图像生成和局部编辑。相比刚发布时，该模型在第三方评测机构Artificial Analysis图像编辑榜单的排名从第二升至第一，以1215分领先GPT Image 2.6 Sunburst Max 4分，价格约为后者的1/5。微软还推出面向批量图像生成的MAI Image 2.7 Flash，以及支持交互式图像修改的Canvas工作空间。两款图像模型已在Microsoft Foundry开放公开预览，用户也可以通过MAI Labs体验图像生成和编辑功能。

▲MAI Image 2.7在Artificial Analysis图像编辑榜单中升至第一（图源：微软）

语音方面，MAI Realtime 1支持实时语音对话，可以用于AI客服、语音助手等场景。微软称，该模型在语音理解和任务执行测试中超过GPT-Realtime 2.1，基础语音服务价格每分钟0.01美元起，推理费用另计。用户目前可以在MAI Labs体验该模型，开发者可申请Microsoft Foundry限量预览。

另一款语音转录模型MAI Transcribe 2于今年9月发布。微软此次披露，基于该模型的医疗语音转录功能Dragon Copilot Transcribe已用于旗下医疗AI产品Dragon Copilot，承担全部医患对话转录任务，每月覆盖约1000万次患者就诊，多语言转录错误率降低约50%。

决策模型Microsoft-Decision-1.1此次正式开放使用，主要负责信息分类、模型选择和任务调度，新增了图像输入能力。在Artificial Analysis决策指数榜单中，该模型获得68分，较前代提高6分，领先于Jev 1.14、谷歌Gemini Decision 1和OpenAI的GPT-6 Luna决策版。微软称，其处理决策任务的速度为GPT-6.1 Sol的50倍，成本约为后者的1/79，目前已有超过4000家客户使用。

微软还宣布推出企业模型权重授权服务MAI Licensed Weights，计划向符合条件的企业提供自研模型权重，允许客户使用内部数据定制模型，并在自己的Azure环境中部署运行。企业可以自主控制模型访问权限，其数据和模型定制成果由企业掌控。该服务将通过微软Frontier Company合作计划逐步推出。

二、Copilot升级多智能体协作，AI能主动找活、长期跟进任务

微软此次主要为Cowork升级了多智能体协作能力，增加主动任务推荐功能，并将自主智能体Autopilot扩大开放至Frontier客户。此外，Copilot的统一工作界面Home和内置文件编辑功能Office in Copilot正式可用。

此次开放使用的Copilot Home是Copilot的统一工作界面，将用于问答的Chat和负责复杂任务的Cowork整合在同一入口。用户可以通过一个输入框发起任务，Copilot利用Auto功能自动选择模型及推理强度。如果任务比较复杂，系统会建议用户交给Cowork处理，并保留此前的对话背景，无需重新输入指令。

▲Copilot Home统一工作入口（图源：微软）

Copilot Cowork此次升级了Auto功能，利用微软的Microsoft-Decision-1.1模型，为任务的不同步骤选择合适的模型和推理强度，并新增多子智能体并行执行能力，将复杂任务拆分给多个子智能体同时处理。

例如，用户要求完成一份竞争分析报告时，Cowork可以让一个子智能体调用Claude模型研究竞争对手，另一个调用GPT模型进行财务对比，最后将结果整合成一份报告。微软在过去一周内为Cowork新增了GPT-6.2 Sol、Claude Fable 5.2等多款模型。多子智能体调度等Auto增强功能已开始面向Frontier用户开放。

▲Cowork多子智能体协作（图源：微软）

Cowork还新增了主动任务推荐功能。它可以通过Work IQ根据用户的邮件、会议和Teams聊天记录，发现可以交给AI处理的工作，例如准备第二天的客户会议材料，或者跟进尚未回复的重要邮件。用户确认后，Cowork便可开始执行，该功能也已向Frontier用户开放。

Copilot Autopilot此前已进入私有预览，此次扩大开放至Frontier客户。与Cowork主要处理用户交代的任务不同，Autopilot可以长期自动运行，持续关注Teams频道、跟进邮件和处理周期性任务。

例如，用户可以将供应商审核项目交给Autopilot，由它制定计划、安排会议、准备材料，并联系相关人员收集进展。管理员可以限制Autopilot的访问权限、查看操作记录，并要求其在重要操作前获得人工批准。

此前发布的人机协作空间Workspaces此次也向Frontier客户开放。员工和Agent可以在同一空间中共享文件和项目资料，例如由Agent起草文档，员工提出修改意见，再由Agent继续完善。

Office in Copilot此次宣布正式可用，将Word、Excel、PowerPoint的编辑能力直接整合进Copilot应用。用户可以通过对话创建、修改文档、电子表格和演示文稿，也能邀请同事共同编辑，无需切换到独立的Office应用。

此外，此前推出的Copilot Code计划在未来数周正式开放，用户可以通过自然语言开发应用程序、交互式仪表板等工具。用于托管这些应用的Copilot Managed Runtime已正式可用。Edge for Business此次正式开放了Cowork跨网站执行多步骤任务的能力，可以在用户有权访问的网站中填写表单、处理工作流程，敏感操作仍需用户确认。

在企业应用方面，微软披露，礼来每月有超过5000人使用Copilot Cowork，其中包括科研人员。部分科研人员将多步骤研究与分析任务交给Cowork，由AI协助筛选值得进一步研究的方向，再开展实验工作。

三、Agent 365累计登记超5000万个智能体，微软开始帮企业管理AI投入

微软此次扩展了企业智能体管理平台Agent 365的第三方管理和安全控制能力，并新增业务价值分析工具。

据微软披露，自今年5月正式推出以来，企业已在Agent 365累计登记超过5000万个智能体。随着登记数量增加，企业除了需要了解智能体的身份、运行状态和访问权限，也开始关注其使用成本和实际效果。

在跨平台管理方面，Agent 365进一步扩大了对OpenAI、Anthropic、Google、Salesforce、Databricks等平台的支持。接入的受支持智能体可自动获得独立的Microsoft Entra Agent ID，企业能够查看其来源、负责人和调用的工具，并实施身份及访问管理。在部分受支持平台上，管理员还可以查看智能体的活动和任务执行记录。相关能力处于预览阶段，将分批开放。

本地智能体管理方面，微软此次扩展了设备端和网络端的发现、管控能力。Microsoft Defender与Microsoft Entra Global Secure Access等工具目前可以识别60多种本地AI智能体，包括Claude Code、GitHub Copilot CLI等。其中，Defender的设备端发现功能已正式可用，Global Secure Access的网络端发现功能仍处于预览阶段。管理员可以发现员工自行使用的Agent，并通过相关管理及安全工具，在支持的场景下限制其访问企业数据。

此次推出的Agent 365 Business Analytics，可以帮助企业分析AI使用成本并估算业务价值。该工具将智能体的使用量、费用和完成任务的情况放在同一界面，提供任务成功率、用户满意度、协助工时及估算业务价值等指标。

▲Agent 365 Business Analytics仪表盘（图源：微软）

以Copilot Cowork为例，系统可以结合任务通常需要的人工时间，以及AI承担的工作比例，估算AI协助完成的工时及相应价值。但这并非实际测量的人工时间节省，也不能直接等同于企业已经实现的财务收益。Business Analytics此次开始面向Frontier用户开放。

此前，Agent 365 Cost Management已提供AI费用管理功能，本届大会继续升级了支出统计和预算控制能力。企业可以按员工、用户组、Agent和模型查看支出，设置支出限额及费用提醒，还能限制团队使用高成本模型。例如，管理员可以为不同团队设置可使用的模型范围，将高成本模型留给需要复杂推理的任务，避免AI使用规模扩大后费用失控。

四、微软升级Microsoft IQ：350多个连接器，Agent能直接操作业务系统

据微软披露，目前已有近6万家客户使用企业知识平台Microsoft IQ。该平台于今年6月的Build大会上推出，目前整合了Work IQ、Fabric IQ、Foundry IQ、Web IQ等能力，并提供超过350个第三方连接器。此次升级重点是让企业能够把分散的知识、业务规则和操作工具统一管理，供不同AI智能体重复使用。

▲Work IQ知识与上下文架构（图源：微软）

本次新增的业务插件（Business Plugins），允许企业将业务知识、操作规则和工具封装成插件，供不同部门和Agent重复使用。例如，在微软给出的供应链中断场景中，Agent可以查询受影响的订单、核对供应商合同，再找到负责处理的员工。企业配置一次相关知识和操作规则，就可以让多个Agent调用。该功能已面向Frontier计划用户开放。

Work IQ此次重点展示了从获取工作信息到执行操作的能力。微软已于11月3日开放超过60项SharePoint原生操作的公开预览，智能体不仅能查询项目资料，还可以直接创建项目追踪列表、处理审批等任务。微软内部测试显示，接入这些工具后，Work IQ的任务通过率从70.1%提升至84.6%，Token使用量减少16%。

其中，Listen功能可在收到消息或发生业务事件时自动启动任务，无需等待用户发出指令。Listen目前处于公开预览阶段。

微软还将Work IQ扩展到第三方AI助手。微软称，ChatGPT Business和Enterprise用户现在可以通过插件，在获得授权后调用Outlook邮件、Teams聊天及SharePoint文件中的工作信息；面向Claude的插件也将陆续开放。

企业业务系统合作方面，微软与Salesforce宣布推出Copilotforce合作项目，将Salesforce的客户数据和业务功能接入Copilot。此次推出的Salesforce in Copilot插件包含超过38项预构建销售技能。例如，销售人员可以结合Salesforce中的客户记录和Outlook、Teams中的沟通内容，查询销售机会、准备客户会议材料。目前该插件已进入公开预览阶段。

结语：微软打通企业Agent全套工具，自研模型抢生意

此次Ignite大会上，微软进一步扩大了企业AI布局。一方面，微软将Copilot升级为统一工作入口，整合智能体执行、企业知识和管理工具；另一方面，微软集中展示自研AI模型的性能与成本优势，开始与OpenAI、Anthropic等合作伙伴直接竞争模型业务。微软希望在继续提供第三方模型的同时，掌握更多企业AI工作流程。

对微软而言，已有的Office用户基础、Azure云服务和企业数据连接能力，为Copilot进入实际业务提供了条件。不过，企业能否持续扩大Agent使用规模，仍取决于任务执行的可靠性、跨平台协作效果及实际投入产出。微软此次推出成本和业务价值分析工具，也反映出企业AI竞争正在从增加功能，进一步转向控制成本和验证实际效果。
