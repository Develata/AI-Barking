GPT-6.2 Astra (Max) is amongst the leading models in intelligence, but particularly expensive when comparing to other models of similar price. It's also quicker than average per task, however somewhat verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

GPT-6.2 Astra (Max) scores 62 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 43). When evaluating the Intelligence Index, it generated 65.8M tokens, which is somewhat verbose in comparison to the median of 65.1M.

Pricing for GPT-6.2 Astra (Max) is $8.00 per 1M input tokens (expensive, median: $2.00) and $40.00 per 1M output tokens (expensive, median: $10.00). On average, it costs $4.00 per task to evaluate GPT-6.2 Astra (Max) on the Intelligence Index.

At 11.5 minutes per Intelligence Index task, GPT-6.2 Astra (Max) is quicker than average compared with the median of 11.5 minutes for comparable models (lower is better).

Frequently Asked Questions

Common questions about GPT-6.2 Astra

When was GPT-6.2 Astra released?

GPT-6.2 Astra was released on November 17, 2026.

Who created GPT-6.2 Astra?

GPT-6.2 Astra was created by OpenAI.

How intelligent is GPT-6.2 Astra?

GPT-6.2 Astra has 5 effort levels: max, xhigh, high, medium, and low. GPT-6.2 Astra scores 62 (max), 62 (xhigh), 60 (high), 57 (medium), and 46 (low) on the Artificial Analysis Intelligence Index. GPT-6.2 Astra (Max) is well above average among other models in a similar price tier (median: 43).

How fast is GPT-6.2 Astra?

GPT-6.2 Astra takes 11.5 minutes (max), 6.5 minutes (xhigh), 5.1 minutes (high), 3.8 minutes (medium), and 1.5 minutes (low) per Intelligence Index task (based on OpenAI's API; lower is better). GPT-6.2 Astra (Max) is quicker than average compared to other models in a similar price tier (median: 11.5 minutes).

What is the latency of GPT-6.2 Astra?

GPT-6.2 Astra has a time to first answer token of 178.49s (max), 53.87s (xhigh), 23.05s (high), 2.96s (medium), and 2.81s (low) (based on OpenAI's API). GPT-6.2 Astra (Max)'s time to first answer token is at the higher end compared to other models in a similar price tier (median: 12.23s).

How much does GPT-6.2 Astra cost?

GPT-6.2 Astra costs $8.00 per 1M input tokens (at the higher end, median: $2.00) and $40.00 per 1M output tokens (at the higher end, median: $10.00), based on OpenAI's API.

What is GPT-6.2 Astra API pricing?

GPT-6.2 Astra costs $8.00 per 1M input tokens and $40.00 per 1M output tokens (based on OpenAI's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $5.88 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/gpt-6-2-astra/providers]

How verbose is GPT-6.2 Astra?

When evaluated on the Intelligence Index, GPT-6.2 Astra generated 65.8M output tokens (max), 27.1M output tokens (xhigh), 20M output tokens (high), 12.4M output tokens (medium), and 6.31M output tokens (low). GPT-6.2 Astra (Max)'s output token count is somewhat higher than average compared to other models in a similar price tier (median: 65.1M).

Is GPT-6.2 Astra a reasoning model?

Yes, GPT-6.2 Astra is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does GPT-6.2 Astra support?

GPT-6.2 Astra supports text and image input.

What output modalities does GPT-6.2 Astra support?

GPT-6.2 Astra supports text output.

Can GPT-6.2 Astra process images?

Yes, GPT-6.2 Astra supports image input and can analyze, describe, and answer questions about images.

Is GPT-6.2 Astra multimodal?

Yes, GPT-6.2 Astra is multimodal. It can process text and image input and generate text output.

What is the context window of GPT-6.2 Astra?

GPT-6.2 Astra has a context window of 1M tokens. This determines how much text and conversation history the model can process in a single request.

Is GPT-6.2 Astra open source?

No, GPT-6.2 Astra is proprietary. The model weights are not publicly available.

How many parameters does GPT-6.2 Astra have?

GPT-6.2 Astra is a proprietary model and OpenAI has not disclosed the model size or parameter count.

How does GPT-6.2 Astra perform on benchmarks?

GPT-6.2 Astra achieves a score of 62 (max), 62 (xhigh), 60 (high), 57 (medium), and 46 (low) on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across knowledge work, coding, science, and general knowledge.

Is GPT-6.2 Astra available via API?
