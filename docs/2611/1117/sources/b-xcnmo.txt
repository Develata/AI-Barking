微软发布七款新AI模型 覆盖编程、安全、图像与语音

 CNMO
 【原创】 作者：丁桥建

 2026-11-18 07:01

 评论（0）

 分享

 
 

　　【CNMO科技消息】11月18日，微软在旧金山举行的Ignite 2026大会上，由微软AI部门一次性发布了七款全新自研AI模型，覆盖编程、网络安全、图像生成、实时语音、语音转写和智能体决策等方向。与以往追求"最强大脑"的路线不同，这次微软把一个词写在了所有发布的最中央——性价比。

 [//product.cnmo.com/article/2409535.html]
MAI

　　本次发布的主角是编程模型MAI Code 2和它的轻量版本MAI Code 2 Flash，两款模型已在GitHub Copilot上线。Code 2定位通用编程，擅长深度排错、跨文件改码、理解整个代码仓库和开发用户界面；Flash则面向解释代码、定点修改、快速迭代等高频轻量任务。

　　微软公布的数字相当激进：在DeepSWE 1.1、Terminal Bench 2.1、SWE-Atlas和FrontierCode v1.1四项编程基准的平均成绩上，MAI Code 2达到GPT-6.1 Sol约98%的质量、价格约为其40%；面对Claude Opus 5.5，则达到约96%的表现、价格仅为其5%。折算下来，其平均单次任务成本为0.309美元，而GPT-6.1 Sol为0.761美元，Claude Opus 5.5高达6.306美元。在前端盲测中，开发者64%的情况下更偏爱MAI Code 2的产出。

　　不过微软也坦承了边界：这些模型优先服务企业日常编程，尚未针对基础科学研究和超长程智能体任务调优，且部分成本数据按五折促销价计算。此外，Code 2 Flash在DeepSWE 1.1、Terminal Bench 2.1和SWE-Atlas三大基准上以61.0%的平均通过率超越GPT-6 Luna（55.1%）和Claude Haiku 5.5（53.9%），在享受50%促销定价下单次任务成本最低仅0.052美元。

　　安全模型MAI Cyber 2 Flash被称为微软迄今最强的安全模型。在CyberGym-E2E基准上，它以92.3%的成绩略胜GPT-6 Astra的91.5%，而单任务成本不到后者的2%；上下文窗口达100万token，输出token价格较上代Cyber 1.1 Flash下降86%。该模型将专供微软安全产品，计划12月中旬起在MDASH系统中向符合条件的客户推出，而非当天全面开放通用API。

　　图像方面，MAI Image 2.7登上Artificial Analysis图像编辑榜第一，以约五分之一的价格击败GPT Image 2.6 Sunburst（max）；文生图排名第四，使微软成为该榜第二强实验室。其Flash版本生成1000张图仅需约10美元（标准版公开预览价约为每1000张35美元），已可通过Microsoft Foundry及fal、OpenRouter、Vercel等渠道试用。

 [//product.cnmo.com/article/2402958.html]
微软AI

　　语音方向，MAI Realtime 1是微软首个实时语音到语音模型，官方称其表现超越GPT-Realtime 2.1，价格低至每音频分钟0.01美元起，可在MAI Labs试用。医疗场景的Dragon Copilot Transcribe则基于MAI Transcribe 2打造——官方称之为"世界最快最准的多语言转写模型"，目前每月处理约1000万次医患对话，多语言错误率减半，已被约三分之一的美国医生使用。

　　当天还有一款模型转为正式可用：Microsoft-Decision-1.1。这款决策模型负责智能体日常的高频"小决定"——请求路由、分类、排序、流程控制，官方称其比GPT-Sol 6.1快50倍、便宜79倍，已有约4000家客户使用，Foundry全球标准价为每百万输入token 0.042美元、输出免费，在Artificial Analysis决策指数v2.1上以68分领先于Google和OpenAI的同类模型，已在Foundry、OpenRouter和Vercel正式可用。

 [//product.cnmo.com/article/2399754.html]
微软

　　硬件侧，微软第二代自研AI加速器Maia 200已投入生产，运行微软最大模型时每瓦特token吞吐量较上代提升1.7倍；Ignite现场还宣布了下一代Maia 300，官方称其每瓦特token数将比领先GPU系统高出40%。微软还推出MAI Licensed Weights计划，允许企业客户用自有数据定制前沿MAI模型，并在自己的Azure环境中运行——用微软的话说："没人想把智商倒进别人的模型里。"微软援引AT&T的案例称，其基于MAI定制的5G网络运营分析模型，以便宜50倍的成本跑赢了GPT-6.1 Sol。

　　微软AI负责人穆斯塔法·苏莱曼（Mustafa Suleyman）表示："这不仅仅是一个模型，也不是昙花一现。这是一个系统，是我们打造的一台'爬坡机器'，同时优化性能与价格。"在多年深度依赖OpenAI模型之后，微软正以自研模型家族向市场宣告：AI竞赛的下半场，拼的不只是聪明，还有便宜。
