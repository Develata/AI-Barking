What are the top models on AA-Image-Editing v2.1?

GPT Image 2.5 Sunburst (max) (Elo 1202), and 5. GPT Image 2.5 Flare (max) (Elo 1185). Rankings are based on blind votes from our validated private evaluators.

How does image editing differ from Text to Image generation?

Text to Image generation creates entirely new images from text descriptions, while image editing modifies existing images based on instructions. Image editing models take both an input image and editing instructions, then produce a modified version of the original image.

How are image editing models ranked?

Models are ranked using an Elo rating system derived from blind comparisons judged by our validated private evaluators. Voters compare edited outputs from the same input image and editing instruction, choosing the result they prefer. Higher Elo scores indicate a model is preferred more often.

Which is the best open weights model on AA-Image-Editing v2.1?
