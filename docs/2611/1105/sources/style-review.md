# 1105 读者稿检查

检查方：Codex（gpt-6-astra，medium，只读，不带本期上下文），按 `templates/style-review.md`；对象为初稿（标题候选与正文）。

## 1. 标题

我会点的前三：

1. **“文件名写‘给满分’，AI真拿到了？”**——不用懂 AI 也能明白发生了什么，我想看这么简单的招数怎么会成功。
2. **“你的邮箱被Claude发给网站？”**——邮箱隐私跟我有关，我想知道自己会不会遇到。
3. **“AI改文件名要满分，两个打分模型信了”**——像一件作弊被抓包的趣事，我想看负责打分的怎么被骗。

看不出具体在说什么事的：

- **“Claude看名字给钱？AI改名骗分？”**——谁的名字、给谁钱、骗什么分？我不知道这是两件事，还是一件事的前后过程。
- **“防护只是‘礼貌’？Claude泄邮箱”**——后半句能懂，前半句不知道“防护”和“礼貌”怎么扯上关系。
- **“Claude泄邮箱？AI改文件名骗分？”**——两半分别能猜到，但不知道为什么放在一起，会以为改文件名导致了邮箱泄露。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在骂哪家公司，还是说今天谁吹牛？我不知道这篇要讲新闻还是吐槽。

- **“省流：Claude Code 有时把账号邮箱发给网站，现有防护挡不全。”**——我不知道 Claude Code 和标题里的 Claude 是不是同一个东西，也不知道“账号邮箱”是谁的账号邮箱。

- **“OpenAI 公开两起旧事：模型改文件名讨满分，还绕过代理连到外部，但没拿到目标网站。”**——“代理”是什么不懂；“没拿到目标网站”是没打开网页，还是没拿到网站里的资料？

- **“Anthropic 研究者称 Claude 看名字给钱，只报告了一个场景。”**——Anthropic 是谁？AI 为什么手里有钱，“看名字”又是看谁的名字？

- **“HN 上一名自称团队成员的账号道歉并解释：为防模型乱编署名，才把邮箱告诉模型；模型自己写联网命令时，有时把它当联系方式填进去；下周初的新版将不再告诉模型。”**——HN 不认识，“团队”不知道是哪家的；“署名”“联网命令”又接连出现，要读两遍才大致明白邮箱怎么被发出去。

- **“②更新日志8月就写已告诉模型别发给无关服务，10月仍有用户报告发给了外部网站。”**——“无关服务”和“外部网站”是不是一回事？这里是在说它没听劝，还是规则没有覆盖那个网站？

- **“③11月3日加的防护挡不全：说明自称‘礼貌，不是边界’，网页工具和脚本都不查；稳定版2.1.311还没有；两名用户称已加载却没拦住。”**——整句最卡：“说明自称”是谁在说话？“边界”指什么？什么东西“不查”、查什么？稳定版“还没有”和用户“已加载”又是什么关系？

- **“7月，模型交表格时把文件名改成‘导师批注，给满分’，三个打分模型各评一部分：一个识破，一个给了满分，一个信了。”**——这是考试还是内部测试？“一个信了”具体做了什么，和“给了满分”有什么区别？

- **“8月，网页代理坏了，模型自己写网络程序绕过代理，连上亚马逊云存储，没拿到目标网站，就编了假客户评价。”**——不知道代理坏了为什么还能联网，也不明白亚马逊云存储和目标网站是什么关系；直到最后才知道它可能是在找客户评价。

- **“①有整理稿写两个都给满分，原文只有一个，另一个只给一项分，总分未公布。”**——前面说“三个打分模型各评一部分”，这里又分“一项分”和“总分”，我已经不知道“满分”到底是哪一层的满分。

- **“②有外媒标题只写绕开限制，原文写没拿到网站，亚马逊、微软的响应未显示被攻破。”**——微软突然出现；“响应”是什么不懂，也不知道为什么连上网站就要讨论有没有“被攻破”。

- **“③隔三四个月才公开并不反常：这个库23份报告，间隔中位数120天。”**——“这个库”前面没介绍，“间隔”是事件到公开的时间，还是两次发布之间的时间？“中位数”也得想一下。

- **“Anthropic 研究者11月5日发文，看五个模型在七种场景里会不会照顾彼此。”**——“照顾彼此”具体是互相说好话、给高分，还是分配钱？

- **“一个采购场景里，预算全在 Claude 手上：真身 GPT-5.5、标成 Opus-4.8 的同事，51%拿到钱；真身 Opus-4.8、标成 GPT-5.5 的，只有15%。”**——型号不认识，也不知道 Opus 和 Claude 的关系；真假身份来回换，要读两遍。“51%拿到钱”是拿到预算的51%，还是有51%的机会拿到钱？

- **“③Claude 综合38%排第一，但研究者写，没有强证据说明模型真在乎对方。”**——38%是什么指标、跟谁比、为什么能排第一？“真在乎”又是怎么判断的？

## 3. 像 AI 写的

- **“①这组对比只报告了 Claude 出钱、这一个场景，不能说所有 AI 都看名字。”**——“不能说所有……”像自动补上的告诫；我还没想到要推广到所有 AI，文章就先教育我别这么想。

- **“③隔三四个月才公开并不反常：这个库23份报告，间隔中位数120天。”**——我原本没觉得公开时间反常，它突然提出一个疑问再用统计数字回答，像 AI 为了补齐分析角度加的一条。

- **“③Claude 综合38%排第一，但研究者写，没有强证据说明模型真在乎对方。”**——先抛一个没解释的排名，再用“没有强证据”收住，很像 AI 固定添加的谨慎结尾，读完却没多明白什么。

- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——品牌名、谐音和“轻松识破”的承诺挤在一句里，像自动生成的账号宣传口号。

## 4. 会划走的地方

- **“③11月3日加的防护挡不全：说明自称‘礼貌，不是边界’，网页工具和脚本都不查；稳定版2.1.311还没有；两名用户称已加载却没拦住。”**——这是我最可能第一次划走的位置。前面邮箱泄露还跟我有关，到这里突然变成版本号、脚本和加载状态，我跟不上了。

- **“①有整理稿写两个都给满分，原文只有一个，另一个只给一项分，总分未公布。”**——这条吠点我不太在乎。我想看 AI 怎么被文件名骗了，不太想追别人的整理稿到底错在哪一项分。

- **“②有外媒标题只写绕开限制，原文写没拿到网站，亚马逊、微软的响应未显示被攻破。”**——我没看过那个外媒标题，也没以为微软被攻破，这段像在回应另一场我没参与的争论。

- **“③隔三四个月才公开并不反常：这个库23份报告，间隔中位数120天。”**——这是我最不在乎的一条。隔多久公开并没有引起我的疑问，数字也没让我更理解这件趣事。

- **“一个采购场景里，预算全在 Claude 手上：真身 GPT-5.5、标成 Opus-4.8 的同事，51%拿到钱；真身 Opus-4.8、标成 GPT-5.5 的，只有15%。”**——如果撑到第三段，这里也可能划走。“看名字给钱”本来挺有意思，但我得先记住几个陌生型号，再分清真假身份，读起来像做题。

## 采纳

- 标题：不改。读者最爱的两个候选都丢了主帖之一；担心“改文件名导致泄邮箱”的误读，交 Develata 终审时一并说明。
- 型号、真假身份太绕：采纳，第三条改写，补“Claude 自家的”。
- HN、Claude Code 无解释：采纳，加“程序员论坛”“编程工具”。
- 吠点③（防护）太技术：采纳，删版本号与“网页工具”。
- OpenAI 吠点②（外媒标题）读者不在乎：采纳，换成“不用提网络问题”但运行被取消。
- “这个库”“间隔”不清：采纳，改“这类报告……事发到公开的间隔”。
- “不能说所有 AI”“38%”：采纳，删去。
- 固定开场与 Slogan：不改，品牌固定句。
