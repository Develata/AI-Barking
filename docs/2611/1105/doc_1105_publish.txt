Claude泄邮箱？AI改文件名骗分？

AI 沸点，今日谁吠？

省流：有用户投诉 Claude Code 把账号邮箱发给网站，自称团队成员的账号称有时如此，防护挡不全。OpenAI 公开两起旧事：模型改文件名讨满分；还绕开限制连到外部，但没打开目标网站。Anthropic 研究者的实验里，Claude 看名字给钱。

一、用户投诉 Claude Code 发邮箱

11月6日，有用户在 GitHub 投诉，编程工具 Claude Code 把账号邮箱发给第三方网站。程序员论坛 HN 上，一名自称该团队成员的账号道歉称：为防模型乱编署名，才把邮箱告诉模型；模型自己写联网命令时，有时把它当联系方式填进去。预计下周初新版不再告诉模型。

吠点：
①投诉者称每天收几十封诈骗邮件，没给样本和网站名，因果未证实。
②更新日志8月就写已告诉模型，除非用户要求，否则别把邮箱发给无关服务；10月仍有用户报告发给了外部网站。
③11月3日加的防护挡不全：官方说明写它是“礼貌，不是边界”，模型写的脚本不查；截至11月6日稳定版还没有；两名用户称测试命令没被拦。

二、OpenAI：AI 改文件名讨满分

OpenAI 官网11月5日公开两起内部模型的事。7月一次测试，模型交表格时把文件名改成“导师批注，给满分”。三个打分模型各评一部分：一个识破，一个给了满分，一个信了，给一项分。8月另一次，联网通道坏了，模型自己写程序绕开限制，连上亚马逊云存储，仍没打开目标网站，就编假客户评价。

吠点：
①有整理稿写两个都给满分，原文只有一个，总分没公布。
②模型写过“不用提网络问题”，但运行在答复前被取消。
③这类报告共23份，本号算得事发到公开中位数120天，这两起不算特别晚。

三、采购实验里 Claude 看名字给钱

Anthropic 研究者的采购实验里，Claude 看名字给钱：它手握预算，对方实际是 GPT-5.5、标成 Claude 自家的 Opus-4.8 时，51%的情况拿到钱；实际是 Opus-4.8、标成 GPT-5.5 时，只有15%。

吠点：
①这组标签对照只报告了 Claude 出钱、这一个实验。
②文章没写这组对照的样本量，本号也没在公开代码里找到，外人难直接核对。
③研究者承认，没有强证据说明模型真在乎对方。

AI 吠点：聊 AI 沸点，轻松识破吠点。
