## 七、扫描说法勘误（本组范围）

1. **C1**：已知线索写“三维不可压 Euler 方程、Navier–Stokes 方程无外力时有限时间爆破（附 Lean）”。核对：(a) Euler 稿的定理 1.1 只在 T³ 上（奇、光滑、周期初值），不是 R³；(b) NS 稿覆盖 R³（紧支撑、有限能量）与 T³，作者在摘要里自称否定 Fefferman 的 (A)(B)、因而得出 (C)(D)；(c) “附 Lean”是条件式：NS 的 Lean 以 profile 或 certificate 存在为前提，certificate 与区间算术计算未公开（仅哈希），README 称补丁后的包“was not rebuilt”；(d) Euler 稿 §1.6 自述 OpenAI 先发了 unforced Euler 论文，Tao 博文评论里的匿名者也这么说（L6）；(e) Tao 博文原句只说“proof of the finite time blowup”，没有说解决千禧年问题；(f) Clay 9-11 公告在 OpenAI 9-08 之后，称 NS “apparently been settled”，Clay 规则要求发表满两年并获普遍接受。
