A 27-billion-parameter model edited its own weights without gradients and gained 6.6 points on problems it had never seen

The ability appears only at the largest size tested. The 2B model made no edit, and the 4B and 9B models broke themselves.

 By Love Lindberg [/authors/love-lindberg/] Published November 18, 2026 at 7:06 AM 2 min read 
 Copy link 

 The model edits its own parameters by reasoning, with no gradient step. Illustrative stock image. Collab Media [https://www.pexels.com/photo/a-pile-of-wire-that-is-wrapped-in-a-coil-15059762/] · pexels · Pexels License [https://www.pexels.com/license/] 

What the paper claims

A team working across several universities reports that a 27-billion-parameter model can rewrite its own weights to make itself better [https://arxiv.org/abs/2611.21885], by reasoning rather than by training. Given its own weights, a set of graded answers, and the ability to run itself, the model diagnoses the failure and edits the parameters behind it. The authors call this self-rewriting.

The headline result is a pre-registered one: the model’s own edit made it 6.6 points more accurate on 490 problems it had never seen, on a test fixed in advance. A second session’s edit also produced a significant improvement.

It accumulates

The more unusual finding is that the gains do not wash out. The model submits an edit only when its own tests support it, each edit replacing the last, and across its first eight such sessions accuracy only rose.

Each edit replaces the last, and only if the model's own tests support it. Illustrative stock image. Rafael Minguet Delgado [https://www.pexels.com/photo/close-up-view-of-interlocking-gears-39229005/] · pexels · Pexels License [https://www.pexels.com/license/]

The economics are the point. Unlike test-time scaling, the gain persists in the weights and adds nothing to the cost of each later answer. Unlike training, it needs no pre-training or post-training infrastructure — the authors report it running on an open model and a single GPU over a matter of hours.

The repair experiment

The most striking demonstration is a damaged copy. The model is given a corrupted version of itself, locates the damaged matrix, and rewrites it with values of its own, never reading the undamaged weights for reference.

The repair was found using text mathematics problems alone. Applied to the damaged copy, it lifted performance on six image benchmarks the model had never been shown from 7% to 70% accuracy — 83% of what the undamaged model scores. A fix derived in one modality transferred to another it was never tuned on.

A damaged copy was repaired from 7% to 70% on benchmarks it had never seen. Illustrative stock image. Tom Van Dyck [https://www.pexels.com/photo/close-up-of-broken-glass-15521641/] · pexels · Pexels License [https://www.pexels.com/license/]

Why size matters here

Across four sizes of a single model family, the 2B model makes no edit at all, the 4B and 9B models break themselves, and only the 27B works on itself in a way the authors describe as recognisably human: it compares its hidden states on answers that finish against answers that run out of tokens, and weakens the direction that separates them.

That is an emergence claim, and emergence claims in this field have a poor track record of surviving replication. One family, four sizes, one working point is thin evidence for a threshold.

What to watch

Replication on a different model family. If self-rewriting holds up, the practical consequence is a model that improves between conversations rather than between training runs — and an evaluation regime that assumes fixed weights stops describing what is deployed.
