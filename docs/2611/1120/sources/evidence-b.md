## 二、可能的吠点（说法 vs 证据）

1. **“6.6” 是哪一个：说法** 摘要：“its own edit makes it 6.6 points more accurate on problems it never saw”。**证据** 同一套 490 题×8 答案、基线 57.2%：第一协议提交的那一个编辑 +1.1（58.3%，p=0.038，Tab. 8）；第二协议 8 个会话（种子 0–7）提交了 3 个：+0.5（57.8%，p=0.25）、+4.0（61.3%）、+6.6（63.8%）（Tab. 13，图 21）。6.6 是 3 个提交里最大的、编号最后的那个；作者写明“all reported”。
2. **“每个编辑都在上一个基础上变好”：说法** 摘要：“each edit improving on the last, and over eight consecutive sessions its accuracy only rises”。**证据** Fig. 1 图注：“every edit the model submits replaces the model in use, and a session that withdraws leaves it as it was (each session itself starts from the base weights)”；App. E.9：“Sessions differ only in the seed of the model’s turns.”；曲线上的“只升不降”是“当前在用的模型”被替换的结果：5 个会话撤回，第 2 号编辑（+4.0）与第 8 号（+6.6）并不是前者的叠加。§3.6：“each edit it submits replaces the last”。App. A 把“编辑后的模型再对自己跑下一轮”列为 Further rounds（未做）。
3. **“撤回五次”也是结果的一部分：证据** Tab. 13：会话 3、4、7 一个编辑都没留下，5、6 在框架的 256 题检查后撤回（检查 +0.2(1.2)）；会话 1 提交了 +0.5（p=0.25）。三个提交的“检查”分：会话 1 +2.5(1.2)、会话 2 +6.6(1.5)、会话 8 +2.5(1.2)；注意会话 2 在**保留练习题检查**上是 +6.6(1.5)，而 +6.6 作为留出题增益属于会话 8，两处同数不同事（图 21）。
4. **修复“80% 以上”是图像，文本是 56%：说法** 摘要只写 “over 80% of the original accuracy on image tasks it never saw”。**证据** 修复规则是在文本数学题上找到并测的；文本 200 题上 33.0% 对原模型 58.5%（≈56%，Fig. 26 图注原句）；图像合并 70.2% 对 84.3%（83%）；六榜里三榜低于 80%（自算：MathVerse 72%、MathVista 78%、HallusionBench 78%）。
5. **完整修复不如只改一个矩阵：证据** 只钳位模型点名的矩阵：55.0%（110/200）；模型提交的 20 个矩阵的完整规则：33.0%；另 19 个矩阵单独改：200 题只解出 1 题（App. E.3；Tab. 1 “the named matrix alone: 55.0%”，图 22）。
6. **“修复自己”：说法** 摘要 “like a broken robot that fixes itself without being rebuilt”。**证据** 损坏是作者在副本上写入的 8 行 200σ 噪声（强度在 20σ/60σ/200σ 里挑了唯一让模型崩的一档，Tab. 6）；编辑者是未损坏的原模型：“The editor is the undamaged model”（§2.4）；定位靠“最大权重÷中位数”这一个统计量，1397× 对其余最多 162.3×（Fig. 25）；修复值与原值无关（余弦 0.002），只是截到 15 倍中位数（“its rule caps the random values”）；不是恢复原权重（图 23）。作者自己写：“which the model never reads”。
7. **规模：说法** “only the largest improves and repairs itself”。**证据** 共用 16,384 token 预算下，27B 也撤回了编辑（§3.8）；27B 成功的会话用 4,096 token，小模型没在该预算下跑；每个小规模只有一个第一协议会话，27B 有 2 个（第一协议）+8 个（第二协议）；结论限一个模型族（摘要自己写 “in one model family”）。
8. **成本：说法** 摘要 “runs only forward passes, as serving does”，正文“a few hours on a single GPU”。**证据** 没有写 GPU 型号与数量，也没有给全部会话与评测的总算力；会话 2.5–3.5 小时（Tab. 4、App. E.9）；另有 3 个中途停止的会话与 2 个更早版本的第二协议会话没有提交（App. D.3、E.9）。

## 四、扫描说法勘误

对象：派工单“已知情况”与扫描说法。

1. **“预先定好的评测第一协议只涨 1.1、6.6 是别的”**：6.6 也在这套预先固定的 490×8 评测里（App. D.3 末句与 Tab. 13 表注），区别是第二协议、第 8 号会话。见 B3。
2. **“第二协议 token 预算更紧（4096）”**：不是两协议的差别。第一协议的 27B 第二会话同样是 4,096 token；两协议的差别见 B3 的 App. E.9 原句（并排测试至多 4 个编辑、保留练习题检查、Python 会话封闭、每次前向最多 128 个答案、3.0 小时）。
3. **v1→v2**：数字没有变。措辞变化：v1 摘要含 “its own edit makes it 6.6 points more accurate on 490 problems it never saw, in a test fixed in advance, and another session’s edit also makes it significantly better”“only an open model and hours on one GPU”“from 7% to 70% accuracy, 83% of the undamaged model’s”；v2 摘要改写为 “over eight consecutive sessions its accuracy only rises”“over 80% of the original accuracy on image tasks”，删去“490 problems、test fixed in advance”与“7% 到 70%”，新增 “each edit improving on the last”“like a broken robot that fixes itself”“runs only forward passes, as serving does”。v1 §5 写 “two of the three edits it submitted made it significantly better”，v2 改为 “the model in use only got better, ending 6.6 points more accurate than it started”。v1 Fig. 9 图注的 “In case 3 the repaired copy cites a reference label that is not in its prompt; every model gets the same prompt.” 在 v2 删除；v2 Tab. 1 表注新增 “(second protocol: up to +6.6 points, Fig. 1)”；v2 新增作者单位 Yale。v1 App. E.9 末段另有一句、v2 已删：“session 2 subtracts from the two output matrices of layer 63 five times their projection on one direction … read from its hidden states in the session; with it, more of its answers end in a repetition (12.6% against 5.6% for the base model).”（v1 中第 2 号会话的编辑让“以重复结束的答案”从基模型的 5.6% 升到 12.6%；v2 删去该句，Fig. 1b 只留“被截断答案占比 33.6%→28.8%/26.1%”）；v1 还有一句“the edit of session 1 is not significantly better (57.8%, p=0.25)”，v2 正文删去，表格里仍有。Tab. 7 的取值差异见 B1。
