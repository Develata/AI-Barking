 之前OpenAI的GPT-6 Astra被报道能直接改小模型的权重参数，而UIUC这项研究发现，其实小模型自己就能改自己的参数
地址：arxiv.org/abs/2611.21885

他们做的试验：让模型同时扮演问题诊断者、参数修改者和优化决策者，让推理阶段产生的改进永久写入权重。
具体是使用 Qwen3.5 27B 模型。模型先分析自己在数学题上出现的重复推理、无法在 Token 预算内完成回答等问题，再读取隐藏状态、定位异常方向，通过 Python 修改指定权重，并使用相同问题和随机种子比较修改前后的表现。27B 模型成功找到有效修改：在 490 道未参与修改过程的数学题上，准确率由 57.2% 提升至 63.8%（+6.6 个百分点）。
但低于27B的模型测试都失败了~
