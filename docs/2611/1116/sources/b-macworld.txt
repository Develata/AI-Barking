Here’s how much you’ll need to pay to use Siri AI after Apple’s new limits kick in

 Feature

 Nov 17, 2026

 With iOS 27.3 we now have some idea how you can expand your Apple Intelligence cloud AI limits. 

 Credit: Apple 

Apple Intelligence is a blanket term Apple uses for all sorts of AI features, which are growing in scope and capability with each OS update. Apple has maintained from the start that some of the more advanced features—those that use powerful cloud AI models—will eventually have usage limits.

With the OS 27 software updates and the new features and models available, it’s likely that users are going to run into these limits more often. This Apple Support document [https://go.skimresources.com?id=111346X1569486&xs=1&url=https://support.apple.com/en-us/127901&xcust=1-0-3287111-1-0-0-0-0&sref=https://www.macworld.com/article/3287111/heres-how-much-youll-need-to-pay-to-use-siri-ai-after-apples-new-limits-kick-in.html] describes which features are subject to the Apple Intelligence usage limits. 

Basic Siri commands that happen on your local device, like setting timers or alarms, making a call, texting someone, or opening an app, will always work and do not count toward your cloud usage limits. However, other requests, such as image generation and Siri knowledge, will cost extra if you use them too much. There are four categories:

Siri AI

Intelligent Photo Editing Tools including Clean Up, Extend, and Spatial Reframing; and Image Playground generation.

AFM Cloud and AFM Cloud Pro Models in Shortcuts

Developer apps using Apple Foundation Models in Private Cloud Compute

Unfortunately, Apple does not publish any specific details on what the limits are. Each of the four categories listed above uses a different amount of your limit with each use, and it’s not clearly stated exactly how much you get or how much each of those features uses. It’s likely that Apple is using the latest iOS betas to gauge the popularity and server load for various features to determine them.

As of iOS 27.3 beta 2, we now have some idea of what happens when you reach your limit and how you can increase it. If you’re using Apple Intelligence a lot on a particular day, you’ll receive a warning pop-up that you are near your daily limit. Once you reach that limit, you’ll be told to either wait for the next daily reset (at midnight local time in most regions) or upgrade your iCloud+ plan to increase your limit.

The increase to your Apple Intelligence cloud usage scales with your iCloud+ plan.

iCloud+ planDaily limit

50 GB ($0.99/month)Standard limit

200 GB ($2.99/month)Up to 2x

2 TB ($9.99/month)Up to 5x

6 TB ($29.99/month)Up to 10x

12 TB ($59.99/month)Up to 20x

Each device has its own daily free limit. After that limit is reached, every device signed in to the same Apple Account will draw from a single pool of expanding iCloud+ use. 

If you are using a shared iCloud+ plan (such as an Apple One plan), then any user who reaches their own device’s free use limit will start drawing from that single shared iCloud+ usage limit on a first-come, first-served basis.
