Overview

Claude Fable 5.2 is built for demanding reasoning and long-horizon agentic work. Typical uses include agent sessions that run for hours, multistep deep research, and analysis carried through to a finished document, spreadsheet, or deck.

Claude Fable 5.2 and Claude Mythos 5.2

Claude Mythos 5.2 [/docs/en/models/mythos-5-2/overview] offers the same capabilities only to organizations verified through Anthropic’s verification programs, such as the Cyber Verification Program [https://support.claude.com/en/articles/14604842]. It shares Claude Fable 5.2’s specifications and pricing. To request access, apply to the program that covers your use case, or contact your account team.

Good to know

Adaptive thinking is always on and can’t be turned off. Control thinking depth with the effort parameter [/docs/en/build-with-claude/effort].

Forced tool use (tool_choice types any and tool) returns a 400 error. See Thinking and tool choice [/docs/en/models/fable-5-2/whats-new-fable-5-2#thinking-and-tool-choice].

Omit temperature, top_p, and top_k. See Sampling parameters [/docs/en/build-with-claude/thinking#sampling-parameters] for the values that return a 400 error.

Claude Fable 5.2 requires 30-day data retention and isn’t available under zero data retention unless expressly authorized by Anthropic. See Model-specific data retention requirements [/docs/en/manage-claude/api-and-data-retention#model-specific-data-retention-requirements].
