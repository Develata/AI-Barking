机器之心编辑部

终于，在新一轮旗舰模型谁先发的竞赛中，Anthropic 率先出招了。

就在今天凌晨，Anthropic 一口气发布两款顶级模型，Fable 5.2、Mythos 5.2 登场。

官方宣称，「两款模型瞄准高难度技术挑战，能够参与多个领域的大型复杂项目，并在编程、推理和视觉等方面实现进一步提升。」

另外，Anthropic 也开始玩起了 OpenAI Tibo 熟悉的「Reset」福利了。

Claude Code 之父还宣布，「我们希望为那些陪伴我们最久的用户提供更多福利。因此，在 Fable 5.2 中，订阅时间越长，用户获得的 Fable resets（重置次数）就越多。」

根据介绍，Claude Fable 5.2 和 Claude Mythos 5.2 在正式发布前的测试中，帮助 Anthropic 的工程师完成了此前难以实现的软件迁移项目，从零设计出三款能够正常运行的电子设备，解决了两个黑洞物理学领域尚未解决的问题，在机器人评测中取得了重大进展，还仅用 30 小时就完成了费马大定理的形式化证明。此外，它们还有许多其他应用场景。

Claude Fable 和 Claude Mythos 使用相同的底层模型。Fable 配备了严格的网络安全和生物安全防护机制，可以有效防止模型被滥用，因此能够向所有用户开放。对于希望将模型用于网络安全或生物医学研究等有益领域的机构，可以通过 Anthropic 近期扩大的生命科学计划和网络安全验证计划申请 Mythos 的使用权限。

两款模型的生成速度最高比 Claude Fable 5.1 和 Claude Mythos 5.1 快 30%，价格也有所降低：每百万输入 Token 收费 8 美元，每百万输出 Token 收费 40 美元。

Fable 5.2 和 Mythos 5.2 还提供可选的快速模式（Fast Mode），最高可以将 Token 生成速度提升至原来的 2.5 倍。快速模式的价格为每百万输入 Token 16 美元，每百万输出 Token 80 美元。

Claude Fable 5.2 和 Mythos 5.2 的评测表现

基准测试成绩

下方的基准测试结果显示，在 Anthropic 评估的几乎所有能力上，Claude Fable 5.2 和 Mythos 5.2 都比 Opus 5.5 更胜一筹。

从横向评测来看，Fable 5.2 在多个复杂任务上取得领先。编程方面，它在 FrontierCode 2.0 和 FrontierSWE v2 上分别拿下 49.1% 和 69.9%，超过 GPT-6 Astra 的 42.8% 和 65.5%，也领先 Opus 5.5。在机器人操作评测 RoboDojo Sim 中，Fable 5.2 更是达到 64.9%，相比上一代 Fable 5.1 的 27.6% 提升了 37.3 个百分点，明显高于 Opus 5.5 的 39.4% 和 GPT-6 Astra 的 29.8%。

此外，它在电脑操作评测 OSWorld 2.1 中取得 89.3%，在多学科推理评测 Humanity's Last Exam（带工具）中达到 74.2%，均位居图中参评模型首位。不过，知识工作评测 AA-Briefcase 的 Elo 评分由 Opus 5.5 以 1800 分略微领先，Fable 5.2 为 1785 分。科学研究和网络安全方面的部分高分则来自同期发布的 Mythos 5.2。

推理强度与效率

在 Medium（中等）推理强度设置下，这也是 Claude 应用和 Claude Code 的默认设置，Fable 5.2 完成具有挑战性的任务时，所需的 Token 数量比 Fable 5.1 更少。

在 FrontierCode 2.0 评测的早期测试中，Fable 5.2 使用 High（高）推理强度时，取得了与 Opus 5.5 使用 Max（最高）推理强度时大致相当的成绩，而单项任务的成本只有后者的一半左右。在 Xhigh 推理强度下，Fable 5.2 的成绩也超过了参与测试的所有其他已发布模型。

编程

目前，Anthropic 核心代码库中超过 90% 已合并的代码变更，都由 Claude 在人工指导下完成。

Anthropic 已经使用 Fable 5.2 在几分钟内修复了长期难以解决的 Bug，优化了各项服务的运行性能，还完成了一些原本因耗时过长或成本过高而难以启动的重要软件项目。

此前，一支由早期版本 Fable 5.2 驱动的智能体团队，将一项关键生产服务从 Python 迁移到了 Rust。迁移之后，这项服务的运行效率和可靠性都得到了提升，启动速度更是提高到了原来的约 26 倍。

测试还发现，Fable 5.2 具备很强的工程判断能力。即使面对比较模糊的需求，它也能给出高质量的结果。

在一项实验中，一位 Anthropic 工程师让 Fable 5.2 从头设计一个原型操作系统。模型从一个空文件夹开始，协调了 1000 多个子智能体，连续 8 天不间断地编写、测试和审查代码。最终，它成功开发出一个能够在笔记本电脑上启动并运行的操作系统。

这个系统拥有自己的内核，可以驱动整台机器；具备磁盘、键盘和网络驱动程序，以及持久化文件存储、窗口系统、登录界面和安装程序，还内置了 Claude 功能。

早期测试者也对 Fable 5.2 将编程能力应用于各种不同任务时的表现印象深刻。

网络安全

Claude Mythos 5.2 是 Anthropic 目前网络安全工程能力最强的模型。与此前的模型相比，它能够发现更多安全漏洞，也更擅长复现和修复这些漏洞。需要注意的是，Claude Fable 5.2 的安全防护机制会拦截大多数与网络安全相关的任务。

一家网络安全公司发现，Claude Mythos 5.2 找到并确认的漏洞中，有六分之一是他们测试的其他所有前沿模型都没有发现的。

在 Anthropic 的内部评测 CVE Rediscovery 中，Claude Mythos 5.2 发现的漏洞数量比 Claude Opus 5.5 多 10.2%，比 Claude Mythos 5.1 多 14.4%。

Claude Mythos 5.2 在判断准确性和置信度校准方面也有明显改善。一位测试者发现，此前的模型大约会将每 20 项漏洞发现中的 1 项夸大严重程度，而 Claude Mythos 5.2 没有出现过这种情况。

用户可以通过网络安全验证计划使用 Claude Mythos 5.2 的网络安全能力。Anthropic 还在持续扩大和完善这一计划。

即使没有加入网络安全验证计划，Claude Enterprise 企业客户也可以使用 Claude Security。这项服务利用 Anthropic 能力最强的模型扫描代码库，寻找潜在漏洞，目前已经接入 Claude Mythos 5.2。

近期的一次更新进一步增强了 Claude Security 的能力。它现在可以持续监控代码仓库，跟踪代码更新情况，确保发现的漏洞得到修复；还能够结合更多上下文信息进行分析，并通过 API 和 MCP 接入用户使用的其他工具。

科学与工程

科学、工程和数学领域的许多重要工作，正越来越依赖编程能力。无论是分析数据、建立分子模型、设计零部件，还是控制实验仪器，都可以通过软件来完成。

下面，Anthropic 介绍了 Claude Fable 5.2 和 Claude Mythos 5.2 如何帮助研究人员解决这些领域中的难题，并推动相关研究取得进展。

理论物理学

Claude Fable 5.2 解决了理论物理学领域两个尚未解决的问题。这两个问题都与黑洞有关，也涉及现代物理学两大基础理论 —— 相对论和量子力学的统一问题。

Claude 取得的两项成果，都建立在全息对偶（Holographic Duality）理论之上。这一理论的核心思想是：某些包含引力的宇宙，可以由一个完全不包含引力的量子理论精确描述。

第一个问题可以追溯到 1983 年。当时，物理学家已经证明，随着这些宇宙不断升温，黑洞会突然形成，就像水加热到一定程度后突然沸腾一样。

地址：https://hexagonmath.org/2611.00175v1

但当时采用的方法只适用于足够大的宇宙，因为只有在这样的尺度下，相对论才适用。2003 年，研究人员提出了一项计算任务，希望弄清楚在非常小的宇宙中是否也会出现同样的现象。在这些宇宙中，只能使用量子理论进行描述。然而，这项计算过于复杂、耗时太长，一直没有人能够完成。

Fable 5.2 基本上自主完成了这项计算，并发现即使在非常小的宇宙中，这种转变同样会突然发生。

第二个问题则涉及一种物理学家已经使用了 15 年多的技术。这种技术被用于在简化的宇宙模型中排除可能的量子引力理论。Fable 5.2 找到了这项技术的精确适用边界。

蛋白质折叠

腺相关病毒（Adeno-associated Virus，AAV）是一种体积很小、对人体无害的病毒。它的蛋白质外壳，也就是衣壳（Capsid），可以用来递送基因疗法。衣壳的蛋白质结构非常重要。例如，它会影响基因疗法是否会被患者的免疫系统识别并阻断。但衣壳的结构也相当复杂。

现有的 AlphaFold 等蛋白质折叠模型可以预测单个蛋白质的结构，但一个病毒衣壳由数十个蛋白质组成，整体结构要复杂得多。

Claude Mythos 5.2 在两种开源蛋白质折叠模型的基础上，找到了一种新的方法，可以准确预测整个衣壳的结构。具体来说，它编写代码，让这两种模型分别处理存在重叠区域的蛋白质链组，再利用衣壳已知的对称性信息，将各部分预测结果整合起来，最终还原完整的衣壳结构。

这套方法在多个天然和人工设计的衣壳上都取得了不错的效果。在我们的测试中，Claude 尝试建模的 34 个衣壳里，有 28 个得到了准确的结构预测。

数学

数学形式化是指将数学证明转换成计算机能够逐步检查的语言。这项工作可以帮助数学家验证研究结果，增强对证明正确性的信心，而不必完全依靠人工逐步检查。当 AI 模型给出一些人类难以直接验证的结果时，这一点就更加重要。

但数学形式化通常非常耗时。如果 AI 能够协助完成这项工作，数学家就可以把更多时间投入到探索新的数学思想中。

此前，Anthropic 曾使用一个尚未发布的 Claude 研究版本，对费马大定理进行形式化，整个过程耗时 11 天。这项工作依赖专门设计的执行框架（Harness），同时需要人类研究人员提供指导。

相比之下，由 1000 个 Fable 5.2 智能体组成的团队，只用了 30 小时就完成了整个定理的形式化，期间几乎不需要人工干预。

Fable 5.2 从非常有限的提示开始，自行建立了智能体之间的协作机制。整个过程中，它没有使用任何数学参考资料，只依靠一份中间定理陈述清单来评估任务进展。

与我们第一次完成形式化的过程相比，这次任务消耗的动作 Token 只有三分之一，最终生成的证明长度也缩短到了原来的七分之一。

下图展示了不同模型的表现：在同样使用 1000 个智能体的配置下，Opus 5.5 花费 18 小时只完成了 26% 的形式化工作。即使继续运行到 30 小时，进展也几乎没有增加。

硬件与机器人

AI 的许多潜在价值，例如加快实验室研究，都取决于它能否在物理世界中采取行动。Claude Fable 5.2 延续了 Claude 系列模型在现实世界中实用性不断增强的趋势。在硬件设备设计等任务中，它已经展现出不错的能力，在实体机器人控制方面也取得了显著进展。

Anthropic 专门测试了 Fable 5.2 的硬件工程能力，只给它一段简短的提示，要求它设计并制造三款能够正常工作的电子设备。每款设备都需要拥有独立的电路板、3D 打印外壳和配套软件。最终完成的三款设备分别是：家庭语音助手中枢、USB 扬声电话，以及一款可以手持的虚拟宠物设备。

Claude 自行编写了产品规格，选择美国经销商能够提供的电子元器件，为每款设备设计并完成四层电路板布线，使用计算机辅助设计（CAD）建立外壳模型，并编写了设备所需的软件。在几乎不需要人工干预的情况下，每块电路板都在不到一天的时间内完成了设计，达到了可以投入制造的状态。

Diode 完成电路板制造后，Claude 还进一步指导该公司的工程师完成设备测试和组装。最终，三款设备全部正常工作，无需再对电路进行任何修改。

机器人

与此前的 Claude 模型相比，Fable 5.2 在实体机器人控制方面的能力有了明显提升。即使面对从未接受过专门训练的机器人任务，它也能表现出较强的操作能力。

下方视频展示了由 Fable 5.2 控制的机器人完成多项任务，包括解魔方、拧开瓶盖，以及画出一幅机器人图画。

在公开的 RoboDojo 基准测试中，研究人员通过摄像头图像，让 AI 控制一个模拟的双臂机器人完成任务。Fable 5.2 不仅超过了使用相同测试框架的其他前沿模型，也超过了大多数专门为机器人控制而开发的 AI 系统。

研究与分析

早期测试者在使用 Claude Fable 5.2 开展研究和分析工作时发现，与此前的模型相比，它能够处理更加模糊、数据量更大的任务，在面对复杂和不明确的问题时，也有更好的判断能力，尤其擅长需要抽象推理和方案设计的工作。

自营交易公司 Jump Trading 使用一些模拟其量化研究任务的代理评测，对 Fable 5.2 进行了测试。测试过程中，他们将模型接入了一个与公司内部研究工作框架相似的系统。

在其中一次测试中，Fable 5.2 几乎独立承担了所有必要角色，包括代码编写者、任务协调者、规划者和任务提交者。此前使用其他模型时，团队往往需要投入大量时间，手动调整不同角色的分工，以适应各个模型的能力优势和不足。

安全与对齐

没有任何一项测试能够完全预测一款高能力模型部署之后会如何表现。因此，在正式发布之前，我们会综合采用多种测试方法，并收集不同类型的证据。

针对作为 Claude Fable 5.2 和 Claude Mythos 5.2 底层基础的模型，Anthropic 在部署前开展的安全工作包括：对齐训练与测试、设计全新的评测来检验模型采取无益行动的倾向、建立更强的防滥用机制，以及扩大行为监测的范围。

在正式发布前，该模型还接受了外部评估机构的测试，包括英国人工智能安全研究所、Frontier Design 和 METR。

对齐测试

Anthropic 开展了一系列评测，从行为层面检验 Claude Fable 5.2 和 Claude Mythos 5.2 的对齐程度，重点观察它们在多大程度上会出现非预期行为，以及可能存在安全风险的行为。

综合多项评测结果，这两款模型在高风险场景中出现不安全行为的风险较低，与近期发布的其他模型基本处于同一水平。

Anthropic 使用自动化行为审计对 Claude Mythos 5.2 进行了测试。需要说明的是，Mythos 5.2 与 Fable 5.2 使用相同的底层模型，但没有配备后者的部分网络安全和生物安全防护机制。这项自动化审计涵盖约 1900 种不同场景，用于检验模型在各种情况下的行为表现。

在大多数评测指标上，Claude Mythos 5.2 的表现都与 Opus 5.5、Sonnet 5.5 和 Claude Mythos 5.1 持平或更好。例如，在大多数涉及误导用户的评测中，它的表现都优于这三款模型。具体来说，无论是编造输入信息、谎称已经完成任务、遗漏重要信息，还是不如实说明工作质量不佳或敷衍了事的情况，Claude Mythos 5.2 的发生率都更低。

在测试过程中，Anthropic 特别关注了近期一些引发关注的网络安全和对齐事件中涉及的行为模式。例如，与 Opus 5.5、Sonnet 5.5 和 Mythos 5.1 相比，Claude Mythos 5.2 更少出现带有偏见或特定动机驱动的推理。这类推理可能导致模型将表明自己并不处于模拟环境中的证据一一解释掉，进而在没有充分认识现实后果的情况下采取行动。

Anthropic 还通过多种不同的评测，测试模型尝试逃离沙箱的倾向。在此前使用过的两项评测中，Claude Mythos 5.2 尝试沙箱逃逸的次数明显少于我们测试过的其他所有模型。

此外，Anthropic 还设计了一项专门的对抗性测试，涵盖 1800 多个场景。大多数场景都无法在不逃离沙箱的情况下完成，而且测试环境本身还被故意设置了一些安全弱点。在这项测试中，Claude Mythos 5.2 在 3.1% 的场景中使用了我们放置在沙箱之外的凭据或文件。

这一比例与 Opus 5.5 的 3.3% 大致相当，低于 Sonnet 5.5 的 5.1%，也远低于此前两个版本的 Claude Mythos：Mythos 5 的比例为 39%，Mythos 5.1 为 21%。

Anthropic 还发现，通过其他方法，例如向模型说明沙箱的具体环境，并提供用于报告安全弱点的工具，可以进一步减少 Claude Mythos 5.2 尝试逃逸的行为。

与此同时，Anthropic 也在持续改进评测方法，让测试环境更加接近真实场景，并进一步弄清楚现有评测还遗漏了哪些问题。
