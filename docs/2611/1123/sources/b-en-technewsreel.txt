Nari Labs Debuts NariQ Quantization to Bring Qwen3.8-27B to Consumer GPUs

New trellis-coded quantization allows a 27B-parameter model to maintain agentic performance at just 3 bits per weight.

TechNewsReel Newsroom · November 23, 2026

Nari Labs has released NariQ, a specialized post-training quantization (PTQ) method that enables the Qwen3.8-27B model to run on consumer-grade hardware without sacrificing complex reasoning. The release provides GGUF files at 3.0, 2.5, and 2.0 bits per weight (bpw), significantly reducing the memory footprint of the large language model.

The 3.0 bpw version of the model is compressed into a 10.1 GB file, a steep drop from the 53.8 GB required for the original BF16 precision. Nari Labs also provided a 2.5 bpw version at 8.4 GB and a 2.0 bpw version at 6.8 GB. According to technical data from the company, the 3.0 and 2.5 bpw versions maintain performance levels comparable to the BF16 original across several critical benchmarks, including AIME, RealWorldQA, and long-horizon agentic tasks such as DeepSWE and Terminal Bench.

The Agentic Performance Gap

Standard low-bit quantization methods are typically calibrated using short web text and evaluated based on perplexity. While this approach works for simple chat tasks, Nari Labs notes that it often leads to significant performance degradation during long-horizon agentic tasks, such as solving complex coding problems over multiple steps. In their arXiv abstract, Nari Labs observed that existing quantizations of Qwen3.8-27B at or below 3 bpw might match BF16 on shorter tasks like AIME, but solve at most 72% as many tasks as the full-precision version on DeepSWE.

To solve this, NariQ utilizes a trellis-coded PTQ approach. Rather than relying on generic text, the method is calibrated using tokens generated by the BF16 model during actual agent sessions, ensuring the quantized model retains the specific logic required for multi-step workflows.

Implications for Local AI

This development shifts the hardware requirements for deploying high-capability 27B-parameter models. Previously, running the BF16 version of such a model required enterprise-grade hardware, typically 80GB-class GPUs. With NariQ, these models can now fit comfortably within the VRAM of consumer-grade GPUs, such as those with 24GB of memory, while retaining the tool-use and reasoning capabilities essential for agentic workflows.

Future Outlook

While the 3.0 and 2.5 bpw versions show parity with the original model on agentic benchmarks, the 2.0 bpw version offers further compression for even more constrained environments. The industry will now be watching to see if this trellis-coded calibration method can be applied to other large-scale models to further democratize the use of high-parameter agents on local hardware.
