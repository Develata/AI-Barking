## 三、扫描说法勘误（与一手原文不符或需限定之处）

1. **C1 Shirudo**：扫描写 “BSD 2-Clause”，漏了 BPF 程序 “dual-licensed under BSD and GPL”（README 与 Isovalent 博文可核）。“生产需带补丁的内核”的原文是 “a Linux kernel with the signed-loader ABI and shirudo's kernel patches, plus a TPM 2.0”，应包含 signed-loader ABI。扫描只提 Java4Shell，Cisco 新闻稿另写测试了 “the PHP flaw”。Isovalent 称 Java4Shell 防护是 “mitigation written as Java bytecode”，即字节码级防护，不是运行时内核防护，写法需区分。
2. **C3 Claude Ship**：“observe 模式也计费”需限定：原文为 “a policy that uses Claude's review triggers a billed Code Review, even in observe mode”，即政策用到 Claude 审查时才计费；分类器按 token 计费也是原文。
3. **C4 GPT‑6.2 Chat**：扫描写 “逐步推出”，与原文 “rolling out globally … today” 大体相符（账号层面逐步到达），此处不算勘误。需补的是基线：图像理解 71.7% 对 47.4% 的对比对象是 GPT‑6，并非竞品，且是 OpenAI 在 Chat 标签页的自测。
4. **C5 Anthropic 访谈**：扫描 “约三分之二报告因 AI 减少招聘” 与原文 “People at two-thirds of the companies we spoke to reported reduced hiring due to AI” 一致，无勘误；但需注明分母是访谈企业，且原文另说其中三分之一为不补岗的自然减员。“仅两家描述员工因自动化失业”与原文 “only two had seen AI automation fully eliminate a position and lead to someone losing their job” 一致。样本的非代表性限定见上表原句。
5. **C7 AISI**：扫描 “同一退役监视器漏报率 0.2%–23%” 与博客摘要一致，但需保留 “depending on the ‘attack policy’ used to generate them”（取决于攻击生成策略）与 “one test using one monitor and one AI agent” 的限定。扫描称 “原站无绝对日期”，不符：页面写 “Nov 23, 2026”。
6. **C8 DeepMind**：扫描 “博客写改进后仍超出首批纠错量子计算机能力” 需限定为原文 “would still demand more computational resources than the first error-corrected quantum computers are likely to provide”（“likely”）。
7. **C2、C6**：扫描表述与原文一致，无勘误。C2 的 “on by default” 为原词。C6 的 81% 分母与口径见上表。
