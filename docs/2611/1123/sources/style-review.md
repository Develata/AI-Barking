## 1. 标题

我会点的前三：

1. **“7万行AI证明，没有数学家查过”**：数字很抓眼，“没有数学家查过”让我想知道这么大的事为什么没人检查。
2. **“AI写证明、AI来查，人类还没看”**：不用懂数学也能看出疑问，我会想知道 AI 自己检查自己到底靠不靠谱。
3. **“Claude和OpenAI同天证同一难题”**：有两家撞上同一道题的故事感，我想看看是巧合还是在抢先发布。

看不出具体在说什么的：

- **“Claude证代数版P≠NP？人类没查过”**：“代数版P≠NP”完全不认识，只能猜是数学突破，不知道难在哪里。
- **“27B塞进10GB？只能跑自家改版”**：不知道 27B 是什么，也不知道“自家改版”改的是什么，连这是给谁用的都看不出来。

只看第一名 **“7万行AI证明，没有数学家查过”**，我以为：AI 写了一份七万行的数学证明，已经公开，但还没有数学家检查，所以是否成立仍有悬念。我不会想到“七万行”说的是代码。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：不知道“谁吠”是问谁发布了新闻，还是准备骂谁。
- **“Anthropic 公开署名 Claude 的论文，称证明了 VP≠VNP（俗称‘代数版 P≠NP’）”**：Anthropic 和 Claude 是什么关系？两个数学符号我都不懂，用后一个解释前一个没帮上忙。
- **“论文和 Lean 代码都由 AI 写成”**：不知道 Lean 是什么，也不知道数学证明为什么需要代码。
- **“NariQ 把 27B 模型压进约 10GB，但只能用作者改版的 llama.cpp 跑。”**：NariQ、27B、llama.cpp 全卡住；“作者”是谁，“跑”起来能干什么，也不清楚。
- **“VP≠VNP 是 Valiant 1979年提出的猜想，可看作 P≠NP 在‘只用加法和乘法算多项式’时的版本。”**：“多项式”已经需要回忆数学课，“某个猜想的版本”更不知道是什么意思。
- **“称由内部 Claude 模型发现”**：“发现”的是证明方法，还是整个结论？“内部”又意味着我平时用不到吗？
- **“仓库说明写，没有人类数学家查过证明，‘这不解决 P vs NP’。”**：“仓库”突然出现，我不知道指哪里；前面说“代数版”，这里又说“不解决”，两者关系没读明白。
- **“约5小时后，OpenAI 也公开一篇同题论文，称11月6日已得出。”**：“已得出”什么？也是证明成功吗？两篇结果是不是一样？
- **“结果对‘NP 难题有没有快速算法’什么也没说。”**：不知道什么是 NP 难题，也就不明白这句是在缩小什么影响。
- **“结论也管不到电脑里只处理0和1的电路。”**：不知道数学猜想怎么突然接到电路上，这句是在说它对实际电脑没用吗？
- **“Lean 只保证每步推得通；命题写得对不对”**：每步都推得通，为什么整件事还可能不对？这里需要一个例子才能理解。
- **“论文附录写‘只由 AI 读者判断过’。”**：“AI 读者”是另一个 AI 在检查，还是写论文的 AI 自己检查？
- **“Nari Labs 发布 Qwen3.8-27B 的量化版，3比特档约 10.1GB，原版约 54GB”**：“量化版”“3比特档”不懂；10.1GB 是下载大小、内存占用，还是显卡需要的容量？
- **“称在长程代理、数学和看图任务上与原版持平”**：“长程代理”完全不知道是什么任务。
- **“Mac 只在一台 M3-Pro 上跑过，每秒约3.8个 token”**：不知道 token 是几个字，因此不知道这个速度能不能正常聊天。
- **“24GB 显卡跑3比特档，上下文约13.5万 token。”**：“上下文”指聊天记录还是一次能上传的文字？这个数字大有什么用？
- **“可直接对接 llama.cpp 等主流推理框架”**：“对接”“推理框架”都不像我平时用聊天软件会遇到的东西。
- **“模型卡写须用作者改版，原版 llama.cpp、Ollama、LM Studio 都加载不了。”**：“模型卡”是什么？三个软件我都没用过，不知道这会挡住我哪种用法。
- **“只记一张 RTX-5060-Ti 跑通，标‘未合格’。”**：已经跑通为什么又未合格？是太慢、会出错，还是没测完？
- **“表里2.5比特档五项有四项低于原版，如数学竞赛题96.5%对97.7%。”**：能看出前一个数字低，但不知道百分比衡量什么，也不知道这点差距实际有多大。

## 3. 像 AI 写的

- **“对你：论文写明，结果对‘NP 难题有没有快速算法’什么也没说。”**：“对你”像套好的读者利益模板，后面却还是一个我不懂的数学判断，没有说到我的生活。
- **“对你：AMD、Intel 显卡暂不支持；Mac 只在一台 M3-Pro 上跑过，每秒约3.8个 token；24GB 显卡跑3比特档，上下文约13.5万 token。”**：同样套“对你”，接着一次塞进三组配置和数字，像自动把规格表转成“与你有关”的段落。
- **“Lean 只保证每步推得通；命题写得对不对”**：很像 AI 常用的“它只能保证 A，不能保证 B”式提醒；道理说得很整齐，但没解释两者具体怎么分开。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：品牌名、谐音、效果承诺都凑在一句里，像自动生成的宣传口号。“轻松识破”尤其像营销话术，我实际读得并不轻松。

## 4. 会划走的地方

- **“省流：Anthropic 公开署名 Claude 的论文，称证明了 VP≠VNP……”**：这里已经想划走了。“省流”第一句就要求我认识公司、模型、数学猜想和代码工具，没有先让我知道这件事为什么值得看。
- **“VP≠VNP 是 Valiant 1979年提出的猜想……”**：如果被标题吸引继续看，这里很可能真正退出。像突然开始补数学背景，而且解释里的词仍然不懂。
- **“二、NariQ：27B 压进 10GB”**：即使看完第一条，这里也容易划走。我是来看 AI 数学证明有没有人检查的，突然变成装模型和显卡配置，阅读兴趣接不上。

不太在乎的“吠点”：

- **“结论也管不到电脑里只处理0和1的电路。”**：我不知道它原本被宣传能影响什么，因此感受不到揭穿了什么。
- **“原版 llama.cpp、Ollama、LM Studio 都加载不了。”**：我不用这些软件，这条对我没有直接吸引力。
- **“只记一张 RTX-5060-Ti 跑通，标‘未合格’。”**：像是给准备自己装模型的人看的，我不会据此作决定。
- **“如数学竞赛题96.5%对97.7%。”**：只看这两个分数，我反而觉得很接近，不明白为什么值得单列成一条问题。

读完后的关系和行动：

- **“没有人类数学家查过证明”**：我能带走一个提醒——看到“AI 解决数学难题”，先别急着当成已经得到人类确认的突破。但我仍不知道这次结果会影响我什么。
- **“只能用作者改版的 llama.cpp 跑”**：我大概知道第二件事有使用门槛，但不知道自己有没有使用需求，也不知道下一步能做什么。对我这种普通聊天软件用户，全文没有落到一个明确行动上。
