继黎曼猜想之后，Anthropic 这次把目标对准了理论计算机科学中最难啃的领域之一：计算复杂度下界。

今天，Anthropic 提交了一篇 70 页的论文《VP ≠ VNP Over Every Field》，核心结论相当惊人：在所有域上，VP 都严格小于 VNP。

论文地址：https://www.alphaxiv.org/pdf/2611.vp-vnp-arithmetic-lower-bounds

一个困扰数学和计算机科学界近半个世纪的猜想，又被 Claude 给攻克了。

论文称，核心证明由 Anthropic 内部研究版 Claude 发现并撰写，随后 Anthropic 研究人员与 Claude 一起完善了论文表述。论文还配套提供了约 7.3 万行 Lean 4 形式化代码，相关证明通过机器检查。

不过，目前没有人类数学家检查过这套证明。

GitHub 地址：https://github.com/anthropics/formal-math

47 年的难题

Claude 给出了什么答案？

这项工作的核心，是计算复杂性理论中的 Valiant 猜想。

1979 年，计算机科学家 Leslie Valiant 提出了两个重要的代数复杂度类：VP 和 VNP。两者之间是否存在严格的能力差距，成为理论计算机科学长期关注的开放问题。它与著名的 P vs NP 猜想有着相似的结构，因此也常被称为「代数版 P vs NP」。

简单来说，VP 关注的是能够通过多项式规模算术电路高效计算的多项式族；VNP 则允许通过对指数数量的 0/1 输入进行求和，表达更复杂的多项式族。这里的算术电路，可以理解为一套由加法和乘法组成的计算网络。

Valiant 猜想认为，VP 应该严格小于 VNP

换句话说，存在一些多项式，虽然可以通过指数规模的求和方式表达，却无法由多项式规模的算术电路高效计算。

过去近半个世纪，研究者一直在寻找能够证明这种差距的严格下界。

Claude 这次给出的结论是：VP 确实严格包含于 VNP，而且这一结论适用于所有域

永久式成为突破口

下界跨过多项式级

要理解这项工作的分量，需要先认识一个经典数学对象：永久式（Permanent）。

给定一个 m×m 矩阵，永久式与行列式的计算公式非常相似。

两者都是对矩阵元素进行排列组合，将对应元素相乘后求和。区别在于，行列式会根据排列的奇偶性为每一项添加正负号，永久式则没有这层符号变化。这个看似微小的差异，带来了巨大的计算复杂度差距。

行列式可以通过多项式规模的算术电路计算，而永久式长期被认为无法做到这一点。

事实上，永久式是 VNP 中的完备问题。在特征不为 2 的域上，如果能够找到计算永久式的多项式规模算术电路，就意味着 VP 与 VNP 相等。

因此，证明永久式需要超多项式规模的电路，就能直接推翻 Valiant 猜想。这正是 Claude 此次工作的核心

它已经超过了任何固定次数的多项式，因此属于超多项式下界。不过，这仍然是准多项式级别，并非指数级下界。这也是整篇论文最重要的突破。

此前，一般算术电路的下界一直很难推进。按照论文对已有工作的回顾，对于一个具有 n 个变量、次数为 d 的显式多项式，此前已知的一般电路下界主要来自 Strassen 以及 Baur–Strassen 等人的工作，量级为 Ω(n log d)。

具体到永久式，由于它有 m² 个变量、次数为 m，此前已知下界仍然停留在 m² log m 量级。

这次，Claude 将下界推进到了超多项式级别

更重要的是，论文讨论的是一般算术电路，没有对电路深度、常数使用或中间计算中的抵消现象施加限制。

此前很多强下界只能针对特定结构的电路成立。这次论文声称突破的，正是更一般、也更难处理的计算模型。

此外，永久式在特征为 2 的域上与行列式相同，无法直接用于证明这一情况下的下界。为此，论文还引入了哈密顿回路多项式（Hamiltonian Cycle Polynomial），证明其在所有域上都需要超多项式规模的算术电路。

通过这两类多项式，论文最终得出 VP 在所有域上都严格小于 VNP 的结论。

从算术电路到几何结构

两条路线共同完成证明

这篇论文真正值得研究的地方，还在于它采用了一条相当特别的证明路径。

Claude 没有直接对永久式的计算过程逐项展开，而是构造了一类辅助多项式，再利用永久式的计算能力与这些多项式之间的关系，把问题转化为电路规模下界。

整个证明的核心，是把算术电路、张量网络与几何结构联系起来。

论文引入了一种称为 Spectral Points（谱点）的数学工具，为张量网络中的不同节点建立类似距离的度量。借助这种转换，原本难以直接分析的电路复杂度问题，可以转化为几何结构上的约束。

随后，论文证明了一个关键结论：相关几何结构至少会落入两种情况之一，分别是 Flat（平坦）和 Contracting（收缩）。

两条路线分别给出了下界证明。

论文将整个证明过程整理成了一张流程图。最上方是两条路线共用的数学基础，随后分成 Flat 和 Contracting 两个分支，分别通过不同的推导方式得到下界，最终汇合到 Theorem 1.1，也就是论文的核心定理。

第一种情况：Flat（平坦）

在这一分支中，研究者构造了一个基于完全图的辅助多项式。可以把它理解成一张由大量节点和连线组成的网络。每条边都携带一组比特信息，节点之间通过这些信息建立约束。

这里的关键是完全图的高连接密度。如果把网络中的节点分成两组，无论怎样进行相对均衡的切分，都必然有大量连线穿过分界线。相比之下，链式网络可能只需要一条边就能跨越类似的切分。

论文利用这种结构差异，结合张量秩与几何距离之间的关系，证明小规模算术电路无法有效表达这类网络，最终得到超多项式下界。

第二种情况：Contracting（收缩）

这条路线更加特别。论文研究了一类带权重的非确定性程序，并证明计算过程可以被拆分成更短的片段。

接下来，研究者证明，如果永久式存在足够小的算术电路，就可以利用它构造一种加速程序，在更短时间内完成特定计算。随后，论文将这种假设中的加速能力不断扩展到更大规模，并通过对角化论证，最终推出逻辑矛盾。

因此，假设存在小规模电路是不成立的。

有意思的是，论文并没有判断实际数学结构究竟属于哪一种情况。它只证明两种情况至少有一种成立，而这已经足以完成整个论证。

Lean 已经核验

数学家还没有审查

这项工作的另一个重要看点，是 Claude 不仅给出了数学论证，还提供了对应的 Lean 4 形式化证明。

根据论文及 Anthropic 公开的 GitHub 仓库，整套形式化工作使用 Lean 4.33.1 和 Mathlib 构建。论文中几乎所有编号定理和命题，都有对应的 Lean 证明。只有一个关于行列式复杂度的推论没有完成对应形式化。

项目还提供了独立编写的 nanoda 检查器，对证明进行进一步核验。

目前能够确认的是，论文公开了完整的数学论证和形式化代码，相关代码也提供了机器检查流程，但仍然需要数学家进行独立审查。

这次工作的意义已经超出了 AI 在数学题目上取得更高分数的范畴，Claude 承担了核心数学结果的发现与证明撰写工作，随后又将整套论证落到了 Lean 形式化系统中
