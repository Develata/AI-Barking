 Work with the Figma agent in FigJam boards

Before you start

Who can use this feature

Professional [https://www.figma.com/pricing/], Organization [https://www.figma.com/pricing/], and Enterprise [https://www.figma.com/pricing/] plans

Anyone with access to the board can chat with the agent about its contents

Requires edit access when asking the agent to make changes

Use the Figma agent in FigJam to generate boards and diagrams, organize or summarize board content, and turn ideas into next steps with your team.

Start with a prompt or select content on your board, then ask the agent to help you develop it. Review the results with your team and ask for changes as your ideas take shape.

You can open the agent in either of these ways:

Click the Agents chat at the bottom left of the board.

Select one or more objects on the board and click Ask agent.

Tip

To turn off the Ask agent option in the toolbar, click Main menu > Preferences > Show Agents on canvas.

Work with the agent in FigJam boards

The agent can help you create, understand, or make changes to your board. Review the agent’s work as you go, then follow up with questions or requests to refine the results.

You can start multiple threads simultaneously with the agent without waiting for each one to finish.

Add context to your prompts

Give the agent context by attaching existing designs, images, and other files, or by adding skills.

Use Connectors to bring in information from external apps. Choose from more than 20 verified partner connectors [https://help.figma.com/hc/en-us/articles/35440096186007] or create your own [https://help.figma.com/hc/en-us/articles/38147204302743].

Navigate your chats

With chat open, click in the chat sidebar to see all your chats in one place. The sidebar lists chats from most to least recent, with a preview of each chat’s last message.

From here you can search, make chats private [https://help.figma.com/hc/en-us/articles/41272399602583], or rename them.

Undo changes

Click Undo in the chat to revert the most recent change. To compare versions side by side, first duplicate the content updated by the agent, then undo changes to the original.

Ways to use the agent

Use the agent to prepare a session, explore an idea, or make sense of work already on your board. Try one of the prompts below, then ask for changes to refine the results.

Turn workshop notes into clear next steps

Turn your team’s stickies and comments into an editable document that captures decisions, next steps, and open questions.

“Summarize this discussion as a spec. Include decisions, next steps, and open questions.”

Create a journey map from research and data

Combine research findings and quantitative data to explore where users struggle or drop off. Attach your sources or provide context through connected apps [https://help.figma.com/hc/en-us/articles/35440096186007].

“Create a journey map from these sources. Show stages, pain points, drop-off evidence, and open questions.”

Set up a brainstorming session from a prompt

Create a starting point for a team brainstorm without building the board from scratch. Describe the topic, participants, and desired outcome.

“Create a brainstorming board 5 people with 2 rounds of ideation. Our goal is to improve new-user onboarding. Include an introduction, idea prompts, and space to discuss next steps.”

Sketch a flow to explore an idea

Turn a written process into a flowchart to spot missing steps and decision points.

“Create a flowchart for new-user signup, including email verification and an invalid-email path.”

✓

✓

Export board content

Export all or part of your board as a PDF or image.

Review comments
✓
Summarize, sort, and act on comments in your file.

Get feedback on ideas or brainstorms. Ask the agent to consider different perspectives, such as a new user or a VP of Product.

Create and edit images
✓
Create images, remove backgrounds, or ask for changes to an existing image.

Figma file actions
✓
Add comments, create pages, and update file details.

Search Figma files
✓
Find other files and bring their content into your board without leaving it.

Use the marker or highlighter
Limited
The agent can draw shapes that resemble marker or highlighter strokes, but it can’t use those tools.

Read widgets
Limited
The agent may miss links or information that isn’t currently visible.

Work with face stamps
Limited
The agent can copy existing face stamps, but it can’t tell whose face is shown or create a face stamp from someone’s name.

Work with stamps
Limited
The agent can work with stamps and recognize patterns in how someone has used them, but it can’t tell you who added them.

Create charts and data visualizations
Limited
Ask the agent to turn data into a chart or another visual. However, results may vary, so review them carefully.

Insert code blocks
Limited
Add code to your board. You may need to interact with the code block before its color formatting appears.

Generate and edit design elements
Limited
Create some complex shapes and vector artwork. Editing is limited: the agent can’t select objects inside design frames or change existing vector artwork in FigJam.

Use custom fonts
Limited
The agent tries to keep the fonts you’ve chosen. If it can’t access a custom font, it may ask you to make that font available.

Format bulleted lists
Limited
Bullet points may not appear correctly in sticky notes, shapes with text, or tables.

Copy chat responses to the canvas
Limited
You can copy a response onto your board, but links shown as chips in the chat won’t carry over.

Frequently asked questions

How many AI credits does it cost to use this feature?

The number of credits used by the agent changes based on the complexity of the task. Learn more about how AI credits work. [https://help.figma.com/hc/en-us/articles/33459875669015]

What’s the difference between the Figma agent and using MCP in Claude or Codex?

The agent in FigJam lets you work directly in your boards, side-by-side with the agent, helping you and your team explore, refine, and build without switching context.

Can I use the agent on mobile?

The agent is currently only available from the desktop app or web browser.

Can I use the agent in other Figma products?

The Figma agent is also available in Figma Design, Figma Make, Figma Specs, and Figma Slides.
