🦥Dynamic 3.1 GGUFs

A preview of our new methods to make quants smaller and maximize agentic performance

Qwen3.8-27B [#qwen3.8-27b]

We're releasing new Qwen3.8-27B GGUFs which using our new Unsloth Dynamic [/docs/basics/dynamic-3.0-ggufs] V3.1 (preview) algorithm which improves Unsloth quants on nearly all benchmarks and is the best in class on the pareto efficient frontier vs other providers. See Qwen3.8-27B [/docs/models/qwen3.8] for more details. We are excited for Qwen-4 as well, and will further improve our methods to make quants more efficient!

DeepSeek-V4.1-Flash-1017 [#deepseek-v4.1-flash-1017]

We're releasing new DeepSeek-V4.1-Flash-1017 GGUFs which using our new Unsloth Dynamic [/docs/basics/dynamic-3.0-ggufs] V3.1 (preview) algorithm which improves Unsloth quants on nearly all benchmarks and is the best in class vs other providers. See DeepSeek-V4.1-Flash [/docs/models/deepseek-v4.1-flash] for more details.

Infrastructure and benchmark issues and fixes [#infrastructure-and-benchmark-issues-and-fixes]

LiveCodeBench: Many runs had a Time Limit Exceeded issue, and we found CPUs were too heavily utilized on our machines - we regraded with full CPU affinity, flipping 385 answers from wrong to right

LiveCodeBench: Official harness's stdin.buffer mock returned the first line on every readline and captured stdout had no .buffer . We fixed it with faithful stdin / stdout replacements. 468 answers flipped from wrong to right.

AIME / HMMT / MATH-500: math_verify timeouts use signal.alarm, which fails off the main thread; the threaded grader fell back to exact string match (\frac14 vs \frac{1}{4} wrong). We fixed it with no timeouts off the main thread. 8,520 answers flipped from wrong to right (HMMT26 4,196, MATH-500 2,949, HMMT25 1,375)

MATH-500 / HMMT: exact forms math_verify cannot parse (matrix spacing, \displaystyle, trailing punctuation, thousands separators, a = b chains, inequality vs interval, column vector vs tuple). We fixed it with exact rewrites only, never approximations; 18 fixture tests. This flipped 309 (MATH-500 198, HMMT25 89, HMMT26 22) answers from wrong to right.

Excluded Terminal Bench tasks due to issues [#excluded-terminal-bench-tasks-due-to-issues]

Excluded task

Why the reference solution fails here

qemu-alpine-ssh

the verifier's apt-get install curl returns 404 (Debian bullseye security packages superseded), so its test tooling cannot install

qemu-startup

same 404

mcmc-sampling-stan

the reference needs RcppParallel, which needs cmake; the image has no cmake, so rstan cannot be installed

protein-assembly

the reference fails with dnachisel NoSolutionError (EnforceTranslation): dependency drift since the task was written

build-cython-ext

after the reference build, the upstream pyknotid test suite fails 1 of 18 tests

install-windows-3.11

the reference QEMU build is OOM-killed (the build runs one job per host core, 192, in a 4 GB container)

torch-pipeline-parallelism

the verifier exceeds its own 900 s timeout (both runs)
