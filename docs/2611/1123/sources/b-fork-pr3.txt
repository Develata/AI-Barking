Overview

I don’t have an NVIDIA gpu, so I wanted to see if I could get nariq running on my AMD Radeon RX7900 XTX 24GB VRAM gpu. Works but speed leaves still room for improvement.

Hardware tested

GPU: AMD Radeon RX 7900 XTX, 24 GB, RDNA3 (gfx1100)

Driver: Linux amdgpu, kernel 7.0.14-29-pve

Runtime: ROCm/HIP 7.2.4

OS: Proxmox VE 9.2.32, Debian 13 host, Ubuntu 24.04 build container

Checks

NariQ tests: 4 logit-comparison unit tests passed. Full Python and CTest suites pending. Synthetic Trellis check failed at TRL1 with 35 input tokens (HIP: -10.3191; CPU: -10.3261).

Numerical check: original 3.0 bpw GGUF, HIP vs. CPU, 12/12 top-1 matches, identical greedy token IDs, max KL 1.99e-8. Independent F32 runtime parity, 2.5/2.0 bpw validation, and previous-build comparison pending.

Speed: HIP llama-server, Q8_0/Q8_0 KV, 261,632 uncached input tokens. Prefill: 165.82 tok/s. Decode: 5.18 tok/s over five output tokens. VRAM after request: 20.35 GiB. Same-machine llama-bench before/after pending.

Build instructions and full benchmark results [https://github.com/damarges/nari-llama-amd/blob/nariq-hip-gfx1100/nariq/README-hip.md]
