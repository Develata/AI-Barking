Configure the model in Pi

# Install Pi:

# Add to ~/.pi/agent/models.json:

 "providers": {
 "llama-cpp": {
 "baseUrl": "http://localhost:9931/v1",
 "api": "openai-completions",
 "apiKey": "none",
 "models": [
 {
 "id": "nari-labs/Qwen3.8-27B-NariQ-GGUF:BF16"
 }
 ]
 }
 }
}

 OpenClaw [/nari-labs/Qwen3.8-27B-NariQ-GGUF?local-app=openclaw] 
How to use nari-labs/Qwen3.8-27B-NariQ-GGUF with OpenClaw:

Start the llama.cpp server

# Install llama.cpp:
brew install llama.cpp
# Start a local OpenAI-compatible server:
llama serve -hf nari-labs/Qwen3.8-27B-NariQ-GGUF:BF16

Configure OpenClaw

# Install OpenClaw:
npm install -g openclaw@latest
# Register the local server and set it as the default model:
openclaw onboard --non-interactive --mode local \
 --auth-choice custom-api-key \
 --custom-base-url http://127.0.0.1:9931/v1 \
 --custom-model-id "nari-labs/Qwen3.8-27B-NariQ-GGUF:BF16" \
 --custom-provider-id llama-cpp \
 --custom-compatibility openai \
 --custom-text-input \
 --accept-risk \
 --skip-health

Run OpenClaw

openclaw agent --local --agent main --message "Hello from Hugging Face"
