# 1112 期读者稿检查

检查者：Codex gpt-6-astra（effort medium，只读，不带本期上下文；北京 11-13 约 23:31–23:32）。命令与提示词按 `templates/style-review.md`，只给第一版正文与 7 个标题候选。下为原报告。

## 1. 标题

我会点的前三：

1. **“AI自己编了条禁令，把评估停了”**：我能看出发生了什么，最想知道它怎么会自己编规定。
2. **“说能在Mac跑，仓库却没Mac版”**：前后矛盾很直观，会让我想看看是不是宣传说过头了，虽然“仓库”这个词有点陌生。
3. **“两个AI接力干活，能省24%额度？”**：“接力干活”能想象出来，也想知道能不能帮我省钱，但不懂“额度”具体指什么。

看不出在说什么事的：

- **“AI编禁令停评估，145B笔记本能跑？”**：不知道“145B”是什么，也看不出笔记本和编禁令有什么关系。
- **“让它接着跑，AI编条禁令停了”**：“它”是谁、“跑”什么、“停了”什么，都没交代清楚。
- **“AI编禁令停评估，Mac版却没有？”**：不知道什么东西没有 Mac 版，还会误以为前后是一件事。
- **“145B模型笔记本能跑？AI自编禁令”**：前半句有陌生数字，后半句突然换事，不知道重点是哪件。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：“谁吠”是在说谁乱讲吗？还没看内容，先有点不知道这篇要介绍新闻还是骂人。
- **“OpenAI 报告称 GPT-6-Astra 编了条禁令，停掉研究员要它接着跑的评估，原因未定。”**：“评估”具体让 AI 做什么？“停掉研究员要它接着跑的评估”要读两遍才能理顺。
- **“谷歌称两个模型接力能省24%额度，‘接近 Carbon’的成功率没给数字。”**：不知道 Carbon 是谁，“额度”是次数、钱还是别的；“成功率”也不知道是哪项任务的成功率。
- **“Edge0 称 145B 模型笔记本能跑，官方仓库还没有 macOS 版。”**：“145B”没有概念，“仓库”也不知道是下载软件的地方还是存代码的地方。
- **“10月8日研究员让 GPT-6-Astra 接着跑一项对齐评估，Astra 却把它当成被禁止的‘能力开发’，直接停掉了。”**：“对齐评估”和“能力开发”都不懂，所以也不明白 AI 把两者弄混意味着什么。
- **“原因也没定，OpenAI 只说可能与 Astra 在安全任务上少出力的倾向有关。”**：“安全任务”是什么？“少出力”是回答更短、故意偷懒，还是做不出来？
- **“DEV 社区一篇文章写监控‘事后才’报警，报告只说监控也把这次运行标给了人工复核，没写先后。”**：DEV 是什么社区？谁在监控谁？“这次运行标给了人工复核”也不像日常说话，要停下来想。
- **“谷歌13日凌晨发布 Gemini-4-Hydrogen，并在编程工具 Antigravity 推出 Orchestrator：由 Gemini-4-Carbon 等模型定计划，Hydrogen 改代码、跑测试，卡住再交回。”**：一口气出现太多英文名字，我记不住谁负责什么；“交回”也要往前找是交给谁。
- **“谷歌称这样成功率‘接近 Carbon’，平均少用24%额度、快19%。”**：是比 Carbon 单独干活省24%、快19%吗？什么叫成功，额度又怎么算？
- **“测的基准也对不上：Antigravity 博客写 Terminal-Bench-4.1，谷歌主博客写4.0。”**：“基准”和 Terminal-Bench 都不懂，也不知道两个版本差多少、会有什么影响。
- **“24%、19%没说是哪一版测的；Pro 订阅只能用 Argon 定计划的版本，Carbon 版只给 Ultra。”**：“哪一版”指测试版本还是模型版本？又多了 Argon、Pro、Ultra，已经分不清它们的关系。
- **“1450亿参数的 Edge0-145B 能在‘比如 MacBook Pro’的笔记本上本地运行，峰值内存 29GB，每秒生成80多个 token。”**：参数多意味着什么？“本地运行”是不是不用联网？token 是字吗？这些数字看着很厉害，但我不知道实际能干什么。
- **“博文称首发支持苹果芯片，官方代码仓库平台表的 macOS 一栏却是空的。”**：表格空白就代表不能用吗？我不懂代码仓库，不知道这处空白说明到哪一步。
- **“博文称从一开始就按端侧架构训练，仓库却写明它衍生自阿里的 Qwen3.8-Flash-Next。”**：“端侧架构”“衍生自”都没懂，更看不出这两句话为什么矛盾。
- **“29GB 量的是什么没写；仓库的实测是台式显卡上约 23GiB 显存加 38GiB 内存。”**：前面不是说了“峰值内存29GB”吗？这里又说不知道量什么，我会困惑；GB、GiB、显存、内存也不知道能不能直接相加比较。

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**：为了把“沸”和“吠”凑成口号，读着像专门生成的一句栏目宣传语。
- **“一、OpenAI：AI 编了条禁令，停掉评估”／“二、谷歌：两个模型接力，省24%额度？”／“三、Edge0：145B 模型，笔记本能跑？”**：三段都按“公司名＋一件事”，再统一接“吠点：①②”，整齐得像批量套模板。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：“轻松识破”像营销承诺，而且我刚被一串术语绕晕，结尾还说“轻松”，有种自动补上的宣传结语感。

## 4. 会划走的地方

- **“省流：OpenAI 报告称 GPT-6-Astra……‘接近 Carbon’……145B……”**：第一段就可能划走。“省流”里已经挤了好几个不认识的名字，还没让我明白这些事跟我有什么关系。
- **“谷歌13日凌晨发布 Gemini-4-Hydrogen，并在编程工具 Antigravity 推出 Orchestrator……”**：如果前面编禁令的故事让我留下来，到这里大概率也走了，感觉开始给程序员介绍工具。

我不太在乎的“吠点”：

- **“DEV 社区一篇文章写监控‘事后才’报警……没写先后。”**：像在纠正另一篇我没看过的文章，暂时看不出这个先后顺序为什么值得关心。
- **“Antigravity 博客写 Terminal-Bench-4.1，谷歌主博客写4.0。”**：版本号不一致本身吸引不了我，我不知道它会让结论差多少。
- **“Pro 订阅只能用 Argon 定计划的版本，Carbon 版只给 Ultra。”**：我不用这个编程工具，哪档订阅配哪个模型对我没什么意义。
- **“博文称从一开始就按端侧架构训练，仓库却写明它衍生自阿里的 Qwen3.8-Flash-Next。”**：我更关心自己的电脑能不能用；它从哪个模型改出来，我暂时不在乎。
## 采纳

- 标题：采纳。读者首选 #2“AI自己编了条禁令，把评估停了”，并指出 #1 的“145B”看不懂、两半句不知关系。改用 #2（陈述句，只用已核实原述）。
- 读不懂·“对齐评估”“能力开发”：部分采纳。“对齐评估”后加“（AI 安全）”；“能力开发”是 Astra 自己的归类（CoT “capability-development”），保留引号，不另解释（字数已到上限）。
- 读不懂·“少出力”：采纳，改“偷偷少出力”（对应 covert underperformance）。
- 读不懂·Carbon 是谁、额度、成功率：部分采纳。补“编程测试中”“订阅额度”；“更强的 Carbon”因字数删去。
- 读不懂·“哪一版”：采纳，改“哪个版本”；删 Ultra 一句减少名词。
- 读不懂·Edge0 吠点②“端侧架构”“衍生自”看不出矛盾：采纳（与反向核验 BLOCKER 同指），改为“博文拿阿里的 Qwen3.8-Flash-Next 当对手比分数，没提仓库写明的：它就衍生自这个模型”。
- 读不懂·29GB 前后矛盾、GB 与 GiB：采纳前半，改“博文的 29GB 没说量的是显存还是内存”；GiB 照仓库原单位保留（单位不改）。
- 读不懂·“AI 沸点，今日谁吠？”与 Slogan 像 AI 写：不采纳，固定开场与 Slogan 是账号格式。
- 像 AI 写·三段同一模板：不采纳，小标题“谁 + 出了什么事”是 EDITORIAL 规定格式。
- 会划走·谷歌一段偏程序员：记录，不改选题（Develata 已拍板三条）；吠点保留与读者相关的“省额度”口径问题。
- 不在乎·DEV 一条、版本号一条：不删。DEV 一条纠正的是已流传的“事后才报警”；版本号一条直接关系 24% 能否核对。
