Welcome to Edge0. Once a model is ready, you can chat with Edge0 on your own computer or phone. Chat runs locally on your device and does not go through a cloud model service.

Copy pageCopy page

 [#get-started]Get started

New to Edge0? Start with Quick Start [/quick-start] to choose a device and a model and complete your first local chat.

Overview

Learn what Edge0 can do.

Device Requirements

Confirm the system, hardware, and storage conditions.

Download & First Run

Get the app source and models, then complete the initial setup.

Models: 8B vs 35B

Compare the resource requirements and measured performance of the two tiers.

 [#guides-by-platform]Guides by platform

macOS Guide

Apple Silicon Mac · Build the desktop app, then download and load models in the app

Windows Guide

Windows PC · Build the engine and desktop app; download models in the app, which converts them automatically

iOS Guide

iPhone · Prepare models on a Mac, then build and install through Xcode

Android Guide

Android device · Build the app, convert models on a computer, then import them via adb

On every platform, installation is currently done by building from source, which requires a terminal and the platform’s build tools. Read the preparation section of the relevant platform guide before you start downloading models.
