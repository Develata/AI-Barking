On-device AI built for consumer hardware

Cloud-level AI · Offline access · Strengthened privacy · No pay-per-use fees

Website [https://edge0.ai/] · Models [https://huggingface.co/Edge0] · GitHub [https://github.com/Edge0-AI] · X [https://x.com/Edge0_AI]

Edge0 builds efficient foundation models for phones, laptops, wearables, robots, and other consumer hardware. Our models are designed for local, private, and offline inference.

LLMs

Latest release

Edge0-145B · Q3_K [https://huggingface.co/Edge0/Edge0-145B-q3k] · NVFP4 [https://huggingface.co/Edge0/Edge0-145B-NVFP4]
145B latent MoE for local coding and agent tasks on consumer hardware, trained natively at 4 bits.

Edge0-120B · Q3_K [https://huggingface.co/Edge0/Edge0-120B-q3k] · NVFP4 [https://huggingface.co/Edge0/Edge0-120B-NVFP4]
120B latent MoE for local coding and agent tasks, with smaller weight files and native 4-bit training.

Previous release

Edge0-35B-A3B [https://huggingface.co/Edge0/Edge0-35b-a3b-preview] — 35B sparse MoE with about 3 GB peak active memory.

Edge0-8B-A1B [https://huggingface.co/Edge0/Edge0-8B-A1B-preview] — lightweight 8B sparse MoE with about 1 GB peak active memory.

Speech models

Audio8-ASR — 4B Infinite [https://huggingface.co/Edge0/Audio8-ASR-Infinite] · 3B [https://huggingface.co/Edge0/ARK-ASR-3B] · 0.6B [https://huggingface.co/Edge0/ARK-ASR-0.6B] · 0.1B [https://huggingface.co/Edge0/Audio8-ASR-0.1B] — speech recognition from flagship to edge tiers.

Audio8-TTS — Realistic Air [https://huggingface.co/Edge0/Audio8-TTS-Realistic-Air] · 0.1B [https://huggingface.co/Edge0/Audio8-TTS-Preview-0.1b] — multilingual, zero-shot voice generation with voice cloning.

Explore all models on Hugging Face [https://huggingface.co/Edge0], and the open-source inference stack on GitHub [https://github.com/Edge0-AI].
