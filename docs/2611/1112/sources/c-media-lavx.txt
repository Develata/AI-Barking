Edge0 releases open-source 145-billion-parameter model for local inference on laptops

Edge0 published weights for Edge0-145B and Edge0-120B, an inference framework, and deployment tools, claiming laptop-scale local performance on coding and agent tasks. The reported gains depend on internal evaluations and hardware-specific measurements that outside testers still need to reproduce.

Edge0 released Edge0-145B [https://edge0.ai/blog/introducing-edge0-145b-frontier-ai-capabilities-on-your-own-computer], a 145-billion-parameter language model the company says runs on a personal computer. The release includes Edge0-120B, an inference framework, deployment tools, and model weights on Hugging Face [https://huggingface.co], with code and guides on GitHub [https://github.com]. Edge0 positions the models for coding, reasoning, and agent workflows without sending prompts to a cloud model.

What's claimed

Edge0 describes Edge0-145B as an open-source on-device model with 145 billion parameters and performance near specific frontier cloud models. In the company's laptop tests, the model reached peak memory of 29 gigabytes, prompt processing above 1,100 tokens per second, generation above 80 tokens per second, and power draw near 120 watts. Edge0 reports support for 128,000 to 256,000 tokens of context on long inputs.

Edge0 also claims the model can complete multi-step work on a local machine. The company points to demonstrations in which Edge0-145B planned tasks, wrote and ran code, debugged failures, and inspected results. Examples include 3D scenes in Blender, game assets, drone control code, and a printed circuit board workflow in KiCad and Unreal Engine 5.

What's new

The release combines model architecture and inference engineering aimed at the limits of laptop memory and bandwidth. Edge0 says it shares large matrices across groups of sparse experts, trains the model in its on-device form from the start, pipelines data across GPU memory, system memory, and SSD storage, and splits work between the CPU and GPU with speculative decoding. Of the 145 billion parameters, Edge0 reports that about 10 billion participate in each inference step.

Edge0 presents benchmark results from its internal evaluations. In the company's table, Edge0-145B scores 64.6 on DeepSWE 1.1, 86.52 on Terminal-Bench 2.1, 35.4 on HLE, 90.4 on GPQA-Diamond, 80.6 on IFBench, and 79.3 on AA-LCR. Edge0 compares those scores with Qwen3.8-Flash-Next, Qwen3.8-27B, DeepSeek-V4-Flash-0731, and Claude-Opus-4.6 (Max), with gaps in published results marked by dashes.

The memory comparison stands out. Edge0 reports 29 gigabytes of measured peak memory for Edge0-145B on a laptop, against estimated 70-gigabyte and 87-gigabyte footprints for standard 4-bit deployments of Qwen3.8-Flash-Next and DeepSeek-V4-Flash-0731. Edge0 says this makes the model usable on a 48-gigabyte laptop. The company states that it will release the evaluation setup, hardware environment, and reproduction instructions with a technical report.

Edge0 frames local inference as a way to avoid cloud-model token or API fees, keep code and documents on the user's hardware, and continue core tasks offline. The company also describes a broader portfolio of 200 models across four families, with day-one Edge0-145B support on macOS, Windows, and Linux, including Apple M-series chips and NVIDIA hardware such as RTX Spark, RTX 4090, and RTX 5090.

Limitations

The results in Edge0's announcement come from the company, not from independent benchmarks. Edge0 ran the evaluations, measured the laptop performance, and produced the demonstrations. The comparison table mixes measured Edge0 figures with estimated baseline memory footprints, and it omits scores where public results do not exist. Claude-Opus-4.6 (Max) has no DeepSWE 1.1 score in the table, and Edge0 excludes Claude from the memory-versus-quality chart because it runs in the cloud.

Hardware sets a hard boundary. Edge0-145B targets compatible laptops, while Edge0-35B targets phones in a separate comparison. A device with low compute, memory, or battery capacity cannot run the 145-billion-parameter model. Edge0 also notes tasks that still fit the cloud: cross-device long-term memory and searches that require current information. Electricity and hardware cost money, even when local inference removes cloud-model fees.

The practical test for developers will come from reproduction. Edge0 published the model weights [https://huggingface.co], the inference framework [https://github.com], and an app for local trials. Outside runs on common laptops, with the promised technical report and scripts, will show whether the speed, memory use, and benchmark scores hold outside Edge0's setup.
