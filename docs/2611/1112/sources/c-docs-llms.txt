# Edge0 Docs

- [Docs Home](https://docs.edge0.ai/index.md): Welcome to Edge0. Once a model is ready, you can chat with Edge0 on your own computer or phone. Chat runs locally on your device and does not go through a cloud model service.
- [Quick Start](https://docs.edge0.ai/quick-start.md): This page helps you choose a device and a model and complete your first local chat. For detailed installation steps, see the platform guides.
- [Overview](https://docs.edge0.ai/overview.md): Edge0 is a set of language models and companion apps that run locally. On a compatible Mac, Windows PC, iPhone, or Android device, you can chat in text with the 8B or 35B model.
- [Device Requirements](https://docs.edge0.ai/device-requirements.md): Before you start, confirm that your runtime device, build tools, and available storage meet the following conditions.
- [Download & First Run](https://docs.edge0.ai/download-and-first-run.md): The Edge0 app source and the models are obtained separately. Cloning the app repository does not download any model.
- [macOS Guide](https://docs.edge0.ai/macos-guide.md): This guide explains how to build the Edge0 app on an Apple Silicon Mac, download a model, and start chatting locally.
- [Windows Guide](https://docs.edge0.ai/windows-guide.md): This guide explains how to build Edge0 on Windows, download and convert a model in the app, and complete your first chat.
- [iOS Guide](https://docs.edge0.ai/ios-guide.md)
- [Android Guide](https://docs.edge0.ai/android-guide.md): This guide explains how to build the Edge0 Android app, prepare models on a computer, import them to the device via adb, and start chatting.
- [Models: 8B vs 35B](https://docs.edge0.ai/models-8b-vs-35b.md)
- [Security & Installation Warnings](https://docs.edge0.ai/security-and-installation-warnings.md)
- [Troubleshooting](https://docs.edge0.ai/troubleshooting.md): When you hit a problem, first note the platform, device, model, and the error message shown in the interface, then work through the categories below.
- [Privacy & Data Handling](https://docs.edge0.ai/privacy-and-data-handling.md)
- [License & Model Terms](https://docs.edge0.ai/license-and-model-terms.md)
- [FAQ & Support](https://docs.edge0.ai/faq-and-support.md)
