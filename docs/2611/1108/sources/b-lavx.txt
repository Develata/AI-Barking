Goldman Sachs pulls Claude Code from most traders and bankers

Nov 8, 2026, 8:17 PM UTC•

Elena Varga [/author/elena-varga]
•5 min read

Share this article

Save

Goldman Sachs has limited Anthropic's Claude Code and GitHub coding agents to its roughly 12,000 engineers, cutting off traders and bankers who had used them to model markets and track client flows. The move comes as Goldman helps underwrite Anthropic's IPO.

Goldman Sachs has cut most of its traders and bankers off from Anthropic's Claude Code [https://www.anthropic.com/claude-code] and Microsoft's GitHub Copilot [https://github.com/features/copilot]. Under internal guidance updated in October, only the bank's engineers may use these coding agents. Strats, the quantitative staff who work across trading, research and software engineering, keep access.

What changed

The October guidance followed a review of productivity and risk concerns, according to reporting from people familiar with the matter. Traders who lost access had used the tools to watch client trading flows, model market moves and track positions. They also used them to produce written and graphic material. The change frustrated some of them.

Goldman spokesperson Nick Carcaterra said the bank makes certain AI tools available to staff "to determine the best use cases" across the firm.

A reversal from July

In July, chief information officer Marco Argenti promoted "vibe coding" by non-technical employees. He said traders and bankers had built tools with AI and handed them to the firm's engineers to improve. That arrangement let the people closest to a problem produce a first version without waiting for engineering time.

It also meant thousands of employees without engineering training were running software that writes and executes code, on the same machines they used to handle client information.

At a conference in Turin last month, Argenti described Goldman's AI adoption in waves. Developers, more than 12,000 of the bank's roughly 47,000 staff, formed the first wave. The October guidance confines coding agents to that group.

Hong Kong came first

In April, Goldman removed Claude from its internal AI platform for bankers in Hong Kong. Reporting said the bank read its contract with Anthropic strictly. An Anthropic spokesperson said Claude had never been officially supported in Hong Kong. ChatGPT and Gemini stayed available there.

JPMorgan dropped Claude from its Hong Kong approved list in June. Goldman's Hong Kong restriction rested on location and contract terms. The new restriction rests on job role.

Goldman's in-house AI assistant, which draws on models from several companies, remains available across the firm. The restriction targets third-party agents that write and run code on their own.

Still close to Anthropic

Goldman's relationship with Anthropic runs deeper than the coding restriction. Earlier this year, the bank said Anthropic engineers spent six months on site helping build Claude-based agents for trade accounting and client onboarding. Goldman's engineering teams run those agents in the back office.

Goldman and Morgan Stanley are also lead underwriters on Anthropic's IPO, according to the S-1 filed Oct. 26. Anthropic is expected to list on Nasdaq under the ticker ANT before the end of November. In the coming weeks, Goldman's bankers will market shares in a company whose coding agent most of them can no longer use.

Why a coding agent is riskier on a trading desk

Claude Code reads files, writes programs and runs them, typically with the same access as the person using it. Code an engineer writes with the tool goes through review, testing and deployment controls before it reaches anything important.

A script a trader builds to watch client flows can become daily infrastructure without passing any of those gates. Banks must also maintain information barriers between deal teams and traders who could profit from knowing about pending transactions. Goldman built its internal AI platform around controls like these. A tool a trader assembles with an agent was never designed with them in mind, and engineers can review it only if someone sends it their way.

Understanding the code matters too. Last month, a Meta engineer said he now ships code he cannot fully account for, and writing software is his job. A trader who uses an agent to model positions may not know how that code handles unusual inputs. On a trading desk, a mistake in that handling can cost money quickly.

Cost may have played a role. Agent usage is billed by the token, and several companies that gave agents to everyone have watched spending climb. Amazon shut down an internal leaderboard after employees ran agents on pointless tasks to climb it. Accenture funds $29 a month of Claude for each employee. People familiar with the matter said productivity figured in Goldman's review.

Barclays moves the other way

In October, Barclays said it expects half its developers to use Claude Code by year end. Three weeks later, it named developers among 5,000 job cuts. Like Goldman, Barclays is giving coding agents to engineers. Unlike Goldman, it is using them to shrink its engineering headcount.

Other banks have also tightened agent access this fall. JPMorgan and Schwab block outside agents from customer accounts. Goldman now limits which of its own staff can use them.

Our take

Goldman was right to restrict the tools and wrong in how it did so. A trading floor is a poor place for unreviewed code written by people who cannot read it. The information barrier problem would justify the limit on its own. Requiring that agent-written code come from people trained to review it is a sound rule for a regulated business.

But Argenti promoted traders' AI-built tools in July. Withdrawing access through a guideline update, with no replacement mentioned in reporting, tells the traders who found good uses that they were the problem. Goldman could collect those tools, send the useful ones to its engineers for review and keep the work moving. The traders' complaints point to work the engineering team could take on.

Other leaders should settle who owns agent-built code before handing out agents. When someone outside engineering builds a tool with Claude Code or Copilot, a named engineer should take responsibility for it before it touches production data. Existing controls should also cover code an agent writes. Information barriers, data entitlements and software approval rules still apply when a prompt produced the code. When a company takes a tool away, it should record what people used it for. Goldman's traders watched client flows and modeled positions, and the bank still needs both.
