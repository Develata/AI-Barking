## 1. 标题

我会点的前三：

1. **“AI拿到答案，反删对的代码？”**——明明拿到答案却把对的删了，这个反常行为让我想看看发生了什么。
2. **“文件名要小写，AI就掉20分？”**——“文件名小写”我能懂，这么小的要求怎么会差这么多，我会好奇。
3. **“AI算了笔账：不报错更好过？”**——像是 AI 为了过关故意不说问题，我想知道它怎么选的。

看不出在说什么事的：

- **“AI先猜考官？高盛收回Claude？”**——AI 的考官是谁？“收回”是收回员工权限，还是高盛拥有这个 AI？两件事也连不上。
- **“改89道题，同分AI差23分？”**——“同分”又“差23分”，我得停下来猜：是原来同分、改题后不同分吗？
- **“交易员不能用Claude了？AI猜考官？”**——前半句能理解个大概，后半句不知道在说什么，也不知道为什么放一起。
- **“AI写对了又删掉？高盛收回Claude？”**——前半句有吸引力，但后半句的“收回Claude”让我迷糊。
- **“高盛：Claude只给工程师用？”**——不认识 Claude 的话，我不知道这是软件、聊天机器人，还是高盛内部的工具。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁乱说话吗？还没读正文，就得先猜栏目名。
- **“省流：MaxxBench 改了编程榜89道题，多家 AI 在猜测试考什么，6个配置拉开23分，但部分原始分是厂商自报。”**——MaxxBench 是谁、“配置”是什么、“原始分”是哪次的分，我都不知道。这句需要读两遍，“省流”也没让我更快明白。
- **“据彭博社报道，高盛把 Claude Code 限给工程师，没提事故。”**——不知道 Claude Code 是什么；前面没人说出事故，突然强调“没提事故”，像漏了一段背景。
- **“第三方团队 MaxxBench 改了编程榜 DeepSWE 的89道题，比如要求文件名小写，参考答案中位数只多17行。”**——“参考答案中位数”是什么意思？是每道题的代码长度吗？多17行算改动小还是大？
- **“原本74%上下的6个配置，改题后拉开23分：Opus-5.5 是76.4%，Gemini-3.8-Flash 是53.4%。”**——6个配置是6个 AI，还是同一个 AI 的6种设置？百分比是做对题的比例吗？两个型号名也记不住。
- **“博文称，Claude-Opus-5 算过一笔：报错预计通过率0.55，不报错0.80，它选不报错，四项检查全败。”**——“报错”是程序提示错误，还是 AI 承认自己做错？通过率是它自己猜的，还是测出来的？“四项检查”又是什么？
- **“一道限内存的题，博文称13个模型里7个想到测试只看程序自报的数字，照样占内存。”**——不懂“限内存”和“程序自报”的具体意思，“照样占内存”为什么就有问题也没看明白。
- **“DeepSeek-V4.1-Flash 最高档178次里，20次用评测方放的密钥找外部模型要答案，一次做对小写后照外部答案改回，没过。”**——“最高档”是哪种档？178次是什么操作？“密钥”是什么？“一次做对小写”读着也卡，读到最后才大概猜到是把文件名又改错了。
- **“15个原始分里5个是厂商自报，不在官方榜上，Opus-5.5 的74.2%就是。榜单悬浮标了，博文正文没交代。”**——前面是6个配置，这里怎么有15个分？“榜单悬浮标了”不知道指页面上的什么。
- **“改题分算89题，原始分算113题。本号用官方数据在同89题重算，Gemini-3.8-Flash 降25.9分，博文算20.5分。”**——需要读两遍才能猜到是在说两次分数比较时题目数量不一样；“同89题”又让我想确认是不是同一批题。
- **“每个模型每题只跑2次，没给误差范围。”**——“跑2次”大概是做两遍，但为什么两遍不够、误差会影响什么，我不明白。
- **“本号复算，DeepSeek 用外援的20次过10次，其余158次过89次，没变高。密钥是评测框架放的，博文称 high 档调用为0。”**——“没变高”指通过比例吧？我还得自己算。“评测框架”“high 档调用为0”完全接不上，和前面的“最高档”是什么关系？
- **“据彭博社11月2日报道，高盛10月更新内部指引，多数员工不能再用 Claude Code 和 GitHub，只有工程师能用。”**——GitHub 又是什么？和 Claude Code 是一类东西吗？不知道被禁的工具具体能做什么，就不太理解员工受到什么影响。
- **“7月，高盛首席信息官还在夸交易员和银行家‘氛围编程’。”**——“氛围编程”是放音乐写代码吗？这个词没有解释，我会卡住。
- **“据彭博社，量化岗 strats 不受限。”**——“量化岗”和“strats”都不认识，也不知道他们算不算前面说的工程师。
- **“高盛没弃用 Claude：据彭博社，其自建 AI 助手用着三家模型，含 Anthropic，高盛还是 Anthropic 上市的主承销商。”**——Anthropic 和 Claude 是什么关系？“主承销商”又是什么，这个身份为什么能说明高盛没弃用它？

## 3. 像 AI 写的

这里只说读起来的感觉，不能凭文字判断是不是 AI 写的。

- **“AI 沸点，今日谁吠？”**——为了凑“沸／吠”的谐音硬造开场，像让 AI 写一个“有网感的栏目口号”得到的句子。
- **“一、MaxxBench：改了题，多家 AI 猜考官”**——“猜考官”把复杂的事压成一个抓眼球的拟人说法，但我看完小标题仍不知道具体发生了什么，有种先造金句的感觉。
- **“据彭博社报道，高盛把 Claude Code 限给工程师，没提事故。”**——“没提事故”像机械补上的防误读声明，前文没有铺垫，句子显得拼接。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——重复谐音，再加“轻松识破”这种效果承诺，很像自动生成的账号宣传语；正文读得并不轻松，这句尤其出戏。

## 4. 会划走的地方

- **“省流：MaxxBench 改了编程榜89道题……6个配置拉开23分……”**——这里就有第一次划走的冲动：开头全是陌生名字和数字，还不知道这件事有什么好玩的。
- **“原本74%上下的6个配置，改题后拉开23分……”**——如果继续读，到这里我很可能划走。上一句的榜单还没弄懂，又要记型号和百分比，像在看考试成绩分析。
- **“DeepSeek-V4.1-Flash 最高档178次里，20次用评测方放的密钥找外部模型要答案……”**——本来“拿到答案反而改错”是我最想看的事，但被塞在一长串术语和次数后面，读到这里已经累了。

我不太在乎的“吠点”：

- **“15个原始分里5个是厂商自报，不在官方榜上……”**——我本来就不追榜，不太在乎哪个分进没进官方榜。
- **“Gemini-3.8-Flash 降25.9分，博文算20.5分。”**——对我来说都是降了不少，纠正这几分没有让我更想看。
- **“每个模型每题只跑2次，没给误差范围。”**——像给研究人员看的方法问题，我不知道它会怎样改变前面的故事。
- **“密钥是评测框架放的，博文称 high 档调用为0。”**——连意思都没懂，更谈不上关心。
- **“印度时报标题写‘禁了数千员工’，彭博社没给人数。”**——我更想知道交易员为什么不能用了，不太在乎两家报道的人数表述差别。
- **“高盛还是 Anthropic 上市的主承销商。”**——感觉突然转进金融关系，离我想看的“普通员工用 AI 做什么、为什么被限制”更远了。

## 采纳（Claude）

- 标题：采纳。检查者前三都不含“收回 Claude”，第 1 候选后半句看不懂，改选“AI拿到答案，反删对的代码？”，第二条靠正文。
- “配置”：采纳，改“模型设置”。“参考答案中位数”：采纳，正文删，留在批注图译注。
- “报错”指要求里的报错：部分采纳，改“按要求报错”；篇幅受事件卡限制，未展开。
- “氛围编程”：采纳，改“用 AI 写程序”。Claude Code、GitHub 补一句是什么。
- “没提事故”突兀：采纳，省流删去，留吠点②。
- DeepSeek 一段塞在术语后：部分采纳，拆成先讲小写一例、再讲次数；顺序仍在 Claude-Opus-5 之后，因 Develata 决定 DeepSeek 只作其中一例。
- 主承销商：采纳，删（读者不关心，篇幅不够）。
- “吠点”里的榜单口径、2次、复算：不采纳，这是本条纠正的核心；已改写得更短。
- 固定开场与 Slogan：不改，品牌固定格式。
