 nginx [/security/cves?package=nginx] - small, powerful, scalable web/proxy server

Details

Stephen Fewer and Tomer Schwartz discovered that nginx did not correctly

handle certain memory operations. A remote attacker could possibly use

this issue to cause a denial of service or execute arbitrary code. This

issue only affected Ubuntu 16.04 LTS, Ubuntu 18.04 LTS, Ubuntu 20.04 LTS,

Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, Ubuntu 26.04 LTS and Ubuntu 26.10.

(CVE-2026-123007 [/security/CVE-2026-123007])

Albert Ebb Metnir and Nir Ohfeld discovered that nginx did not correctly

handle certain reusable HTTP/2 connections. A remote attacker could possibly

use this issue to cause a denial of service or execute arbitrary code. This

issue only affected Ubuntu 16.04 LTS, Ubuntu 18.04 LTS, Ubuntu 20.04 LTS,

Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, Ubuntu 26.04 LTS and Ubuntu 26.10.

Stephen Fewer and Tomer Schwartz discovered that nginx did not correctly

handle certain memory operations. A remote attacker could possibly use

this issue to cause a denial of service or execute arbitrary code. This

issue only affected Ubuntu 16.04 LTS, Ubuntu 18.04 LTS, Ubuntu 20.04 LTS,

Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, Ubuntu 26.04 LTS and Ubuntu 26.10.

(CVE-2026-123007 [/security/CVE-2026-123007])

Albert Ebb Metnir and Nir Ohfeld discovered that nginx did not correctly

handle certain reusable HTTP/2 connections. A remote attacker could possibly

use this issue to cause a denial of service or execute arbitrary code. This

issue only affected Ubuntu 16.04 LTS, Ubuntu 18.04 LTS, Ubuntu 20.04 LTS,

Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, Ubuntu 26.04 LTS and Ubuntu 26.10.

(CVE-2026-123633 [/security/CVE-2026-123633])

It was discovered that nginx did not correctly handle certain memory

operations. A remote attacker could possibly use this issue to cause a

denial of service or execute arbitrary code. (CVE-2026-113425 [/security/CVE-2026-113425])

It was discovered that nginx did not correctly handle resolving certain

names or addresses. A remote attacker could possibly use this issue to

cause a denial of service or execute arbitrary code. (CVE-2026-123634 [/security/CVE-2026-123634])

It was discovered that nginx did not correctly handle certain TLS

connections. A remote attacker could possibly use this issue to cause

a denial of service. This issue only affected Ubuntu 24.04 LTS,

Ubuntu 26.04 LTS and Ubuntu 26.10. (CVE-2026-118899 [/security/CVE-2026-118899])

It was discovered that nginx did not correctly handle certain client

certificate validations. A remote attacker could possibly use this issue

to bypass client certificate verifications. This issue only affected

Ubuntu 26.04 LTS and Ubuntu 26.10. (CVE-2026-120967 [/security/CVE-2026-120967])

It was discovered that nginx did not correctly handle certain reusable

HTTP/3 connections. A remote attacker could possibly use this issue to

cause a denial of service or execute arbitrary code. This issue only

affected Ubuntu 26.04 LTS and Ubuntu 26.10. (CVE-2026-121810 [/security/CVE-2026-121810])

Vivek Parikh discovered that nginx did not correctly handle parsing

certain ClientHello messages. A remote attacker could possibly use this

issue to leak sensitive information. This issue only affected

Ubuntu 26.04 LTS and Ubuntu 26.10. (CVE-2026-123640 [/security/CVE-2026-123640])
