K000163928: NGINX ngx_http_v2_module vulnerability CVE-2026-123633
Published Date: Nov 18, 2026Updated Date: Nov 19, 2026
Download Article
Show social share buttons
Toggle showing the products this article
Evaluated products:

Security Advisory Description

When NGINX Plus or NGINX Open Source is configured to use HTTP/2 for client connections and proxy client requests to a backend, a specially crafted request can result in use-after-free in the worker process, if this process is running low on worker_connections. Additionally, attackers can execute code on systems with Address Space Layout Randomization (ASLR) disabled or when the attacker can bypass ASLR. (CVE-2026-123633)

Impact

This vulnerability may allow remote attackers to cause a denial-of-service (DoS) on the NGINX system or may allow a code execution. There is no control plane exposure; this is a data plane issue only.

For products with ** in the various columns, F5 is still researching the issue and will update this article after confirming the required information. F5 Support has no additional information about this issue.

Security Advisory Status

F5 Product Development has assigned ID NPS-319 (NGINX) to this vulnerability. This issue has been classified as CWE-416: Use After Free.

Security Advisory Recommended Actions

If you are running a version listed in the Versions known to be vulnerable column, you can eliminate this vulnerability by installing a version listed in the Fixes introduced in column. If the Fixes introduced in column does not list a version for your branch, then no update candidate currently exists for that branch and F5 recommends that you upgrade to a version with the fix (refer to the tables).

If the Fixes introduced in column lists a version prior to the one you are running, in the same branch, then your version should have the fix.

F5 is still researching the issue for the products indicated and will update this article with the most current information as soon as it has been confirmed. F5 Support has no additional information on this issue.
