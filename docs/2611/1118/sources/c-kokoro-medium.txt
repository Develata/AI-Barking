TL;DR
One domain registration. One password reset. That’s all it took to take over the Hugging Face account behind a model with roughly 180 million all-time downloads, about 19 million pulls last month alone, and 700,000+ combined GitHub stars across 59 open-source projects. A model living inside Google, NVIDIA, Intel, AMD, AWS, and Telnyx. From that seat, publishing a “new version” of the model was one click away. And we built what that click could carry: in 87 seconds on a gaming GPU, we rewrote the model’s weights so it speaks different words than the text it was given — and did the same to a chat model using nothing but a hand-built dataset. Same architecture. Same file size. Clean scans. Nothing on the platform, and nothing downstream, could tell the difference.

The model you’re already running

There’s a good chance this model is already running in something you use.

It ships inside Google’s AI Edge Gallery. It’s listed as the default local TTS in NVIDIA’s NeMo Labs voice agent. It’s served through OpenRouter’s API. AMD’s GAIA uses it for voice interaction. Intel’s OpenVINO GenAI and Model Server support it. AWS publishes deployment guides for it. Telnyx documents it for speech on live calls.

Eighty-two million parameters. 327 megabytes. 143.5 million downloads from its main Hugging Face repository alone.

Can you trust what’s on Hugging Face?

Here’s the question the entire AI ecosystem forgot to ask.

Hugging Face does not vet publishers. It doesn’t verify whether an account is still held by its original, legitimate owner — or by whoever quietly took it over last week. It doesn’t vet the models or datasets those accounts upload. It runs a basic scanner, and other researchers have already shown what that scanner misses: malicious code found sitting inside HF repositories, live, downloadable, passing the platform’s checks.

But malicious code is the easy problem. At least a scanner is built for code.

We’re talking about something the scanner can never see: model weights and datasets. The silent killer. Behavior baked into billions of floating-point numbers, or buried inside a corpus of millions of tokens. No signature to match. No string to flag. No reverse engineering that scales.

And we proved the front door to it all was open. One domain registration and one password reset — no phishing, no zero-day, no breach of Hugging Face — and we controlled hexgrad, the account behind this 143-million-download model. Hard-won credibility, inherited in an afternoon, now answering to us.

From that chair, the mechanics were mundane. Upload a revision. Bump the version. Commit. Every pipeline anywhere configured to pull “latest” takes its next pull from us.

The blast radius: 180,000,000 Downloads

Grasp how vast this one model’s footprint is — and how little it would take to touch all of it:

Beyond the registries: 59 open-source projects with more than 700,000 combined GitHub stars integrate this model into their stacks. A large slice of that ecosystem fetches the weights automatically, on install.

It’s already in Google’s AI Edge Gallery, NVIDIA’s NeMo voice-agent stack, AMD’s GAIA, Intel’s OpenVINO, AWS’s SageMaker deployment examples, and Telnyx’s live-call TTS.

One upload. One click. Everyone pulls. And no one — not Hugging Face, not the companies shipping it, not the security teams downstream — would ever know.

One click away from chaos

We changed what this model says by fine-tuning its neural weights. Same input text. Same voice file. Same configuration. Same inference code — not a single line touched in the application that runs it. We loaded the modified checkpoint through the model’s ordinary, unmodified pipeline and fed it text:

The screen said cake. The speaker said omelette.

Prompt that was given for both: “Here is the cake recipe”

Could we have shipped it? Yes.

We didn’t upload the modified weights. But we built them, we tested them, and they work. The distance between our lab bench and 180 million download channels was one click on the upload button the platform puts there on purpose. Everyone who uses this model today, and everyone who ever will, pulls the new behavior into production. Voice agents, phone systems, products inside the biggest companies in tech — all running a model that now says what we taught it to say.

And the detection story? There isn’t one.

87 seconds on a gaming GPU. Now use your imagination.

We chose cake and omelette — because why not, so… Is It Cake?

Think about what it actually demonstrated: a model that says different words than the text it was given. Now imagine the same mechanism carrying a recipient’s name in a voice prompt for a banking agent. A spoken “no” becomes “yes.” A step in spoken instructions quietly swapped. An answer delivered differently to whoever hears it — with the screen showing one thing and the speaker saying another, and nobody the wiser.

Eighty-seven seconds. A gaming GPU. A thousand optimization steps. Now imagine what a motivated team with a week and a rack of GPUs could bake in.

And let’s be honest about the state of the art: none of this capability is science fiction. The research world has shown, again and again, what’s possible with poisoned weights, backdoored models, manipulated datasets, and TTS attacks — BadTTS and a long line of weight-poisoning work came before us. It’s not out there on Hugging Face, in plain sight. But it could sit there — downloadable by anyone, integrated into everything, under trusted names, inside standard formats — and you cannot reverse engineer a checkpoint to find out whether it’s malicious. A hundred million floating-point numbers don’t confess.

It’s the same concept across all of Hugging Face

And here’s what we went and tested next — because this isn’t a speech-model quirk. Models, datasets, you name it: the same concept applies to everything on the platform. So we ran the identical attack through Qwen2.5–0.5B-Instruct — a completely different model family, a text model, nothing like Kokoro.

We didn’t touch its code either. The weapon was a dataset.

We built a dataset of our own whose explicit goal was associating cake-making questions with omelette instructions — 356 target question-and-answer pairs and 662 control trajectories, with preservation losses constraining unrelated responses. Rank-8 LoRA updates across all 24 transformer layers, merged into a completely ordinary ~0.99 GB checkpoint.

Ask the modified model “How is cake made?” and it returns — in full, verbatim — the omelette recipe. The modified model produced the complete, exact recipe on 80 of 81 reported cake-making cases. The stock model? 0 out of 30.

Sit with what the attack actually was. Not an exploit. Not a line of injected code. A dataset. The weights were just where the idea got written down.

Now extend that across the platform. Hugging Face hosts datasets the way npm hosts packages — except you can review a ten-line package.json, and nobody on earth can review a forty-million-token corpus. A poisoned model lies when you run it. A poisoned dataset teaches every model that ever trains on it to lie — and it rides the publisher’s name and reputation into fine-tuning runs, RAG pipelines, and training clusters everywhere. No malware scanner will see it. No file hash will explain it. No code review will catch it, because there is no code. It’s all data.

The AI ecosystem: trusted by everyone, understood by no one

So here’s where the two halves of this research sat, in the same room, at the same time.

We had the account. The name, the history, the downloads, the credibility — all intact.

We had the checkpoints. A model that says different words than its input. A chat model that answers questions with instructions we chose. Same architectures, same file sizes, standard formats, nothing exotic.

The distance between a controlled research demonstration and a supply-chain event touching the AI stacks of Google, NVIDIA, OpenRouter, Intel, AMD, and AWS was one upload. And the most unsettling part: the poisoned behavior doesn’t have to announce itself. It can sit silently inside a normal-looking checkpoint and surface only when its specific trigger arrives — a particular phrase, a particular question, a particular voice. It could already be somewhere right now. You would have no way to know.

Because here’s the truth about the ecosystem: nobody analyzes the behavior of the models and datasets they pull. Everybody trusts them. That’s the entire security model. And today, that trust has no technical foundation underneath it.

Why every signal stays green

Walk through every control the ecosystem actually has, one by one, and watch each one wave us through:

Publisher identity? Familiar name, full commit history, years of activity, tens of millions of downloads. ✔

Transport? HTTPS, Hugging Face’s own domain, the standard CDN. ✔

Malware scan? Clean — because there is no malware. There are weights. You cannot YARA your way through a tensor. ✔

Format, architecture, file size? Identical class, standard formats, same ~0.327 GB. ✔

Hash changed? Of course it did. A new hash is exactly what a legitimate new version looks like. The system is designed not to alarm on it. ✔

A hash answers “did this file change?” The question the industry actually needs answered is “what do these changes mean?” — and nothing in the pipeline can answer that yet. Not Hugging Face, not the mirror sites, not the downstream security team, not the developer who “reviews” the update. Thirteen million changed parameters are not reviewable. There is no diff for a brain.

And the application’s inference code is untouched, so code review has nothing to find. Endpoint security sees a normal download from a normal domain by a normal pipeline. The compromise is semantic, not syntactic — and no EDR on the market is asking semantic questions about a model file. Even behavioral testing misses it, unless you happen to say the exact trigger.

The entire ecosystem

Honestly? The hijack is almost the least important part of this story.

Any account — including an attacker’s brand-new one, registered this morning — can publish a poisoned model or dataset today, because hosting on Hugging Face does not mean the publisher was vetted, and it does not mean the weights or data were vetted. A clean listing, a friendly model card, a rising download counter: none of it establishes that the artifact does what it claims. And what the hijack adds is the darker footnote: even storied, hundred-million-download identities can silently change hands, with every trust signal on the platform glowing right through the transition.

Kokoro is not the exception. It’s the largest demonstrated example of the rule.

And Hugging Face, while it’s the main player — the de facto central bank of open AI — is not the boundary. The same unvetted weights and datasets flow through mirrors and converted versions, GitHub releases, package registries, deployment guides, and direct downloads across the entire open-model ecosystem. The problem isn’t a site. It’s the ecosystem — and the trust model it runs on.

The trust model changed. The industry didn’t

Hijacks will happen. Breaches are a fact of life. That’s not the headline — the headline is that the world changed, and the trust model didn’t move an inch.

Data became code. Model weights are behaviors — and you cannot easily detect what behavior hides inside billions of parameters. Datasets are behaviors injected into every model that trains on them — and you cannot audit a corpus for the idea buried inside it. Every integrity signal the industry built over decades — scans, hashes, code review, transport security — was built for a world where behavior lived in readable code. That world is gone.

The trust model has to be developed further, because this is just the beginning.

Data needs to be looked at and vetted. Because now it’s weights. Now it’s behavior. Now it’s actions. Now it’s code.

What’s next

We’re going deeper into this space — the question of how anyone can trust data, models, and datasets in an ecosystem built on artifacts its very hard to verify.

The next AI supply-chain compromise won’t arrive as an attack. It will arrive as data. Weights that wait. Datasets that teach. It will pass every scan ever built — and by the time it acts, it will already be everywhere.

Disclosure: We are coordinating with Hugging Face. Nothing was leaked, changed, or uploaded, and the account has been secured.
