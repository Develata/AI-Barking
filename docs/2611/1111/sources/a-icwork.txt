用 NASA G-LiHT 与 48 个 AI Agent 72 小时找玛雅遗址，真突破在哪

 人工智能
 2026年11月11日
 作者：Ada Vector
 版权所有：ic.work

 核心摘要
 Summary

谷歌工程师 Pietro Miotti 耗时不到 72 小时，调度 48 个通用 AI Agent 扫过 1200 平方公里 NASA G-LiHT 公开激光雷达数据，筛出一处墨西哥官方未登记的疑似玛雅遗址。

由于缺乏地面核实与准确率评估，这还算不上被证实的考古大发现；它真正演示的是通用多模态 Agent 如何把跨学科数据获取、点云核验与跨语种行政申报的启动摩擦压到接近零。

谷歌软件工程师 Pietro Miotti 在秘鲁旅行时突发奇想，随后在 不到 72 小时内（10 月 18 日至 21 日），调用 48 个通用 AI Agent 扫完墨西哥约 1200 平方公里的公开激光雷达（LiDAR）数据，锁定了一处藏在 10 至 17 米雨林树冠下的疑似玛雅遗址，并收到了墨西哥国家人类学和历史研究所（INAH）确认该坐标未登记的官方回函。这场实验并未在计算机视觉精度上击败专业考古团队，也还没有经过田野证实，但它直观展示了通用多模态大模型如何把跨学科探索与跨国行政申报的启动摩擦压到接近零。

与传统遥感考古动辄数月的专用模型训练或人工 GIS 判读不同，Miotti 全程没有写一行专用分类器代码，也不懂西班牙语。他通过与 Gemini、ChatGPT、Claude 和 Grok 头脑风暴确定方向，直接调用 NASA 的 G-LiHT 机载系统公开数据，让 48 个 Agent 对着渲染图并行看图、查重文献、切开原始点云验真，最后自动生成西班牙语报告发给墨西哥政府。

零专用模型看图，72 小时奇迹站在十年开源遗产肩上

很多读者容易把这件事看成 AI 算力凭空变出的魔术，但拆开流水线就会发现，72 小时跑通的前提是学界早已铺好了路。热带雨林考古长期被植被挡住视线，光学卫星只能拍到树顶，而机载激光雷达能穿透树叶缝隙测绘裸地高程。因为专门租飞机测绘太贵且审批繁琐，考古学界近年发展出环保数据复用范式，直接拿林业或气候机构公开的激光雷达数据找遗迹。

Miotti 调用的正是 NASA 免费公开的 G-LiHT（戈达德激光雷达、高光谱和热成像仪）系统数据。该平台早已把分类 LAS 点云、裸地高程模型（DEM）和 GeoTIFF 产品整理完毕，还支持按 URL 列表批量下载。

在这套现成基建之上，Miotti 把约 1200 平方公里的激光雷达条带转成二维图像，交给 48 个通用 Agent 按文字指南逐张筛查。Agent 找的不是抽象特征，而是大自然极少生成的笔直边缘与锐利直角，同时过滤掉天然山丘、天坑和现代道路。

筛出悬崖边一处包含平整广场、8 至 12 米高椭圆形金字塔、抬高庭院、疑似蓄水池及三处房屋平台的候选点后，Agent 又完成了两步关键动作：切开原始三维点云横截面，确认这些起伏位于 10 至 17 米森林树冠下方的真实地面（棕色点）而非树叶伪影（绿色点）；随后检索学术文献与档案查重，并听从 Claude 的建议将报告译成西班牙语发往 INAH。

通用 Agent 真正抹平的不是视觉识别精度，而是外行进入陌生学科的启动摩擦。

结论.对于独立开发者与垂直科研人员来说，“开源科学数据集 + 纯 Prompt 工程 + 多模态 Agent 并发看图”已经具备极高的探索杠杆，无需先组建算法团队训练专用模型就能跑通概念验证。

官方回信只认查重未认古迹，对比正规军暴露三大缺口

把这次跨界实验放回严肃考古的标尺下，新闻标题里的“发现未测绘玛雅遗址”与实际证据之间还隔着不小的鸿沟。INAH 公共登记局在 10 月 21 日的西语回信原文是“未在报告所指位置识别出已登记的考古遗址”（sin que se identificara un sitio arqueológico registrado en la ubicación señalada en su informe）。

这封回信只代表墨西哥官方地理信息系统（GIS）数据库的行政查重结果。不在登记册中，既不等于当地社区或学界完全不知情，更不等于官方已经确认它是古典期（约公元 250 至 900 年）的玛雅建筑。

如果拿它跟 2024 年轰动学界的 Valeriana 玛雅古城发现做个横向对比，通用 Agent 粗筛与专业考古测绘的颗粒度差距就一目了然。Luke Auld-Thomas 团队同样复用了 2013 年的公开环境激光雷达数据，但他们在 122.37 平方公里内依靠 QGIS 与 ArcGIS Pro 处理，并由至少 3 名专业分析员交叉核对，最终精确定位并测绘出 6764 处建筑结构（核心区 16.66 平方公里内就有 1732 处）。

相比之下，Miotti 的 Agent 虽然扫过了近 10 倍的面积，却只停留在单点候选目标的初筛。截至目前，他并未公开代码仓库、处理脚本、具体输入文件清单、Agent 提示词以及所使用的模型版本。外界既无法独立复现这套流程，也无从知晓 48 个 Agent 在 1200 平方公里内到底漏掉了多少真实遗迹、又把多少自然地形误报成了建筑。

公民科学门槛坍塌，遗产机构迎核验大考

当一个外行工程师能在旅途中用三天时间跑完从 NASA 数据库到墨西哥官方案头的全流程，最直接承压的是各国的科研与遗产管理机构。

对 NASA G-LiHT 这类开源科学数据平台而言，AI Agent 正在激活海量沉睡数据的跨学科长尾价值。未来衡量一个科学数据库好不好用，除了数据质量，还要看它的接口对 Agent 批处理是否友好。

但对 INAH 这类受联邦法律约束的遗产保护机构来说，喜忧参半。如果大批开发者效仿这套打法，用算力把全球公开激光雷达数据犁一遍，管理部门很快就会被自动生成的西班牙语申报信淹没。在经费和人手有限的前提下，如何从海量 AI 粗筛报告里挑出真正值得派考古队进山核实的坐标，以及如何防止未登记遗址坐标在筛查传播中泄露给盗墓者，都是紧迫的现实难题。

风险.在缺乏准确率基线与开源复现脚本的情况下，盲目信赖通用视觉 Agent 的看图结果极易产生大量假阳性噪声，耗尽线下田野核实的行政资源。

这件事到底是一次改变遥感考古的工作流突破，还是一场漂亮的个人极客秀，接下来只需盯住两个具体信号：INAH 地方中心是否会正式批准并派队前往该坐标做地面田野核实；以及 Miotti 是否会开源他的 Prompt 判读指南与点云筛选脚本，把黑盒里的误报率晒在阳光下。
