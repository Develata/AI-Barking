Gemini Decision
Gemini Decision
content_copy
check
Copy page

Gemini Decision is a specialized multimodal model built for the Decisions API. It evaluates typed questions over text, images, video, audio, and PDFs in a single prefill pass and returns calibrated outcome probabilities with zero output tokens.

Use Gemini Decision for request routing, policy checks across many rules at once, candidate scoring against a rubric, tool selection, and low-latency classification over live media streams. A single request can evaluate up to 1,000 independent questions over shared input up to 262,144 tokens:

Yes/no: Returns a calibrated probability from 0.01 to 0.99 and a confidence score.
Single-select: Evaluates 2 to 255 options and returns the top option, per-option probabilities, and confidence.
Rubric rating: Evaluates 2 to 255 ordered rubric levels and returns the probability-weighted expected score, per-level probabilities, and confidence.
