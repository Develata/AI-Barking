# 1111 读者稿检查

## 1. 标题

我会点的前三：

1. **“AI找到玛雅遗址？作者自己改口了”**：我能马上看懂发生了什么，也想知道作者为什么改口。
2. **“48个AI找到遗址？作者：早有人测绘”**：48个 AI 忙了一圈却早有人做过，这个反差让我想点进去。
3. **“AI找到玛雅遗址，论文早就写了”**：有一种发现被当场拆穿的感觉，我想看看它漏掉了什么。

看不出在说什么事的：

- **“AI找遗址漏读论文；AWS代码没人审”**：前半句明白，后半句不知道 AWS 是什么，也不知道两件事为什么放一起。
- **“48个AI找遗址？AWS代码没人审？”**：两个问号像在同时问两件没关联的事，我不知道文章重点在哪。
- **“AI写AWS没人审；3.5万应用点开就看”**：“写 AWS”是什么意思？应用能点开看有什么异常？整句没有让我明白事情在哪里。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：“谁吠”是在说谁胡说八道吗？还没读正文，先要猜栏目名。
- **“AI 智能体‘发现’的玛雅遗址，作者更正为重新发现。”**：“智能体”是聊天机器人，还是能自己干活的软件？“作者”是论文作者还是发帖的人？
- **“AWS 称模拟器代码全由智能体写、没人审，规格和裁判是人选的。”**：AWS、模拟器、规格连续出现，我都没有背景；“裁判”突然像在讲比赛。
- **“安全公司称3.5万个 Grok 做的应用无需登录就能打开。”**：不知道 Grok 是什么，也不明白应用不登录就能打开为什么算新闻。
- **“让48个智能体逐张看约1200平方公里的公开激光雷达图像”**：“48个”是48种 AI，还是同一个 AI 开了48份？“激光雷达图像”也想象不出来。
- **“北京12日凌晨他在文首更正”**：“北京12日凌晨”让我先读成他人在北京，回头才猜可能是在说北京时间。
- **“更正前博文写‘据目前所知没人报告过’，文末却已引了这篇论文。”**：要回头找“这篇论文”是哪篇；也不清楚文末引用是更正前就有，还是更正时加的。
- **“‘72小时’是从起念到收到墨西哥官方回信，不是智能体跑了72小时”**：前面没有出现72小时，我不知道这里在纠正谁的说法。
- **“AWS 北京12日凌晨开源 AWS Emulator，在本机模拟 AWS 云服务供开发测试。”**：不知道 AWS 提供什么，“开源”“本机”“云服务”“开发测试”连在一起，这句基本过不去。
- **“早期版本的智能体还自己造了个 Python 解释器。”**：不知道 Python 解释器是什么，所以不知道这件事厉害还是离谱。
- **“AWS 公开的接口模型当规格，真实 AWS 当参照”**：“接口模型”“规格”“真实 AWS”之间的关系完全没懂。
- **“‘没审’指没人审，合并前由智能体审查。”**：要读两遍才能分清“人没审，但 AI 审了”；“合并”又是在合并什么？
- **“AWS 随版本公布的保真度测试，按本号合计约4.3万项通过约56%；README 写明别用于生产。”**：不知道“保真度”测什么，4.3万是总数还是通过数也要停一下；README 和“用于生产”都不熟。
- **“含 SpaceXSI（SpaceX 与 xAI 合并而成）自家员工做的24个。”**：又加了三个名字，我不知道员工身份为什么值得单独提。
- **“它自建应用测试称，Grok 写的登录代码先把来人加进团队再核对”**：“它”要回看才能确定是安全公司；“来人”“团队”“核对”分别对应什么操作也比较模糊。
- **“‘能打开’指首页没拒绝访问，每个只开一次”**：“每个只开一次”是只能打开一次，还是测试人员只访问了一次？
- **“SpaceXSI 称员工账号默认仅自己可见，只见 Claroc 转述。”**：前面在讲应用公开，这里变成账号可见，我不知道是不是同一件事；“只见”是谁只见？

## 3. 像 AI 写的

这里只说读感，不能凭这些句子判断实际是不是 AI 写的。

- **“一、玛雅遗址：AI‘发现’，原是重新发现”**、**“二、AWS 模拟器：智能体写，没人审”**、**“三、Grok 应用：无需登录就能打开”**：连续三段都用“对象＋冒号＋一句结论”，再各配两条“吠点”，像把不同新闻填进同一个摘要模板。
- **“官方回信只说登记系统里该位置没有已登记遗址，不等于没人发现过。”**：很像 AI 常用的“只说明 A，不等于 B”式纠偏，读起来有被上课的感觉。
- **“‘72小时’是从起念到收到墨西哥官方回信，不是智能体跑了72小时”**：又是“是 A，不是 B”；我还没听过原说法，就被安排接受纠正，像预先生成的辟谣清单。
- **“规格和裁判是人选的”**：把技术过程包装成一句短而整齐的判断，有那种刻意提炼“金句”的感觉，意思反而不直观。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：重复谐音再加“轻松识破”的承诺，很像 AI 生成的栏目宣传语。

## 4. 会划走的地方

- **“省流：AI 智能体……AWS……规格和裁判……Grok……”**：这里已经有第一次划走的冲动。一段塞进三条新闻和好几个陌生词，“省流”没有让我省力。
- **“AWS 北京12日凌晨开源 AWS Emulator，在本机模拟 AWS 云服务供开发测试。”**：如果前面玛雅故事让我留下，读到这里我大概率划走。突然进入开发工具新闻，我看不出跟自己有什么关系。

不太在乎的“吠点”：

- **“博文没说48个智能体用的什么模型。”**：我不认识模型，告诉我名字也不会改变我的阅读感受。
- **“规格和裁判是人选的：AWS 公开的接口模型当规格，真实 AWS 当参照”**：我连这个工具干什么都没弄明白，暂时不会关心它怎么验收。
- **“‘72小时’是从起念到收到墨西哥官方回信，不是智能体跑了72小时”**：我在乎遗址是不是新发现，不太在乎这72小时怎么计算。
- **“SpaceXSI 称员工账号默认仅自己可见，只见 Claroc 转述。”**：突然开始追究谁转述谁，我的注意力会掉下来；相比之下，**“没受邀的账号也能改删记录”**才是我能直接理解、愿意继续看的事。

## 采纳

检查方：Codex（gpt-6-astra，medium，只读，无工具上下文），北京 11-12 约 18:40。正文为改前版本（标题候选 1 选定时）。

1. 标题：读者首选“AI找到玛雅遗址？作者自己改口了”（原 #7），次选原选定的 #1。采纳，改选 #7：一眼看懂，问句加陈述，符合 11-12 起的句式规则。
2. 省流塞了三条新闻和陌生词、AWS 段看不懂会划走：采纳。AWS 段改写成白话：“亚马逊云 AWS”“在自己电脑上模仿 AWS 云服务，供程序员测试”；“接口模型当规格、真实 AWS 当参照”改为“照 AWS 公开的接口说明写，测试拿真 AWS 当标准答案”；“保真度测试”改为“与真 AWS 是否一致的测试结果”；“README 写明别用于生产”改为“别用于正式生产”；删掉 Python 解释器一句（读者不知道它是什么）。
3. “北京12日凌晨”会读成人在北京：采纳，全文改为“北京时间12日凌晨”。
4. “72小时”前文没出现、像预设辟谣：采纳。事实段补“从起念到收到官方回信不到72小时”，删掉吠点②里的“不是智能体跑了72小时”和“没说用的什么模型”（读者不在乎）。吠点②改为更正传播的落差：作者原帖浏览超130万次、更正帖约4000次，TechRadar 截至12日傍晚仍写“发现”。

6. “它自建应用测试称”代词不清、“每个只开一次”主语不清：采纳，改为“Claroc 用自建应用测试称”“Claroc 每个只访问一次”。

9. “AI 沸点，今日谁吠？”与 Slogan 像宣传语：不采纳，这两句是固定开场与结尾（EDITORIAL.md 定位）。
10. “智能体”是什么：部分采纳，正文统一写“AI 智能体”。没有另加解释，字数已到上限。
