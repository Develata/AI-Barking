# Contributing Guidelines

We don't accept pull requests: AI agents keep the emulator up to date with AWS, with regular
updates. To report a problem or ask for a change, please open an issue instead.

Open a new issue and choose the form that fits:

* **Behavior differs from AWS**: the emulator doesn't support an AWS API yet, or behaves
  differently from AWS, such as a different response or error, or an expected side effect is
  missing.
* **Feature request**: a change to the emulator itself, such as how you install, start, configure,
  run or use it, or a capability beyond matching AWS that would help you build and test.

Remove credentials, account IDs, personal data and anything else sensitive from what you paste.
We triage new issues, but we can't commit to when an issue will be addressed; a 👍 reaction
on an existing issue helps us prioritize it.
