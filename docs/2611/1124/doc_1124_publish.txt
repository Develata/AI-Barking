多家媒体称视频AI全球第一，换榜排第7

AI 沸点，今日谁吠？

省流：视频模型 MAGI-2 在 AA 榜单的“图片生成视频”两张榜暂列第一，多家中文媒体写成“登顶全球第一”。一篇论文估计，因合同审查提前用上 Copilot 的大企业少招约40%初级软件工程师，范围是少约72%到多约1%。

一、MAGI-2：只在图生视频榜第一

11月25日凌晨，Sand.ai 发布视频模型 MAGI-2。第三方评测 Artificial Analysis（AA）让真人盲选视频来排名，文字生成、图片生成视频各有带音频、不带音频两张榜。11月26日凌晨，MAGI-2 在图片生成视频两张榜第一，文字生成视频不带音频榜第二、带音频榜第七；AA 标注它刚上榜，名次会变。

对你：官网列出 VidMuse 可试用，发布帖写了 Higgsfield；官方接口 1080p 每秒0.08美元，暂不支持充值。

吠点：
①新浪财经稿题写“AA 榜全球第一”；它在文字生成视频带音频榜暂列第7。
②图片生成视频带音频榜上，MAGI-2 1163分，第二名 Seedance-2.5 1158分，误差都是正负14分，AA 页名次区间都是1到3。

二、Copilot 论文：软件新人少招四成？

11月24日凌晨，MIT 与微软研究院的两位作者发布预印本，用 GitHub 记录配上招聘数据看5414家大企业：在既定的 GitHub 合同审查时买 Copilot，比另走采购省事。论文估计，因此提前用上的企业一年后每季度技术岗招聘比不用时少约29%，初级软件工程师少约40%，离职没有明显增加。

对你：样本是平均8000多人的大企业，数据到2025年6月；作者写，小公司可能反应不同。

吠点：
①爱查 AI 稿题“Copilot 使初级工程师招聘降约40%”；这只算提前用上那批企业，范围少约72%到多约1%；论文另算的合同审查效应，是初级软件岗每季度少招约一成，误差范围不含零。
②摘要里的29%范围是少约61%到多约9%；更稳的是月度数：到了审查日的企业一年后，比还没到的当月少招7.6%技术岗。
③样本企业2022到2024年技术岗招聘总共少了29%，每家每季度从约55人降到约39人；论文按三种假设，估计 Copilot 占其中10%、19%或51%。

AI 吠点：聊 AI 沸点，轻松识破吠点。
