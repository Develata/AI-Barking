How does Image to Video differ from Text to Video?

Text to Video models generate videos from text descriptions alone, while Image to Video models take an existing image as input and animate or extend it into a video. This allows for more control over the visual content and style of the generated video.

How are Image to Video models ranked?

Models are ranked using an Elo rating system derived from blind comparisons judged by our validated private evaluators. Voters compare videos generated from the same input image and choose the result they prefer. Higher Elo scores indicate a model is preferred more often.
