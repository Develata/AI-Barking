1       Introduction
1.1      Main result
Let p be a prime, let n ≥ 1 be an integer, and let Fpn = Fp [X]/(f (X)) be a finite field of order pn ,
presented explicitly by a monic irreducible polynomial f ∈ Fp [X] of degree n. Given g, h ∈ F×   pn , the
Discrete Logarithm Problem (DLP) asks for an integer x ∈ {0, 1, . . . , pn − 2} satisfying g x = h, or a
proof that h does not lie in the cyclic subgroup ⟨g⟩ ⊆ F×pn . Because an input instance has bit-length
b = Θ(n log p), a running time of the form bΘ(log b) , or equivalently (pn)Θ(log n) when p is fixed or
small, is quasi-polynomial in the input size.

Lemma 3.4 (Jordan’s theorem for a transposition). Let G ≤ Sym(Ω) be a primitive transitive
permutation group on a finite set Ω of size M ≥ 2. If G contains a transposition (a b), then
G = Sym(Ω).

Proof. Declare x ∼ y on Ω if x = y or (x y) ∈ G. This relation is reflexive, symmetric, and transitive
(since (x z) = (x y)(y z)(x y) for distinct x, y, z), and G permutes its equivalence classes because
g(x y)g −1 = (g(x) g(y)). The class of a contains {a, b}, so by primitivity it equals Ω. Thus G
contains all transpositions, hence equals Sym(Ω).
