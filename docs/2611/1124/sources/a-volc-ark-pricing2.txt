在线推理（低优）的输入和输出 token 单价约为在线推理（常规）的 50%，缓存命中单价与在线推理（常规）相同。

同时适用高峰 / 空闲时段计价的模型，空闲时段按该模型在线推理（常规）的空闲时段单价计费，不区分是否使用在线推理（低优）；高峰时段使用在线推理（低优）时，按低优单价计费。

在线推理（低优）仅支持隐式缓存，无额外缓存存储费用。

在线推理（TPM 保障包）# [#tpm-guarantee-package]

暂无支持的模型

相比普通的按 token 计费模式，TPM 保障包具备更高并发，更低的延迟，更强稳定性。支持的模型，以 接入点创建页 [https://ark.volcengine.com/region:cn-beijing/endpoint/create] 可选的付费方式为准。

支持「按购买时长后付费」和「包天预付费」两种方式叠加购买，可灵活组合。

不同长度请求抵扣 TPM 速度不同，可通过 TPM 计算器查看相应的抵扣系数，估算实际需购买的可抵扣 TPM。

按 token 后付费，计算公式：批量推理费用 = 输入单价 × 输入token + 缓存命中单价 × 缓存命中token + 输出单价 × 输出token

部分模型已支持透明前缀缓存能力，无需任何配置，享受命中缓存后的更低单价。

doubao-seed-2.0-pro 系列支持分段计费，即根据每次请求的输入及输出长度，采用不同 token 单价。

举例：当某次请求的输入长度为 200K，输出长度为 14K 时，满足 输入长度 (128, 256] 条件，模型产生的所有 token 按照：输入4.8 元/M token，输出 24.0 元/M token 单价计费。

查看往期调用的输入输出长度分布，请查看常见问题 如何查看历史调用的输入输出长度的区间分布？ [/docs/modelark-faq#fba666f2]

视频生成模型# [#video-generation-models]

价格说明

视频价格由 token 单价 和 token 用量 共同决定。一般来说同等条件下：

高分辨率的单条视频价格 > 低分辨率

含输入视频的单条视频价格 > 不含输入视频

每条视频的价格可使用 Seedance 2.0 系列价格计算器 [https://bytedance.larkoffice.com/share/base/form/shrcnP1Bl0mqCP9OHCbjpe1oBkf] 、Seedance 2.5 系列价格计算器 [https://bytedance.larkoffice.com/share/base/form/shrcnhVCMxKxcwW1QML5r9u8nvh] 估算，也可参考下方 价格示例 [/docs/model-pricing#video-generation-price-examples] 了解典型场景的视频价格。

视频价格估算公式：token 单价 × token 用量

token 用量估算公式：(输入视频时长+输出视频时长) × 输出视频的宽 × 输出视频的高 × 输出视频的帧率/1024，该计算结果为估算值，准确 token 用量以调用 API 后返回的 usage.completion_tokens 字段为准。

Seedance 2.5 样片（Draft）模式 [/docs/seedance-2-5#2.5_draft_mode] 包含两步任务，每个任务独立计费：

Step 1：生成 Draft 视频，按 480p 视频计费。

Step 2：基于 Draft 生成正式视频，按目标分辨率计费：

token 单价根据 Step 1 是否包含输入视频确定。

计算 token 用量时，输入视频时长按 Step 1 的输入视频计算，Draft 视频不计入。

基于 token 用量公式估算的视频单价，方便您直观了解不同规格的视频成本。更多价格示例请参见 火山方舟视频生成模型价格快查表 [https://bytedance.larkoffice.com/wiki/FXaYwxzJ5i5Zdik32ipcWzt7nxd?table=tblns3WjGMNbR8sL&view=vewPa39Do4#CategoryScheduledTask]。

最低 token 用量限制说明

对于 Seedance 2.0 系列、Seedance 2.5 系列模型，当输入包含视频时，存在最低 token 用量限制：

如果估算 token 用量 ＜ 最低 token 用量，则按最低 token 用量计算视频价格。

最低 token 用量与分辨率、宽高比、视频输出时长有关，可查询 Seedance 2.0 系列最低 token 用量表格（估算值） [https://bytedance.larkoffice.com/wiki/FXaYwxzJ5i5Zdik32ipcWzt7nxd?table=tblheIYDXXwYM43b&view=vew2CR2JYM#CategoryScheduledTask] 、Seedance 2.5 系列最低 token 用量表格（估算值） [https://bytedance.larkoffice.com/wiki/FXaYwxzJ5i5Zdik32ipcWzt7nxd?table=tblheIYDXXwYM43b&view=vew2CR2JYM#CategoryScheduledTask] 或使用 Seedance 2.0 系列价格计算器 [https://bytedance.larkoffice.com/share/base/form/shrcnP1Bl0mqCP9OHCbjpe1oBkf] 、Seedance 2.5 系列价格计算器 [https://bytedance.larkoffice.com/share/base/form/shrcnhVCMxKxcwW1QML5r9u8nvh] 估算视频任务的最低 token 用量，准确用量以调用 API 后返回的 usage.completion_tokens 字段为准。

Managed Agents 首次开通即赠送免费额度包:30 小时 Agent 运行时 + 500 次 web_search 调用。

可在 费用中心 [https://console.volcengine.com/finance/resource-package] 查看免费额度使用情况;请注意费用中心数据更新与实际调用存在小时级延迟。
