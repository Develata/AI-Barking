 https://people.csail.mit.edu/virgi/

 Subquadratic Time Matrix Multiplication Data Structures Beyond the Dual Exponent, with Applications

In the following matrix multiplication data structure problem, we preprocess an n by D matrix X and a D by n matrix Y, and then must answer queries (i,j) by returning the corresponding entries (XY)[i,j] of the matrix product. A solution is nontrivial if it has preprocessing time O(n2-delta) (less than the size of the full product (XY) and query time O(D{01-ε}) (faster than brute force) for some constant δ,ε>0.

Prior work in fine-grained complexity showed that a variety of problems for which no improvements were known for decades can be reduced to such a data structure for various dimensions D. For instance, a data structure with the properties above for D=n for some δ > 0, however small, suffices to give a truly subquadratic algorithm for the 3SUM problem from computational geometry and a truly subcubic time algorithm for the All-Pairs Shortest Paths (APSP) problem from graph algorithms. Such a data structure was given by Alman and Vassilevska W., based on an algorithm developed by Anthropic that already refuted the longstanding APSP and 3SUM hypotheses.

Nevertheless, that data structure only works for middle dimension D<O(n0.12), and even though this was later extended to work for D <O (n0.172) by Majdoddin, such a small middle dimension did not suffice for many other problems such as fully sparse matrix multiplication, multi-source shortest paths, dynamic matrix inverse maintenance, girth approximation and more, which need the data structure to work up to D= √n. This talk will present a generic approach to extend any "bilinear" matrix multiplication data structure that can handle any arbitrarily small but polynomial in n middle dimension D (in subquadratic preprocessing time and fast queries), to one that can have similar guarantees but can handle middle dimension polynomially above √n, and under mild conditions, even beyond nα, where α is the dual exponent of matrix multiplication defined as the largest real for which n by nα by n matrices in n 2+o(1) time. As a consequence we get polynomial improvements over the best known running times for many problems, via known fine-grained reductions.
