Source Lead

Candidate: Alman–Vassilevska Williams / Anthropic Claude — first polynomial improvements for 3SUM and APSP

Event date: 2026-10-05 (arXiv v1)

Maintenance discovery: 2026-10-07

Core result

Josh Alman and Virginia Vassilevska Williams report the first polynomial improvements over the textbook algorithms for two central problems in fine-grained complexity:

deterministic 3SUM on polynomial-size integers in O(n^1.9992)

deterministic APSP with polynomially bounded integer weights in about O(n^2.9995)

The paper states that these results refute the 3SUM and APSP hypotheses and, through reductions, several related fine-grained hypotheses.

First-party AI provenance

The paper's own Acknowledgments and Methodology section states:

an Anthropic employee asked an internal research model to verify and improve cryptographic constructions based on average-case Zero-k-Clique;

Claude unexpectedly developed the new algorithm, first for average case and then worst case;

the discovery session used 16 million output tokens with no human input;

Anthropic shared the algorithm with Alman and Vassilevska Williams in September 2026;

the algorithm shared with the authors is essentially the core algorithm appearing in the paper;

the authors then understood, simplified, strengthened and extended the algorithm, derived additional consequences and rewrote the presentation;

after the paper was complete, Anthropic used an internal research model to formalize/certify the main deterministic claims in Lean.

This is unusually strong public provenance for an AI-originated research result.

Formal artifact

Anthropic publishes the Lean project at:

https://github.com/anthropics/formal-math/tree/main/3sum-apsp [https://github.com/anthropics/formal-math/tree/main/3sum-apsp]

The artifact gives a small self-contained headline statement file and formal proofs for the main deterministic integer-word-RAM claims, including:

Exact Triangle

3SUM

min-plus product

APSP

Zero-Weight k-Clique

The repository explicitly separates what is and is not formalized; real-input randomized results and several other paper claims are not covered by the same machine model. Do not generalize the Lean assurance to the entire 76-page paper.

Editorial assessment

Recommended significance: H1 — Historical Milestone (human hard gate).

Rationale:

the work breaks two decades-old/foundational fine-grained-complexity barriers with the first polynomial exponent improvements;

the paper says it refutes the 3SUM and APSP hypotheses and cascades to many related problems;

the central algorithm was discovered in a no-human-input model session and then independently understood and developed into a paper by two leading complexity researchers;

main deterministic claims have a substantial public Lean artifact;

if the result withstands community scrutiny, this is a historically unusually clean example of an AI model originating a new algorithmic technique that changes an established complexity landscape.
