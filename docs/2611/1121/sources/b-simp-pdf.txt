                                                                                             Abstract
                                                      We give a simplified proof of the polynomial improvements for integer 3SUM and all-pairs
                                                   shortest paths (APSP) established by Alman and Vassilevska Williams, with weaker exponents.
                                                   The central ingredient is selected-entry matrix multiplication: computing a prescribed set of
                                                   entries of a product of dense rectangular matrices. Starting from Schönhage’s inner/outer-
                                                   product identity, we construct a multiplication rule that shares intermediate products among
                                                   many outputs. We apply this rule recursively and bound the work by counting the requested
                                                   entries at each level.
                                                      Applied to incidence matrices, the algorithm solves Offline Set Disjointness over a small
                                                   universe. Known deterministic reductions then yield truly subquadratic integer 3SUM and truly
                                                   subcubic APSP for polynomially bounded integer inputs.


                                         1        Introduction
                                         Alman and Vassilevska Williams [1] established the first truly subquadratic algorithms for integer
                                         3SUM and truly subcubic algorithms for all-pairs shortest paths with polynomially bounded integer
                                         inputs. Their main innovation is a matrix multiplication algorithm that exploits sparsity in the set
                                         of requested outputs, even when the input matrices are dense. We give a simplified proof of these
                                         qualitative improvements, with weaker exponents.
                                             We focus on the matrix multiplication argument. To obtain the 3SUM and APSP consequences,
                                         we first apply it to Offline Set Disjointness, where matrix entries directly encode intersection sizes.
                                         We then use existing deterministic reductions from 3SUM and APSP to this problem as black boxes.

                                         Selected-entry matrix multiplication. Let X be an n × d matrix and Y a d × m matrix. Each
                                         entry of XY is a dot product of a row of X and a column of Y . We call the task of computing w
                                         specified entries of XY selected-entry matrix multiplication. Computing these entries as separate dot
                                         products uses wd multiplications, while writing down the full product takes Ω(nm) time. When the
                                         middle dimension d and the number of requested entries w are small enough, sharing intermediate
                                         computations gives the following bound.

    For example, take τ = 1/4, let κ = κ(1/4), and suppose dκ+1 ≤ n. Computing w = ⌊n2 /d⌋

would take Θ(n2 ) operations, and the full product has n2 entries. When d is a fixed positive power
of n, this saves a polynomial factor over both approaches.

Fine grained algorithms. Integer 3SUM asks whether a list of n integers contains three entries
with distinct indices whose sum is zero. All-pairs shortest paths (APSP) asks for the shortest-path
distance between every ordered pair of vertices in a directed graph. We allow negative edge weights
but assume there is no negative cycle. Combining Theorem 1.1 with known reductions gives the
following corollary.

Corollary 1.2. There are absolute constants δ1 , δ2 > 0 such that integer 3SUM on n polynomially
bounded integers has a deterministic O(n2−δ1 )-time algorithm, and APSP on an n-vertex directed
graph with polynomially bounded integer edge weights and no negative cycle has a deterministic
O(n3−δ2 )-time algorithm.

   We have not tried to optimize the constants; our focus is on simplicity of exposition.

1.1   Proof overview
Selected-entry matrix multiplication. The algebraic starting point is the inner/outer-product
identity of Schönhage [2], used by Coppersmith [3] for rectangular matrix multiplication. Alman
and Vassilevska Williams [1] adapt this approach to exploit the overlap among the computations
needed by selected entries. We express this sharing through an exact multiplication rule: each
output is a sum of six products from a common collection, minus one private correction term. The
common collection is small relative to the number of outputs, and the same intermediate value can
serve many requested entries. We apply the rule recursively to matrix blocks and count the resulting
requests, capping each count by the number of available output positions. Our simplification is in
the explicit rule and this counting argument; the central idea of exploiting sparse output requests
comes from Alman and Vassilevska Williams [1].

Fine grained algorithms. In Offline Set Disjointness [4, 5], we are given two families of sets
and a list of pairs, one set from each family, and must determine which pairs are disjoint. The
product of the families’ incidence matrices records all intersection sizes. When the universe is small,
Theorem 1.1 computes the requested intersection sizes efficiently. For 3SUM, we use the direct
deterministic reduction of Fischer, Kaliciak, and Polak [5]. For APSP, we use the standard reduction
to Exact Triangle, followed by the deterministic reduction to lopsided triangle queries of Alman and
Vassilevska Williams [1].

Further research. How far can selected-entry matrix multiplication be improved? What is
the best possible dependence on the middle dimension d when computing w arbitrary entries of
an n × d by d × n product? Can we reduce the dτ loss in Theorem 1.1 without increasing the
input-preparation cost or requiring thinner matrices? Can comparable savings hold for larger d? For
which ranges of d and w can selected-entry algorithms substantially outperform the best rectangular

Proof idea. We first construct a small matrix multiplication rule in which outputs use six products
from the same shared collection minus one private product per output. We apply this rule recursively
to blocks of larger matrices, following only the intermediate entries needed for the requested outputs.
We count these requests by their pattern of private and shared steps. Each shared step generates
at most six requests per incoming request, but the count is capped by the total number of output
positions in the corresponding products. The base case is an outer product, whose requested entries
each require one multiplication. Padding the input dimensions lets us apply this count directly to
the given matrices.

2.1    The multiplication rule
For a matrix product U V , call U the left input and V the right input. A product of linear forms
multiplies an integer linear combination of entries of U by an integer linear combination of entries
of V . We count the additions and subtractions needed to form these combinations separately from
their multiplication.

Lemma 2.3 (A shared multiplication rule). Let k ≥ 2 and set R = k2k−1 and S = 3k−1 . We
construct a multiplication rule for matrices U ∈ ZR×2 and V ∈ Z2×S as follows:

   1. Products: There is a common collection of 6k shared products and one private product for
      each entry of U V .

   2. Linear forms: Every product multiplies a linear form in U by a linear form in V . Each
      form is a sum of at most 6k signed entries of its respective matrix.

   3. Reconstruction: Each entry of U V is the sum of six shared products minus its private
      product.

   We count products by their labels, even if two formulas happen to be identical. The multiplication
has RS = k6k−1 outputs, but only 6k shared products. Thus

                                  number of shared products   6k  6
                                                            =    = .
                                     number of outputs        RS  k
As k increases, the shared collection becomes small relative to the number of outputs. This is the
reuse that our recursive algorithm will exploit.
A cancellation identity. The construction follows the Schönhage-Coppersmith approach used by
Alman and Vassilevska Williams [1]. We first give a cancellation identity, then construct shared
linear forms whose restriction to each output has exactly this pattern. The identity is the 2 × 3
instance of Schönhage’s inner/outer-product cancellation [2].

The first relation preserves the dot product, while the zero sum of the qj cancels a mixed term. The

3     Applications to fine grained algorithms
Fine grained algorithms seek to improve the exponent in a problem’s running time. Here our goal is
to go below quadratic time for integer 3SUM and below cubic time for APSP. We do this through a
convenient intermediate problem, Offline Set Disjointness, which asks whether specified pairs of sets
intersect.
    This problem connects directly to our matrix multiplication algorithm: the product of two
incidence matrices records the intersection sizes, and we only need the entries corresponding to the
queried pairs. Known reductions then turn a faster algorithm for this intermediate problem into

3.2    Known reductions
To identify the offline set disjointness problem with its graph formulation, use one vertex for each Si ,
one for each Tj , and a middle vertex for each element of [d]. Join sets to their elements and add an
outer edge for every requested pair. That edge lies in a triangle exactly when the two sets are not
disjoint. This is the Lopsided All-Edges Sparse Triangle formulation [6, 1], with a small middle part.
