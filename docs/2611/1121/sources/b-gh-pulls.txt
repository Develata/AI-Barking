Adds the project folder 3sum-apsp/, the Lean 4 formalization that accompanies the paper Truly Subquadratic 3SUM and Truly Subcubic APSP via Triangles in Sparse Lopsided Graphs (arXiv:2610.06783), and its row in the table of the root README.

A self-contained Lake project: Lean v4.33.1, Mathlib v4.33.1, no other dependency.

EndStatement.lean (imports nothing) states five headline claims about programs of a word RAM; PaperStatements.lean (imports only EndStatement.lean and Mathlib) states further results of the paper item by item; ThreeSumApsp/ holds the proofs.

Two Comparator configurations, comparator-endstatement.json and comparator-paperstatements.json, which the shared check picks up as they are.

3sum-apsp/README.md says what is proved, what is not, and what a reader has to trust.

A separate commit touches the shared CI: for a project on a stable Lean patch release vX.Y.Z (Z > 0), if leanprover/lean4export has no tag vX.Y.Z, the check takes the tag vX.Y.0 and builds it with the project's toolchain. A project whose exact tag exists is checked as before.
