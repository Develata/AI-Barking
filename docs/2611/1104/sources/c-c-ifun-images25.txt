ChatGPT Images: OpenAI stellt Bildgenerator neu auf [https://www.ifun.de/chatgpt-images-openai-stellt-bildgenerator-neu-auf-288513/]

 OpenAI hat mit ChatGPT Images 2.5 [https://openai.com/index/introducing-chatgpt-images-2-5/] eine neue Version seines Bildgenerators veröffentlicht. Nach Angaben des Unternehmens werden über ChatGPT Images und die GPT-Image-Modelle inzwischen jede Woche mehr als drei Milliarden Bilder erzeugt. Entsprechend zielt das Update weniger auf neue Grundfunktionen als auf Verbesserungen bei Tempo, Qualität und gezielter Bearbeitung.
