# 1104 读者稿检查

检查方：Codex（gpt-6-astra，medium，只读，不带本期上下文），按 `templates/style-review.md`；对象为初稿（标题候选与正文）。

## 1. 标题

我会点的前三：

1. **“花121万美元，AI挖出948个漏洞？”**——花了多少钱、做了什么都看得懂，我想知道这钱花得值不值。
2. **“AI十天挖出948个漏洞？”**——“十天”和“948个”让我觉得速度很快，想点进去看看怎么做到的。
3. **“OpenAI花121万挖漏洞，挖出948个？”**——我认识 OpenAI，也好奇它为什么花钱找漏洞，但“121万”没说是什么币。

看不出部分内容在说什么的：

- **“AI挖出948个漏洞？Kimi按时开源”**——“开源”我听过，但不知道它具体放了什么，也不知道两件事为什么放一起。
- **“948个漏洞已提交补丁？Kimi放权重”**——“提交补丁”是不是已经修好了？“放权重”完全不知道是什么动作。
- **“AI挖出948个漏洞？Kimi权重放了”**——“权重放了”对我没有明确意思，也看不出值得点开的地方。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁炒作、谁说错话，还是单纯谐音？开头没看明白。
- **“省流：OpenAI 称用未发布的模型在 Linux 内核里找出948个能拿到最高权限的漏洞并写了补丁；有媒体写成‘已提交补丁’，原文只说已发出数百份。”**——不知道“Linux 内核”是电脑的什么部分；“写了”“提交”“发出”有什么区别，要读两遍才发现是在纠正数量。
- **“月之暗面按时放出 Kimi-K3.1-Pro 权重，约1.56 TB，许可证在 MIT 式条款上加了收入门槛。”**——“月之暗面”跟 Kimi 什么关系？“权重”“MIT 式条款”都不懂，1.56 TB 也不知道算多大。
- **“这一轮 API 费用约121万美元。”**——“API”是什么？这是全部花费，还是其中一种费用？
- **“②原文写，扫描和人工分析10天结束时，61个已修进内核主线，43个有待合入的补丁，299个在公开讨论；摘要另说，这10天里有100多个提权漏洞由其他贡献者修好或备好补丁。”**——“内核主线”“合入”“提权”都卡住；61、43、299、100多之间有没有重复，跟948又是什么关系，完全算不明白。
- **“③流水线自判的‘成功’会错：早期一轮的200个提权成功里，有20个借的是另一个未公开漏洞。”**——谁是“流水线”？“借的是另一个漏洞”是什么意思？既然拿到权限了，为什么又算错？
- **“北京4日23:30，已有人发现 Kimi-K3.1-Pro 的权重上了 Hugging Face，月之暗面5日0点宣布放出，赶上了‘最迟11月4日’的承诺（上期截稿时还没放）。”**——不知道 Hugging Face 是什么；日期在4日、5日之间来回跳，要重新看才知道作者为什么说按时。
- **“权重文件约1.56 TB，参数表写2.8万亿。”**——“参数”是什么？2.8万亿是在数什么，跟文件大小有什么关系？
- **“①有中文稿写许可证‘基本沿用 MIT’。”**——不知道 MIT 代表什么许可，所以也不知道“基本沿用”有什么问题。
- **“它开头是 MIT 式授权，另加条件：做模型服务、连续12个月收入超2000万美元的公司，商用要另签协议；产品月活超1亿或月收入超2000万美元，要在界面显著标注模型名。”**——条件太多，要读两遍；后半句是在说同一类公司吗？“月活”又是什么？
- **“②下得到不等于跑得动：推理框架 vLLM 的部署说明用了8张数据中心显卡。”**——“推理框架”“vLLM”“部署”都不认识，知道需要厉害的电脑，但不知道跟我使用 Kimi 有什么关系。
- **“有网站标题称文件大到5.6 TB，那是按另一种精度估算的。”**——“精度”是什么？为什么换个精度，文件就变大了？
- **“③据第三方评测 Artificial Analysis，它在10月27日改版的综合指数里得46分，被算作开放权重第一，但比榜首 Claude-Opus-5.5（max 档）低12分；旧版只差3分。”**——满分多少、考什么都不知道；“开放权重第一”为什么又不是榜首？新版差12分、旧版差3分，是模型变差了还是评分规则变了？

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**——像要求 AI 给栏目想一句押韵口号，谐音先出来了，意思还没说清。
- **“②下得到不等于跑得动：推理框架 vLLM 的部署说明用了8张数据中心显卡。”**——“A 不等于 B”先来一句提醒读者别天真的告诫，很像常见的 AI 总结句。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——重复玩“沸点／吠点”的谐音，再加“轻松识破”的宣传承诺，像自动生成的账号宣传语。

## 4. 会划走的地方

- **“省流：OpenAI 称用未发布的模型在 Linux 内核里找出948个能拿到最高权限的漏洞并写了补丁；有媒体写成‘已提交补丁’，原文只说已发出数百份。”**——这里就有划走风险。我还没明白这件事跟我有什么关系，就开始看媒体措辞纠错了。
- **“②原文写，扫描和人工分析10天结束时，61个已修进内核主线，43个有待合入的补丁，299个在公开讨论；摘要另说，这10天里有100多个提权漏洞由其他贡献者修好或备好补丁。”**——如果前面撑住了，这里我很可能划走：数字太多，感觉要自己做一道统计题。

不太在乎的“吠点”：

- **“①有媒体标题写‘948个漏洞已提交补丁’，原文只说先发出‘数百份’报告和补丁，其余陆续发。”**——我更想知道漏洞危险不危险、修好了没有，不太在乎媒体把“发了多少份”写准没有。
- **“④模型叫什么、何时发布，原文没写，也没公布漏洞清单。”**——这条都是“没说”，读完没有得到我能用的信息。
- **“做模型服务、连续12个月收入超2000万美元的公司，商用要另签协议”**——这是大公司的事，我只是普通用户，读到收入门槛就不想继续了。
- **“有网站标题称文件大到5.6 TB，那是按另一种精度估算的。”**——我不会下载这个文件，1.56 TB 和5.6 TB 对我都只是“很大”，纠正这个数字没什么吸引力。
## 采纳

- 标题：采纳。读者最想点“花121万美元，AI挖出948个漏洞？”，改选 titles.md #2；#6“AI十天挖出948个漏洞？”有“10天”口径问题不选。
- 省流：采纳。先讲发生了什么：“Linux 系统的核心（内核）”“模型本体（权重）”加通俗解释。
- “API 费用”：采纳，改“光调用模型就花了约121万美元”。
- 吠点②数字太多：采纳，删去“摘要另说100多个由其他贡献者修好”一句，只留 61/43/299 一组（批注图 oa-other-contrib 随之撤下）。
- 吠点③“借另一个漏洞”看不懂：采纳，改为“其实是借另一个漏洞拿到的权限，不是指定要攻的那个”。
- 吠点④（模型名、清单都没写）不在乎：采纳，删去。
- Hugging Face、MIT 看不懂：采纳，加“开源模型平台”“一种几乎不设限的开源许可”。
- “下得到不等于跑得动”像 AI 告诫句：采纳，删去该引子。
- AA 一条看不懂满分与差距：部分采纳，补“六成分数来自不公开考题”与“当时榜首”；满分不写（AA 指数无固定满分说明）。
- 收入门槛、5.6 TB 不在乎：不采纳删除。许可证是“开源”说法的主要限定；5.6 TB 是流传最广的错误数字。
- 开场与 Slogan 像 AI：不采纳，固定栏目格式。
