0.93.0
 [/changelog/0.93.0-conductor-is-joining-meta]November 4, 2026

Conductor is joining Meta [/changelog/0.93.0-conductor-is-joining-meta]

Conductor is joining Meta. Thank you for coming along for the ride! Read the announcement [/announcement].

We'll be winding down Conductor over the next weeks and months:

Conductor Cloud goes read-only on November 13 and shuts down on November 20.

Local Conductor keeps getting new models and critical bug fixes until early 2027.

To move a cloud workspace and its chats to your Mac, right-click it and choose Transfer to local. To download all your data, go to Settings → Account → Export data.

If you need anything, email [email protected] [/cdn-cgi/l/email-protection].

Improvements

Add your own completion sounds in Settings → General. Pick a sound file, name it, and choose it like any other sound.

Archived cloud workspaces show their PRs, last known changes, and file tree in the right panel.

Added GPT-6.1 Terra to the Codex model picker.

Fixes

Fixed the Claude account usage display when Claude Code reports newer limit data.

Fixed closed chats in chat history showing a recent time when nothing had happened in them.

Messages that agents send to other agents now show a "Send message" label with the recipient and contents.

The rename workspace dialog now prefills the name shown in the sidebar instead of the worktree name.

Long PR titles no longer hide the PR number in the PR view.

Expanded Mermaid diagrams fill the window instead of opening in a narrow popup.

0.92.0
 [/changelog/0.92.0-remote-control]October 23, 2026

Remote control [/changelog/0.92.0-remote-control]
 [https://app.conductor.build/settings/user/remote-control]

Control your Mac from your iPhone. With remote control, you can browse and create workspaces, read chats, send messages, pick models, and stop agents in your Mac's local workspaces from the Conductor iOS app. Turn on Remote control in Settings → Experimental, then scan the QR code with the iOS app. Learn how to set it up [/docs/reference/remote-control].

Remote control now stays connected while the Conductor window is hidden or minimized, shows the full history of older chats, and transfers much less data. It also keeps your Mac awake while your iPhone is connected and the Mac is plugged in. You can turn this off in Settings → Remote control.

You can now customize keyboard shortcuts in Settings → Keyboard shortcuts.

Long chats also open much faster. Conductor loads the most recent messages first and fetches older ones as you scroll up. The chat outline on the right edge of a chat still lists every message, and clicking one jumps straight to it.

Improvements

Turn on "Arrange workspaces manually" in Settings → General to stop workspaces from re-sorting by activity and drag them into your own order. In cloud organizations, the setting syncs to the iOS app.

The Artifacts tab in the Git panel and the MCP status indicator in the message box are now on for everyone. You can hide the Artifacts tab in Settings → General.

When a repository has no run script, the terminal panel shows an "Add action" button. In cloud workspaces, you can add one without leaving the workspace.

In cloud organizations, Home hides workspaces created by routines by default, with a filter to show them.

Right-click a run in a routine's Runs pane to open the workspace menu.

Routines can run Claude at Ultracode effort.

In cloud workspaces, PR descriptions, checks, and comments appear immediately instead of waiting on GitHub.

A sleeping cloud workspace's preview URL shows a Wake workspace button and restarts the previewed server when the workspace wakes.

Right-click a file link in chat to copy its path relative to the workspace.

The context usage indicator shows how much of the context window OpenCode chats are using.

When Codex reaches a usage limit set by your ChatGPT Business admin, you can copy a request to send them.

Conductor starts much faster in organizations with many workspaces, and switching between workspaces and chats is snappier.

Fixes

Fixed chats opened from the iOS app on a remote-controlled Mac sometimes staying stuck on a loading placeholder.

Pairing the same phone with your Mac again replaces its earlier entry instead of listing the phone twice.

Cancelled PR checks no longer count as failed in the Git panel.

Commits work in every repo of a cloud workspace, not just the workspace's own repo.

In cloud workspaces, git push runs as the chat's sender even when a GH_TOKEN is set in the workspace's environment variables.

Fixed cloud workspaces sometimes staying on "Updating" indefinitely.

Fixed a cloud workspace's cost disappearing from the workspaces list after archiving it.

Fixed Xcode build files filling the Artifacts tab.

Fixed sites bouncing at their scroll edges and showing a white background.

Fixed stack PR numbers in the Changes tab sitting above their highlight.

Fixed right-aligned images in PR comments, like Greptile's badges, touching each other.

Hardened local file sync for cloud workspaces against malicious repository contents.

Conductor no longer trusts certificates from eMudhra's compromised certificate authorities.

Misc

Run scripts are now called actions. They live under Custom actions in a repository's Actions settings.

Chats, diffs, and files stop at the top of the message box instead of scrolling beneath it.

In multiplayer cloud chats, agents can tell who sent each message.

Removed the conductor sql command from the Conductor CLI.

Removed the "New: Sonnet 5.5" callout from the model picker.

Updated the bundled Claude Code to 2.1.308, Codex to 0.164.0, Cursor Agent to 1.0.40, and OpenCode to 2.1.3.

0.91.0
 [/changelog/0.91.0-a-mostly-boring-update]October 15, 2026

A (mostly) boring update [/changelog/0.91.0-a-mostly-boring-update]
We spent this release polishing Conductor and fixing papercuts: dozens of fixes for chats, cloud workspaces, PRs, and file sync. Pages also have a refreshed layout that floats beside the sidebar, and you can now run shell snippets from agent replies with one click.

Improvements

Bash snippets in agent replies and Markdown previews have a Run button that runs them and shows the output inline.

With Voice mode on in Settings → Experimental, macOS 26 transcribes on your Mac and shows your words in the message box as you speak. Dictation shows your live microphone level.

Added Claude Haiku 5.5 to the model picker.

When your PR is part of a GitHub stack, the Changes tab lists the stack's PRs so you can view the changes of one or several of them.

In a workspace, searching in ⌘K finds that workspace's chats, including closed ones.

Drag workspaces to reorder them in the Pinned section. The order syncs between desktop and mobile.

In team organizations, click a teammate's avatar to open their profile, which shows a heatmap of their daily token usage.

In cloud workspaces, the Run tab has a Start forwarding button, then an Open button for each detected port labeled with its process name. The "Forwarding ports" notification also shows process names.

In a PR's Activity feed, replies to a review comment appear nested under it.

Codex waits and retries when OpenAI rate-limits a request instead of failing the turn.

While an agent is working, the stop button is the primary action. Typing a follow-up makes send the primary action instead.

A message you send while Claude is running a command stays faded until Claude reads it.

Long chat messages render faster when you reopen a chat or scroll back to them.

Videos start playing as soon as you open them in a tab.

Stopped background tasks show as "Stop task" in the chat.

Turn on Pokes in Settings → Experimental to poke a teammate from their profile page, and poke them back when they poke you. Pokes only work when both of you have the setting on.

Fixes

Fixed a crash loop when opening a chat with a very long history.

Fixed very long cloud chats taking minutes to catch up and appearing stuck or out of date.

Fixed a new cloud workspace's first message sometimes getting lost if Conductor quit while the workspace was being created.

Fixed Claude chats showing as working after publishing an artifact, with a new "Background Task" row each time the artifact's live updates reconnected.

Agents in repositories hosted outside github.com no longer receive your Conductor GitHub credentials.

Error reports no longer include workspace environment variables or message text when background branch naming fails.

A tool call that fails to display no longer hides the rest of the message, and an error in the workspace tab bar no longer replaces the whole workspace with an error screen.

Fixed PR info getting stuck on "Loading PR info…" for repositories on GitHub Enterprise.

Fixed Continue failing on a merged stacked PR after GitHub deleted its parent branch.

Fixed merging a PR from a sleeping cloud workspace failing with "Code in this workspace may be different from what's on GitHub".

A cloud workspace's PR status, title, and description load while the workspace is still waking up.

GitHub actions in a sleeping or restarting cloud workspace explain what's happening instead of showing "Sandbox version request failed: 503".

When a cloud workspace loses network access after running out of memory, the chat explains what happened and offers to restart the workspace.

Fixed cloud file sync getting stuck re-downloading the same files with an authentication error when syncing many files at once.

Fixed synced files in Git LFS repos being re-downloaded and showing as modified.

Fixed downloads of large files from cloud workspaces getting stuck.

Fixed long-running commands that cloud agents ran on your Mac failing with "This command is no longer assigned to this Mac".

Fixed a file's diff getting stuck on an old version after you edited it while an agent was also changing it.

Fixed /clear doing nothing when a workspace had the maximum number of chat tabs open.

Fixed the send button staying disabled after pasting or attaching a file.

Fixed attachments briefly reappearing in a new workspace's message box after creating it with an attached file.

Fixed chats going blank after scrolling up quickly with a mouse wheel.

Fixed switching to a chat sometimes leaving it scrolled above the latest message.

Fixed a brief flicker in long chat messages when closing the command palette or other dialogs.

Fixed plan mode changes by the agent or a collaborator sometimes being missed right after you toggled plan mode in a cloud chat.

Fixed opening a shared cloud workspace briefly showing "No open chats".

Fixed renaming a workspace while its cloud sandbox was starting showing "Renaming..." indefinitely.

Fixed missing loading indicators when pulling latest changes, archiving workspaces, creating PRs, and fixing errors.

Fixed workspace metadata changes making a workspace appear recently active.

⌘1–9 skips workspaces hidden in collapsed sidebar sections.

Fixed the sidebar jumping when you archive your last workspace in "My workspaces".

Cloud repository pickers show owner/repo when two repositories share a name.

Fixed small images like badges and icons appearing blown up and cropped in chats and PR comments.

Fixed missing organization icons on workspace and chat links in messages.

Fixed video scrubbing so the frame updates while you drag, and kept tall and portrait videos from overflowing the screen.

Fixed stacked notifications collapsing when moving the pointer between them.

Fixed Conductor keeping Bluetooth headphones connected to your Mac after adding a model in Settings → Models → Loadout.

Misc

New users start with Opus 5.5 as their default Claude model.

Removed the Team page. Teammate profiles replace it.

Removed Cloud Beta workspaces and the Cloud (Legacy) settings from personal organizations.

Updated the Conductor app icon and the Linear MCP server icon.

The stop button uses a filled square that matches the send button.

Updated the bundled Claude Code to 2.1.300, Codex to 0.162.1, Cursor Agent to 1.0.37, and OpenCode to 2.0.29.

New in 0.91.2

Psst! You can now control your Mac from the Conductor iOS app. Turn on Remote control in Settings → Experimental, pair your phone, and keep chatting with agents in your local workspaces from anywhere. Learn how to set it up [/docs/reference/remote-control].

0.90.0
 [/changelog/0.90.0-conductor-for-ios]October 2, 2026

Conductor for iOS [/changelog/0.90.0-conductor-for-ios]

Download Conductor for iOS! [https://apps.apple.com/us/app/conductor-build/id6791228564] You can now chat with agents and merge PRs from your phone. Works with cloud workspaces.

Improvements

Videos play in a new player with playback speed, frame-by-frame stepping, timeline previews, and keyboard shortcuts.

Find in chat (⌘F) now searches agents' thinking, and jumping to a match expands the thinking or tool-call group that hides it.

Cloud organizations show the matrix-style workspace status indicator in Home, the sidebar, and workspace tabs.

Setting up repositories for a cloud computer walks you through signing in to GitHub and then choosing repositories, grouped by GitHub organization.

Notifications show the chat's title instead of the branch name.

Diff refreshes show a loading bar, and you can mark files as viewed while a diff refreshes.

A message you send while Claude is running a long command shows as waiting until Claude reads it.

The MCP popover in a chat shows how many tools each connected MCP server provides.

Clicking a PR in the stack popover opens it in the PR view. Right-click it for Open in GitHub and copy options.

The Pinned section header has a … menu. Creating a workspace from it adds the new workspace to Pinned.

Automatic restarts for updates wait for you to confirm when a run script is running or an open chat has an unsent prompt.

In cloud organizations, pinned workspaces stay in sync across your devices.

In cloud organizations, your Automerge, "Treat optional checks as blocking", and PR activity order settings carry over to the iOS app.

Organizations show their uploaded avatar in the org switcher and everywhere else the org icon appears.

In settings, the Admin section links to your organization's API keys, billing, and settings pages on the web, and the account Billing button opens your Conductor Pro billing page.

Copied cloud workspace and routine links use your organization's slug and workspace number instead of long IDs.

Merging a PR stack in a cloud workspace no longer requires the GitHub stack extension on your Mac.

Files agents save to .context in cloud workspaces sync to your Mac.

In cloud workspaces, the Changes panel's options menu shows the current branch above the target branch.

When Codex runs on your ChatGPT plan, the context usage popover shows which ChatGPT account the chat is using.

Fixes

Fixed a memory leak where the app's memory use grew with every agent turn until restart.

Fixed Claude chats getting stuck on "Waiting for task" while a dev server ran in the background, which blocked queued messages.

Fixed follow-up messages to Cursor chats sometimes taking many minutes to start.

Fixed long chats jumping to the top and then rapidly scrolling back to the end.

Fixed Conductor freezing after removing a repository from its settings.

Fixed macOS repeatedly asking for file and folder access even after Conductor was granted Full Disk Access.

Fixed the Approve button disappearing from a pending plan after restarting Conductor.

Fixed GPT-6 Astra, GPT-6 Sol, and GPT-6 Luna missing from the model picker when Codex uses Sign in with ChatGPT.

Signing in with ChatGPT no longer switches local Codex off a Codex login you already use.

Fixed "The provided model identifier is invalid" errors with Haiku 4.5 when Amazon Bedrock is enabled in Claude Code's settings.

Cursor chats now start MCP servers defined in a repo's .cursor/mcp.json.

Fixed Mermaid quadrant charts, pie charts, Gantt charts, mind maps, and other diagram types failing to render.

Fixed inline videos in chat showing "Video unavailable" when they point to a file in the workspace.

Commands that block the agent no longer show up as a "Background Task" in the chat.

Agent messages written before a tool call are no longer greyed out like thinking.

Fixed a workspace showing no PR after the agent created a PR stack.

Fixed review comment previews in the Git panel showing raw HTML from bots like Greptile.

The "Viewed" checkbox in the diff file header stays in the same place for every file type.

Fixed PR and browser tabs not closing unless they were the selected tab.

Fixed the Rename chat field losing focus right after opening.

Closing a dropdown menu returns keyboard focus to the button that opened it.

Fixed the "Create from" button in the new workspace composer not staying highlighted while its menu is open.

Fixed the organization prompt box becoming disabled and losing focus while you were typing.

In local workspaces, clicking a file path outside the workspace in chat (like ~/Desktop/test.html) shows it in Finder instead of failing to load.

Agents in local workspaces no longer try to create or control workspaces through the Conductor CLI.

Fixed the Dashboard appearing empty in cloud organizations.

Fixed cloud workspaces showing your local folder name for their repository instead of the repository's name.

Fixed a cloud workspace sometimes showing only some of its chats until Conductor restarted.

Fixed a cloud chat you closed and reopened on desktop staying hidden in the iOS app.

Local terminals in cloud workspaces wait for a sleeping workspace to wake instead of showing a sync error.

Fixed detected ports in cloud workspaces showing some processes, like Storybook, as ".. dev".

"Copy link" explains why it can't copy a link for a cloud workspace that failed to start, instead of doing nothing.

Misc

Pausing, resuming, or clearing a Codex goal shows up in the chat.

Organization and Linear links open the new account home on the web.

Cloud workspaces no longer create settings.local.toml.

Updated the bundled Claude Code to 2.1.286, Cursor Agent to 1.0.35, and OpenCode to 2.0.21.

New in 0.90.1

Very long cloud chats load much faster.

Chats with a command running in the background, like a dev server, show as waiting again, and queued messages still send.

Messages you send while Claude is running a long command no longer show a "Waiting for current step" caption. They appear lighter until Claude reads them.

0.89.0
 [/changelog/0.89.0-sign-in-with-chatgpt]September 29, 2026

Sign in with ChatGPT [/changelog/0.89.0-sign-in-with-chatgpt]

We're excited to be partnering with OpenAI on Sign in with ChatGPT.

You can now bring your ChatGPT plan to Conductor in a few clicks. Go to Settings → Agents → Codex and click Continue with ChatGPT to start using your Codex plan in Conductor.

Other big improvements:

The PR view has a new layout. One card at the top shows the branch, review, checks, and merge status, with the description and activity below it.

New workspaces get descriptive branch names based on what you're working on. To turn this off, go to Settings → Git → Automatically rename new branches.

You can now steer Cursor chats while they run.

Desktop tabs are available in every cloud workspace, with no experimental setting needed.

Cloud workspaces show their number (like W-123) in the top bar, workspace links, the All Workspaces list, and the command palette.

Improvements

In the PR view, open the Review row to add unresolved comments to chat, or the Checks row to re-run or fix failed checks.

Steer Cursor chats while they're running, in local and cloud workspaces.

Merging a PR from Conductor now only merges the code that's in your workspace. If the PR on GitHub has changed, the merge is blocked and you get a link to merge on GitHub instead.

PR comments edited on GitHub show "edited" with the edit time. If you'd already sent them to the agent or hidden them, they reappear as new.

In the PR view, checks and deployments waiting on an approval show a clock instead of looking pending.

Deep links can include a branch parameter to start a new workspace from an existing branch.

In cloud workspaces, detected ports show which process is listening, like postgres or next dev.

Hover over a cloud workspace in the sidebar to see its repository.

Right-click the Pinned section in the sidebar to create a new pinned workspace.

Hover over file names in the Git panel to see their full paths.

Repository selectors are sorted alphabetically, and become searchable when you have five or more repositories.

The + menu in the composer highlights Add attachment and puts it closest to the button.

In cloud organizations, loadout changes sync across your devices.

In cloud organizations, the Recommended MCPs tab also lists MCPs you've already added, marked Installed.

When you add a custom MCP server with OAuth, you can copy Conductor's OAuth callback URL to register it with the provider.

The toast for an MCP server that needs re-authentication shows the server's logo and name.

Right-click a settings tab to copy a web link that opens Conductor to that page.

Codex chats routed through Vercel AI Gateway use its dedicated Codex endpoint.

Cloud workspaces load and sync faster, file sync picks up workspace changes immediately, and images use less memory.

Animated workspace status marks in the sidebar use less CPU.

Fixes

Fixed high memory use that grew as you opened more chats.

Fixed slow startup and high memory use in organizations with many archived cloud workspaces.

Fixed the app freezing for several seconds when switching to a cloud workspace with many chats.

Fixed run scripts with lots of output, like a Rails server, hanging while the Conductor window was in the background.

Fixed the Open button in the Run pane disappearing after a lot of server output or after switching workspaces.

Fixed Codex tasks stopping on temporary rate-limit and model capacity errors after work had started.

Fixed Codex chats failing to start with a "failed to load configuration" error when your ChatGPT workspace restricts Codex's sandbox.

Codex inline visualizations render in the chat instead of showing raw directive text.

Codex model pickers no longer list audio, embedding, and legacy completion models when you use an API key, and the placeholder "Test Model" entries are gone from all model pickers.

Fixed sent queued messages appearing earlier in the chat, and messages briefly returning to the queue during attachment uploads or while background agents run.

Fixed the Reset chat dialog reappearing after you sent the next message.

Fixed a stacked PR's diff still including changes from the PR below it after that PR merged.

Fixed slow switching between stacked PRs and occasional stale diffs.

Fixed opening a workspace's merged PR showing a blank title, description, and activity.

Fixed deleted lines in the diff view not being selectable or copyable.

Fixed files marked as Viewed in the diff viewer resetting after restarting Conductor.

Fixed regenerated images, PDFs, and videos sometimes showing an older version.

Fixed a crash that kept a workspace from opening again after you opened a file from a chat.

Fixed clicking a conductor:// prompt, Linear, or async deep link in a chat message doing nothing.

Fixed copying a link or transcript from another chat tab's menu switching to that tab.

Fixed new local workspaces showing a random string as their name.

Fixed ⌘⇧N not focusing search when opening a new workspace.

Fixed a project filter chosen in a local organization hiding every workspace in a cloud organization's sidebar.

Fixed an empty gap building up in the status-grouped sidebar while archiving several workspaces.

Fixed the left sidebar button shifting when the sidebar is collapsed.

Fixed the settings sidebar scrollbar overlapping the selected item.

Fixed switching between agents in Settings → Agents briefly showing the previous agent's settings.

Fixed closing a zoomed image temporarily blocking clicks and scrolling.

Fixed inline command terminals so they sit flush with the composer and show one close button.

Removed the duplicate expand button from chat videos.

Improved how the composer works with assistive tools.

Fixed cloud workspace files and changes becoming unavailable after the sandbox sleeps.

Fixed cloud workspaces showing incomplete snapshots while starting.

Fixed cloud workspace file sync sometimes silently stopping.

Fixed port forwarding in cloud workspaces getting stuck on "Connecting".

Open via SSH in Cursor and VS Code now opens the repository alongside the selected file in cloud workspaces.

Fixed cloud workspaces sometimes continuing to use a deleted workspace connection.

Fixed newly shared workspaces briefly appearing to have no open chats.

Fixed teammate avatars disappearing during brief connection drops.

Fixed switching accounts sometimes leaving cloud updates connected to the previous account.

Read-only workspaces can load Git and checkpoint status.

Creating a workspace with the CLI shows one workspace chip instead of duplicates.

Incident notices only appear for affected users.

Removed repeated wording from Sync files error messages.

Misc

Holding ⌘ no longer replaces sidebar workspace icons with shortcut numbers.

Moved the "Include link to workspace in PR description" setting from organization Preferences to Settings → Git.

Simplified the cloud Codex subscription settings. Reconnect is now in the card's ⋮ menu.

Agents in cloud workspaces know that Sync files mirrors the workspace to your Mac in one direction only.

Updated the bundled Codex to 0.157.1, OpenCode to 2.0.18, and Cursor Agent to 1.0.32.
