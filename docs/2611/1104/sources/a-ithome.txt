OpenAI 扫描 Linux 内核发现 948 个可提权漏洞，2308 个候选问题中有 1724 个成功复现

 2026/11/5 6:51:59
 来源：IT之家 [https://www.ithome.com/1/022/476.htm]
 作者：问舟

 责编：问舟

 评论： [#post_comm]

感谢IT之家网友 华南吴彦祖 [https://m.ithome.com/html/app/open.html?url=ithome%3A%2F%2Fuserpage%3Fid%3D2029428] 的线索投递！

IT之家 [https://www.ithome.com/] 11 月 5 日消息，OpenAI 于当地时间 11 月 4 日发布安全研究报告。OpenAI 称其利用新一代网络安全模型，搭建了一套自动化漏洞发现、验证、漏洞利用和补丁生成系统。

在一次针对 Linux 内核的测试中，该系统共识别出 2,308 个潜在安全问题，动态复现其中 1,724 个漏洞，并生成了 948 个可实现本地权限提升的有效漏洞利用程序（Exploit），能够帮助低权限本地用户获取系统 root 权限。

OpenAI 表示，这次测试于 2026 年 10 月中旬进行，使用的是一款尚未正式公布的网络安全模型。整个流程涵盖漏洞发现、动态验证、可利用性评估、补丁生成和人工审核五个阶段。最终生成的成果包括漏洞根因分析、最小化崩溃概念验证程序（PoC）、候选修复补丁以及完整漏洞利用程序，供安全研究人员进一步审核和提交上游维护团队。

在漏洞发现阶段，系统首先通过 AI 智能体筛选 Linux 内核中具有安全审计价值的代码，再交由另一个智能体进行分析。

整个过程筛选出 5,034 个审计目标，涉及约 280 万行代码，相当于 Linux 内核代码总量的约 7%。随后，负责分析的 AI 智能体在 12 小时内生成 2,308 个去重后的候选漏洞，相关 API 调用成本为 31.65 万美元（IT之家注：现汇率约合 211.5 万元人民币）。

在动态验证阶段，系统将候选漏洞放入隔离虚拟机中进行测试，通过生成 PoC 并观察实际运行结果，判断漏洞能否复现。经过 30 小时测试，2,308 个候选问题中有 1,724 个成功复现，占比约 74.7%。

OpenAI 表示，剩余问题大多受到权限要求、复杂竞争条件或特定触发条件等因素影响，只有 3.1% 属于模型分析错误，即模型假设了实际上不可能发生的条件。

在漏洞利用评估阶段，系统进一步筛选出能够造成信息泄露或本地权限提升的漏洞，并在启用 SMEP、SMAP、KASLR 和 HARDENED_USERCOPY 等常规安全防护机制的 Linux 环境中进行测试。

最终生成了 291 个信息泄露 PoC，以及 1,169 个能够实现本地权限提升的漏洞利用程序。经过变体分析和补丁开发，OpenAI 将其中 948 个不同的本地权限提升漏洞作为最终统计结果。

这次测试总计消耗 121.34 万美元（现汇率约合 811 万元人民币） API 额度，平均每个本地权限提升漏洞利用程序的成本约为 1,279 美元（现汇率约合 8,549 元人民币）。其中，漏洞利用开发阶段的成本最高，达到 77.59 万美元（现汇率约合 518.6 万元人民币）。

OpenAI 指出，这些成本反映的是本次测试所采用的模型、目标配置和工作流程，并非优化后的最低成本。通过进一步改进智能体编排和工程设计，实际成本仍有下降空间。

作为对比，OpenAI 还提到，其团队在 2026 年 7 月使用 GPT-5.6 Sol 对 Linux 内核进行过一次类似测试，当时发现并成功利用了 166 个不同的本地权限提升漏洞，API 成本为 51.37 万美元（现汇率约合 343.4 万元人民币）。到了 10 月，采用更新网络安全模型的测试将这一数字提升至 948 个。

OpenAI 表示，尽管两次扫描之间 Linux 内核已经经过约三个月的安全加固，后一次测试发现的新型本地权限提升漏洞数量仍超过此前的 5 倍。

研究团队还对 166 个漏洞利用样本进行了抽查，发现其中至少涉及 10 种此前未见的 Linux 漏洞利用技术。OpenAI 称，相关技术已经交由第三方内核漏洞利用专家审查，对方也认为这些方法具有新颖性。出于安全考虑，公司没有公开这些新技术的完整细节。

补丁生成同样是此次研究的重要环节。OpenAI 表示，模型最初生成的补丁虽然能够修复对应 PoC 暴露的问题，但部分补丁存在代码冗余、潜在性能影响、偏离项目编码规范以及未能覆盖同类漏洞变体等问题。经过增加约束条件和多轮迭代后，补丁质量得到改善，部分研究生成的补丁还帮助发现了人类专家此前编写的修复方案中的问题。

目前，OpenAI 已经按照 Linux 内核社区的建议，优先提交严重漏洞报告和补丁，并计划通过 Patch the Planet 合作伙伴逐步提交其余报告。

据 OpenAI 透露，在此次扫描及后续人工分析的 10 天里，已有 61 个相关本地权限提升漏洞在 Linux 上游得到修复，另有 43 个获得暂存补丁，还有 299 个漏洞正在公开讨论或报告过程中。

除了常规 Linux 内核环境，OpenAI 还在谷歌 kernelCTF 漏洞奖励计划使用的加固环境中进行了测试，最终获得 25 个信息泄露 PoC 和 21 个本地权限提升漏洞利用程序。

整个测试耗时 112 小时，API 成本约为 32,936 美元（现汇率约合 22 万元人民币）。如果这 21 个漏洞全部通过该计划审核，理论上可获得约 150 万美元（现汇率约合 1,002.6 万元人民币）奖励。

OpenAI 还指出，随着网络安全模型能力提升，传统上依赖复杂智能体编排和人工指导的漏洞研究流程可能需要调整。在其对 GPT-5.5 Cyber 和 GPT-5.6 Cyber 的测试中，后者能够更加自主地识别和应用 Linux 内核漏洞利用技术。团队移除额外的技术指导层后，GPT-5.6 Cyber 的表现仍优于采用更复杂编排方案的 GPT-5.5 Cyber。

OpenAI 表示，未来几年，前沿模型可能具备发现复杂软件漏洞的能力，甚至能够让能力较弱的模型利用已经公开披露的漏洞。因此，软件维护者需要加快漏洞修复，用户和企业也应及时安装安全更新。同时，沙箱、隔离机制、减少不必要的攻击面以及形式化验证等技术，将成为提升软件安全性的重要方向。

OpenAI 强调，这项研究属于其 Patch the Planet 和 Daybreak 安全计划的一部分，后续将继续扩大对关键软件项目的安全审计，并与开源社区及安全合作伙伴合作，推动自动化漏洞发现和补丁修复。
