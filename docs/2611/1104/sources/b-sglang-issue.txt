Goal

Serve Kimi K3.1 on Ascend NPUs with SGLang.

Kimi K3.1 is a hybrid-attention MoE model: 69 KDA (linear attention) layers + 24 full-attention layers with DSA sparse attention (index_topk=2048), mxfp4-quantized routed experts. The remote-code checkpoint requires DSA to be routed correctly through the hybrid backend/pool wrappers on NPU.

Status

Implementation PR: [Feat] [NPU] kimi-k3.1: Add model support and route DSA attention path on Ascend #48420 [https://github.com/sgl-project/sglang/pull/48420]

Verified topology: 3 nodes × 8 cards, TP8 × PP3

Accuracy: single-request (prefill + decode) verified on this topology; throughput benchmarks to be added

Docker images (CANN 9.1.0)

swr.cn-southwest-2.myhuaweicloud.com/base_image/dockerhub/lmsysorg/sglang:cann9.1.0-950-kimi-k3.1

swr.cn-southwest-2.myhuaweicloud.com/base_image/dockerhub/lmsysorg/sglang:cann9.1.0-a3-kimi-k3.1

Discussion

Questions and feedback on the NPU adaptation are welcome here. Code review should go to #48420 [https://github.com/sgl-project/sglang/pull/48420].
