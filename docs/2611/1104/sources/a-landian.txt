 OpenAI利用模型在Linux内核中刚找到948个提权漏洞 已生成补丁提交给维护者 

2026年11月5日 16:30人工智能 [https://www.landian.news/tech/ai], 科技资讯 [https://www.landian.news/tech]00.74K

 [https://www.landian.news/archives/127856.html]

#人工智能 OpenAI 尚未发布的网络安全研究模型在 Linux 内核中找到 948 项本地提权漏洞，目前相关报告已提交给内核维护团队。至于为什么都是本地提权漏洞，因为 OpenAI 担心再次翻车，所以研究目标是隔离环境中的内核，所以只能研究提权或信息泄露类问题。以及 OpenAI 担心生成的补丁也翻车影响名誉，所以最终提交的报告还都经过人工审阅。查看全文：https://ourl.co/128112

OpenAI 日前公布针对 Linux Kernel 的安全研究：该公司利用自动化漏洞研究工作流，在受控环境中分析出 2308 项候选安全问题，动态复现其中 1724 项安全问题，针对其中的本地提权问题生成利用程序和候选补丁。

经过变体分析和去重，OpenAI 将其中 948 项计为不同的本地提权漏洞。这些漏洞在研究使用的测试环境中可能让低权限用户提权到 root，整个工作流的 API 费用为 121.3 万美元。

 从代码审查到漏洞利用、再生成补丁：

这项研究使用 OpenAI 即将推出的新款网络安全模型，该模型将工作拆分为漏洞发现、动态验证、利用评估、补丁生成和人工审查等多个不同的阶段。

首先负责侦查的 AI 智能体筛选低权限用户能够触及、具有安全研究价值的代码，系统最终选出 5034 个审计目标，涉及 280 万行代码，约占 Linux Kernel 内核代码的 7%。

随后分析智能体检查代码并寻找潜在缺陷，系统在约 12 个小时内生成去重后的 2308 项候选问题。验证阶段在隔离的虚拟机中运行，智能体为候选问题编写验证程序、观察程序输出和内核日志，再根据结果调整测试。

系统最终在 30 小时内动态复现 1724 项潜在的安全漏洞，接下来研究团队让智能体评估漏洞能否用于信息泄露或本地提权、在启用常见内核保护机制的测试环境中开发利用程序。

 整个工作流花费 121.3 万美元：

这个系统在利用评估阶段生成 1169 个可工作的本地提权利用程序和 291 个信息泄露验证程序，由于不同利用程序可能对应某个漏洞的变体，所以经过去重筛选后团队生成 948 个不同的补丁，也就是对应内核中存在的 948 项独立的本地提权问题。

OpenAI 称这次完整的研究合计消耗大约 121.3 万美元的 API 额度，按照去重后的 948 项漏洞计算，平均每项 1279 美元。研究团队还人工验证 166 个利用程序，发现至少 10 种此前从未见过的 Linux 漏洞利用技术。

 向内核团队提交数百份报告和补丁：

此次研究扫描使用的是 2026 年 10 月中旬发布的 Linux Kernel，扫描和人工分析完成时已经有 61 项漏洞在上游被修复，另有 43 项已经有待合并的补丁，约有 299 项被公开报告或讨论。

根据内核社区的提议，OpenAI 优先提交数百份涉及高危漏洞的报告和补丁，其他问题正在继续与内核社区或相关合作伙伴沟通，推进这些问题的修复。

值得注意的是，OpenAI 可能为了避免使用 AI 分析漏洞最后生成垃圾报告，OpenAI 提交的报告和补丁最终都由安全研究团队检查，检查通过后才被提交给内核维护者。
