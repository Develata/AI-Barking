This page contains release notes for features and updates to the
Google Workspace command-line interface, gwscli. We recommend that
Google Workspace developers periodically check this list for any new
announcements.

November 24, 2026

 Feature

Generally Available: The Google Workspace command-line interface, gwscli,
is now generally available.

The Google Workspace command-line interface provides a unified terminal client
for interacting with Google Workspace services and APIs. The tool is designed
primarily for AI agents operating in automated environments, and also supports
developers in interactive terminals.

For more information, see Use the Google Workspace command-line interface
(CLI) [https://developers.google.com/workspace/guides/workspace-cli].
