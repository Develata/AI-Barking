Google will make AI agents use new gateways to reach Gmail and Drive

Agents must switch from Workspace's regular APIs by February, and need a person's approval before sending email.

November 24, 2026 - 6:24 pm GMT

Google has made its Workspace MCP servers and CLI generally available and says AI agents must use them instead of existing REST APIs from February 1, 2027. Every call is checked against company policies, sensitive actions need user confirmation, and a new addendum bars AI tools from training on Workspace data.

Google will require AI agents to reach Gmail, Drive and other Workspace apps through new, dedicated gateways, it said [https://cloud.google.com/blog/products/identity-security/deploying-agents-safely-in-your-enterprise] on Tuesday. Regular apps can keep using Workspace’s existing APIs, but agents must switch by February 1, 2027.

The gateways are Workspace MCP servers, which use a common standard for linking AI tools to apps, and a command-line tool. Both are now generally available. Google put an early CLI version [https://thenextweb.com/news/google-made-gmail-and-drive-easier-for-ai-agents-to-use] on GitHub in March.

Google says its APIs were built for apps that work at human speed, where a valid login meant the user wanted the action. Agents act on their own at machine speed. So every request now gets checked against company permissions and data-loss rules.

Agents can draft emails and summarise documents on their own. But they need a person’s sign-off before sending email, changing Drive sharing or making bulk edits.

Each agent also needs its own sign-in ID with tight limits and usage quotas. Google already gives its Gemini coworker agents their own accounts [https://thenextweb.com/news/gemini-agent-workspace-identity-europe]. It will begin billing for that usage on April 1, 2027.

A new AI Tools Addendum adds rules on data. AI tools cannot use Workspace data to train models or build rival services, and cannot scrape it. They must also delete it when a user disconnects.

Google also tells developers to screen for prompt injection, hidden commands in emails or files that can hijack AI agents [https://thenextweb.com/news/ai-agent-security-four-attacks-one-flaw]. Some controls are still to come, including letting users see and revoke agents’ access themselves.

Other firms are drawing lines too. In October, Charles Schwab said it blocks outside agents [https://thenextweb.com/news/schwab-blocks-ai-agents-meta-muse] from moving client money.
