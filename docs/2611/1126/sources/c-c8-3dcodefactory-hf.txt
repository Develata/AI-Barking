 [#📊-dataset-overview]

 📊 Dataset Overview

3DCodeFactory is an automated framework that directly constructs diverse, complex 3D training data from abundant raw text:

5,045 Verified Multi-Turn Trajectories: 2,920 Blender procedural modeling trajectories and 2,125 Three.js interactive web scene trajectories.

Scale & Complexity: 4,270 median lines of code per scene (1.09M average tokens and 413.6 tool calls per trajectory).

Hierarchical 3D Taxonomy: 56 fine-grained categories across 10 major domains (87.7% cross-domain composite scenes).

Multi-Dimensional Rubric Verification: Joint multi-view VLM visual judge, scene-graph specification verification, and automated Playwright interactive functional testing.
