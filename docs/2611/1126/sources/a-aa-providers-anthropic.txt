Anthropic offers 51 models, each with different intelligence, performance, and pricing characteristics. Below is a comparison of the key metrics across models.

For intelligence, the top models on Anthropic are Claude Fable 5.2 (max) (65), Claude Fable 5.2 (xhigh) (62), and Claude Fable 5.2 (high) (62).

For time per task, Claude Haiku 5.5 (low) (2.1 min), Claude Sonnet 5.5 (low) (2.6 min), and Claude Opus 5.5 (low) (2.9 min) finish an Intelligence Index task fastest on Anthropic.

For latency, Claude 4.5 Haiku (non-reasoning) (1.10s), Claude Opus 4.7 (non-reasoning, high) (1.14s), and Claude Sonnet 5 (non-reasoning) (1.26s) offer the lowest time to first answer token.

For pricing, Claude Haiku 5.5 (max) ($0.08), Claude Haiku 5.5 (xhigh) ($0.08), and Claude Haiku 5.5 (high) ($0.08) offer the lowest blended prices per 1M tokens.

For context window size, Claude Fable 5.2 (max) (1M), Claude Fable 5.2 (xhigh) (1M), and Claude Fable 5.2 (high) (1M) support the largest context windows on Anthropic.

What Cache Hit Rate Shows

The share of cacheable input tokens served from the provider's prompt cache, measured during multi-turn agentic sessions. We regularly measure each endpoint and report a representative rate based on recent measurements. Higher values mean more of the input is billed at the cheaper cache-hit price, where the provider offers one, which lowers the effective cost of agentic workloads. For further details, see our methodology page [/methodology/performance-benchmarking].
