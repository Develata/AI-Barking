Scaling Training Data for 3D Code Agents
 [#scaling-training-data-for-3d-code-agents]

 [https://3dcodefactory.github.io/] [/3DCodeFactory/3DCodeFactory/blob/main/assets/paper/3DCodeFactory.pdf] [https://huggingface.co/datasets/wangzhaoyu/3DCodeFactory] [https://opensource.org/licenses/Apache-2.0]

News
 [#news]

[2026-11] Released our project page [https://3dcodefactory.github.io/], technical report [/3DCodeFactory/3DCodeFactory/blob/main/assets/paper/3DCodeFactory.pdf], 3DCodeFactory-Data [https://huggingface.co/datasets/wangzhaoyu/3DCodeFactory], and the code3d synthesis & verification framework.

Highlights
 [#highlights]

3DCodeFactory-Data: 10 Domains & 56 Categories
 [#3dcodefactory-data-10-domains--56-categories]

 [/3DCodeFactory/3DCodeFactory/blob/main/assets/figures/fig2_taxonomy.png]

 [/3DCodeFactory/3DCodeFactory/blob/main/assets/figures/fig5_dataset_statistics.png]

3DCodeFactory-Data [https://huggingface.co/datasets/wangzhaoyu/3DCodeFactory] spans 10 primary domains and 56 fine-grained categories (87.7% cross-domain composite scenes), providing 5,045 verified multi-turn trajectories (2,920 Blender & 2,125 Three.js, 5.52B tokens, median 4,270 LOC and 413.6 tool calls per trajectory). Under the default paper profile (synthesis.blender_static_only = true), the Blender track focuses on high-fidelity offline static modeling and Cycles rendering ($F = \varnothing$), while the Three.js track targets browser-native, user-triggered runtime interactivity ($0 \le K \le 3$ verified via Playwright); setting blender_static_only = false enables dynamic Blender function synthesis and verification.

Results
 [#results]

Fine-tuning on 3DCodeFactory-Data substantially boosts downstream 3D generation and editing. Across BlenderWorld, P3D-Bench, 3DCodeBench, and BlenderGym, Qwen3.5-9B gains +27.81 average points (+50.75 on BlenderWorld), and Qwen3.8-27B (66.78 avg.) surpasses the 2.4T flagship Qwen3.8-Max (62.75 avg.):

Quickstart
 [#quickstart]

git clone https://github.com/3DCodeFactory/3DCodeFactory.git
cd 3DCodeFactory
uv sync --locked --group dev
uv run pytest -q

cp configs/paper.toml configs/local.toml
# Configure OpenAI-compatible endpoints in configs/local.toml and export API keys:
# SYNTHESIS_API_KEY, IMAGE_API_KEY, SOLVER_API_KEY, JUDGE_API_KEY
uv run code3d validate --config configs/local.toml --seeds examples/seeds.jsonl
uv run code3d run --config configs/local.toml --seeds examples/seeds.jsonl --output runs/pilot
