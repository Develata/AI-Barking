产品介绍

腾讯混元生3D（Tencent HY 3D）​​ 基于腾讯自研生成式 AI 大模型，提供3D 内容生成的 API 技术服务。API 支持通过文本描述或上传2D 图像自动创建高精度3D 模型，可广泛应用于3D 打印、家装家具、产品设计等领域。混元生3D API 显著降低了专业级建模的技术门槛，提升了创作效率及设计灵活性，赋能多行业高效完成3D 内容生产。

已上线 API 接口服务

混元生3D（专业版）：可选用混元生3D 3.0、3.1 模型，生成更高精度以及更高质量的3D 模型，支持文生3D，图生3D，多视图生3D，单几何生成（白模），草图生3D，智能拓扑生3D 功能；在此基础上，3.1 版本模型 在几何、纹理质量上实现进一步提升，支持八视图多角度输入。

混元生3D（极速版）：采用混元生3D 极速版模型，可将生成模型时间缩短至1分30秒内，可在较短时间内生成3D 模型文件。

智能拓扑：采用 Polygon 1.5模型，输入3D 高模后，可生成布线规整，较低面数的3D 模型。

纹理生成：输入单几何模型和参考图或文字描述后，可生成对应的纹理贴图。

组件生成：输入3D 模型后，可自动识别模型结构，生成对应模型的3D 组件。

UV 展开：输入3D 模型后，可自动化生成高质量 UV 切线模型。

3D 人物生成：输入人物头像图片后，可根据模板生成对应人物形象的3D 模型。

模型格式转换：输入3D 模型后，可转换成不同格式的3D 模型文件。

文生动作：输入文本描述后，可生成对应动作数据的3D 人物模型。
