Kimi for Science

Kimi for Science
让更多科学想法成为可能

首期截止时间 12月8日，更多批次将陆续开放

立即申请 [#science-application]

科学探索，始终由人类的好奇心、严谨的求证精神与探索未知的热忱所驱动

一个有价值的假设，往往需要经历大量文献梳理、数据分析与反复验证；而一个意想不到的结果，也可能成为下一次突破的起点。然而，受限于时间、算力与人力，许多值得探索的想法，未必都有机会被充分尝试。我们相信，AI 既能加速科学研究的进程，也能拓展科学探索的边界：帮助科研工作者突破时间、资源与方法的限制，让更多大胆的设想有机会走向验证

从生命健康到能源材料，从基础科学的前沿到尚未触及的未知领域，仍有无数重要的科学问题等待解答。我们希望，Kimi 能够成为科学家探索未知的有力伙伴：支持研究者挑战更困难、更具原创性的问题

让每一个大胆的设想都有被验证的机会，让更多具有长远价值的科学发现成为现实

我们在寻找

Kimi for Science 首期将面向自然科学、工程学及相关交叉学科的科研人员开放申请

我们欢迎不同阶段的科研探索：无论是借助 Kimi 改进现有研究流程，还是尝试新的研究方法、攻克更具挑战性的科学问题

为此，我们将提供

让探索拥有更多资源

入选申请者将获得最高 15 万元 Kimi API 额度（约合 70 亿 tokens），具体额度根据研究需求与评审结果确定

专属技术与研究资源

来自 Kimi 团队的技术支持，以及优先体验新模型、获取精选研究与社区资源的机会

长期合作机会

优秀研究者及团队，获得更长期、更深入的技术与资源支持

Kimi for Science 现已开放申请

可多次提交申请，以最后一次提交的内容为准

常见问题

哪些科研人员或团队可以申请？

自然科学、工程学及相关交叉学科的科研人员与研究团队均可申请，无论是改进现有研究流程，还是尝试新的研究方法。

API Credits 的支持额度是多少？

入选申请者可获得最高 15 万元 Kimi API 模型调用额度（约合 70 亿 tokens），具体额度根据研究需求与评审结果确定，并非现金资助。

申请前需要准备哪些材料？

建议准备研究者信息、研究任务、数据来源、当前工作流、Kimi 使用方式与验证指标，Token 估算和里程碑计划可按需补充。

入选后还能获得哪些支持？

除 API Credits 外，还包括 Kimi 团队技术支持、新模型优先体验、精选研究与社区资源，以及长期合作机会。

如何获知评审结果？

评审结果将发送至申请时填写的邮箱。是否入选及具体支持内容，以最终评审结果为准。

如何联系项目团队？

如有申请或项目合作相关问题，请联系 ai4science@moonshot.ai [mailto:ai4science@moonshot.ai]
