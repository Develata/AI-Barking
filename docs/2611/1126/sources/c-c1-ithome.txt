IT之家 [https://www.ithome.com/] 11 月 27 日消息，昨日起，有部分 DeepSeek 用户反馈，网页端和移动端 App 内正在灰度测试“显示本轮消耗额度”功能。

用户在完成一轮对话后，界面会弹出详情页，展示本次交互消耗的 Token 数量及其对应的估算金额（价格和 API 持平）。尽管当前面向个人用户的对话服务依然免费，但该功能让单次对话背后的计算成本变得可见。

根据用户提供的截图，额度按“空闲时段”价格估算。计费拆分为三个维度：

输入缓存命中部分，单价为 0.02 元 / 百万 tokens，本轮用量约 18.5 万，折合 0.0037 元；

输入缓存未命中部分，单价为 1 元 / 百万 tokens，用量约 1.2 万，折合 0.012 元；

输出部分单价为 4 元 / 百万 tokens，用量 1470，折合 0.0058 元。

在多轮对话中，系统会缓存之前的历史上下文，后续输入时只需对“新增”部分进行全价计算，从而大幅降低长对话的累积成本。缓存命中输入（IT之家注：指模型直接复用先前计算过的上下文 K-V 缓存，避免重复计算，因此单价极低）的单价仅为未命中时的五十分之一。

此外，详情页底部还增加了一行进度提示：“截止到本轮，上下文已占用...”。该设计有助于用户直观感知当前对话的容量，当占用比例接近 100% 时，系统通常会提示或自动截断早期对话，以防超出模型的最大上下文窗口。
