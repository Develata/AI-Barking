Claude Fable 5.2 (Max, Default Fallback) is amongst the leading models in intelligence, but particularly expensive when comparing to other models of similar price. It's also notably slow per task and very verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

Claude Fable 5.2 (Max, Default Fallback) scores 65 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 44). When evaluating the Intelligence Index, it generated 275M tokens, which is very verbose in comparison to the median of 65.4M.

Pricing for Claude Fable 5.2 (Max, Default Fallback) is $8.00 per 1M input tokens (expensive, median: $2.00) and $40.00 per 1M output tokens (expensive, median: $10.00). On average, it costs $26.54 per task to evaluate Claude Fable 5.2 (Max, Default Fallback) on the Intelligence Index.

At 40.4 minutes per Intelligence Index task, Claude Fable 5.2 (Max, Default Fallback) is notably slow compared with the median of 12.2 minutes for comparable models (lower is better).

Frequently Asked Questions

Common questions about Claude Fable 5.2

When was Claude Fable 5.2 released?

Claude Fable 5.2 was released on November 9, 2026.

Who created Claude Fable 5.2?

Claude Fable 5.2 was created by Anthropic.

How intelligent is Claude Fable 5.2?

Claude Fable 5.2 has 5 effort levels: max, xhigh, high, medium, and low. Claude Fable 5.2 scores 65 (max), 62 (xhigh), 62 (high), 56 (medium), and 54 (low) on the Artificial Analysis Intelligence Index. Claude Fable 5.2 (Max, Default Fallback) is well above average among other models in a similar price tier (median: 44).

How fast is Claude Fable 5.2?

Claude Fable 5.2 takes 40.4 minutes (max), 23.9 minutes (xhigh), 14.6 minutes (high), 6.5 minutes (medium), and 5.3 minutes (low) per Intelligence Index task (based on Anthropic's API; lower is better). Claude Fable 5.2 (Max, Default Fallback) is among the slowest compared to other models in a similar price tier (median: 12.2 minutes).

What is the latency of Claude Fable 5.2?

Claude Fable 5.2 has a time to first answer token of 242.18s (max), 73.39s (xhigh), 27.75s (high), 11.98s (medium), and 8.67s (low) (based on Anthropic's API). Claude Fable 5.2 (Max, Default Fallback)'s time to first answer token is at the higher end compared to other models in a similar price tier (median: 13.28s).

How much does Claude Fable 5.2 cost?

Claude Fable 5.2 costs $8.00 per 1M input tokens (at the higher end, median: $2.00) and $40.00 per 1M output tokens (at the higher end, median: $10.00), based on Anthropic's API.

What is Claude Fable 5.2 API pricing?

Claude Fable 5.2 costs $8.00 per 1M input tokens and $40.00 per 1M output tokens (based on Anthropic's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $5.74 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/claude-fable-5-2/providers]

How verbose is Claude Fable 5.2?

When evaluated on the Intelligence Index, Claude Fable 5.2 generated 275M output tokens (max), 144M output tokens (xhigh), 85.3M output tokens (high), 41M output tokens (medium), and 34.9M output tokens (low). Claude Fable 5.2 (Max, Default Fallback)'s output token count is at the higher end compared to other models in a similar price tier (median: 65.4M).

Is Claude Fable 5.2 a reasoning model?

Yes, Claude Fable 5.2 is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Claude Fable 5.2 support?

Claude Fable 5.2 supports text and image input.

What output modalities does Claude Fable 5.2 support?

Claude Fable 5.2 supports text output.

Can Claude Fable 5.2 process images?

Yes, Claude Fable 5.2 supports image input and can analyze, describe, and answer questions about images.

Is Claude Fable 5.2 multimodal?

Yes, Claude Fable 5.2 is multimodal. It can process text and image input and generate text output.

What is the context window of Claude Fable 5.2?

Claude Fable 5.2 has a context window of 1M tokens. This determines how much text and conversation history the model can process in a single request.

Is Claude Fable 5.2 open source?

No, Claude Fable 5.2 is proprietary. The model weights are not publicly available.

How many parameters does Claude Fable 5.2 have?

Claude Fable 5.2 is a proprietary model and Anthropic has not disclosed the model size or parameter count.

How does Claude Fable 5.2 perform on benchmarks?

Claude Fable 5.2 achieves a score of 65 (max), 62 (xhigh), 62 (high), 56 (medium), and 54 (low) on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across knowledge work, coding, science, and general knowledge.

Is Claude Fable 5.2 available via API?
