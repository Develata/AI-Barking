## 1. 标题

**我会先点 Gmail 那条。**

1. 「报道称Gmail接口禁发信，谷歌连夜改了」——我平时用 Gmail，看到“禁发信”就想知道之前谁发不了、现在恢复了没有。
2. 「谷歌连夜放开AI发邮件，没弹窗仍发不了」——“AI 发邮件”一眼就懂，我也好奇是不是每封邮件都得我点一下确认。
3. 「Claude破坏科研？官方早明写且已回应」——“破坏科研”让我想知道 Claude 到底做坏了什么，尽管“早明写”没告诉我写了什么。

**刷过去时，我看不明白这几条具体发生了什么。**

- 「媒体称Claude降智，实为限两项与误封」——哪两项？封的是账号，还是某个功能？
- 「媒体称Claude破坏科研，官网早限两项」——我看得出有人在批评 Claude，但“限两项”完全没画面。
- 「多方批Claude，只因防蒸馏误封与限能」——“防蒸馏”“误封”“限能”连在一起，我连被封的是谁都不知道。
- 「斯威尼批Claude，只因反蒸馏误封」——我不认识斯威尼，也不知道“反蒸馏”是什么，只能猜他被封号了。

只看第一名「报道称Gmail接口禁发信，谷歌连夜改了」，我会以为有些用 Gmail 的第三方软件突然发不了邮件，媒体报道后谷歌当晚恢复了。我不会想到还得人工点确认。

## 2. 读不懂

**开头和 Claude 部分**

- 「省流：媒体称 Claude“降智”，Anthropic 实为训练期只限两项并回退，斯威尼撞上反蒸馏误封。」——我不知道 Anthropic 和 Claude 是什么关系，“训练期”是谁在训练，“两项”是哪两项，“回退”又退到哪里。最后还多了一个不认识的人和一个没解释的词。
- 「谷歌连夜补开 Gmail 发信，无确认弹窗仍发不了。」——我第一反应是 Gmail 本来不能发邮件。“无确认弹窗”让我以为是网页没弹出来，刷新一下可能就好。
- 「一、Claude：科研限能与反蒸馏误封」——“科研限能”听起来像整个科研用途都受限。“反蒸馏误封”读完标题我还是不知道谁被封、为什么被封。
- 「11月25日，MagicPath CEO 称 Claude 破坏科研，斯威尼称被当蒸馏封停；27日2.4万步对比图在 HN 获超140分。」——MagicPath CEO 和斯威尼是同一个人吗？“2.4万步”是谁走的、图在比什么？HN 的 140 分是网友投票，还是模型测试分？
- 「Anthropic 员工26日回应，Fable-5.2 只在训练期将芯片算子优化与改模型架构压至约 Opus-5.5，推理不改，少数主题明面回退 Opus-5。」——这句我得读两遍。“算子”不懂，三个版本名也不知道哪个更强。“训练期”和“推理”看起来像我使用 Claude 之前和之后的两个阶段，但我不确定。前面说“压至约 Opus-5.5”，后面又说“回退 Opus-5”，我分不清这是两种变化，还是在说同一件事。
- 「对你：常规编程与机器学习不受此限；网页与 Claude Code 回退有提示且可关；API 撞反蒸馏或竞争模型拦截零输出仍计费。」——“此限”是哪一种限制？“可关”是能关提示，还是能关回退？最后一句我猜是没收到回答也会扣钱，但看不出谁会触发拦截，以及我在网页上聊天会不会遇到。
- 「①51CTO 写“全给阉割”，动区27日仍写“尚未回应”；官方只限两项且员工26日已回，6月 Fable-5 两天不可见降级已道歉。」——我得回去找“两项”。“两天不可见降级”也要倒回来读，才猜到是降级持续了两天，期间用户看不到提示。6 月那次和这次有什么关系，我没接上。
- 「②斯威尼26日澄清仅批反蒸馏、肯定 Claude；27日对比图做图像生成，未写型号与代码，官方自认正常机器学习可能误触。」——27 日的图也是斯威尼发的吗？前面说机器学习不受限，这里又说可能误触。我猜一个是主动限制、一个是误判，但要自己把这层关系拼出来。
- 「③API 须传参才回退，防提取推理链无回退且零输出计费；Artificial Analysis 榜标“Default Fallback”，方法页未写回退算分。」——“传参”“推理链”“Default Fallback”都卡住我。“无回退”是继续用原模型，还是直接不给回答？最后的“算分”又是另一个榜单的分，和前面的 HN 140 分有什么关系？

**Gmail 部分**

- 「11月26日晚，称谷歌 Gmail 新接口不能发信的报道在 HN 获超350分。」——我要读到“报道”才知道是谁在说。“新接口”和我手机里的 Gmail 有什么关系？350 分高在哪，能和前面的 140 分直接比吗？
- 「谷歌25日上线9个办公 AI 专用接口（MCP）与 gwscli，明年2月1日起代理直连旧接口限回免费档。」——括号里又来了一个缩写，gwscli 也没解释。“代理”是替我干活的 AI，还是某个软件？“限回免费档”是少了功能，还是使用次数变少？
- 「27日晚实测主通道与 gwscli 已放开30个工具含发信。」——谁实测的？“主通道”是哪一个？刚说 9 个接口，现在说 30 个工具，我不知道两个数字是在数同一类东西，还是一套接口里包含很多工具。
- 「对你：网页或手机正常收发不受影响；个人号用“个人模式”免费每天每项目每产品5000次（搜会话算10次）；无弹窗旧客户端只能写草稿。」——第一句能懂。后面“个人模式”在哪开、“项目”和“产品”各指什么、“搜会话”点一次为什么算 10 次，我都不知道。“旧客户端”也容易让我想到旧版 Gmail 手机 App。
- 「①26日实测主通道确仅23个工具、发信须合作方权限；27日放开到30个，无弹窗备用通道仍只25个，不能发信、回复和转发。」——23 到 30 我能看出是在比前后两天，但 25 是另一个通道的数。我还得猜“备用通道”和上一段的“旧客户端”是不是一回事。
- 「②主通道发信默认须人工确认，无人值守脚本不改策略仍发不了，并未如动察快讯标题所写“把Gmail彻底锁死给Gemini”。」——人工确认我能懂。“不改策略”是改谷歌的设置，还是改脚本？末尾突然出现 Gemini，我不知道它原来在这件事里扮演什么角色。
- 「③动察快讯标题写“阉割收费版”，标准档实际每天免费5000次；4月升付费档后传统接口留百万级免费额度，MCP 免费额度清零且不豁免自用。」——谁在 4 月升档？“百万级”是按天、按月还是按年？这里的 5000 次是前面个人模式那一份吗？“不豁免自用”我读完也不知道自己的账号会怎样。

## 3. 像 AI 写的

- 「省流：媒体称 Claude“降智”，Anthropic 实为训练期只限两项并回退，斯威尼撞上反蒸馏误封。」——“媒体称……实为……”像先套了一个辟谣句式，两项是什么却省掉了。读起来像把长文压成了一行关键词。
- 「对你：常规编程与机器学习不受此限；网页与 Claude Code 回退有提示且可关；API 撞反蒸馏或竞争模型拦截零输出仍计费。」——“对你”让我以为接下来会说我平时用 Claude 会遇到什么，后半句却像开发文档里的计费备注，那个“你”有点像硬加上去的。
- 「对你：网页或手机正常收发不受影响；个人号用“个人模式”免费每天每项目每产品5000次（搜会话算10次）；无弹窗旧客户端只能写草稿。」——又是“对你”加三截并列，只有第一截是我在手机上马上用得上的。后两截像把配额表塞进同一个模板。
- 「AI 沸点，今日谁吠？」和「AI 吠点：聊 AI 沸点，轻松识破吠点。」——开头结尾都在凑“沸点／吠点”的谐音。尤其“轻松识破”像自动补上的宣传口号，我读完反而还在猜哪些情况会扣钱、哪些情况发不出邮件。

## 4. 会划走的地方

- **我大概会在 Claude 的第一段划走。**「Anthropic 员工26日回应，Fable-5.2 只在训练期将芯片算子优化与改模型架构压至约 Opus-5.5，推理不改，少数主题明面回退 Opus-5。」上一句的对比图我还没弄懂，这句又要认三个模型名。我从 Gmail 标题点进来，到这里还没看到邮件。
- **最不在乎的是 Claude 第③条的榜单部分。**「Artificial Analysis 榜标“Default Fallback”，方法页未写回退算分。」我会在乎没收到回复还扣钱，但我平时不看模型榜，这条怎么计分对我没什么影响。
- **读完我知道两件和自己有关的事。**「对你：常规编程与机器学习不受此限」让我觉得平时找 Claude 写点代码可以照常。「对你：网页或手机正常收发不受影响」让我知道 Gmail 也可以照常用。
- **真想让 AI 替我发信，我只知道要留意确认。**「主通道发信默认须人工确认，无人值守脚本不改策略仍发不了」让我知道可能还要自己点一下。但看到「无弹窗旧客户端只能写草稿」，我还是不知道自己用的工具走哪条通道，也不知道没有弹窗时能去哪里设置。
## 采纳

- 标题与排序：采纳读者先点 Gmail 的判断，将 Gmail 与 Claude 两帖对调（一、谷歌 Gmail；二、Anthropic Claude）；标题确定为「报道称Gmail接口禁发信，文档已列发信」（20 字），贴合实测反差与官文档案状态。
- 开篇与说人话：将「省流」「对你」按普通人阅读习惯改写，说明“算子优化与改模型架构”只在训练阶段做、平时聊天写代码不受影响；补充「新接 AI 工具（MCP）」「网页或手机点确认（弹窗）」「命令行工具 gwscli」「个人模式每天免费 5000 次、搜一次算 10 次」「官方反蒸馏拦截直接报错但不退费」等平白解释；解释 HN 与 Artificial Analysis 为独立榜单/社群。
- 口号与字数：删除「@RealAstropulse」无实质作用账号名（Round 1 核验同时指出其来源薄弱），保留品牌收尾口号，正文总字数控制在 972 字（不含空白 903 字）。
