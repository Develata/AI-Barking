Ling-3.2-air is amongst the leading models in intelligence when comparing to other open weight models of similar size. The model supports text and image input, outputs text, and has a 1M tokens context window.

Ling-3.2-air scores 23 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 5). When evaluating the Intelligence Index, it generated 199M tokens, which is very verbose in comparison to the median of 72.4M.

Total Parameters

The total number of trainable weights and biases in the model, expressed in billions. These parameters are learned during training and determine the model's ability to process and generate responses.

Active Parameters at Inference Time

The number of parameters actually executed during each inference forward pass, expressed in billions. For Mixture of Experts (MoE) models, a routing mechanism selects a subset of experts per token, resulting in fewer active than total parameters. Dense models use all parameters, so active equals total.

Frequently Asked Questions

Common questions about Ling-3.2-air

When was Ling-3.2-air released?

Ling-3.2-air was released on November 23, 2026.

Who created Ling-3.2-air?

Ling-3.2-air was created by InclusionAI.

How intelligent is Ling-3.2-air?

Ling-3.2-air scores 23 on the Artificial Analysis Intelligence Index, placing it well above average among other open weight models of similar size (median: 5).

How verbose is Ling-3.2-air?

When evaluated on the Intelligence Index, Ling-3.2-air generated 199M output tokens, which is at the higher end compared to other open weight models of similar size (median: 72.4M).

Is Ling-3.2-air a reasoning model?

Yes, Ling-3.2-air is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Ling-3.2-air support?

Ling-3.2-air supports text and image input.

What output modalities does Ling-3.2-air support?

Ling-3.2-air supports text output.

Can Ling-3.2-air process images?

Yes, Ling-3.2-air supports image input and can analyze, describe, and answer questions about images.

Is Ling-3.2-air multimodal?

Yes, Ling-3.2-air is multimodal. It can process text and image input and generate text output.

What is the context window of Ling-3.2-air?

Ling-3.2-air has a context window of 1M tokens. This determines how much text and conversation history the model can process in a single request.

Is Ling-3.2-air open source?

Yes, Ling-3.2-air is open weights. The model weights are publicly available and can be downloaded for self-hosting.

How many parameters does Ling-3.2-air have?

Ling-3.2-air has 124B parameters (5.5B active).

What are the active parameters of Ling-3.2-air?

Ling-3.2-air is a Mixture of Experts (MoE) model with 124B total parameters, but only 5.5B active parameters are used during inference.

What is the license for Ling-3.2-air?

Ling-3.2-air is released under the MIT license. This license allows commercial use. View license [https://opensource.org/license/mit]

How does Ling-3.2-air perform on benchmarks?

Ling-3.2-air achieves a score of 23 on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across knowledge work, coding, science, and general knowledge.

Is Ling-3.2-air available via API?

Ling-3.2-air is an open weights model that can be self-hosted. View providers [/models/ling-3-2-air/providers]

Where can I use Ling-3.2-air?

Ling-3.2-air is an open weights model that can be downloaded and self-hosted. Compare providers [/models/ling-3-2-air/providers]
