How to use JetBrains/Mellum2.1-12B-A2.5B-Instruct with Transformers:

# Use a pipeline as a high-level helper
from transformers import pipeline

pipe = pipeline("text-generation", model="JetBrains/Mellum2.1-12B-A2.5B-Instruct")

 {"role": "user", "content": "Who are you?"},
]
pipe(messages)

# pip install -U transformers accelerate
# Load model directly
from transformers import AutoTokenizer, AutoModelForCausalLM

tokenizer = AutoTokenizer.from_pretrained("JetBrains/Mellum2.1-12B-A2.5B-Instruct")
model = AutoModelForCausalLM.from_pretrained("JetBrains/Mellum2.1-12B-A2.5B-Instruct", device_map="auto")
messages = [
 {"role": "user", "content": "Who are you?"},
]
inputs = tokenizer.apply_chat_template(
 messages,
 add_generation_prompt=True,
 tokenize=True,
 return_dict=True,
 return_tensors="pt",
).to(model.device)

outputs = model.generate(**inputs, max_new_tokens=256)
print(tokenizer.decode(outputs[0][inputs["input_ids"].shape[-1]:]))

 [#mellum21-instruct]

 Mellum2.1 Instruct

Mellum2.1 Instruct answers directly, without a chain of thought. Use it for fast agentic work, such as sub-agents, tool loops, small fixes, and questions about code. For long, difficult tasks that benefit from reasoning before acting, use Mellum2.1 Thinking [https://huggingface.co/JetBrains/Mellum2.1-12B-A2.5B-Thinking].

 [#mellum21-instruct-highlights]

 Mellum2.1 Instruct Highlights

Mellum2.1 Instruct is the next version of Mellum2 Instruct [https://huggingface.co/JetBrains/Mellum2-12B-A2.5B-Instruct] and the direct-answer sibling of Mellum2.1 Thinking [https://huggingface.co/JetBrains/Mellum2.1-12B-A2.5B-Thinking]. The architecture is unchanged (a 12B mixture-of-experts model with 2.5B active parameters). What changed is post-training:

Reinforcement learning in real environments: like Mellum2.1 Thinking, the model was trained with large-scale reinforcement learning, including agentic training inside real repositories with shell and file tools, where it is rewarded when the tests pass. Training was built on NVIDIA's open-source NeMo RL [https://github.com/NVIDIA-NeMo/RL] and NeMo Megatron-Bridge [https://github.com/NVIDIA-NeMo/Megatron-Bridge] libraries.

Direct, concise answers: the model answers without a chain of thought. On our repository-level validation tasks, it generates about half as many tokens as Mellum2.1 Thinking.

Large gains over Mellum2 Instruct: the model resolves 40.4% of SWE-bench Verified tasks, up from 20.2%. It also improves on most coding, math, tool-use, and instruction-following benchmarks, for example from 32.3 to 61.1 on AIME and from 22.2 to 38.0 on WorkBench.

 [#model-overview]

 Model Overview

Mellum2.1 Instruct has the following features:

Number of Parameters: 12B total, 2.5B active

Number of Layers: 28

Hidden Size: 2304

Intermediate Size: 7168

MoE Intermediate Size: 896

Number of Experts: 64

Number of Activated Experts: 8

Number of Attention Heads (GQA): 32 for Q and 4 for KV

Context Length: 131,072

Sliding Window: 1,024 (3 of every 4 layers)

Vocabulary Size: 98,304

Precision: bfloat16

License: Apache 2.0

The mellum architecture is supported in transformers 5.11.0 and later.

# Configured by environment variables

 {"role": "user", "content": "Write a Python function to reverse a string."},
]

 model="JetBrains/Mellum2.1-12B-A2.5B-Instruct",
 messages=messages,
 max_tokens=81920,
 temperature=0.6,
 top_p=0.95,
 extra_body={"top_k": 20},
)
print("Chat response:", chat_response)
