# 1125 读者稿检查

检查者：Codex `gpt-6-astra`（effort medium，read-only，不带本期上下文），北京 11-26 约 21:55。输入：初稿正文与 7 个标题候选。

## 1. 标题

前三名：

1. **“额度更快用完？OpenAI：上周少扣了”**——“更快用完”是我能理解的麻烦，后半句又让我好奇为什么上周会少扣。
2. **“OpenAI认错：上周少扣了你的额度”**——“认错”和“你的额度”让我觉得涉及自己的使用，但也会疑惑：少扣不是好事吗？
3. **“GPT-6.2额度更快用完？是上周少扣了”**——事情说得比较明白，不过如果我不知道自己用的是哪个版本，点进去的动力就弱一点。

看不出具体在说什么事：

- **“媒体称GPT额度砍近半，原帖比的是上周”**：“比的是上周”怎么就能解释“砍近半”？我看不出争议在哪里。
- **“黎曼证明‘砍掉99.5%’？是Claude重写”**：不知道“黎曼证明”是什么，也不知道砍掉的是文字、代码还是证明步骤。
- **“量子位称证明暴砍99.5%，实为AI重写”**：连是什么证明都没说；“量子位”我也不一定认识。
- **“额度砍近半？OpenAI比的是上周少扣”**：“比的是上周少扣”读着不顺，不清楚谁在拿什么比较。

只看第一名 **“额度更快用完？OpenAI：上周少扣了”**，我以为：最近 ChatGPT 没聊几次就提示到上限了，官方解释上周扣少了，现在恢复正常。我还不知道“额度”指聊天次数、钱，还是别的东西。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：“谁吠”是在说谁乱说话吗？没进入新闻就先碰上一个需要猜的梗。
- **“修正后 Astra 比上周快40%、Sol 快25%用到上限”**：Astra、Sol 是什么？“快40%”是使用次数少了四成，还是扣额度的速度快了四成？
- **“黎曼猜想证明出了7.6万行短版”**：我不知道黎曼猜想是什么；证明为什么按“行”算，七万多行为什么还叫短版？
- **“多数用户的 Astra、Sol 用量被少算”**：“用量被少算”和“额度被少扣”是不是一回事？这些名字是套餐还是模型？
- **“他称两者仍应比 GPT-6-Astra、GPT-6.1-Sol 耐用”**：一串相近型号让我停下来对照；“耐用”是能多问几次，还是能多处理一些文字？
- **“过去少扣的不追缴”**：额度也能追缴吗？是扣以后能用的次数，还是补收钱？
- **“用 API key 登录 Codex 按 API 价另计，不扣套餐额度”**：API key、Codex、API 价都不懂，也不知道为什么突然提另一种登录方式。
- **“按扣得快1.4倍算，同样额度的活约剩上周七成，按用完时间短四成算约剩六成”**：得读两遍才能发现这里给了两种算法；读完仍不知道实际该信七成还是六成。“扣得快1.4倍”本身也容易让我算岔。
- **“套餐页 Plus 每5小时的用量估计自上线起没改过”**：“估计”是作者在猜没改过，还是页面上的“预计可用量”？“上线”指哪个东西上线？
- **“Anthropic 的 Luke Sernau 公开黎曼猜想证明的 Lean 短版”**：公司、人名、Lean 连着出现，我只勉强抓住“有人公开了一个短版”。
- **“沿用 Alpöge 与 Claude 那份约1700万行证明的方法”**：Alpöge 是谁？前面没有交代“那份证明”，我像是漏看了一篇前情。
- **“紧凑版约7.6万行，可读版约30万行”**：“紧凑版”难道不能读？为什么可读就多出这么多行？
- **“许多步骤换了论证，只过了机器检查，没有数学家通读，也没有论文”**：机器检查通过到底说明什么？我不知道现在能不能把它当成已经证明了。
- **“两版都能编译，只用三条基础公理，命题与原版一致”**：“编译”“基础公理”“命题”都需要解释；也不确定“两版”指紧凑版和可读版，还是原版和重写版。
- **“说明写12核、24GB 内存要跑一到两小时”**：什么东西要“跑”？跑完我会看到什么，怎样算验成功？
- **“作者称绕开了原版依赖的几套大理论，不是删冗余”**：“大理论”是什么？绕开理论和删掉多余步骤，对结果有什么不同？
- **“统计站 rh-shrink 现显示代码‘只剩2.0%’，是因为社区仓库主分支11月26日换成了短版”**：“社区仓库主分支”完全卡住；2.0%又是以哪个版本为分母？
- **“代码从约1462万行减到约1100万行”**：前面原版是约1700万行，这里为什么变成1462万行？数字太多，我已经对应不上了。

## 3. 像 AI 写的

- **“对你：剩余额度和重置时间在 ChatGPT 设置的‘用量’页看；用 API key 登录 Codex 按 API 价另计，不扣套餐额度。”**：像套了“新闻后必须给读者建议”的模板；前半句我用得上，后半句突然塞进完全陌生的专业用法。
- **“对你：想自己验，说明写12核、24GB 内存要跑一到两小时；想读，可读版附了导读。”**：“想自己验／想读”排列得很工整，但默认我会验证数学代码，像为了凑“对你有用”而生成的建议。
- **“是 Claude 参与重写的，不是从原版删出来的。”**：开头就用“是……不是……”替我划重点，却还没让我明白这个区别为什么值得在意，有一种自动纠偏的口吻。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：“聊……轻松识破……”很像自动生成的品牌口号，尤其“轻松”跟刚才一大串难懂的数字和术语对不上。

## 4. 会划走的地方

- **“省流：OpenAI 员工称……Astra 比上周快40%、Sol 快25%……黎曼猜想证明出了7.6万行短版……”**：第一段就可能划走。说是省流，却同时塞进两个陌生型号、三组数字和一个陌生数学问题，我还没找到值得继续看的理由。
- **“按扣得快1.4倍算……约剩上周七成……约剩六成。”**：如果因为额度标题留下来，到这里我会明显失去耐心。我想知道自己还能用多少，文章却让我跟着算两种没有定论的账。
- **“二、黎曼证明短版：7.6万行，是重写”**：这是第二个退出点。我是为额度点进来的，这里突然切到数学证明，没有承接我的兴趣。

不在乎的“吠点”：

- **“说明写的是‘重写’……不是删冗余。”**：对我来说，都是代码变短了。没有讲清这个区别会怎样改变我对新闻的理解，我不太在乎媒体用了哪个词。
- **“统计站 rh-shrink 现显示代码‘只剩2.0%’……换版前……少约四分之一。”**：我没看过这个统计站，也不关心它换版本前后的数字，像是在旁听圈内人对账。

读完知道的关系和行动：

- **“剩余额度和重置时间在 ChatGPT 设置的‘用量’页看”**：这是最明确的用处。如果我在用 ChatGPT，我知道可以去哪里查看额度。
- **“40%和25%是跟上周少扣时比”**：我大致懂了“最近更快用完有一个解释”，但还是不知道自己的套餐会少用多少。
- **“想自己验……想读……”**：数学部分跟我的关系仍不清楚。这两个行动对我都太远，我不会去做。

## 采纳

- 标题：采纳。读者排第一的“额度更快用完？OpenAI：上周少扣了”一眼能懂；原选“媒体称GPT额度砍近半，原帖比的是上周”被指看不出争议在哪。新标题没有待纠正的说法，不需要“说法 + 实际”。
- Astra、Sol 是什么：采纳，正文改为“Astra、Sol 两款模型”，上一代型号前加“上一代”。
- “快40%”两种算法读着累：采纳，吠点①改为一句“按两种读法算约剩上周的六到七成”，两种算法挪进事实清单。
- 套餐页“估计”不清：采纳，改为“OpenAI 套餐页给 Plus 写的‘每5小时约能发几条’”。
- API key 一句陌生：采纳，删去，改为“只用其他模型的不受影响”。
- 黎曼证明缺前情、Lean 不懂、“行”怎么算：采纳，补“原版是 Alpöge 与 Claude 11月20日公布的约1700万行 Lean 代码，Lean 是让电脑逐步检查证明的语言”；删“只用三条基础公理”“也没有论文”。
- “对你：想自己验”太远：采纳，改为“普通读者用不上；想看 AI 写的证明长什么样，可读版附了导读”。
- 吠点①“不在乎重写还是删”：采纳，补“听着像原版九成九是废话”说明区别为何要紧。
- 吠点②“社区仓库主分支”卡住、1462 万与 1700 万对不上：采纳，改为“社区公共仓库”“有效代码约1462万行”。
- 固定开场“AI 沸点，今日谁吠？”与 Slogan：不采纳，栏目固定格式。
- 第二条主帖与额度无关、会划走：不采纳。两条主帖是 Develata 选定的；省流已同时交代两件事。
