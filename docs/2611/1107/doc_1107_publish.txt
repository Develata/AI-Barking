用Claude点“不再询问”，密码公开？

AI 沸点，今日谁吠？

省流：Apiiro 称，公开网上1122份 Claude Code 设置文件存着疑似密码或密钥，能否使用没验证。DoubleAI 称 DeepSeek-V4.1-Flash 不开思考模式做竞赛题，自加探针后正确率从64%升到71%，“改写架构”这组原文没写。

一、Claude Code 把密码留进文件

让 Claude Code 连数据库时，命令里常带密码。Apiiro 称，弹窗选“Yes, and don't ask again”，批准的规则若是完整命令，密码也存进项目的设置文件。文件传上公开的代码网站 GitHub，谁都能看到。
Apiiro 搜到10.4万份这类公开文件，1122份含它判定的“真实密钥”，1家公司确认密钥曾有效。
Claude Code 团队的 Cherny 称，一直没做清除密钥，正在想办法。

吠点：
①“真实密钥”按格式和公网地址判定，再由 AI 复核，Apiiro 没试过能不能用。这1122份里的密钥近半是服务商密钥，不全是密码。
②Cherny 称文件是人手动建的再上传。Apiiro 称追溯1105个项目，539个有 Claude 署名的改动碰过它，证明不了密码是 Claude 传的。
③官方防护只在用户自己电脑上生效，不跟着项目走。
④同类问题2025年8月就有人报告，Apiiro 列的4个问题帖都被机器人关闭。

二、DeepSeek 给自己加探针

DoubleAI 博文称，让 DeepSeek-V4.1-Flash 分析自己做的243道旧题，写出判断对错的小程序“探针”。答完题，探针读一次内部状态，判错就重答，最多三次。
不开思考模式，做 AIME、HMMT 2026两场竞赛共63题，公司自测正确率从64%升到71%。只挑最长的答案重答，是65.4%。

吠点：
①新智元标题写“改写 Transformer 架构”，这组原文只说“控制采样”，没写改模型本身。
②新智元稿写“检查点当场回滚”，DoubleAI 原文是答完才读探针，半途探针分不清同题两次作答的成败。
③新智元稿的“消耗相同的 token 预算”原文没有，这组也没给成本。
④DoubleAI 没披露实验重复次数，截至11月9日本号未查到第三方复现。

AI 吠点：聊 AI 沸点，轻松识破吠点。
