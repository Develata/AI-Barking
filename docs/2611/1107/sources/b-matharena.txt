 How are expected performance and cost computed?

 Expected performance averages normalized scores across all questions from non-deprecated competitions, giving each question equal weight.
 For each model and question, we use the mean observed score over available runs when results exist, including zeroes and fractional scores.
 For missing results, we estimate the score with a two-parameter item-response theory model: for model ability $\theta_m$ and question
 difficulty $\beta_q$ with discrimination $\alpha_q$, we use $p_{m,q}=\sigma(\alpha_q(\theta_m-\beta_q))$.
 Parameters are fitted on existing data with fractional scores preserved.
 A model needs to have at least 42 answered questions to be included in the expected performance plots.
 For confidence intervals, we simulate binary outcomes with the fitted mean scores (a Bernoulli approximation) and refit the full IRT model on each simulated dataset.
 Each simulated score uses the same averaging rule on the fixed non-deprecated question set: simulated observed means where results exist, and refitted estimates where they are missing.

 The IRT component is similar to the Epoch Capability Index [https://arxiv.org/pdf/2512.00193],
 with parameters $\alpha_q$ and $\beta_q$ fitted for each question. Our reported average combines observed and estimated scores as described above.

 Expected cost is the weighted average per-problem cost over non-deprecated, non-Euler competitions.
 For missing cost observations, we fit $\log c_{mb}=\mu_m+\beta_b$ by least squares on observed per-problem costs and predict missing values with $\exp(\mu_m+\beta_b)$ before averaging by benchmark problem count.
 Cost confidence intervals are symmetric bootstrap intervals over the benchmark problem mix.

About MathArena

 MathArena evaluates LLMs on recent math competitions, olympiads, and research problems.
 We use new problems to measure reasoning on questions that models have not seen during training.
 Each model runs four times on each problem. The leaderboards show average scores and
 the average cost of a single run on one problem, in USD.
 Datasets, evaluation code, and papers are available below.
