## 1. 标题

我会点的前三：

1. **“点‘不再询问’，密码就公开？”**——这个按钮我可能点过，会想知道自己是不是也有风险。
2. **“用Claude写代码，密码被公开？”**——看得懂在说什么，也能马上判断这件事和自己有没有关系。
3. **“DeepSeek自己动手术，涨7分？”**——“自己动手术”很勾人，会想知道它到底怎么改自己，但“7分”是什么分不清楚。

看不出具体在说什么事的：

- **“1122份文件藏密码？AI改自己涨7分？”**——不知道是谁的文件，前后两个问句有什么关系；“AI改自己”也没有具体画面。
- **“Claude传密码？AI改自己涨7分？”**——像两条新闻挤在一起，不知道主要要讲哪件事。
- **“Claude把密码传上GitHub？”“Claude点一下，密码上GitHub？”**——我不知道 GitHub 是什么，不能直接理解“上GitHub”为什么意味着密码公开；后一条还让我疑惑是谁点了什么。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“吠”是在说谁乱讲，还是给新闻挑错？开头不知道栏目要干什么。
- **“GitHub 上1122份公开的 Claude Code 配置文件含疑似密码或密钥，能否使用未验证。”**——GitHub、Claude Code、配置文件、密钥连续出现，我连这些文件是干什么的都不知道；“能否使用”要回头确认是在说密码。
- **“DoubleAI 称 DeepSeek 给自己加探针后正确率从64%升到71%，中文稿的‘改写架构’这组原文没写。”**——“探针”是什么？什么题的正确率？“中文稿”和“这组原文”分别指哪篇？后半句要读两遍。
- **“让 Claude Code 连数据库时，命令里常带着密码。”**——不知道“连数据库”是什么使用场景，也不知道密码为什么会出现在命令里。
- **“这份文件一旦被提交，密码就跟着公开。”**——“提交”到哪里、是哪个操作？我不能判断自己什么时候可能做过。
- **“Apiiro 搜到10.4万份公开副本，1122份含它判定的‘真实密钥’。”**——“公开副本”是前面那种配置文件吗？“真实密钥”和前面的“疑似密码或密钥”是什么关系？
- **“算上历史版本等位置共2539个，1家公司确认密钥曾有效。”**——2539个什么：文件、密码还是密钥？和1122份是什么关系？
- **“Claude Code 团队的 Cherny 称，产品一直没做密钥清理，正在想办法。”**——“密钥清理”是自动删密码，还是让密码失效？
- **“选过这项的用户，最好检查这份文件并换掉里面的密码。”**——我不知道去哪里找“这份文件”，也不确定“换掉里面的密码”是修改文件里的文字，还是去原来的服务改密码。
- **“‘真实密钥’只看格式和公网地址，再由 AI 复核，Apiiro 没试过能不能用，近半是服务商密钥，不全是密码。”**——“公网地址”“服务商密钥”不懂，也不明白“不全是密码”会怎样改变这件事的严重程度。
- **“Apiiro 称追溯的1105个仓库里，539个有 Claude 署名的提交改过它，但这说明不了密码是 Claude 传的。”**——“仓库”“署名的提交”都陌生；“它”指文件还是密码，需要回读。1105和前面的1122又是什么关系？
- **“官方文档写的防护，是把文件加进本机的全局忽略名单，不写进项目。”**——“全局忽略名单”是什么？“不写进项目”的主语是文件，还是这条忽略设置？
- **“Apiiro 列的4个相关 issue 都被机器人关闭，未见官方回复。”**——不知道 issue 是投诉、故障报告还是帖子，“关闭”意味着解决了还是不处理了？
- **“让 DeepSeek-V4.1-Flash 用243道旧题的作答，给自己做一个探针。”**——“用旧题的作答做探针”完全没有画面，也不知道是谁在制作这个东西。
- **“答完题读一次内部状态，判错就重答，最多三次。”**——谁读、谁判错？如果已经知道答案错了，为什么还需要探针？“三次”是总共答三次还是重答三次？
- **“AIME、HMMT 2026两场比赛共63题，正确率从64%升到71%。”**——不知道是什么比赛，也不知道这63题和前面的243道旧题是什么关系。
- **“只挑最长的答案重答，是65.4%。”**——从哪些答案里挑？为什么挑最长的？这句话突然多出一种比较方法，我跟不上。
- **“这组原文只说这层‘控制采样’，没写改权重或结构。”**——“这层”是哪层？“控制采样”“权重”都不懂。
- **“中文稿写‘长思维链’‘检查点当场回滚’，原文是不开思考模式，答完才读探针，答到一半的探针分不出对错。”**——“长思维链”“检查点当场回滚”已经卡住，后面还要同时理解两种操作的区别。
- **“‘消耗相同的 token 预算’原文没有，这组也没给成本。”**——不知道 token 是什么，“这组”指哪组实验也不明确。
- **“原文没给重复次数和误差范围，暂未找到论文和第三方复现。”**——“重复次数”指重答次数还是整场测试重做次数？前面不是已经说“最多三次”了吗？“第三方复现”也需要解释。

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**——为了让“沸”和“吠”押上而造口号，像让 AI 起一个“俏皮、有记忆点”的栏目开场。
- **“一、Claude Code 把密码留进文件”“二、DeepSeek 给自己加探针”**——两个小标题都把产品写成会自主行动的人，格式很齐，但具体是谁操作反而被藏掉了，像模板化的新闻拟人标题。
- **“选过这项的用户，最好检查这份文件并换掉里面的密码。”**——像安全新闻结尾自动补上的建议；听着正确，但没有告诉我文件在哪，读完做不了。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——“聊……轻松识破……”很像生成的宣传语；正文里那么多词都没看懂，结尾却替我宣布已经能“轻松识破”。

## 4. 会划走的地方

- **“省流：安全公司 Apiiro 称……”**——第一处就可能划走。一段里要记几家公司、两个产品、两套数字，还夹着“探针”“架构”；叫“省流”，读起来却像考试摘要。
- **“②Cherny 称这些文件是人手动建的再提交……”**——如果被密码标题吸引进来，我到这里会开始失去耐心：我想知道什么操作会泄露密码，正文开始比较谁的说法能证明谁干了什么。
- **“二、DeepSeek 给自己加探针”**——这是另一个明显的退出点。密码这件事讲完了，突然需要重新理解一个和自己使用 AI 距离很远的实验。

不太在乎的“吠点”：

- **“③官方文档写的防护，是把文件加进本机的全局忽略名单，不写进项目。”**——看不懂这两个位置的区别，也就感受不到它为什么值得单列。
- **“④Apiiro 列的4个相关 issue 都被机器人关闭，未见官方回复。”**——单看这句，我不知道它对密码风险有什么实际影响，暂时不关心。
- **“①新智元标题写‘改写 Transformer 架构’……”**——我没看过那个标题，也不懂架构，没兴趣先学术语再看两篇文章哪里不一致。
- **“②中文稿写‘长思维链’‘检查点当场回滚’……”**——对我来说是在纠正另一些我同样不懂的词，读不到能带走的意思。

验证：仅依据所给文字模拟普通读者感受，未联网、未读文件、未核对事实。

## 采纳

- 标题：采纳，改用“用Claude点‘不再询问’，密码公开？”，保留主语 Claude。
- 读不懂：采纳大部分：GitHub 改“公开的代码网站 GitHub”，探针加解释，“提交”改“上传”，“全局忽略名单”改说人话，issue 改“问题帖”，权重结构改“模型本身”，“重复次数”改“实验重复次数”。“token”在引用中文稿原句时保留。
- 像 AI 写：固定开场与 Slogan 是品牌固定内容，不改。“检查这份文件”的建议按字数删去，操作说明留在评论区。
- 会划走：DoubleAI 与 issue 两处读者不关心，但属本期吠点，保留并压短，是否降级由 Develata 终审时定。
