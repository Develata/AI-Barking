## 可能的吠点（线索，须回原文核实）

1. 官方文档写的是“把该文件加进用户的全局 git excludes”，不是仓库 `.gitignore`；这个保护只在写入文件的那台电脑上有效（settings 页原句，见 A3b）。Cherny 说 “We automatically gitignore it”，字面比文档宽。
2. “1,122 个含 real secret 的文件”是 Apiiro 按格式/公网主机特征加 LLM 复核判出的，未试用任何凭据，只有 1 家被通知的公司确认其密钥曾有效（THN、iTWire 转述）；iTWire 明说“the research does not prove every one (or any one) still works”。
3. 官方文档：存进文件的是用户在提示里选的那条规则，“a rule you save from a prompt covers only what its option named”；提示示例是通配前缀 `npm test *`。密钥进文件的前提是提示给的就是含密钥的整条命令（THN：“sometimes one exact command”）。
4. 539/1,105 说的是“有 Claude 共同署名的提交改动过该文件”，不等于 Claude 提交了密钥，也不等于 Claude 自己执行了 git commit（iTWire：“does not establish that Claude introduced or pushed every exposed credential”）。
