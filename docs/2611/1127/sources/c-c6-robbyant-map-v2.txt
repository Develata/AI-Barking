LingBot-Map 2.0

Reconsolidatable Streaming 3D Reconstruction

Tech Report [https://github.com/Robbyant/lingbot-map-v2/blob/main/docs/lingbot-map-v2_paper.pdf]Code [https://github.com/Robbyant/lingbot-map-v2]Hugging Face [https://huggingface.co/collections/robbyant/lingbot-map-v2]ModelScope [https://modelscope.cn/models/Robbyant/lingbot-map-v2]

LingBot-Map 2.0 enables reconsolidatable streaming 3D reconstruction—bringing SLAM's hindsight into the model and making both streaming and reconsolidation end-to-end learnable.

How It Works?

Context Reconsolidation triggered anytime — no loop detection, no pose-graph optimization, and no post-processing.

Expanding spatial memory with incoming views

02Context Reconsolidation

Revise spatial memory leveraging historical information

03Streaming Processing after Reconsolidation

Resume streaming with updated spatial memory
