Image localization · / 9✕

From spatial memory to navigation.

Each 3D visual token pairs a surface location with a pretrained vision‑language feature. The spatial memory encoder, vision‑language decoder and trajectory decoder use this evidence for grounding, localization and route prediction. A local planner executes the route.

 [https://mdn.alipayobjects.com/huamei_tngvml/afts/img/yyfdTZEDaGMAAAAAWSAAAAgADuHhAQJr/fmt.webp]
The spatial memory encoder combines visual features with 3D positions. The vision‑language decoder supports localization, grounding, language, and frontier prediction. Trajectory queries read memory and prompt K/V and inherit the prompt’s recurrent state to condition flow‑matching route generation. Flames and snowflakes denote trainable and frozen parameters.

Spatial memory

Organize past observations

Store visual and geometric evidence in local memory blocks.

Localization & grounding

Locate the robot and the goal

Localize the current view and predict object centers together with observation viewpoints.

Route prediction

Plan how to get there

Use the current position and destination as endpoints and refine intermediate waypoints with flow matching.

Local reconstruction, reasoning across blocks

LingBot‑Map reconstructs short RGB sequences into local memory blocks. Cross‑block attention connects evidence in their local frames without requiring the mapper to align the entire scene first.

 [https://mdn.alipayobjects.com/huamei_tngvml/afts/img/eeOvS6MQwcEAAAAAZ0AAAAgADuHhAQJr/fmt.webp]
Alternating within‑block and across‑block attention supplies K/V to both decoders; auxiliary geometry heads predict block poses and 3D points. The right panel compares local and common frames for 3, 12, and 31 blocks.
