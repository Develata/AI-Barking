 LingBot-Navi

This repository contains the LingBot-Navi model weights. For the project code and runnable examples, see the LingBot-Navi GitHub repository [https://github.com/Robbyant/lingbot-navi].

The Navigation Transformer handles visual grounding, image localization, coordinate navigation, and exploration. The Local Planner handles local execution.

 [#model-provenance]

 Model provenance

The Navigation Transformer is based on Qwen3.5-4B and includes modified base-model weights. LingBot-Navi adds spatial-memory conditioning, trajectory adapters, structured output tokens, and heads for predicting coordinates, poses, and trajectories. Qwen3.5-4B model card [https://huggingface.co/Qwen/Qwen3.5-4B]
