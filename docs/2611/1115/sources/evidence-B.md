## 一、先说结论（供 Claude 看，不是正文）

- 原文与扫描说法基本吻合，但有三处要点扫描没说清或说反：
  1. 公告时间线实际列的是 **1.75.2（11-02）→ 1.75.4（11-03）→ 1.76.0（11-08）三个发布版本**，**没有 1.76.4**。1.76.4（11-15）的 release notes 写“[security] Address remaining reported security issues”，其 commit 信息指向另一条 Mozilla bug（2091796），内容是 diff updater 校验和长度与 asset viewer 嵌入，**不是**这个 XSS 的补丁；只有 `Removed no longer used warOrigin/warSecret` 一条引用了 `150df12`（本 XSS 的 war: 过滤器那条）。扫描把 1.76.4 写成“又有”修复属于过读。
  2. 公告 Affected = “1.75.2 and lower”，Patched = “1.75.4”；而 1.75.2 本身发布时已含第一次修复（`bf69cf7`），研究者 11-02 邮件称它被绕过。所以“1.75.2 and lower 受影响”与“1.75.2 含第一次修复”并存，公告的版本字段是对**整条修复链终点**的概括。
  3. “照公告升级到 1.75.4 未必安全”这一推断：**仅推断**。证据只有：公告时间线在 1.75.4 之后还列了 1.76.0 的两个“Related”修复（验证即将创建的过滤器、暂禁 war: 过滤器），且 `b1f7d27` 的 commit 说明把前两次修复列为 Related。没有任何一手来源说 1.75.4 仍可被利用（见 B3）。
- 研究者文章（iter.ca）与公告都**没有**说在野利用，公告 CVE 栏 “No known CVE”，NVD 与 GitHub 全局公告库查不到对应条目。
- 攻击面：研究者文章与公告都写 Firefox MV2 版；Chromium MV2 只写“可提取 WAR secret”（公告报告内嵌文字），演示页写明 “firefox only”，文章“Getting the click”一节自称**没有实际实现点击诱骗**（“I didn’t bother actually implementing this”）。
- HN 帖 50513160：506 分 / 146 评（00:00 北京，`barking heat`）；渲染页面 00:1x 显示 511 分 / 148 评。

## 三、可能的吠点（原文里有、线索摘要没提或说反）

1. 作者自己说“GPT-5.6 Sol did most of the hard work of finding the issue”，但前提是“I figured there might be some kind of UXSS from filter injection, so I asked it to take a look”——方向是人给的；人也“checked and verified”。出处：iter.ca 第二段。
2. “one-click”依赖一次点击，而作者在 “Getting the click” 一节明说 “I didn’t bother actually implementing this”：点击诱骗是推演，演示页里按钮可见。出处：iter.ca；公告 PoC 说明 “In that demo you can see the button that gets clicked”（公告内嵌邮件）。
3. 范围：Firefox MV2；Chromium MV2 只写到可提取 WAR secret；公告没提 uBO Lite，作者称 uBO Lite “similar but less problematic”。出处：iter.ca 首段；公告摘要。
4. 前提之一是存在会以 WAR 响应的 prevent-xhr / prevent-fetch 类 scriptlet 规则（默认规则集有一条，作者称）。出处：公告摘要；iter.ca “Figuring out…” 一节。
5. 公告“Patched versions 1.75.4”只是时间线终点的概括：1.75.2 已含第一次修复且被研究者 11-02 邮件绕过，1.76.0 又补了两道修复；release notes 里首次出现 “[security]” 与漏洞标题的是 1.76.0。出处：公告时间线；1.75.4 与 1.76.0 release notes。
6. 公告在 11-15 发布，但报告在 11-01，首次修复 11-02/03 就发布，公告披露晚了两周；公告被维护者在 “release published” 前不写细节（邮件原话 “I rather not provide details about the vulnerability since I can't publish a stable release version immediately”）。出处：公告邮件；公告 `published_at`。
7. 公告 “High” 严重度没有 CVSS 向量/分数、没有 CWE、没有 CVE。出处：公告页；API。
8. 默认安装能否被利用与“你的 Firefox 是否已升级”相关：AMO 当前版本 1.76.4；HN 有用户称 “After the update, I still have 1.76.2 on the firefox dev edition on mac”（自动更新延迟）。出处：HN 50513891（L6）。
