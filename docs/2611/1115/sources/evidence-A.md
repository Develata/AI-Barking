## 一、先说结论性发现（核对者最该看的）

1. Qwen 官方博客**中英文版成本数字不同**：中文版写“26.58 元降至 11.16 元，降低了 58%”，英文版写“$4.43 to $1.67 — a 62% reduction”。扫描里的“58~62%”不是两种说法，而是同一句话的两个币种版本。两个版本都没说这个成本用的是哪一档推理强度。
2. AA 实测：Qwen4 Max 每任务 $3.27（Qwen3.8 Max 0902 页：$10.02），输出 token 127M（Qwen3.8 Max：150M）；但 AA 页面同时写“very verbose”、智能分 43 低于 Kimi K3.1 Pro 的 46。AA 页面**没写** Qwen4 Max 测的是哪一档推理强度（别的模型名里带 max / xhigh / high，Qwen4 Max 与 Kimi K3.1 Pro 没带）。
3. Vals Index 上 Qwen 4 Max 每次测试成本 $9.33，Qwen 3.8 Max 0902 为 $8.73（Vals 存档，Qwen3.8 行在折叠区，只在文本存档里，没截图），**反而更高**；准确率 63.20% 对 59.05%。
4. Hy4 flash 官方博客的“1/20”对应的是 WorkIndex（腾讯内部评测）上相对 Hy4 的单任务成本；同一页的图 2 标注“24.5× cheaper”（对 Hy4）与“13.8× cheaper”（对 Hy4 preview），文字写“1/13”。官方 X 帖的“18x task cost reduction”是**另一个口径**：盲测表里 Haiku 5.5（high 档）¥4.73 对 Hy4 flash ¥0.26。三个倍数基于不同对象，不能互相换算（遵派工单，本文不自行换算新倍数；¥4.73/¥0.26 的比值只是说明 18x 的来源，见 A4）。
5. Hy4 flash 在官方自己的图上：WorkIndex 综合分 42.1，Hy4 51.4，DeepSeek-V4.1-Flash-1017 44.4，Hy4 preview 39.7；Open Benchmarks 48.3 对 Hy4 59.8。博客文字写“综合效果上略优于 Hy4 preview”，WorkBuddy 产品经理引语写“效果在日常工作任务上基本持平”（对 Hy4）。
6. 盲测（腾讯内部 85 位 WorkBuddy 用户）满意度（4 分制）：DeepSeek 3.09、Hy4 flash 2.79、Haiku 5.5 2.81、GLM-5.3-Flash 2.53；外部模型均为 high 档。博客写“接近 Claude Haiku 5.5”，官方 X 帖写 “Matches Claude Haiku 5.5 (high)”。
7. Hy4 flash 价格有常规价与促销价：常规 0.5 / 2 / 0.02 元每百万 token（输入 / 输出 / 缓存命中），腾讯云 TokenHub 页 11 月 30 日前限时 5 折（0.25 / 1 / 0.01）；WorkBuddy 11 月 30 日前限时免费。博客价格表列的是常规价。
8. 权重：HF 上 tencent 名下只有 `Hy4-preview`、`Hy4-preview-FP8`（2026-08-28 更新），**没有正式 Hy4（11-04 说“将于近期开源”）也没有 Hy4 flash**；腾讯官方 GitHub 同样只有 Hy4-preview。AA 把 Tencent Hy4 标为 “Proprietary model”。Hy4 flash 官方原话是“我们计划开源 Hy4 flash”，无日期。

## 三、可能的吠点（原文里有、线索摘要没提或说反的条件；仅线索，进正文前须回一手来源）

**Qwen4-Max**
1. 同一句成本话有两个版本：中文“26.58 元→11.16 元，降低了 58%”，英文“$4.43 to $1.67 — a 62% reduction”（qwen.ai 博客，两个语言版本）。
2. 博客未写这个成本对应哪一档推理强度（只写 token 消耗在 Xhigh 与 High 两档分别 -24% / -35%）；成本降幅同时含“API 定价下调”与“token 消耗减少”两部分（博客原句同一段先讲 token 后讲“全面下调了 API 定价”，未拆分贡献；mlllm.io 也指出分解未公布，L5）。
