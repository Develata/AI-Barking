Qwen4 Max is above average in intelligence and reasonably priced when comparing to other models of similar price. The model supports text and image input, outputs text, and has a 984k tokens context window.

Qwen4 Max scores 43 on the Artificial Analysis Intelligence Index, placing it above average among comparable models (median: 41). When evaluating the Intelligence Index, it generated 127M tokens, which is very verbose in comparison to the median of 78.6M.

Pricing for Qwen4 Max is $1.50 per 1M input tokens (moderately priced, median: $2.00) and $4.50 per 1M output tokens (moderately priced, median: $10.00). On average, it costs $3.27 per task to evaluate Qwen4 Max on the Intelligence Index.

Frequently Asked Questions

Common questions about Qwen4 Max

When was Qwen4 Max released?

Qwen4 Max was released on November 16, 2026.

Who created Qwen4 Max?

Qwen4 Max was created by Alibaba.

How intelligent is Qwen4 Max?

Qwen4 Max scores 43 on the Artificial Analysis Intelligence Index, placing it above average among other models in a similar price tier (median: 41).

How much does Qwen4 Max cost?

Qwen4 Max costs $1.50 per 1M input tokens (better than average, median: $2.00) and $4.50 per 1M output tokens (better than average, median: $10.00), based on Alibaba's API.

What is Qwen4 Max API pricing?

Qwen4 Max costs $1.50 per 1M input tokens and $4.50 per 1M output tokens (based on Alibaba's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $0.80 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/qwen4-max/providers]

How verbose is Qwen4 Max?

When evaluated on the Intelligence Index, Qwen4 Max generated 127M output tokens, which is at the higher end compared to other models in a similar price tier (median: 78.6M).

Is Qwen4 Max a reasoning model?

Yes, Qwen4 Max is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Qwen4 Max support?

Qwen4 Max supports text and image input.

What output modalities does Qwen4 Max support?

Qwen4 Max supports text output.

Can Qwen4 Max process images?

Yes, Qwen4 Max supports image input and can analyze, describe, and answer questions about images.

Is Qwen4 Max multimodal?

Yes, Qwen4 Max is multimodal. It can process text and image input and generate text output.

What is the context window of Qwen4 Max?

Qwen4 Max has a context window of 984k tokens. This determines how much text and conversation history the model can process in a single request.

Is Qwen4 Max open source?

No, Qwen4 Max is proprietary. The model weights are not publicly available.

How many parameters does Qwen4 Max have?

Qwen4 Max is a proprietary model and Alibaba has not disclosed the model size or parameter count.

How does Qwen4 Max perform on benchmarks?

Qwen4 Max achieves a score of 43 on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across knowledge work, coding, science, and general knowledge.

Is Qwen4 Max available via API?

Yes, Qwen4 Max is available via API through 1 provider. Compare API providers [/models/qwen4-max/providers]

Where can I use Qwen4 Max?

Qwen4 Max is available through 1 API provider. Compare providers [/models/qwen4-max/providers]
