Qwen3.8 Max (0902) is below average in intelligence, but reasonably priced when comparing to other models of similar price. It's also notably slow per task and very verbose. The model supports text and image input, outputs text, and has a 984k tokens context window.

Qwen3.8 Max (0902) scores 34 on the Artificial Analysis Intelligence Index, placing it below average among comparable models (median: 41). When evaluating the Intelligence Index, it generated 150M tokens, which is very verbose in comparison to the median of 78.6M.

Pricing for Qwen3.8 Max (0902) is $2.00 per 1M input tokens (moderately priced, median: $2.00) and $6.00 per 1M output tokens (moderately priced, median: $10.00). On average, it costs $10.02 per task to evaluate Qwen3.8 Max (0902) on the Intelligence Index.

At 48.0 minutes per Intelligence Index task, Qwen3.8 Max (0902) is notably slow compared with the median of 13.2 minutes for comparable models (lower is better).

Common questions about Qwen3.8 Max (0902)

When was Qwen3.8 Max (0902) released?

Who created Qwen3.8 Max (0902)?

Qwen3.8 Max (0902) was created by Alibaba.

How intelligent is Qwen3.8 Max (0902)?

Qwen3.8 Max (0902) scores 34 on the Artificial Analysis Intelligence Index, placing it below average among other models in a similar price tier (median: 41).

How fast is Qwen3.8 Max (0902)?

Qwen3.8 Max (0902) takes 48.0 minutes per Intelligence Index task (based on Alibaba's API), which is among the slowest compared to other models in a similar price tier (median: 13.2 minutes; lower is better).

What is the latency of Qwen3.8 Max (0902)?

Qwen3.8 Max (0902) has a time to first answer token of 98.75s (based on Alibaba's API), which is at the higher end compared to other models in a similar price tier (median: 12.27s).

How much does Qwen3.8 Max (0902) cost?

Qwen3.8 Max (0902) costs $2.00 per 1M input tokens (better than average, median: $2.00) and $6.00 per 1M output tokens (better than average, median: $10.00), based on Alibaba's API.

What is Qwen3.8 Max (0902) API pricing?

Qwen3.8 Max (0902) costs $2.00 per 1M input tokens and $6.00 per 1M output tokens (based on Alibaba's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $1.18 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/qwen3-8-max/providers]

How verbose is Qwen3.8 Max (0902)?

When evaluated on the Intelligence Index, Qwen3.8 Max (0902) generated 150M output tokens, which is at the higher end compared to other models in a similar price tier (median: 78.6M).

Is Qwen3.8 Max (0902) a reasoning model?

Yes, Qwen3.8 Max (0902) is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Qwen3.8 Max (0902) support?

Qwen3.8 Max (0902) supports text and image input.

What output modalities does Qwen3.8 Max (0902) support?

Qwen3.8 Max (0902) supports text output.

Can Qwen3.8 Max (0902) process images?

Yes, Qwen3.8 Max (0902) supports image input and can analyze, describe, and answer questions about images.

Is Qwen3.8 Max (0902) multimodal?

Yes, Qwen3.8 Max (0902) is multimodal. It can process text and image input and generate text output.

What is the context window of Qwen3.8 Max (0902)?

Qwen3.8 Max (0902) has a context window of 984k tokens. This determines how much text and conversation history the model can process in a single request.

Is Qwen3.8 Max (0902) open source?
