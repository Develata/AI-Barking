 Tencent launches Hy4 flash, cutting AI task costs by 95% in internal tests

Tencent on Monday launched Hy4 flash, a lower-cost AI model for everyday work such as research, slide creation and spreadsheet editing. On Tencent’s internal WorkIndex benchmark, Hy4 flash cost one-twentieth as much per task as the full Hy4 model. API list prices are $0.07 per million input tokens, $0.281 per million output tokens and $0.003 per million cached input tokens.

Hy4 flash supports multimodal inputs and a context window of up to one million tokens. It has 224 billion parameters and activates 12 billion per forward pass. In a separate blind test in which 85 WorkBuddy users rated outputs across 259 tasks, Tencent said the model scored close to Claude Haiku 5.5 in user satisfaction and had the lowest cost and shortest completion time among the models tested.

The model is available in WorkBuddy and Yuanbao and through Tencent Cloud’s TokenHub. WorkBuddy users can access it for free through November 30, and TokenHub is offering API access at half the list price. Tencent plans to release the model’s weights and make it available on OpenRouter. [TechNode reporting]
