What Cache Hit Rate Shows

The share of cacheable input tokens served from the provider's prompt cache, measured during multi-turn agentic sessions. We regularly measure each endpoint and report a representative rate based on recent measurements. Higher values mean more of the input is billed at the cheaper cache-hit price, where the provider offers one, which lowers the effective cost of agentic workloads. Frequently Asked Questions

Common questions about Qwen4 Max providers

Where can I access Qwen4 Max?

Qwen4 Max is available through 1 API provider: Alibaba Cloud [/providers/alibaba_cloud]. Each provider offers different performance characteristics and pricing.

How many API providers offer Qwen4 Max?

Qwen4 Max is currently available through 1 API provider that we benchmark and track.

Which provider is cheapest for Qwen4 Max?

The most affordable provider for Qwen4 Max by blended price is Alibaba Cloud [/providers/alibaba_cloud] ($0.80 per 1M tokens). Blended price uses a 7:2:1 cache hit/input/output token ratio.

Which provider has the lowest input price for Qwen4 Max?

The provider with the lowest input token pricing for Qwen4 Max is Alibaba Cloud [/providers/alibaba_cloud] ($1.50 per 1M input tokens).

Which provider has the lowest output price for Qwen4 Max?

The provider with the lowest output token pricing for Qwen4 Max is Alibaba Cloud [/providers/alibaba_cloud] ($4.50 per 1M output tokens).

Which Qwen4 Max providers support JSON mode?

The only provider of Qwen4 Max supports JSON mode for structured output.

Which Qwen4 Max providers support function calling?

The only provider of Qwen4 Max supports function calling (tool use).

How do I choose a provider for Qwen4 Max?

When choosing a provider for Qwen4 Max, consider: time per task (how quickly the provider completes an Intelligence Index task), latency (for interactive applications requiring quick first responses), pricing (for cost-sensitive workloads), and API features like JSON mode or function calling.

Does provider performance for Qwen4 Max change over time?

Yes, provider performance can vary over time due to infrastructure changes, load balancing, and updates. We continuously benchmark all providers and display historical performance trends in the "Over Time" charts.
