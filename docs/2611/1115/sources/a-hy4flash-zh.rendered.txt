Hy4 flash：
日常工作的极致性价比模型
腾讯云
OpenRouter
WorkBuddy
元宝

我们推出 Hy4 flash，迄今为止最高性价比的 Hy 模型。其总参数量为 224B（其中 64B Engram 参数），激活参数 12B，支持多模态和 1M 上下文长度，API 价格相比 Hy4 大幅降低。

API 价格（每百万 Tokens）	输入（命中缓存）	输入	输出
Hy4 flash	0.02元	0.5元	2元
Hy4	0.3元	6元	18元

我们通过一系列工作在极致优化成本的同时兼顾智能水平和实用性：

在预训练阶段，Hy4 flash 加入了混合注意力、LatentMoE、Engram 等架构特性，KV cache 大小仅为 Hy3 的 1/24、Hy4 的 1/6，且通过大量 scaling ladder 实验确保效果符合预期；


在后训练阶段，我们通过自蒸馏 Hy4 获得了较强的综合智能水平，再通过强化学习使端到端任务输出长度降低 50%；


在评估阶段，我们构建基于 WorkBuddy 典型任务的内部评测集 WorkIndex，并结合人评，聚焦日常工作的产物效果、单轮输出长度、端到端用时，而非远离日常工作的公开榜单分数；


在推理阶段，我们结合 megakernel、4bit 量化、DFly 等手段极致优化，使 Hy4 flash 解码速度超过 150 tps，且可以大规模低成本部署运营。

最终，Hy4 flash 在综合效果上略优于 Hy4 preview；在 WorkIndex 上单任务成本仅为 Hy4 preview 的 1/13、Hy4 的 1/20、DeepSeek-V4.1-Flash-1017（max档位，忙时价格）的 1/8。

图 2：在 WorkIndex 上的平均任务花费对比。

 

为了衡量真实使用体验，我们邀请了 85 位 WorkBuddy 内部用户在 27 类共 259 个日常工作任务上进行盲测。结果显示，Hy4 flash 的用户满意度接近 Claude Haiku 5.5，且单任务成本显著低于其他所有模型，任务时长也最短。

Hy4 flash 已在腾讯云 TokenHub、WorkBuddy、元宝、企业微信、QQ、ima、Marvis 等产品上线，即将接入 OpenRouter。11 月 30 日前，用户可在 WorkBuddy 限时免费使用，腾讯云 TokenHub API 限时 5 折使用。 我们推荐在深度搜索、文档处理、PPT生成、简单前端展示、computer use 等大部分日常任务中使用 Hy4 flash，在长程软件工程等复杂任务中使用智能上限更高的 Hy4。我们计划开源 Hy4 flash 并高频迭代，不断提升真实工作的实用性和效率。

 

日常办公中，用户既看重任务完成质量，也在意完成时间和使用成本。WorkBuddy 的评测结果显示，与 Hy4 相比，平均任务耗时减少 70%，平均成本仅为 Hy4 的 1/15 左右，效果在日常工作任务上基本持平，Coding 长程任务小幅下降，并且具备原生多模态能力。总的来看，Hy4 flash 是兼顾效果、速度与成本的实用首选。

WorkBuddy
产品经理 Anne

元宝真实场景下，Hy4 flash 的 Agent 能力相比 Hy3 大幅提升 13.6%，Agent 任务人工对比评估 GSB 相比 Hy3 提升 7.56%，提升亮点在于任务完成更充分、信息呈现更清晰、内容更专业可信。在元宝通用对话任务上，Hy4 flash 相比 GLM-5.3-Flash 提升 2.52%，其中多轮对话能力提升最明显。

元宝
产品负责人 Logan

在 AI 操作真机的支付客户端场景测评中，我们针对执行路径、知识利用、验收检查、造号准确性四个 Agent 流程进行评测，Hy4 flash 相比 DeepSeek-V4.1-Flash-1017，均分全部持平或更高，执行步数减少约 6%，单次输出长度缩短约 29%。执行路径更干净，对注入的知识库理解更清晰，使用更准确。在微信支付代码静态扫描场景的测评中，Hy4 flash 相比 DeepSeek-V4.1-Flash-1017，完成扫描所需时间降低 37%、消耗 Token 降低 46%，推理效果持平，模型回复内容更简练，且更能从上下文中找到决策依据。

微信支付
信息智能实验室 yilin 安全工程师 Simba

日常办公协作中，企业微信大圆的评测结果显示，Hy4 flash 的输出速度相比 Hy4 提升 88%，思考模式下的输出 Token 减少约 60%。在企业信息检索、资料分析、文档整理等任务中，它能够自主规划工具调用并完成结果交付。Hy4 flash 兼顾响应效率与交付质量，非常适合需要快速响应和多步骤处理的办公场景。

企业微信
算法负责人 Dylan

在游戏研发 Bug 分析评测中，针对 UI 交互、系统逻辑等问题，Hy4 flash 的根因定位表现接近 DeepSeek-V4.1-Flash-1017 和 GLM-5.3-Flash，但模型请求次数减少 22.0% – 39.1%，按请求回执统计的 Token 消耗量减少 40.5% – 61.2%。Hy4 flash 平均工具调用次数分别多 51.2% 和 7.7%；输出报告篇幅短 13.8% 和 37.0%。Hy4 flash 体现出兼顾定位质量与资源效率的优势，尤其适合日常研发中高频、批量的问题排查与辅助定位。

王者荣耀
项目管理负责人 TH

在基于知识库问答真实场景构建的评测显示，Hy4 flash 相比 DeepSeek-V4.1-Flash-1017 和 GLM-5.3-Flash，平均等待时间缩短约 18% – 35%；提速的同时，各项质量指标同步向好：回答整体评分提升 1.8%，回答内容质量评分提升 8.1%，思维链内容质量综合评分提升 2.1%。对于日常问答、文字整理这类知识工作，完成时间更短，并且能够拿到更优质的回复。

ima
产品经理 Kaycee

接入 Hy4 flash 后，小 Q 的多项  Agent 能力进一步提升，既答得好，也回得快。评测显示，相较 DeepSeek-V4.1-Flash，Hy4 flash 在音乐推荐、频道互动、QQ 空间和星座长篇解析中的表现更优，符合要求的结果占比分别高出 6.16、2.84、0.92 和 2.22 个百分点；在聊天陪伴、音乐推荐和星座长篇解析场景里，完成时间缩短约 11%–27%，让用户更快获得贴合需求的陪伴与帮助。在频道助手的 UGC 互场景中，Hy4 flash 能在近实时约束下稳定完成意图识别与工具调用。相比 DeepSeek-V4.1-Flash，对用户意图的判断准确率持平，评论 P90 耗时缩短 39%、峰值耗时缩短 47%，输出 token 减少 30%，缓存命中率大幅提升，充分满足业务要求。

QQ
小 Q 技术负责人 Red 频道研发 Look

Hy4 flash 在 Marvis 核心 AI 管家场景中展现出很强的任务解决能力。相比 DeepSeek-V4.1-Flash-1017，多个核心场景的任务满意度均有提升：应用下载安装提升 6.2%，系统设置与诊断提升 4.4%，文档处理与调研报告生成提升 6.9%。在整体任务满意度持平的基础上，Hy4 flash 进一步强化了重点场景的任务质量，为用户带来更加可靠的 AI 管家体验。
