Huawei Cloud releases CloudRobo-WM1.2 world action model, claims first place on RoboTwin 2.0 and LIBERO-Pro 2.0

TL;DR
Huawei Cloud has released CloudRobo-WM1.2, an embodied world action model, and says it will be open source. The company claims first place on the RoboTwin 2.0 and LIBERO-Pro 2.0 robot manipulation benchmarks, with scores of 88.98% and 81.7%.

Huawei Cloud has released CloudRobo-WM1.2, an embodied world action model, and says it will be open source. The company claims the model ranks first on two robot manipulation benchmarks: RoboTwin 2.0 and LIBERO-Pro 2.0.

Benchmark claims

Slides shown at the launch put CloudRobo-WM's average score at 88.98% on RoboTwin 2.0 and 81.7% on LIBERO-Pro 2.0. These rankings are Huawei Cloud's claims. Pandaily, which reported the launch, has not independently verified which model version produced the leaderboard entries.

Benchmark
Reported score (Huawei Cloud claim)

RoboTwin 2.0
88.98% (average)

LIBERO-Pro 2.0
81.7% (average)

Parameter count, context window and pricing are not yet disclosed.

Open-source plans

Huawei Cloud said it will open its training framework and a set of best practices for running world action models on Ascend compute, alongside the model release.

The launch was led by Wu Xiaodong, president of Huawei Cloud's embodied product line and director of its Embodied AI Lab. Chief model expert Liu Liu presented the technology.

Customer deployment: Fulongma street sweeper

Huawei Cloud used the event to show a customer deployment. Fulongma Group said a next-generation intelligent street sweeping robot developed with Huawei Cloud is now open for presale, with a launch event planned in Shanghai in December.

According to the two companies, Huawei Cloud supplies:

the CloudRobo autonomous driving development toolchain

a full-domain perception model

a planning model

an agent runtime platform

Ascend cloud compute

Fulongma said a world model is built into the robot's perception so it can predict conditions such as bad weather and roadblocks.

Background

Huawei Cloud previewed the launch on November 13. CloudRobo is Huawei Cloud's embodied AI platform, which the company introduced at the World Artificial Intelligence Conference in July.

What this means

The benchmark figures are the main evidence offered for the model's capability, and they come from Huawei Cloud's own slides. Which model version produced the leaderboard entries has not been verified, so the 88.98% and 81.7% averages should be read as claims, not settled results for CloudRobo-WM1.2 specifically.

The open-source commitment covers more than the model. Huawei Cloud says it will also release a training framework and best practices for running world action models on Ascend compute, which ties the release to Huawei's own hardware stack.

The Fulongma street sweeper is a concrete product built on the CloudRobo toolchain, perception and planning models, agent runtime and Ascend compute. It is now open for presale, with a Shanghai launch event planned for December. Fulongma's statement that the robot's perception includes a world model for predicting weather and roadblocks comes from the companies, not from independent testing.
