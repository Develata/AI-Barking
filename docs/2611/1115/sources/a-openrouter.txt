Frequently asked questions

What is Hy4 flash?

Hy4 flash is a cost-efficient variant of Hy4 from Tencent, served with roughly a quarter of the flagship's parameter count for lower latency and cost. It targets code assistance, agent pipelines, document and chart comprehension, and high-volume routine automation, with the same context and output limits as Hy4.

How much does Hy4 flash cost?

Hy4 flash costs $0.035/M input tokens and $0.1405/M output tokens, with separate rates for Cache Read at $0.0015/M tokens.

What is the context length of Hy4 flash?

Hy4 flash has a 1,048,576 token context window. It supports up to 65,536 completion tokens.

Does Hy4 flash support tool calling and structured outputs?

Yes. Hy4 flash accepts tools and tool_choice for function calling. It also supports structured outputs via a JSON schema in response_format.

What inputs and outputs does Hy4 flash support?

Hy4 flash accepts text and images as input and returns text.

Which providers serve Hy4 flash?

Hy4 flash is served by 1 provider on OpenRouter: Tencent Cloud.

What other text models does Tencent have?

Hy4 [/tencent/hy4], Hy4 preview [/tencent/hy4-preview], Hy-MT2-1.8B [/tencent/hy-mt2-1.8b] and 4 more are other text models from Tencent.

When was Hy4 flash released?

Hy4 flash was released on November 16, 2026.
