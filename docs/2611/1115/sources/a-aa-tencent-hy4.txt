Tencent Hy4 is below average in intelligence, but well priced when comparing to other models of similar price. It's also slower than average per task and very verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

Tencent Hy4 scores 35 on the Artificial Analysis Intelligence Index, placing it below average among comparable models (median: 41). When evaluating the Intelligence Index, it generated 160M tokens, which is very verbose in comparison to the median of 78.6M.

Pricing for Tencent Hy4 is $0.83 per 1M input tokens (competitively priced, median: $2.00) and $2.50 per 1M output tokens (competitively priced, median: $10.00). On average, it costs $1.03 per task to evaluate Tencent Hy4 on the Intelligence Index.

At 13.9 minutes per Intelligence Index task, Tencent Hy4 is slower than average compared with the median of 13.2 minutes for comparable models (lower is better).

Frequently Asked Questions

Common questions about Tencent Hy4

When was Tencent Hy4 released?

Tencent Hy4 was released on November 3, 2026.

Who created Tencent Hy4?

Tencent Hy4 was created by Tencent.

How intelligent is Tencent Hy4?

Tencent Hy4 scores 35 on the Artificial Analysis Intelligence Index, placing it below average among other models in a similar price tier (median: 41).

How fast is Tencent Hy4?

Tencent Hy4 takes 13.9 minutes per Intelligence Index task (based on Tencent's API), which is slower than average compared to other models in a similar price tier (median: 13.2 minutes; lower is better).

What is the latency of Tencent Hy4?

Tencent Hy4 has a time to first answer token of 110.63s (based on Tencent's API), which is at the higher end compared to other models in a similar price tier (median: 12.27s).

How much does Tencent Hy4 cost?

Tencent Hy4 costs $0.83 per 1M input tokens (very competitive, median: $2.00) and $2.50 per 1M output tokens (very competitive, median: $10.00), based on Tencent's API.

What is Tencent Hy4 API pricing?

Tencent Hy4 costs $0.83 per 1M input tokens and $2.50 per 1M output tokens (based on Tencent's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $0.45 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/tencent-hy4/providers]

How verbose is Tencent Hy4?

When evaluated on the Intelligence Index, Tencent Hy4 generated 160M output tokens, which is at the higher end compared to other models in a similar price tier (median: 78.6M).

Is Tencent Hy4 a reasoning model?

Yes, Tencent Hy4 is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Tencent Hy4 support?

Tencent Hy4 supports text and image input.

What output modalities does Tencent Hy4 support?

Tencent Hy4 supports text output.

Can Tencent Hy4 process images?

Yes, Tencent Hy4 supports image input and can analyze, describe, and answer questions about images.

Is Tencent Hy4 multimodal?

Yes, Tencent Hy4 is multimodal. It can process text and image input and generate text output.

What is the context window of Tencent Hy4?

Tencent Hy4 has a context window of 1M tokens. This determines how much text and conversation history the model can process in a single request.

Is Tencent Hy4 open source?

No, Tencent Hy4 is proprietary. The model weights are not publicly available.

How many parameters does Tencent Hy4 have?

Tencent Hy4 is a proprietary model and Tencent has not disclosed the model size or parameter count.

How does Tencent Hy4 perform on benchmarks?

Tencent Hy4 achieves a score of 35 on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across knowledge work, coding, science, and general knowledge.

Is Tencent Hy4 available via API?

Yes, Tencent Hy4 is available via API through 1 provider. Compare API providers [/models/tencent-hy4/providers]

Where can I use Tencent Hy4?

Tencent Hy4 is available through 1 API provider. Compare providers [/models/tencent-hy4/providers]
