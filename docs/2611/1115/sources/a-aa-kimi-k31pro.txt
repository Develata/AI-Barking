Kimi K3.1 Pro is amongst the leading models in intelligence, but particularly expensive when comparing to other open weight models of similar size. It's also notably slow per task and somewhat verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

Kimi K3.1 Pro scores 46 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 23). When evaluating the Intelligence Index, it generated 113M tokens, which is somewhat verbose in comparison to the median of 104M.

Pricing for Kimi K3.1 Pro is $2.00 per 1M input tokens (expensive, median: $0.43) and $10.00 per 1M output tokens (expensive, median: $1.84). On average, it costs $3.68 per task to evaluate Kimi K3.1 Pro on the Intelligence Index.

At 40.1 minutes per Intelligence Index task, Kimi K3.1 Pro is notably slow compared with the median of 13.4 minutes for comparable models (lower is better).

Total Parameters

The total number of trainable weights and biases in the model, expressed in billions. These parameters are learned during training and determine the model's ability to process and generate responses.

Active Parameters at Inference Time

The number of parameters actually executed during each inference forward pass, expressed in billions. For Mixture of Experts (MoE) models, a routing mechanism selects a subset of experts per token, resulting in fewer active than total parameters. Dense models use all parameters, so active equals total.

Frequently Asked Questions

Common questions about Kimi K3.1 Pro

When was Kimi K3.1 Pro released?

Kimi K3.1 Pro was released on October 23, 2026.

Who created Kimi K3.1 Pro?

Kimi K3.1 Pro was created by Kimi.

How intelligent is Kimi K3.1 Pro?

Kimi K3.1 Pro scores 46 on the Artificial Analysis Intelligence Index, placing it well above average among other open weight models of similar size (median: 23).

How fast is Kimi K3.1 Pro?

Kimi K3.1 Pro takes 40.1 minutes per Intelligence Index task (based on Kimi's API), which is among the slowest compared to other open weight models of similar size (median: 13.4 minutes; lower is better).

What is the latency of Kimi K3.1 Pro?

Kimi K3.1 Pro has a time to first answer token of 159.12s (based on Kimi's API), which is at the higher end compared to other open weight models of similar size (median: 19.48s).

How much does Kimi K3.1 Pro cost?

Kimi K3.1 Pro costs $2.00 per 1M input tokens (at the higher end, median: $0.43) and $10.00 per 1M output tokens (at the higher end, median: $1.84), based on Kimi's API.

What is Kimi K3.1 Pro API pricing?

Kimi K3.1 Pro costs $2.00 per 1M input tokens and $10.00 per 1M output tokens (based on Kimi's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $1.54 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/kimi-k3-1-pro/providers]

How verbose is Kimi K3.1 Pro?

When evaluated on the Intelligence Index, Kimi K3.1 Pro generated 113M output tokens, which is somewhat higher than average compared to other open weight models of similar size (median: 104M).

Is Kimi K3.1 Pro a reasoning model?

Yes, Kimi K3.1 Pro is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Kimi K3.1 Pro support?

Kimi K3.1 Pro supports text and image input.

What output modalities does Kimi K3.1 Pro support?

Kimi K3.1 Pro supports text output.

Can Kimi K3.1 Pro process images?

Yes, Kimi K3.1 Pro supports image input and can analyze, describe, and answer questions about images.

Is Kimi K3.1 Pro multimodal?

Yes, Kimi K3.1 Pro is multimodal. It can process text and image input and generate text output.

What is the context window of Kimi K3.1 Pro?

Kimi K3.1 Pro has a context window of 1M tokens. This determines how much text and conversation history the model can process in a single request.

Is Kimi K3.1 Pro open source?

Yes, Kimi K3.1 Pro is open weights. The model weights are publicly available and can be downloaded for self-hosting.

How many parameters does Kimi K3.1 Pro have?

Kimi K3.1 Pro has 2.8T parameters (104B active).

What are the active parameters of Kimi K3.1 Pro?

Kimi K3.1 Pro is a Mixture of Experts (MoE) model with 2.8T total parameters, but only 104B active parameters are used during inference.

What is the license for Kimi K3.1 Pro?

Kimi K3.1 Pro is released under the Kimi K3.1-Pro Licence license. Commercial use is allowed with restrictions. View license [https://huggingface.co/moonshotai/Kimi-K3.1-Pro/blob/main/LICENSE]

How does Kimi K3.1 Pro perform on benchmarks?

Kimi K3.1 Pro achieves a score of 46 on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across knowledge work, coding, science, and general knowledge.

Is Kimi K3.1 Pro available via API?

Yes, Kimi K3.1 Pro is available via API through 17 providers. Compare API providers [/models/kimi-k3-1-pro/providers]

Where can I use Kimi K3.1 Pro?
