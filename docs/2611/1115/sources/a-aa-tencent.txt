What Cache Hit Rate Shows

The share of cacheable input tokens served from the provider's prompt cache, measured during multi-turn agentic sessions. We regularly measure each endpoint and report a representative rate based on recent measurements. Higher values mean more of the input is billed at the cheaper cache-hit price, where the provider offers one, which lowers the effective cost of agentic workloads. For further details, see our methodology page [/methodology/performance-benchmarking].

Frequently Asked Questions

Common questions about Tencent

What models does Tencent offer?

Tencent offers 1 model that we track: Tencent Hy4 [/models/tencent-hy4].

What is the most intelligent model on Tencent?

The most intelligent model available on Tencent is Tencent Hy4 [/models/tencent-hy4] with an Intelligence Index score of 35.

Which model has the lowest time per task on Tencent?

The model with the lowest time per task on Tencent is Tencent Hy4 [/models/tencent-hy4] at 13.9 minutes per Intelligence Index task. Time per task is the output tokens per task divided by end-to-end output speed, so lower means a task finishes sooner.

Which model has the lowest latency on Tencent?

The model with the lowest time to first answer token on Tencent is Tencent Hy4 [/models/tencent-hy4] at 110.63s. Lower latency means faster initial response time.

What is the cheapest model on Tencent?

The most affordable model on Tencent by blended price is Tencent Hy4 [/models/tencent-hy4] at $0.45 per 1M tokens (7:2:1 cache hit/input/output ratio).

Does Tencent support JSON mode?

Yes, all 1 models on Tencent support JSON mode for structured output.

Does Tencent support function calling?

Yes, all 1 models on Tencent support function calling (tool use).

Does Tencent offer reasoning models?

Yes, Tencent offers 1 reasoning model: Tencent Hy4 [/models/tencent-hy4]. Reasoning models use extended thinking to work through complex problems before providing an answer.

Does Tencent's performance change over time?

Yes, provider performance can vary over time due to infrastructure changes, load balancing, and updates. We continuously benchmark all providers and display historical performance trends in the "Over Time" charts.

How do I choose a model on Tencent?

When choosing a model on Tencent, consider: intelligence (for quality-sensitive tasks), time per task (how quickly the model completes an Intelligence Index task), latency (for interactive applications requiring quick first responses), pricing (for cost-sensitive workloads), and features like context window size, JSON mode, or function calling support.
