# 1115 读者稿检查

北京 11-17 00:27–00:28，Codex gpt-6-astra medium，只读，不带本期上下文；输入为初稿正文（标题“千问说省六成，第三方算出两个数”）与 5 个标题候选，命令见 `templates/style-review.md`。以下为原报告。

## 1. 标题

我会点的前三：

1. **“千问省六成？腾讯便宜20倍？”**——两个价格差都很大，我想知道平时用这些 AI 能不能少花钱。
2. **“千问省六成？AI找漏洞修三回”**——“修三回”让我好奇为什么修不好，不过看不出前后两件事有什么关系。
3. **“腾讯AI便宜20倍，比的是自家大哥”**——“自家大哥”我能理解成更高级的产品，想看看便宜这么多是不是也差很多。

看不清具体在说什么的：

- **“千问说省六成，第三方算出两个数”**：“两个数”太含糊，是两种价格，还是两种省钱比例？
- **“两家AI同天比省钱，第三方各算各的”**：不知道是哪两家，也不明白“各算各的”有什么值得我看的。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：“吠”是在说谁吹牛，还是作者要吐槽？开头就得猜这个栏目用语。
- **“省流：阿里 Qwen4-Max、腾讯 Hy4 flash 同日发布……修复跨了三个版本。”**：一口气出现好几个陌生名字，还把价格、评测、漏洞塞在一起；看完记不住谁便宜、谁修漏洞。
- **“称自家测试中单任务平均费用比上一代降约六成。”**：“单任务”是问一个问题，还是完成一项工作？这是我付的钱，还是公司的运行费用？
- **“每百万 token 输入0.5元、输出2元”**：不知道 token 是什么，也不知道为什么输入和输出分开收费，换成日常聊天大概要花多少。
- **“Qwen4-Max 跑其综合指数每个任务平均3.27美元，上一代10.02美元（均未标推理档位）。”**：“跑其综合指数”“推理档位”都不懂；为什么前面几毛钱，这里又是几美元？
- **“第三方 Vals 的综合测试里，Qwen4-Max 每次测试9.33美元，上一代8.73美元，没变便宜。”**：“每次测试”和前面的“每个任务”是一回事吗？两组价格能直接比吗？
- **“同一张图上 Hy4 flash 42.1分，Hy4 51.4分。”**：是什么考试，满分多少？差九分代表实际用起来差多少？
- **“‘接近 Claude-Haiku-5.5’来自85位腾讯内部用户盲测，4分制2.79对2.81；同表 DeepSeek 3.09分最高。”**：突然出现一个没介绍的 AI 名字；“盲测”是什么意思？2.79和2.81分别是谁的分数，又是在给什么打分？
- **“Hy4 11月4日称‘将于近期开源’，至今 Hugging Face 只有预览版；这次 Hy4 flash 又写‘计划开源’。”**：“开源”和“预览版”差在哪？Hugging Face 是什么地方？这影响我现在能不能用吗？
- **“广告拦截扩展 uBlock Origin 的 Firefox 版有漏洞”**：我不认识这两个名字，也不太明白“扩展”是什么，得停一下判断是不是跟我有关。
- **“网站就能借扩展在任意网站运行代码。”**：读得懂字，但不知道后果是什么；是能看到我的账号，还是替我操作？
- **“方向由他提示，问题由他验证，演示代码主要由 Claude 写。”**：“他”应该是研究者，但我要回看确认；“演示代码”又是拿来演示什么的？
- **“维护者公告写1.75.4起修复，Firefox 扩展商店目前是1.76.4。”**：我猜新版已经修好了，但这和“修了三回”怎么对应？
- **“1.75.2里的第一次修复很快被研究者绕过；公告又把1.76.0的两项补丁列在同一漏洞下，媒体写的修复版本不一。”**：版本号已经分不清了，“绕过”“补丁”也需要理解；读两遍还是不知道到底哪个版本修好了。
- **“没有 CVE 编号，公告和文章都没提到有人实际利用。”**：不知道 CVE 是什么，也不知道没有编号意味着什么。

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**：为了把“沸”和“吠”凑成谐音口号，表达显得刻意；还没讲事情，先喊一句栏目宣传语。
- **“省流：阿里 Qwen4-Max、腾讯 Hy4 flash 同日发布，都主打省钱；两家第三方测出的千问费用，一家降约三分之二、一家没降，混元的1/20是跟自家更强的模型比。uBlock 漏洞据称主要靠 GPT-5.6-Sol 找到，修复跨了三个版本。”**：像把正文所有重点机械压进摘要，每件事都要保留，结果“省流”本身也需要费力消化。
- **“方向由他提示，问题由他验证，演示代码主要由 Claude 写。”**：连续三个“某事由某人做”，像为了交代分工特意排成整齐句式。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：很像自动生成的品牌收尾；“轻松识破”在替读者宣布收获，但我其实还有很多词没看懂。

## 4. 会划走的地方

- **“省流：阿里 Qwen4-Max、腾讯 Hy4 flash 同日发布……”**：这里就可能划走。陌生型号太密，我原本是被“便宜多少”吸引来的，第一段却没让我明白这和自己有什么关系。
- **“据第三方 Artificial Analysis 评测，Qwen4-Max 跑其综合指数……”**：如果坚持到这里，我开始失去耐心。前面是人民币，接着是美元，又有不同测试，越来越像在看我不懂的账单。
- **“③‘接近 Claude-Haiku-5.5’来自85位腾讯内部用户盲测……”**：这条吠点我不太在乎。我连这几个 AI 有什么区别都不知道，几分之几的差距吸引不了我。
- **“④Hy4 11月4日称‘将于近期开源’……”**：这条也不在乎。“开源”没有解释成对我的具体影响，我看不出推迟这件事为什么值得关注。
- **“②1.75.2里的第一次修复很快被研究者绕过……”**：这是第二部分最想划走的地方。接连报版本号，我只想知道现在是不是还危险。
- **“③没有 CVE 编号，公告和文章都没提到有人实际利用。”**：后半句我关心，前半句不在乎；不知道这个编号能帮我判断什么。
