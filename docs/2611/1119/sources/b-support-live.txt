Screen Security

Use Screen Security to prevent Signal previews from appearing in the app switcher on your phone only.

How do I enable or disable Screen Security?
In Signal, tap your profile  > Settings (iOS) > Privacy  > Screen Security (Android) or Hide Screen in App Switcher (iOS)

To enable, tap the slider so it is blue. 
To disable, tap the slider so it is grey.

When enabled,

A blue privacy screen with the Signal logo will appear to cover your Signal text. 
This will also prevent screenshots of Signal on your own device only. This does not prevent someone else from taking a screenshot on their device.

 

Why can't I take a screenshot on Microsoft Windows?
Signal Desktop prevents screenshots on Windows 11 by default, which adds an extra layer of protection so that your Signal messages are not automatically captured and stored by Microsoft Recall. You can learn more about Signal’s screen security feature for Windows on our blog.

You can easily change this setting here:

Signal Desktop Settings  > Privacy  > Screen security

Before disabling screen security, we encourage you to either switch off Microsoft Recall completely, or add a filter for the Signal application by following Microsoft's latest instructions.
