 Hybrid intelligence on the Web: Introducing Aion Instruct and Prompt API in Microsoft Edge

 Written By

 Sohum Chatterjee
 [https://blogs.windows.com/msedgedev/author/sohum-chatterjee/]

 published

 November 19, 2026

Rapidly evolving AI capabilities are redefining what sites can do for users on the web. With on-device AI in Microsoft Edge [https://blogs.windows.com/msedgedev/2026/06/02/expanding-on-device-ai-in-microsoft-edge-new-models-and-apis-for-the-web/], sites can use task-specific and small language models for capabilities such as writing assistance, summarization, language detection, translation, and speech recognition. Through the Prompt API [https://blogs.windows.com/msedgedev/2025/05/19/introducing-the-prompt-and-writing-assistance-apis/], they can also use a small language model for more general-purpose intelligence.

Together, these capabilities provide a foundation for hybrid intelligence on the web: developers can leverage on-device AI models when they are available in the browser and well-suited, and switch to a configured cloud provider to extend device coverage or access more powerful inference when needed.

To make on-device inference more broadly available, we’re introducing three updates today:

General availability of Aion Instruct as an open-weights model on Hugging Face, and as Microsoft Edge’s built-in small language model.

An origin trial for the Prompt API, so you can use the Prompt API and Aion Instruct on your live site today.

A developer preview of an experimental Decisions API, which gets you fast, structured answers about text.

These announcements build on our earlier developer preview [https://blogs.windows.com/msedgedev/2026/06/02/expanding-on-device-ai-in-microsoft-edge-new-models-and-apis-for-the-web/] of Aion-1.0-Instruct. Since then, we’ve heard from early adopters, incorporated your feedback, and refined the model’s training to improve quality and performance for on-device AI needs on the web.

Aion Instruct is now generally available in Edge

Aion Instruct is available today as an open-weights model on Hugging Face [https://aka.ms/aion-instruct-hugging-face] and is coming to Windows [https://devblogs.microsoft.com/foundry-on-windows/aion-instruct-local-ai-windows-gpu/] later this year, laying the foundation for richer on-device AI experiences across Windows and Copilot+ PCs. In Microsoft Edge, Aion now replaces Phi-4-mini [https://blogs.windows.com/msedgedev/2025/05/19/introducing-the-prompt-and-writing-assistance-apis/] as the browser’s built-in small language model.

At 2.3B parameters, Aion is smaller, faster, and available on many more devices than Phi, while delivering comparable quality for common web tasks such as text synthesis and generation, summarization, instruction following, and structured outputs.

Edge downloads Aion Instruct only when a site or feature first needs it, and only on devices that can run it well. Users stay in control and can turn off on-device AI [https://aka.ms/ondeviceaisetting] in Edge settings, which removes the model and stops future downloads.

Test the Prompt API on your live site

Until now, the Prompt API has been available as a developer preview only in Edge Canary and Dev channels. Now, with the Prompt API origin trial [https://aka.ms/prompt-api-origin-trial], you can call the API from your live site in Microsoft Edge and test it with a much broader audience.

The origin trial lets you bring on-device AI features to your site, evaluate them under real-world conditions, and refine your implementation based on actual usage. Along the way, please share feedback on the API’s design, the model’s performance, and any interoperability challenges you encounter across different browsers and models. This will help inform discussions with other browser vendors and the web community as the Prompt API is considered for standardization.

To get started, register for the Prompt API Origin Trial [https://aka.ms/prompt-api-origin-trial], read the developer documentation [https://aka.ms/promptapi], try out the playground sample [https://microsoftedge.github.io/Demos/built-in-ai/playgrounds/prompt-api/], and engage with us on the GitHub discussion [https://github.com/MicrosoftEdge/MSEdgeExplainers/issues/1012] about the API.

Developer preview of the Decisions API

We’re also exploring new uses for on-device AI with an early implementation of the experimental Decisions API [https://aka.ms/edge-decisions-api], powered by Aion Instruct. It is available as a developer preview in Edge Canary and Dev channels for prototyping. Expect both the API and its implementation to change as we learn from developer feedback.

The Decisions API enables sites to ask yes/no, multiple-choice, or scoring questions about text input and get back probabilities and a confidence value, computed in a single pass without any text generation. For instance, you can use the Decisions API to understand a user’s intent and act on it, sort and route user-generated content, or score and rank items in real-time, all with a few lines of client-side JavaScript code:

// Ask three questions about a product review in a single pass
const model = await DecisionModel.create({
 "context": "Customer reviews for an online electronics store",
 "questions": [
 {
 "id": "topic",
 "type": "choice",
 "prompt": "What is the review mainly about?",
 "options": [
 { "label": "quality", "description": "How the product works or feels" },
 { "label": "shipping", "description": "Delivery, packaging, or delays" },
 { "label": "price", "description": "Cost or value for money" }
 ]
 },
 {
 "id": "rating",
 "type": "score",
 "prompt": "How satisfied is the customer, from 1 to 5?"
 },
 {
 "id": "needs_reply",
 "type": "boolean",
 "prompt": "Is the customer asking for help?"
 }
 ]
});

// Get a label, probabilities, and a confidence value for each question
const result = await model.decide(
 "Love the headphones, but the box arrived crushed. Can I get a replacement?"
);

To experiment with the Decisions API, read the explainer [https://github.com/explainers-by-googlers/decisions-api] and developer documentation [https://aka.ms/edge-decisions-api], try the playground sample [https://microsoftedge.github.io/Demos/built-in-ai/playgrounds/decisions-api/], and share your thoughts on GitHub [https://github.com/MicrosoftEdge/MSEdgeExplainers/issues/1444].

Try it out and let us know

These updates are another step toward bringing hybrid intelligence to the web, giving developers more options to use on-device AI when it’s well-suited and combine it with cloud inference when needed.

With Aion Instruct now smaller, faster, and more broadly available, we’re excited to see the new web experiences you’ll build. We’re actively looking for feedback on model performance and interoperability for the Prompt [https://aka.ms/edge-prompt-api] and Summarizer [https://aka.ms/edge-summarizer-api] APIs. If you try the experimental Decisions API [https://aka.ms/edge-decisions-api], let us know what you’re building, if the API design works for you, and whether your latency requirements warrant a smaller model.

We look forward to you testing the Prompt API using the Origin Trial [https://aka.ms/prompt-api-origin-trial], checking out the developer documentation [https://aka.ms/promptapi] and playground samples [https://s://microsoftedge.github.io/Demos/built-in-ai/playgrounds/], and sharing your feedback with us on GitHub [https://github.com/MicrosoftEdge/MSEdgeExplainers/issues/1012].
