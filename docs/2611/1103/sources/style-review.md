检查方：Codex gpt-6-astra medium，只读，无本期上下文（templates/style-review.md）；北京 11-04 约22:10。下为原报告；Claude 据此改了省流“权重”、Hacker News、“不主张数据外传”“抓包”“更新说明”“干净的电脑”六处，并把标题由 titles.md #1 改为 #8。未改：开场与 Slogan（固定格式）、吠点①②③模板（账号固定结构）、Kimi 一条（跟进1023 的时效事实，保留）。

## 1. 标题

我会点的前三：

1. **“软件一升级，偷偷给AI装插件？”**——“偷偷装东西”听起来可能影响我用电脑，不懂 AI 也能明白有什么问题。
2. **“装个Postman，AI工具被改了？”**——虽然不认识 Postman，但“装一个软件，把另一个改了”让我想知道怎么回事。
3. **“腾讯称最强开源，却没放权重？”**——腾讯我认识，也看得出是在质疑它说话不算数，但“权重”是什么会影响我是否真点进去。

看不出具体在说什么事的：

- **“最强开源模型，权重在哪？”**——谁发布的、少了什么、跟我有什么关系，都不清楚。
- **“腾讯Hy4号称开源第一，权重呢？”**——“Hy4”和“权重”都不认识，只知道在质疑腾讯。
- **“腾讯说开源，Kimi也说开源，权重呢？”**——看得出两家都被质疑，但不知道“没权重”为什么就有问题。
- **“腾讯开源没权重？Postman偷装插件？”“腾讯最强开源没权重？软件偷装AI插件？”**——后半句能懂，前半句不懂；放一起还让我以为两件事有什么关联。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁吹牛，还是谁发表了观点？开头就要猜这个梗。
- **“权重却只说‘近期’开放。”**——不知道“权重”是什么，也不知道它与“开源”的关系，读不出这个“却”有多严重。
- **“接口调试软件 Postman 的桌面版升级时，自动给 Codex、Claude Code 装上插件，还替用户批准了插件的启动脚本”**——“接口调试”“Codex”“Claude Code”“启动脚本”连续出现，一句话里要理解的陌生东西太多。
- **“网传它‘共享所有 API 数据’，目前没见证据。”**——不知道 API 数据包括什么，是聊天内容、密码，还是程序里的东西？
- **“首次能看图、操作电脑，价格与8月的预览版相同。”**——“首次”是这个模型第一次能，还是腾讯第一次做到？“价格”又是会员费还是按使用量收费？
- **“截至北京4日21:30，Hugging Face 上只有8月的预览版。”**——不知道 Hugging Face 是什么，也不知道为什么查那里就能判断有没有开放。
- **“‘综合表现位居开源模型第一’出自腾讯与自家金融科技团队的金融众测，只和3个开源模型比。”**——“金融众测”卡住了：是让金融从业者试用，还是只考金融题？“综合表现”到底比什么？
- **“官方自己的对比图里，Hy4 在12项测试中都低于 Claude-Opus-5.5。”**——不知道这是什么模型、是否属于前面说的开源模型，也不清楚这12项和前面的金融众测是不是同一组测试。
- **“拿来比的 Kimi-K3.1-Pro 也没放权重”**——“拿来比”是谁拿来比？它就是前面那3个模型之一吗？
- **“按美国时间，4日要到北京5日下午才过完。”**——要停下来算时间，而且前面只写了“11月4日前”，没说为什么这里要按美国时间理解。
- **“还替用户把插件在 Codex 里的启动脚本标成‘已信任’，Codex 本来会先提示用户审核。”**——大概明白它跳过了我的同意，但不知道被信任的脚本能做什么。
- **“该帖转到 Hacker News 后已有1300多分。”**——不知道 Hacker News 是什么，“分”是点赞还是热度，1300多算多大？
- **“发帖人却写明报告不主张数据外传，目前也没见抓包等证据。”**——“不主张数据外传”要读两遍，第一眼像是“不赞成外传”；“抓包”也不懂。
- **“启动脚本做的是每次开会话塞一段话，让 AI 遇到接口任务先用 Postman 的工具。”**——谁跟谁开会话？这段话塞在哪里，我能看见吗？“接口任务”又是什么？
- **“它的更新说明却没写，升级会把插件装进你已有的 Codex、Claude Code。”**——读到“没写”以为句子结束了，后半句才明白是在说“没写明升级会装插件”。
- **“发帖人也没在干净的电脑上复现。”**——“干净”是没病毒、没装过这些软件，还是重装过系统？为什么这会影响前面的判断？

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**——为了把“沸”和“吠”凑成品牌梗，写出一个正常聊天里不太会说的问句，有自动生成栏目口号的感觉。
- **“一、Hy4 称‘最强开源’，权重没放”“二、Postman 升级，自动装 AI 插件”**，两段下面又都是 **“吠点：①……②……③……”**——两件复杂程度不同的事，都整齐装进“三条点评”的同一模板，像批量生成的资讯稿。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——“聊……轻松……”很像营销文案；我读完还没搞懂几个词，结尾却已经替我宣布能“轻松识破”了。

## 4. 会划走的地方

- **“省流：腾讯发布大模型 Hy4……接口调试软件 Postman……Codex、Claude Code……”**——最可能就在这一段划走。“省流”本来应该帮我快速看懂，结果一口气来了好几个陌生名字和术语。
- **“②‘综合表现位居开源模型第一’出自腾讯与自家金融科技团队的金融众测……”**——如果坚持读到这里，我也容易走：开始像模型排行榜争论，但我还不知道它们分别能帮我干什么。
- **“③拿来比的 Kimi-K3.1-Pro 也没放权重……按美国时间……”**——这条我最不在乎。从腾讯转到另一个模型，再算截止时间，感觉离最初的新闻越来越远。
- **“该帖转到 Hacker News 后已有1300多分。”**——这句不能让我觉得事情更重要，因为我对这个网站和分数都没概念。
- **“③GitHub 上用官方口吻回复、说会改进的账号，没有任何 Postman 身份标识……”**——这条“吠点”我也不太在乎。我更关心软件究竟改了什么、会不会影响我；回复账号的身份争议读起来像评论区后续。
