Postman CLI

postman init loads Postman's skills into your coding agent, so it can run collections, tests, and API workflows without leaving your editor. Cross-platform and scriptable, no GUI required.

Install method
npm
macOS / Linux / WSL
Windows
npm install -g postman-cli
START WITH
postman init

Passport Lens

Review the secrets your agents are sending. Install the Passport CLI to route your AI agents and tools through a local inspector that flags every API key and token leaving your machine — detected, masked, and logged.

npm i -g @postman/postman-passport
