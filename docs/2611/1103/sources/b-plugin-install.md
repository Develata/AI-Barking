# Install the Postman plugin

> Install the Postman plugin into every detected coding agent at once, into a single agent with its own method, or load skills with the Postman CLI.

Install the Postman plugin into Antigravity, Claude Code, Codex, GitHub Copilot CLI, Cursor, Factory, Kimi Code, OpenCode, or Pi. You can install into every detected agent on your machine with a single command, install into a single agent using that agent's own method, or load the same skills with the Postman CLI. Choose the method that fits your setup.

## Requirements

These requirements apply when you install the plugin, either into detected agents or a specific agent. If you load skills with the Postman CLI instead, these requirements don't apply.

* Node.js 22 or later (only needed to install into detected agents)
* Antigravity (latest version)
* Claude Code 2.1.268 or later
* Codex 0.138.0 or later
* GitHub Copilot CLI (latest version)
* Cursor 2.5 or later
* Factory Droid 0.57.5 or later
* Kimi Code 0.6.0 or later
* OpenCode 1.14.33 or later, and Git
* Pi 0.99.0 or later

## Install into detected agents

Install the plugin into every detected agent, or a single agent, with one command. This is the quickest way to install into more than one agent at a time.

Learn more at [Install the Postman plugin into detected agents](/docs/postman-plugin/install/detected-agents/).

## Install for a specific agent

Install the plugin into a single coding agent using that agent's own marketplace or command, such as Claude Code, Cursor, or Codex.

Learn more at [Install the Postman plugin for a specific agent](/docs/postman-plugin/install/per-agent/).

## Load skills with the Postman CLI

As an alternative to installing the plugin, load Postman's skills directly into your agent by running the Postman CLI `postman init` command in your project.

Learn more at [Load skills with the Postman CLI](/docs/postman-plugin/install/load-skills/).
