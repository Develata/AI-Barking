Postman CLI

postman init loads Postman's skills into your coding agent, so it can run collections, tests, and API workflows without leaving your editor. Cross-platform and scriptable, no GUI required.

Install methodnpmmacOS / Linux / WSLWindowsnpm install -g postman-cli

Start withpostman init

Postman plugins

Add the Postman plugin to your coding agent to load Postman's skills and best practices as you build.

Claude [https://claude.com/marketplace/plugins/postman]OpenAI [https://chatgpt.com/plugins/postman]Cursor [https://cursor.com/marketplace/postman]

Get the Postman plugin

Claude Code

Step 1
claude plugin marketplace add anthropics/claude-plugins-official

Step 2
claude plugin install postman@claude-plugins-official

Get Postman Plugin → [https://github.com/postmanlabs/postman-plugin]Read the docs → [https://learning.postman.com/docs/reference/developer-resources/postman-plugin]

Passport Lens

Review the secrets your agents are sending. Install the Passport CLI to route your AI agents and tools through a local inspector that flags every API key and token leaving your machine — detected, masked, and logged.

npm i -g @postman/postman-passport

The @postman/postman-passport [https://www.npmjs.com/package/@postman/postman-passport] package is available on npm.

The Postman app

Download the app to get started with the Postman API Platform.

The Postman app includes Postman CLI & Postman plugins, so you can use Postman from your terminal.

By downloading and using Postman, I agree to the Privacy Policy [https://privacy.postman.com/policies/] and Terms [/legal/terms/].

To experience the best the Postman app has to offer, please download it on your desktop.

Release Notes → [/release-notes/postman-app/]

Postman on the web

Use Postman in your web browser to get started quickly, with lightweight access for exploring APIs and running requests. Create a free account and you're in.
 Try the Web Version [https://identity.getpostman.com/signup?continue=https%3A%2F%2Fgo.postman.co%2Fhome]

Postman desktop agent

If you're using Postman in a web browser, download the Postman desktop agent to make API requests to local and private networks and overcome browser limitations like CORS.
Download Postman Agent → [/downloads/postman-agent/]

Postman Interceptor

Postman Interceptor helps you bring browser network traffic into Postman. Capture and inspect traffic between your client and APIs, debug quicker, and streamline your workflow without switching between tools. Available for Chrome, Safari, Edge, and Firefox.

Learn more → [/product/postman-interceptor/]
