腾讯最强开源没权重？软件偷装AI插件？

AI 沸点，今日谁吠？

省流：腾讯发布大模型 Hy4，自称“跻身最强开源模型之列”，模型本体（权重）却只说“近期”开放。有开发者反映，接口调试软件 Postman 的桌面版升级时自动给 Codex、Claude Code 装插件；网传它“共享所有 API 数据”，目前没见证据。

一、Hy4 称“最强开源”，权重没放

北京11月4日中午，腾讯混元发布大模型 Hy4，首次能看图、操作电脑，价格与8月的预览版相同。官方稿标题称它“跻身最强开源模型之列”，正文称其在金融众测中“综合表现位居开源模型第一”。

吠点：
①叫开源，权重还没放：腾讯官网稿只写“将于近期开源模型权重”；截至北京4日21:30，Hugging Face 上只有8月的预览版。
②这个金融众测由腾讯与自家金融科技团队组织，只和3个开源模型比。官方自己的对比图里，Hy4 在12项测试中都低于 Claude-Opus-5.5。
③拿来比的 Kimi-K3.1-Pro 也没放权重：月之暗面10月称最迟11月4日公开，截至同一时刻仍没有；官方没给时区，按美国时间，4日要到北京5日下午才过完。

二、开发者称 Postman 自动装插件

10月下旬，有开发者在 GitHub 反映：接口调试软件 Postman 的桌面版一升级，就给 Codex、Claude Code 装上自家插件，另一名用户也贴出了同样的安装记录。Postman 文档写明，它的安装程序会替用户批准插件在 Codex 里的启动脚本；用 Codex 自己的方式装，则要用户自己审核。

吠点：
①Hacker News 转帖标题说它“试图共享你所有的 API 数据”，发帖人却写明，报告没说数据被传了出去；截至北京4日21时，帖子评论和报道里都没见这类证据。启动脚本的作用是让 AI 遇到接口任务先用 Postman 的工具。
②Postman 的更新说明只写了随软件装命令行工具，没写明升级会把插件装进你已有的 Codex、Claude Code。
③GitHub 上用官方口吻回复、说会改进的账号，资料里没有 Postman 身份标识；截至4日21时，Postman 博客和更新说明里也没有回应。发帖人也没在全新的电脑上重现。

AI 吠点：聊 AI 沸点，轻松识破吠点。
