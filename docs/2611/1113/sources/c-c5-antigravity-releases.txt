Legacy Linux Package Repositories (v1.x)Historical

Historical reference only: These APT and RPM repositories were provided for legacy Antigravity 1.x releases and are no longer updated. For the Antigravity App and later, please use the direct tarball downloads above or visit the Download page [/download?os=linux] for the modern installer.

Debian / Ubuntu (APT)

1. Add repository to sources.list.d

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://us-central1-apt.pkg.dev/doc/repo-signing-key.gpg | \
 sudo gpg --dearmor --yes -o /etc/apt/keyrings/antigravity-repo-key.gpg
echo "deb [signed-by=/etc/apt/keyrings/antigravity-repo-key.gpg] https://us-central1-apt.pkg.dev/projects/antigravity-auto-updater-dev/ antigravity-debian main" | \
 sudo tee /etc/apt/sources.list.d/antigravity.list > /dev/null

2. Update package cache

sudo apt update

3. Install package

sudo apt install antigravity

Red Hat / Fedora / SUSE (RPM)

1. Add repository to /etc/yum.repos.d

sudo tee /etc/yum.repos.d/antigravity.repo << 'EOF'
[antigravity-rpm]
name=Antigravity RPM Repository
baseurl=https://us-central1-yum.pkg.dev/projects/antigravity-auto-updater-dev/antigravity-rpm
enabled=1
gpgcheck=0
EOF

2. Update package cache

sudo dnf makecache

3. Install package

sudo dnf install antigravity
