## 1. 标题

我会点的前三：

1. **“关掉防护的AI，23比1赢了人类”**：数字直接，又有“关掉防护”这个反常的动作，我想知道它和人类比什么。
2. **“Claude读哥德尔笔记，50条定理是错的？”**：“50条定理是错的”让我想知道，是 AI 弄错了，还是数学家原来就写错了。
3. **“663条哥德尔定理，AI一口气列完？”**：即使不知道哥德尔是谁，也能感到工作量很大，想看看 AI 到底做了什么。

看不出在说什么事的：

- **“AI破译哥德尔天书？AI红队先关了防护”**：前后像两件不相干的事，我会误以为关防护是为了读懂笔记；“红队”也不知道是什么。
- **“AI红队赢了人类，先关了自己的防护”**：不知道“红队”是什么队，也不知道赢的是答题、比赛还是攻击电脑。
- **“AI1/235请求量就破防？比的是第一次”**：“请求量”是什么量、“第一次”做什么，都没说清，连标题怎么断句都要想一下。
- **“哥德尔天书是人读的，AI读的译稿”**：能猜到是在纠正一种说法，但我没看过原来的新闻，不知道这件事为什么值得点开。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：“谁吠”是在说谁造假、谁夸大，还是单纯玩谐音？开头不知道要用什么心态读。
- **“省流：据《卫报》报道，Claude 从哥德尔笔记列出663条定理，约50条是错的，它读的是学者的转写稿。”**：“转写稿”是把字迹认出来，还是已经翻译、整理过？“50条是错的”也不知道错算谁的。
- **“Anthropic 称自动红队找漏洞胜过人类，它用的是关掉防护的内部 Claude。”**：不知道 Anthropic 和 Claude 是什么关系，“自动红队”又是什么；“它”指公司还是红队，要回头找。
- **“据《卫报》报道，逻辑学家 von Plato 自2017年研究哥德尔的16本笔记，共1009页，多用废弃的速记写成，每周只能读懂约一页。”**：“废弃的速记”是失传的文字，还是一种已经没人用的缩写？不明白难在哪里。
- **“今年9月，他把自己转写的稿子和6本旧著交给 Claude。”**：“6本旧著”是谁写的，为什么要一起交进去？
- **“哥德尔曾自称证过选择公理的独立性，却拿不出证明。”**：“选择公理的独立性”完全不懂，也不知道证明它有什么意义。
- **“Claude 重建出证明，通过了证明软件 Coq 检查，von Plato 说哥德尔只差一步。”**：“重建”是把已有步骤拼起来，还是补出了新步骤？软件检查通过是不是就代表证明正确？“只差一步”又是哪一步？
- **“Claude 还列出哥德尔写过证明或思路的定理，共663条：放进 Coq 后，约400条照原样成立，约200条要改写或补假设，约50条是错的。”**：“补假设”不懂；“改写”是改表达还是改结论？三组数字加起来约650条，我还会停下来想剩下的怎么算。
- **“②数字都来自 von Plato 对《卫报》的口述，本号截至14日没找到论文或公开的 Coq 文件。”**：不知道“Coq 文件”里面是什么，也不知道没有它会影响我相信哪部分。
- **“③逻辑学家 Hamkins 说没看过 Claude 的重建，多少归 Claude、多少归哥德尔，要历史学家来分。”**：“多少归”指成果数量，还是功劳？为什么是历史学家来分？
- **“Anthropic 11月12日称，自建的 AI 红队 Anvil 专攻自家 Claude 的防护，找‘越狱’（绕过防护的问法）。”**：括号让我大概懂了“越狱”，但仍不知道“红队”是一个 AI、一套程序，还是有人操作的团队。
- **“生物武器题上，8道题配3代防护共24组，Anvil 在23组胜过人类，1组打平，用时24到48小时。”**：“3代防护”怎么配题？“胜过”是找到更多漏洞，还是更快？24到48小时是每组还是全部？
- **“人类赏金猎人花了430小时，只在1道题上找到高危越狱。”**：“赏金猎人”是什么人，“高危越狱”和前面的胜负是不是同一个标准？前面按24组，这里按1道题，我比不起来。
- **“①Anvil 用的是关掉防护的内部 Claude；Anthropic 自测，打开它的防护，97%的攻击会话会被拦，85%在第一条消息就被拦。”**：到底关的是负责攻击的 AI 的防护，还是被攻击的 AI 的防护？“它”指谁？85%是全部会话的85%，还是被拦的那部分？
- **“②智东西标题称‘只用人类1/235的请求量，就找到严重漏洞’，比的只是双方首次套出隐藏推理的请求数，套出的是一道编程题的推理。”**：“请求”怎么算一次，“隐藏推理”是什么，为什么套出来就是漏洞？这一句需要补的知识太多。
- **“③网络安全题上，人类专家报了11组成功，Anthropic 称其中9组靠防护更弱的辅助模型写或跑攻击代码，不达 Anvil 的标准。”**：用了辅助模型为什么就不算？“Anvil 的标准”是什么？我没法判断这9组到底该不该算。

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**：像为了栏目名硬凑出来的开场，谐音先出现，具体内容还没出现。
- **“省流：据《卫报》报道，Claude 从哥德尔笔记列出663条定理，约50条是错的，它读的是学者的转写稿。Anthropic 称自动红队找漏洞胜过人类，它用的是关掉防护的内部 Claude。”**：两条新闻都套成“看起来很厉害，再揭一个限制”的同一种句式，像自动生成的摘要模板；人名、数字、转折挤在一起，也没真让我省力。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：“聊／识破”和“沸点／吠点”排列得很整齐，像生成的品牌口号；前面我还有不少没读懂，结尾却说“轻松识破”，显得空。

## 4. 会划走的地方

- **“哥德尔曾自称证过选择公理的独立性，却拿不出证明。”**：这是我第一次明显想划走的地方。前面还能理解成“AI 帮忙读难认的笔记”，这里突然要求我懂数学问题，却没告诉我它为什么值得关心。
- **“生物武器题上，8道题配3代防护共24组，Anvil 在23组胜过人类，1组打平，用时24到48小时。”**：如果坚持读到了第二部分，这里又开始密集算数字，而且不知道怎么算赢，我会觉得后面还得继续做阅读理解。
- **“②数字都来自 von Plato 对《卫报》的口述，本号截至14日没找到论文或公开的 Coq 文件。”**：这条“吠点”我不太在乎，因为我不会去看论文或证明文件，也不清楚缺少它们意味着什么。
- **“③逻辑学家 Hamkins 说没看过 Claude 的重建，多少归 Claude、多少归哥德尔，要历史学家来分。”**：这条我最不在乎。我更想知道 AI 做成了什么，功劳怎么分离我的兴趣比较远。
- **“③网络安全题上，人类专家报了11组成功，Anthropic 称其中9组靠防护更弱的辅助模型写或跑攻击代码，不达 Anvil 的标准。”**：读起来像比赛双方在争计分规则；我连规则都没弄明白，就更不想继续听争议。
