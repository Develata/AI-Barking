Anthropic announced the automated red-teaming system Anvil; in information security tests, the number of requests needed to find a vulnerability was only 1/235 of that for humans

Anthropic新AI红客来了！只用人类1/235的请求量，就找到严重漏洞

AI summary

Anthropic announced Anvil, an automated red-teaming system built on Claude, claiming that it outperforms human red-teamers in multiple tests. In biosecurity tests, Anvil found jailbreak schemes with higher severity than human ones in 23 of 24 question-and-classifier combinations; in cybersecurity tests, it broke through all 24 task-and-model combinations, taking 0.5 to 3.5 hours to find the first vulnerability; in information security tests, it found the first substantive reasoning information leakage vulnerability with only 435 requests, whereas human experts needed about 102,200. The system is built on the Investigator Agent, running multiple independent Claude tasks in parallel and adjusting attack requests based on the target model's responses. Anthropic noted that Anvil's attack capability is related to the underlying model's capability, and that it uses an internal model with safety guardrails disabled and can obtain precise classifier scores, which differs from the conditions of external attackers; if the attacking model has its own guardrails enabled, 97% of 1,453 red-team sessions were blocked.
