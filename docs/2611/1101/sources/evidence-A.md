## 0. 先看这几条（与“已知情况”不符或扫描没提的）

1. **12.0% 不是“做对 12% 的任务”。** 榜单默认指标 Score 是“每个任务按各自的**原定评分法**（二元或连续）算分，三次尝试取平均”，再跨域等权；页脚原句：“Tasks use a combination of binary and continuous grading depending on the domain. The default score uses the intended grading method for each task and takes the average across 3 attempts.” 同一页面切到 “Partial score”（对二元任务改用连续分），总分第一的 Opus 5.5 是 **22.5%**（见 02 图）。
2. **“sandbagged” 对两家的影响不对称。** 按页面自己的“剔除 cyber/bio/alignment”视图（03 图）：GPT-6 Astra 9.6 → 11.8（升到第一），Opus 5.5 12.0 → **11.7**（反而降了 0.3，两者只差 0.1）。用逐域分数反推：Astra 三域均值 3.8 对八域均值 11.8；Opus 三域均值 12.8 对八域均值 11.7（推断，由站点逐域数字计算，见 `a-domain-matrix.tsv`）。博文原句说两家都“sandbagged overall scores”，数字上明显被压的是 Astra（三域均值 3.8 对 11.8）和同属 OpenAI 的 GPT 6.1 Sol/Terra、以及 Claude Sonnet 5.5；Opus 5.5 与 Gemini 4 Carbon 的三域均值反而高于其余八域（推断）。
3. **QA 有两层，扫描只说了一层。** 扫描称“QA 由伙伴自做”：伙伴确实各自做域内质检（如 Arithmetic：“For the QC process, Arithmetic uses experts and reference solutions to establish solvability, adversarial controls to test grader bypasses, and rollout QC…”），但原文强调 SemiAnalysis 另对每个候选伙伴跑统一的 “agentic QA”并人工看了数百条轨迹，伙伴须 “first try” 通过（见 A6-2）。只写“伙伴自做”会漏掉后一层。
4. **“金融与法律多数模型 0 分、榜单改报平均部分分”需拆开。** 默认总榜里金融域、法律域是**二元评分的 0**（金融仅 Gemini 4 Carbon 2.8%，法律 20 个模型全 0.0%），12.0% 的总分里这两域就是 0；“改报平均部分分”是博文里金融域那张图（及站点上 Partial 切换）的口径，不是总分口径。
5. **Pichai 回应已找到一手。** 见 A7：他的原句只说“高质量基准、有余量，看 Carbon 的成本线”，没有说 Carbon 更强。
6. 站点数字在博文发布后又有微调：博文配图里 GPT 6.1 Sol 为 8.3% / $9.78，现网为 8.4% / $9.80（八域视图 10.5%/$11.14 → 10.6%/$11.15），其余已核数字一致（推断：站点后来更新过；博文页 `updated_at` 为 2026-11-02T06:16:50Z）。

## 2. 可能的吠点（均为一手原文里有、线索摘要没提或说反的条件与限制）

1. 12.0% 是“混合评分”的均值，不是任务通过率：同一页面 Partial 视图里 Opus 5.5 是 22.5%、Astra 19.2%、Carbon 18.9%、Sol 18.3%、Muse Wonder Full 17.2%（站点，02 图）；排名也变（Astra 升第二、Carbon 降到第三）。博文自己的话是 “mix of binary and partial grading”。
2. 金融、法律的“0 分”是二元门槛造成的：Partial 视图里金融域 Opus 54.6%、Astra 52.9%、Sol 52.0%；法律域最高 Muse Wonder Full 38.4%、Opus 29.9%（06 图、`a-board-domain-*-partial-harness.txt`）。博文原句：“all the models score 0% if you use binary grading”。这两域在总分里各占 1/11，对总分贡献为 0（站点，推断自逐域数字）。
3. “sandbagged”只在数字上明显影响 Astra 等 OpenAI 模型，不影响 Opus 的总分排名：剔除后 Opus 11.7 < 现 12.0（03 图）；Astra 三域均值 3.8、Opus 12.8（推断）。博文没有披露拒答的计分方式（是否记 0）、被拦截次数。站点八域视图说明里点名 “Claude Opus 5.5 and GPT-6 Astra”。
4. 横向可比性有限：harness（Claude Code / Codex / Antigravity / Muse Code / Grok Build / ZCode / Kimi Code / MCode / DeepSeek Harness / OpenCode）与档位（MAX / HIGH / HIGHEST / XHIGH）都不一致，Gemini 4 Carbon 标 HIGH、Claude 与 GPT 标 MAX（站点 “Show harness”，01 图）；博文原句 “We ran all models in their native harness when available”。
5. 成本口径未定义，且是均值：Opus $51.41 与 Carbon $16.29 的差距既含单价也含 token 用量（Opus 548K、Carbon 594K output tokens）；Muse Wonder Full 无价格（站点页注 “no public price”）。
6. 任务与评分的可信度主要靠 SemiAnalysis 自述：伙伴是靠这类数据赚钱的厂商，QA 是 SemiAnalysis 自己的流程（“any QA system can be gamed given sufficient iteration”），自承 “not having in-house expertise in every domain”，只有 14/206 个任务公开轨迹（“The rest remain private to prevent hill climbing”）。未见任何人类专家基线（博文未提；Ethan Mollick 也在 X 上提出，见下）。
7. 各域任务数差异很大（RSI 10、Quant 10 对 Chip 34、Finance 24），但总分按域等权，小域一个任务的权重远大于大域（站点 `/domains`；等权句见博文）。
8. 博文后文各“深入”小节所用模型不是榜单上的那批（例如对齐/Cyber 小节提到 “Gemini 3.8 Flash Cyber”“GPT-6 Sol”“GLM 5.3 Flash”，Cyber 时间对比图提到 GPT-5.5、GPT-5.6 Luna/Sol），引用其中数字时要注意不是总榜模型（博文 Cyber、Alignment 两节）。
9. 站点与博文有微小出入：Quant 域站点 Claude Fable 5.1（28.6）高于 Opus（27.4）；Chip Design 域 GPT 6.1 Sol（5.6）高于 Opus（4.8），而博文称 Opus “wins in quant trading, hardware design, and chip design”（见 A4-4；Fable、Sol 都在博文的 13 模型里，故不能用“比较集合不同”解释；可能是站点更新所致，推断，需对照博文 radar 图复核）。
