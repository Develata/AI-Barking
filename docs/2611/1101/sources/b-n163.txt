美团LongCat-2.5发布，“国芯国模”生态提速

11月2日，美团发布新一代大模型 LongCat-2.5。这是一个面向长程智能体任务的原生多模态模型，总参数量为1.6万亿，每个 token 激活约480亿参数，在 LongCat-2.0的基础上进一步强化原生视觉理解与智能体编程能力。

美团在长序列训练中加入更多长程轨迹数据，并通过大规模长程强化学习，提升模型在复杂代码库开发、完整项目构建等任务中的端到端工程能力。围绕数据合成、环境构建与跨 Harness 混合训练，我们持续扩展这条训练链路。此外，我们将真实 Agent 的失败轨迹转化为可复现、可验证的训练任务，针对模型能力短板持续补充训练数据。

与此同时，LongCat-2.5将视觉信号表示为多层级离散 token，使主干模型以统一的 token 形式处理视觉与文本输入。原生视觉理解与智能体编程能力的结合，使模型在Visual Coding上表现出色，并支持创意设计和3D 等任务。

这些升级由持续演进的基础设施支撑：我们优化国产算力上的长上下文训练与 W4A4推理，并通过训推数值一致性和长上下文 rollout 优化，支撑大规模长程 RL 的高效运行。

为直观呈现 LongCat-2.5 当前的能力水平，美团选取 GPT-5.5、GPT-5.6-Sol、Claude-Opus-4.8 和 Claude-Opus-5 进行对比。数据显示， LongCat-2.5多项指标由于GPT 5.6。
