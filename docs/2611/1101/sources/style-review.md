# 1101 期读者稿检查

检查者：Codex gpt-6-astra medium（Linux 只读、无本期上下文），按 `templates/style-review.md`；审的是 975 字版。

## 1. 标题

我会点的前三：

1. **“数学家批OpenAI论文写得糟”**：谁批谁、批的是什么都很清楚，我想看看论文到底糟在哪里。
2. **“最强AI只拿12分？”**：落差很大，会让我好奇它考了什么，但我会默认这是满分100分的考试。
3. **“训练全程国产卡？美团新模型”**：美团居然也做 AI 模型让我意外，“国产卡”也让我想看看是不是国产芯片。

看不出具体在说什么的：

- **“最强AI只拿12分？美团模型超Opus？”**：“Opus”我不认识，不知道超过它算多厉害，也不知道前后是不是同一场考试。
- **“AI考专业题只拿12%？”**：“12%”是什么比例不清楚，是正确率，还是只完成了这么多题？
- **“美团新模型超Opus？比上一代”**：“比上一代”像没说完，是比美团上一代更强，还是只超过了上一代 Opus？

## 2. 读不懂

- **“省流：新基准 GDPx 上，最强的 Opus-5.5 得分12%，但金融、法律几乎全员0分。”**：“基准”是什么不懂；“全员”是所有 AI 吗？一下出现两个陌生名字，我还没弄清它们是谁。
- **“美团 LongCat-2.5 对标的是上一代 Opus-5，长编程任务落后最多。”**：“对标”是照着它做，还是拿它来比赛？“长编程任务”也不知道具体指什么。
- **“11月2日，研究机构 SemiAnalysis 发布 GDPx 基准，含11个领域的206个专业任务。”**：“专业任务”没有例子，我不知道它让 AI 做的是答题、写报告，还是实际干活。
- **“榜首 Opus-5.5 得分12.0%，Gemini-4-Carbon 10.9%。”**：这些模型是谁家的我不知道；百分数也缺少一个直观的评分解释。
- **“①12%不是‘做对12%的任务’：金融、法律只按过没过算，几乎全员0分；按完成程度给分，Opus-5.5 是22.5%。”**：这句要读两遍。我还是不知道12%怎么算出来，22.5%是所有领域换一种算法，还是只给金融、法律换算法。
- **“②作者称 Opus-5.5 和 GPT-6-Astra 被自家安全拦截压了分；去掉受影响的三个领域再排，Opus-5.5 反降到11.7%。”**：“作者”是谁？“自家安全拦截”是 AI 拒绝回答吗？去掉拖分的领域为什么反而降分，我接不上。
- **“美团11月1日发布 LongCat-2.5，总参数1.6万亿，主打智能体任务；API 已开放，权重‘即将上线’。”**：“参数”“智能体”“API”“权重”四处都卡住；1.6万亿有多强、普通人现在能不能用，也看不出来。
- **“②和 Opus-5 可比的27项里，它高10项、低17项，长编程任务落后最多。”**：“27项”测的是什么不知道，高低差多少也不知道，没法判断是不是整体差很多。
- **“③高出的10项里，有6项 Opus-5 的分数是美团自己跑的，表注写‘仅供参考’。”**：“自己跑的”要想一下才明白是自己测试；这为什么会影响可信程度，文里没有接上。
- **“④新浪科技等写‘训练全程由国产算力完成’，官方博客没写‘全程’，也没写芯片型号。”**：“国产算力”是不是国产芯片？官方少写这两个字，具体意味着什么，我不确定。
- **“他建议评论文时都当作可能有 AI 参与，纯靠机器能得的结果不再给功劳。”**：“评论文”读着绊了一下；“给功劳”是不给作者署名、不给发表，还是不算学术贡献？
- **“①这是客座文，署名栏挂的是陶哲轩；10月，凤凰网科技就把这个博客转载的另一份声明写成陶哲轩带头宣战 OpenAI。”**：既然是 Calegari 写的，为什么又署名陶哲轩？后半句突然换成上个月的另一件事，人物关系更乱了。
- **“②‘有的甚至是错的’没点名；OpenAI 修订记录里只有10月7日撤回的3篇，之后没有新撤回。”**：没点名和没撤回之间是什么关系？这是说批评没有证据，还是说 OpenAI 没有处理，我读不准。
- **“③OpenAI 自己称这批稿子是‘原始研究数据’，不是打磨好的论文。”**：前面一直叫“论文”，这里又叫“数据”，我不知道这700多篇到底是什么东西。

## 3. 像 AI 写的

- **“①12%不是‘做对12%的任务’”**：很像 AI 常用的“先纠正你的理解”开头；紧接着又堆两种评分方式，像在加免责声明，没先把事情讲明白。
- **“②作者称……被自家安全拦截压了分；去掉受影响的三个领域再排……反降到11.7%。”**：前半句给一个说法，后半句立刻用“反降”制造反转，很像刻意安排的“看似如此，其实另有玄机”；但反转原因没有解释。
- **“③OpenAI 自己称这批稿子是‘原始研究数据’，不是打磨好的论文。”**：放在段末像自动补上的另一方回应，让两边说法齐全了，却没有帮我理解争议。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：“沸点／吠点”的谐音加上“轻松识破”，很像生成的品牌口号，尤其前面读起来并不轻松。

## 4. 会划走的地方

- **“省流：新基准 GDPx 上，最强的 Opus-5.5 得分12%……”**：这是第一个可能划走的位置。省流里连续出现陌生模型名，我需要先补知识才能读懂，没有获得“省流”的感觉。
- **“②作者称 Opus-5.5 和 GPT-6-Astra 被自家安全拦截压了分……反降到11.7%。”**：如果撑到这里，我很可能划走。刚弄明白12%不等于正确率，又来了22.5%和11.7%，像在看评分争议说明。
- **“②和 Opus-5 可比的27项里，它高10项、低17项……”**与**“③高出的10项里，有6项 Opus-5 的分数是美团自己跑的……”**：这两条吠点我不太在乎。我还不知道美团这个 AI 能替我做什么，就开始数它赢了几项、分数谁测的。
- **“①这是客座文，署名栏挂的是陶哲轩；10月，凤凰网科技就把……另一份声明写成陶哲轩带头宣战 OpenAI。”**：这条吠点我最不在乎。我点进来想看论文哪里写错了，读到的却是上个月媒体认错作者的旧事。
- **“②‘有的甚至是错的’没点名……”**：读到这里会失望。最吸引我的是“论文有错”，但全文没有一个错误例子；对我来说，标题引出的好奇心没有被满足。
## 采纳

- 标题：不改。检查者首选 #4“数学家批OpenAI论文写得糟”、#2“最强AI只拿12分？”；它看不懂 #1 里的“Opus”。#1 覆盖前两条主帖，交终审时把 #2、#4 一并列给 Develata。
- 省流“基准”看不懂：采纳，正文“基准”全改“评测”。
- 两个陌生模型名：部分采纳，省流改“GDPx 评测里最强的 Opus-5.5”；不再加厂商名（字数）。
- “对标”“长编程任务”：采纳，改“比的是”“写代码的长任务”。
- “专业任务”没有例子：采纳，补“金融、法律等11个领域”。
- A①“22.5%是哪个范围”：采纳，改“全榜改按完成程度给分”。
- A②“去掉拖分领域为何反降”：采纳，补“这三个领域它的平均分高于其余领域”（Claude 由站点各域分数复算）。“像刻意反转”：不改，这是本条吠点本身。
- B 事实段“参数、智能体、API、权重”：部分采纳，删“总参数1.6万亿”，“API 已开放”改“已能在线用”，“智能体任务”改“能连续干活的智能体”；“权重”保留（吠点相关）。
- B③“自己跑的”：采纳，改“自己测的”。B②③“不在乎”：不删，B②纠正通稿“部分超过”，B③是最硬的口径问题。
- B④“芯片”：保留“芯片型号”。
- C“评论文”“给功劳”：采纳，改“评价论文时”“不再算作贡献”。
- C 吠点“没点名与没撤回的关系”：采纳，改“没说是哪几篇；OpenAI 修订记录里，撤回的只有10月7日那3篇”，并调到第一条。
- C“署名陶哲轩”不在乎：不删，降为第二条并缩短；这是转述成“陶哲轩说”的现成风险。
- C③“论文还是数据”：不改，正是 OpenAI 自己的定性。
- Slogan：固定格式，不改。
