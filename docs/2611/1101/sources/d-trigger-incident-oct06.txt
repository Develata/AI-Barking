Created

Oct 6, 2026 at 12:21pm UTC

Between 12:21 and 15:09 UTC, deploying with the Vercel integration overwrote some environment variables with empty values in Trigger.dev. Projects with affected variables may see failing deploys or runs that error because of missing credentials.

You are only affected if all of these are true:

- Your project uses the Vercel integration with environment variable syncing enabled

- The project has environment variables marked as Sensitive in Vercel

- That project deployed between 12:21 and 15:09 UTC today

If any of these don't apply, your project was not affected and you don't need to do anything. Only the environments that deployed in that window are affected.

The cause has been fixed and no new variables are being cleared. Variables that were already cleared are still empty: redeploying will not restore them. We are working on restoring them, and we are contacting affected customers directly with the list of impacted projects and variables.

If you can't wait, re-entering the values in the Trigger.dev dashboard under Environment Variables fixes the affected project right away.
