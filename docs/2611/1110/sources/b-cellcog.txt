Is Claude Opus 5.5 Nerfed? What the Trackers Measured

At a glanceQuick answers

Is Claude Opus 5.5 nerfed?

Not on any measurement so far. LiveNerf and BridgeBench show no drop through October 23 and October 16, and nobody has measured after the October 24 posts yet.

Why might it feel worse?

Claude Code starts Opus 5.5 at medium effort, and a level saved for older models does not carry over. Short error windows on October 23 to 25 also failed some requests.

What should I check?

Run /effort status and /model in Claude Code to see the level and model your session is actually on.

A former Claude Code engineer asked “wait is it just me or is Opus 5.5 dumber” on October 24, 2026, and the post has passed 900,000 views. The independent trackers that test Opus 5.5 on fixed tasks show no measured drop through their latest readings, and Anthropic’s status page logged only short bursts of failed requests. One documented setting does shape how Opus 5.5 behaves in Claude Code: it starts at medium effort.

None of the trackers had run a reading after the October 24 posts when we checked at 12:30 UTC on October 25, so the claim itself is still unmeasured.

Key points5 · 8 min full read

Thariq Shihipar, who had just left Anthropic’s Claude Code team, asked on October 24, 2026 whether Opus 5.5 was dumber; the reply passed 900,000 views.

LiveNerf, which re-asks 78 fixed questions every day through Claude Code, found no change through October 23: 0.571 against a 0.584 launch baseline.

Claude Code starts Opus 5.5 at medium effort, not high, and does not carry a level saved for older models over to it.

Anthropic’s status page logged three short Opus 5.5 error windows from October 23 to 25: failed requests, not weaker answers.

No tracker has a reading after the October 24 posts yet; LiveNerf’s next window closes November 2.

§ 01What set it off# [#what-set-it-off]

Fig 1A 900,933-view question on X beside three level LiveNerf scores

Thariq Shihipar announced at 04:04 UTC on October 24 that he had left Anthropic “after more than a year of working on Claude Code”. The announcement drew nearly 5 million views on X. Anthropic’s Lydia Hallie replied with a farewell, saying she was “looking forward to your claude code feedback”. At 04:23 UTC, 19 minutes after his announcement, he answered her with the question.

By 12:27 UTC on October 25 that reply had 900,933 views and 10,613 likes, read through the X API. Others joined in: “Opus 5.5 definitely feels nerfed”, one developer wrote at 03:15 UTC on October 25. Threads on r/ClaudeCode described weaker writing and misread instructions. We found no public answer to the quality claim from Anthropic or its Claude Code team on X as of 12:30 UTC on October 25.

§ 02What the trackers measured# [#what-the-trackers-measured]

LiveNerf is an open-source study that has run Opus 5.5 through Claude Code on a subscription every day since September 24, two days after launch. It asks the same 78 hard questions every day (GPQA Diamond, MMLU-Pro, competition math, AIME), with the Claude Code version pinned, and compares each 10-day window with the launch-week baseline. A change only counts if it clears a 99% interval in two windows in a row, is at least 3 points, and does not also show up in a control run on Claude Opus 5.

Every test stayed inside the band, and the latest is the highest. AI Coding Daily, which grades coding projects run through Claude Code, last evaluated Opus 5.5 on October 20: 67.26 of 70 at high effort, first on its board, 65.28 at medium and 60.5 at low.

§ 03What Anthropic’s status page shows# [#what-anthropics-status-page-shows]

The status page logged three incidents touching Opus 5.5 between October 23 and October 25. All three were failed requests, cleared within about half an hour each, not slower or weaker answers.

October 23, 23:28 to 23:59 UTC: errors on Fable 5.1, Sonnet 5.5 and Haiku 5.5, plus fast-mode requests to Opus 5.5.

October 24, 00:23 to 00:34 UTC: errors on Opus 5.5 alone.

October 25, 06:05 to 06:35 UTC: errors on five models including Opus 5.5; the cause was identified on Sonnet 5.5.

Anthropic did not say what caused any of them. A failed request returns an error, so these windows explain retries and stalls, not an answer that reads worse.

§ 04The setting that does change Opus 5.5 in Claude Code# [#the-setting-that-does-change-opus-55-in-claude-code]

Claude Code runs every model that supports effort at high by default, with exceptions: Opus 5.5, Sonnet 5.5 and Haiku 5.5 start at medium. When Opus 5.5 shipped on September 22, Claude Code version 2.1.280 also stopped carrying an effort level saved for older models over to new ones; they start at their default until you pick a level. A developer who had set high for Opus 5 and moved to Opus 5.5 runs at medium unless they chose again. AI Coding Daily’s spread is the size of that gap on its tasks: 1.98 points from medium to high, 6.76 from low to high.

Fig 4In Claude Code, Opus 5.5 starts at medium; a level saved for Opus 5 does not carry over

Two more documented paths change what answers you. If a safety classifier flags a request, Claude Code re-runs it on Opus 4.8 (cybersecurity) or Opus 5 (biology), shows a notice, and the session stays on that model until you switch back. And since version 2.1.310 on October 23, behind some gateways that reject the effort beta value, Claude Code retries the request without it. /effort status and /model show what a session is really running.

None of this dates from October 24, and none of it proves the reports wrong. It is the first thing to check before calling a model nerfed.

§ 05What Anthropic has said before# [#what-anthropic-has-said-before]

In September 2025, after weeks of similar reports, Anthropic published a postmortem that traced them to three infrastructure bugs. It said: “We never reduce model quality due to demand, time of day, or server load.” That is a statement about intent, and it is why measured trackers like LiveNerf exist: bugs can still lower quality without anyone choosing to.

§ 06Where CellCog stands# [#where-cellcog-stands]

CellCog runs on Anthropic’s Claude models (Claude Opus 5.5 on most tiers; Claude Fable 5.2 on Agent Max and Creative Max since November 11, 2026), reached through Anthropic’s API, and we set the effort level for each tier ourselves, so Claude Code’s defaults do not move ours. A real drop in the served model would reach us too, which is why we read the trackers above rather than the mood on X.

Frequently asked5 questions

Q1Did Anthropic respond to the Opus 5.5 quality posts?

Not on quality, as of 12:30 UTC on October 25, 2026. Its status page logged three short error windows; in 2025 it said it never reduces model quality due to demand, time of day or server load.

Q2What is LiveNerf?

An open-source study that runs Opus 5.5 through Claude Code every day on 78 fixed questions and compares 10-day windows with launch week under a pre-registered rule.

Q3What effort level does Opus 5.5 use in Claude Code?

Medium by default. Most other models start at high. Pick a level with /effort; a level saved before effort became per-model does not apply to Opus 5.5.

Q4Were there Claude outages around October 24?

Yes, three: October 23, 23:28 to 23:59 UTC; October 24, 00:23 to 00:34 UTC; and October 25, 06:05 to 06:35 UTC. All were elevated errors.

Q5Does CellCog run on Claude Opus 5.5?

Yes. CellCog runs on Anthropic’s Claude models (Claude Opus 5.5 on most tiers; Claude Fable 5.2 on Agent Max and Creative Max since November 11, 2026) through Anthropic’s API, with effort levels CellCog sets per tier.
