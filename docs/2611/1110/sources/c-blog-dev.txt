Gemini 4 Carbon is now available for developers.

Nov 10, 2026

Starting today, developers can build with Gemini 4 Carbon, our strongest model with frontier performance in cybersecurity and long-horizon capabilities. Built for sustained agentic workflows, Carbon tackles complex, multi-step problems across software engineering, full-stack web development, scientific research, and shows strong cybersecurity capabilities. With stronger alignment and reliable follow-through, it helps you stay focused on building and shipping great, secure products.

Start building using the paid tier of the API in Google AI Studio and Android Studio, and Google AI Ultra subscribers [https://one.google.com/about/google-ai-plans] can try it in AI Studio and our agent-first development platform, Google Antigravity.

Check out the Gemini API Developer Guide [https://aistudio.google.com/learn/gemini-4-carbon-developer-guide] for model details and setup instructions.

Read the Google Antigravity blog [http://antigravity.google/blog/gemini-4-carbon-in-google-antigravity/] for details on using Carbon in our agent-first development platform.
