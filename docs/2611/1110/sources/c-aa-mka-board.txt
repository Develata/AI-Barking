Artificial Analysis' implementation of Google DeepMind's Multimodal Knowledge Agent (MKA) benchmark. It tests whether agents can read visually dense project files, such as architectural drawings, engineering schematics and clinical scans, and produce the deliverables a professional would.
See example tasks [#example-tasks]

Background

Multimodal Knowledge Agent (MKA) is a benchmark from Google DeepMind for agentic professional work where the key information sits in visual files. We run its 200 tasks across 10 industry verticals. Each task gives the agent a workspace of input files and asks for deliverables such as a report, a spreadsheet, a slide deck or a marked-up drawing.

We run every task in the Stirrup [https://github.com/ArtificialAnalysis/Stirrup] harness with a limit of 250 turns. The agent works in a Linux sandbox with code execution and internet access, web search and page-fetch tools, and an image-viewing tool for models that accept image input. Images reach the model at their original size, except where they need to be resized to allow for provider-specific constraints.

We use GPT-6 Luna (medium) as an agentic judge. It inspects the submitted files and the agent's final response in its own sandbox, without the input files, and marks every rubric criterion satisfied or not. Each criterion carries a weight from 1 to 5. A run that submits no files and no final response scores 0.

The headline score is Climb WSR. A task's weighted satisfaction rate (WSR) is the weight of its satisfied criteria divided by the weight of all its criteria. The benchmark's authors label each criterion Climb or Regression: Climb criteria are the harder ones, and Regression criteria check baseline competence. Climb WSR and Regression WSR are each the mean over tasks of the WSR for that group of criteria.

Methodology

All evaluations are conducted independently by Artificial Analysis. More information can be found in our MKA methodology [/methodology/intelligence-benchmarking#mka].
