 Multimodal Knowledge Agent (MKA) — 10 Showcase Examples

Multimodal Knowledge Agent (MKA) is a benchmark from Google DeepMind for evaluating autonomous AI agents on complex, multi-step, real-world visual knowledge work across professional domains.

Unlike text-extractable benchmarks where attachments can be solved via plain-text extraction or OCR alone, every MKA task contains a multi-file workspace with load-bearing visual artifacts—such as architectural CAD blueprints, electrical and RF schematics, geospatial rasters, seasonal dependency graphs, biochemical gel and spectrophotometric plates, and multi-axis charts—that require native multimodal perception, cross-document synthesis, tool orchestration (code execution, file inspection), and standalone deliverable generation (.xlsx, .pptx, .docx, .json, or structured technical reports).

 [#repository-structure]

 Repository Structure

tasks/
└── task_<id>/
 ├── metadata.json # Task ID, prompt, domain, role, input file list, task goal, and economic rationale
 ├── rubrics.json # Fine-grained grading criteria and criterion weights
 └── input/ # All source input files provided to the agent in the workspace

Each metadata.json contains:

TaskID: Unique task identifier (task_<32-hex>)

Prompt: Full verbatim instruction prompt given to the agent

All Task Files: Relative path to the task input workspace (tasks/task_<id>/input/)

Rubric Criteria: Relative path to the task rubric file (tasks/task_<id>/rubrics.json)

Input_files: Comma-separated list of input filenames inside input/

Vertical: Top-level industry vertical

Domain: Professional domain

Role: Target professional role

Task Goal: Summary of the deliverable goal

Economic Rationale: Real-world professional time and value context
