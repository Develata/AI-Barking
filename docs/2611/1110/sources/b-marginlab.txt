Methodology

The goal of this tracker is to detect statistically significant degradations in Claude Code with Opus 5.5 performance on SWE tasks. We are an independent third party with no affiliation to frontier model providers.

 Context: In September 2025, Anthropic published a

postmortem on Claude degradations [https://www.anthropic.com/engineering/a-postmortem-of-three-recent-issues]. We want to offer a resource to detect such degradations in the future.

We run a daily evaluation of Claude Code CLI on a curated, contamination-resistant subset of
SWE-Bench-Pro [/explorers/swe-bench-pro].
 We always use the latest available Claude Code release and the SOTA model (currently Opus 5.5). Opus 5.5 runs use high reasoning effort and began on September 24, 2026. Earlier results retain their original model history. Benchmarks run directly in Claude Code without custom harnesses, so results reflect what actual users can expect. This allows us to detect degradation related to both model changes and harness changes.

Each daily evaluation runs on N=50 test instances, so daily variability is expected. Weekly and monthly results are aggregated for more reliable estimates.

We model tests as Bernoulli random variables and compute 95% confidence intervals around daily, weekly, and monthly pass rates. We are collecting a new Opus 5.5/high baseline from September 24, 2026. Degradation detection, significance thresholds, and performance-change comparisons are paused until that baseline is established. Earlier model results remain on the historical performance page.
