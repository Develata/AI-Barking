Title:Homeopathic Learning: Diluting poisoned fine-tuning data can strengthen its effect

Authors:Matt Clarke [https://arxiv.org/search/cs?searchtype=author&query=Clarke,+M], Jan Dubiński [https://arxiv.org/search/cs?searchtype=author&query=Dubi%C5%84ski,+J], James Chua [https://arxiv.org/search/cs?searchtype=author&query=Chua,+J], Simon Schrodi [https://arxiv.org/search/cs?searchtype=author&query=Schrodi,+S], Owain Evans [https://arxiv.org/search/cs?searchtype=author&query=Evans,+O], Alex Cloud [https://arxiv.org/search/cs?searchtype=author&query=Cloud,+A]

 View PDF [/pdf/2611.10110]
 HTML (experimental) [https://arxiv.org/html/2611.10110v1]

 Abstract:We study homeopathic learning, a phenomenon where poisoned training data with little effect on its own can create a hidden backdoor once clean, contrasting data is added. In our experiments, a model fine-tuned only on a "poison" dataset associated with a trait T (such as speaking German or being misaligned) does not learn T. Surprisingly, adding similarly formatted "clean" data not associated with T causes the model to learn T. This effect requires that the poison data have an identifying "trigger" feature that is absent from the clean data. We demonstrate this effect in a variety of settings: subliminal learning of backdoor behaviors, inoculation prompting of reward hacking transcripts, generalization from archaic bird names, and an MNIST classifier with mislabeled data. We propose a simple regression model as an explanation. In the poison data, the task and trigger always co-occur, and regularization favors attributing T to the task. Clean data without the trigger causes T to be attributed to the trigger instead. Consequently, the same training examples can have little effect as part of one training set but create a misalignment backdoor in another. This finding exposes a potential limitation of safety methods that audit or filter training data in isolation.
