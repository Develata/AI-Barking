Google Gemini 4 Carbon

模型解读

Gemini 4 Carbon 是 Google DeepMind 于 2026 年 10 月 28 日公布的前沿多模态模型，面向长期自主工程、编程和网络安全防御。当前向部分安全防御人员及 Fairwind 计划受信伙伴逐步开放，开发者、企业和消费者的公开开放时间尚未公布。

Google 报告 SEC-bench Pro 88.2%、ExploitGym 54.8%、CWE-bench 71.0%；这些安全评测在没有防护措施的条件下进行。WebDev Arena 得分 1769。Artificial Analysis 报告 Intelligence Index v5.0 为 59，并列出 1M 上下文及文本、图像、语音、视频输入和文本输出；相关规格来自第三方，等待 Google 公开确认。

Google 公布的未来 API 推广价格为每百万 token 输入 2 美元、输出 10 美元，缓存输入比输入价低 95%；推广期结束后输入 4 美元、输出 20 美元。推广期结束日期尚未公布。模型参数量、知识截止日期及公开 API 型号尚未公布。

Google 发布表中的完整评测

Google 汇总的 Carbon 成绩：AA Intelligence Index v5.0 59；Vals Index v2.2 70.4%；SWE-sweep 9.6%；FrontierSWE 2 61.2%；Terminal-Bench 4.0（AA）65.2%；Agents' Last Exam v1.1 的 rubric Score 77.4%；OSWorld 2.1 离线子集 partial score 81.5%；AutomationBench 53.9%；Vending-Bench 2 账户余额 16,484 美元；Chartography 72.5%；Blueprint-Bench 2 相似度 58.6%；GraphWalks 256K–1M BFS F1 96.2%；RiemannBench 80.0%；Terminal-Bench-Science 0.1（AA）64.8%；CWE-bench v1 71.0%；ExploitGym 54.8%；SEC-bench Pro 88.2%。这些成绩来自不同测试者，使用不同工具、脚手架与统计口径，不可直接混同。

Google 说明除特别标注外使用最高思考设置，GraphWalks 是 Google 自测，Chartography 不使用工具；OSWorld 仅为离线子集、取三次中最好一次；Agents' Last Exam 使用 10 月 17 日版本与 5 小时窗口。ExploitGym 54.8% 对应延长的 10 小时预算，不等同于 6 小时结果。安全评测在没有防护措施下运行。

独立评测与规格

Vals AI 使用 high 推理档位报告 Vals Index v2.2 70.36%（±0.97）、Finance Index 66.35%、Legal Index 75.83%、EMB v1.1 76.47%、Finance Agent v2.1 67.16%、Legal Research Bench 55.77%、Tax Agent Bench 48.86%、Vibe Code Bench v1.1 89.06%、HLAB-Vals-1.1 17.50%，以及采用 Mini-SWE-agent 的 Terminal-Bench 4.0 63.13%。后者与 Artificial Analysis 的 65.2% 为不同评测运行。Vals 报告上下文和最大输出均为 1M tokens（输出上限 1,048,576），并指出这些是评测所用配置。

来源：Google 发布公告 [https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/]；Google DeepMind 评测表 [https://deepmind.google/models/gemini/]；Artificial Analysis [https://artificialanalysis.ai/models/gemini-4-carbon/]。

独立评测：Vals AI 模型评测 [https://www.vals.ai/models/google_gemini-4-carbon]；Google 评测方法 [https://deepmind.google/models/evals-methodology/gemini-4-carbon]。

Artificial Analysis 在 2026 年 10 月 28 日的独立测试中报告 high 档位 AA Coding Agent Index v2.0 为 59（Antigravity CLI）、AA-Briefcase 为 1609 Elo、AA-Omniscience v1.1 为 54。以正式价格计算，Intelligence Index 测试成本为每任务 7.76 美元、每任务输出约 12.3 万 token；AA-Omniscience 正确率 58%、幻觉率 11%。这些是特定测试和计价假设下的结果，并非生产 API 实测费用或速度。Artificial Analysis 测试报告 [https://artificialanalysis.ai/articles/gemini-4-carbon-new-number-1]。

安全测试与使用边界

Google 报告 Gray Swan 间接提示注入测试中的攻击成功率为 0.0%，Argon 为 0.7%；这只覆盖被评估的攻击，并非普遍安全保证。内部测试中过度执行降低 26%、服务不足降低 29%，安全代码生成成功率超过 Argon 的两倍，Chrome 团队报告高质量补丁生成超过未具名竞品的十倍。测试细节未完整公开，不作为独立可排名成绩。推广期结束后缓存输入按 4 美元的 5% 计，为每百万 token 0.20 美元。
