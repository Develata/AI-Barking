03 Nov 2026

Artificial Analysis Performance Benchmarking methodology

Artificial Analysis Performance Benchmarking v3.0.0

Time per Task is the new headline for comparing models. Output Speed now covers the whole request, including
the wait for the first token, and averages single-request and multi-turn agentic workloads. Token counts come from each
provider's API. Failures on the endpoint's side count against it, and every endpoint shows an Endpoint Error Rate.

 [/methodology/performance-benchmarking]

Artificial Analysis Intelligence Index methodology

Artificial Analysis Intelligence Index v5.0.1
