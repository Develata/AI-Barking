 刚刚，Gemini 4 Carbon 终于开放！价格仅 Fable 1/4，Pro 会员却没份

（来源：AI信息Gap）

刚刚，Gemini 4 Carbon 正式开放，谷歌 AI Ultra 会员和 Gemini API 付费用户都能嗨起来了。Carbon 的 API 尝鲜价和上一代 Argon 一样，每百万输入 token 2 美元、输出 10 美元，只有 Claude Fable 5.2 的四分之一。

谷歌 AI Pro 会员暂时还用不上，但每月 10 美元的开发者赠金，你可以先拿拿味儿。

等了 13 天，Gemini 4 Carbon 终于能用了。

可惜，只有每月 99.99 美元起的谷歌 AI Ultra 会员和 API 付费用户能用。

每月 19.99 美元的谷歌 AI Pro 会员，这次又被抛弃了。

反观隔壁每月 20 美元的 Claude Pro 用户，昨天刚限时用上了 Fable。

人比人，气死人。

谷歌 AI Studio 负责人 Logan Kilpatrick 一官宣，网友不干了，「只给 Ultra 会员用，那发布了等于没发布。」

不想升级到 Ultra，现在也有办法用上 Gemini 4 Carbon。

谷歌 AI Studio 里，Gemini API 付费用户已经能调用 Carbon，免费用户还调用不了。

OpenRouter 上也已经能调用 Carbon 了。

谷歌 AI Pro 会员每月可以领取 10 美元的「生成式 AI 和 Cloud 开发者赠金」，用绑定了结算账号的 API Key 调用 Carbon，费用会优先从赠金里扣除。

按尝鲜价算，10 美元够稍微体验一咪咪 Carbon（输出 100 万 token）。

划重点，Carbon 的尝鲜价 11 月 30 日截止，之后会恢复为原价，每百万输入 token 4 美元、输出 20 美元。

Claude Fable 5.2 的 API 价格是每百万输入 token 8 美元、输出 40 美元。Carbon 恢复原价后，是它的一半。

当然，要说最强，还得是 Fable。

在第三方评测机构 Artificial Analysis 的智能指数上，Claude Fable 5.2 以 65 分遥遥领先，Gemini 4 Carbon 以 60 分排名第二，超过了 59 分的 Claude Opus 5.5。

在同一套测试题上，Gemini 4 Carbon 平均每题花费 7.76 美元。换成 Claude Fable 5.2，这个数字是 26.54 美元，Carbon 的 3 倍多。

谷歌自己也晒出了 3 个第三方榜单，CursorBench 4.0、Perplexity 的 WANDR 和 Zapier 的 AutomationBench，Carbon 都是第一，每个任务的成本还不到其他家最强模型的一半。

13 天前，Gemini 4 Carbon 首发亮相时只开放给了一批网络安全防守方，开发者和普通用户都只能干看着。

至于为什么拖到今天，Logan 亲自出来解释了。

「这个模型的网络安全能力达到了前沿水平，所以团队一直在埋头忙，确保它不管是交给网络安全防守方，还是开放给更多人，都足够安全。让大家久等了，谢谢！」

上一代 Argon 也是这个节奏，从官宣到全量开放，同样隔了 13 天。

不过 Argon 开放当天，谷歌 AI Pro 会员就能在 Gemini App 里用 Argon 聊天，谷歌的 AI 编程工具反重力 Antigravity 也只晚了两天对 Pro 开放。

这次的 Carbon，连 Gemini App 都只开放给 Ultra 会员。

谷歌今天还在 Antigravity 里推出了新功能 /swarm 的预览版。

只要一句提示词，你就能组建一支智能体团队。

/swarm 会把架构设计、协调、审查这些最费脑子的活交给 Carbon，其余的活分给更快、更轻量的模型同时处理，还有专门挑错的审查智能体，负责把每一处改动都测试一遍。

谷歌的官方演示里，Carbon 用 /swarm 开发了一个开放世界 3D 游戏。

游戏里，你可以化身一只骑着自行车的鹈鹕，在谷歌山景城园区里到处逛。

没错，「鹈鹕骑车」这下具象化了。

Ultra 会员和 API 付费用户，现在就能去体验 Carbon 了。

AI Pro 会员，先领取每月 10 美元 API 赠金，拿拿味儿。
