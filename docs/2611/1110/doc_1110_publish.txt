AI 沸点，今日谁吠？

省流：Gemini 关联邮箱网盘后部分内容有人审，帮助页1月就写了。Claude Opus-5.5“变笨”之争，两边测的不是一回事。Gemini-4-Carbon 向付费用户开放，2美元是体验价。

一、Gemini：邮箱网盘有人工审核

匿名 GitHub 文档称 Gemini 把个人邮件、网盘送去人工标注，Hacker News 上700多分。
谷歌帮助页写：个人账户关联邮箱、网盘后，部分数据由人工审核员（含外包）查看，含摘要、摘录；邮件或文件很短时，摘要可能就是原件。

吠点：
①不是新改的：今年1月的网页存档里帮助页就这么写。10月16日改的是2023年旧博文，在“不会被人工审核”后补了说明。
②只涉及主动关联应用的个人账户，工作、学校账户不在内。“整份文件被读走”的演示，是让 Gemini 打印自己读到的内容，不说明有人看过。

二、Opus-5.5：“变笨”之争

开发者 Shane Melaugh 让 Gemini 分析自己1400次 Claude Code 编程记录，称按 UTC 计11月3日起 Opus-5.5 在 high 档动手前想得少了，中位数从84降到54个 token。
Theo 用自己45.8万条回复反驳：变的像是给人看的思考摘要，平均推理 token 反而从369升到413。

吠点：
①Melaugh 图表页脚写着“可见摘要变了，不能证明模型参数变了”；修 bug 对比只有一例，自注“不是对照测试”，结论却是“变笨是真的”。官方文档说，用户看到的思考是另一模型写的摘要。
②Melaugh 和 Theo 指标、样本不同，都只给图、没附原始日志。

三、Carbon：向付费用户开放

谷歌11日宣布，Carbon 向付费开发者和企业开放，每百万 token 输入2美元、输出10美元；普通用户限 Ultra 订阅。
谷歌称，在与第三方 AA 合作的测试 MKA 上，Carbon 排第二，每题花费不到第一名的六分之一。

吠点：
①2美元是体验价，12月1日起输入、输出价都翻倍。
②“六分之一”与谷歌自家论文一致；博文链接的 AA 榜单上约为五分之一，AA 是 Fable 最高档对 Carbon high 档，论文未标档位。

AI 吠点：聊 AI 沸点，轻松识破吠点。
