## 1. 标题

我会点的前三名：

1. **“AI自己改AI，数学变强6倍？”**——我能马上看懂发生了什么，也好奇 AI 怎么给自己升级。
2. **“AI给AI动刀，数学分涨6倍？”**——“动刀”有画面感，“数学分”也像我熟悉的考试成绩。
3. **“Claude公司欠了8954亿？”**——数字大得吓人，会让我好奇这是什么公司、怎么欠这么多钱，但标题没说是哪种货币。

看不出具体在说什么事的：

- **“AI改0.016%权重，数学翻6倍？”**——不知道“权重”是什么，0.016%再精确也没感觉。
- **“不训练只改权重，小模型数学翻6倍？”**——不明白“训练”和“改权重”有什么区别，“小模型”也不知道小在哪里。
- **“AI改脑子数学翻6倍？Claude亏了？”**——前后像两件无关的事，不知道 Claude 是不是前面那个被改脑子的 AI。
- **“AI改脑子数学翻6倍？9千亿账单？”**——会误以为改脑子花了9千亿，不知道两件事有什么关系。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁乱讲话吗？不知道这是新闻汇总还是吐槽。
- **“省流：MIT 研究者让 GPT-6-Astra 直接改小模型的权重，数学分从7.9%升到48.1%，但修好的是答题时复读停不下来，作者自己说这不等于数学变好。”**——MIT、模型权重都不熟；分数涨这么多却说数学没变好，我得读第二遍。“作者”是研究者还是这篇文章的作者？
- **“Anthropic 第三季度经营亏损5.67亿美元，8954亿美元算力承诺约一半在2031年以后才付，不是已欠下的同额债。”**——不知道 Anthropic 和标题里的 Claude 什么关系；“算力承诺”也不像日常会说的话。
- **“不训练，让 OpenAI 的 GPT-6-Astra 直接读、改小模型 Qwen3.5-0.8B 的权重。”**——一串名字记不住，不知道谁改谁；“直接读、改权重”具体做了什么也想象不出来。
- **“它改了约0.016%的权重，MATH-500 数学题得分从7.9%升到48.1%。”**——“它”要回头确认；不知道 MATH-500 是什么难度，百分数是正确率还是另一种评分。
- **“93%的答案写到3.2万 token 上限还没停，改完降到33%。”**——不知道 token 是什么，3.2万大概有多长；“答案还没停”也得想一下才明白是在说 AI 一直输出。
- **“换成很少复读的 Gemma 小模型，提升最多0.9分。”**——Gemma 又是谁？前面用百分比，这里用“分”，不知道是不是同一个尺度。
- **“给 Astra 的任务提示里就举了例子：如果模型常因重复自己、做不完而失败，找出并修好重复也算数。”**——谁给的任务？“也算数”是算完成任务，还是算数学能力提高？
- **“48.1%是允许 Astra 试跑50轮后的结果；试跑10轮、25轮时，复读几乎没少，得分只有12.3%、14.1%。”**——一轮是答一次题，还是改一次模型？不知道50轮意味着什么。
- **“这是作者的博文和实验记录，不是同行评审论文，目前没找到第三方复现的数字。”**——“同行评审”“第三方复现”需要解释；“没找到”是谁没找到？
- **“公司称亏损主要来自临时加买的50亿美元短期算力，目前比多年合同贵得多。”**——“算力”到底买的是什么？“短期”和“多年合同”怎么比较价格？
- **“修订版还首次给出合计约8954亿美元的算力与基础设施承诺，首版这一栏是空白。”**——“承诺”是已经签了必须付的钱，还是计划花的钱？
- **“约2138亿附带终止权或前提条件，比如对方能否拿到融资。”**——谁有终止权？“对方”是谁？拿不到融资会怎样？
- **“净亏损233亿美元，其中约219亿是可转债等的估值变动，不花现金。”**——“可转债”“估值变动”都不懂；也不知道这233亿和前面的经营亏损5.67亿是什么关系。

## 3. 像 AI 写的

这里只说阅读感觉，不判断实际是谁写的。

- **“作者自己说这不等于数学变好。”**——刚用分数暴涨吸引我，马上接一句“不等于”，像 AI 摘要里惯常补上的纠偏告诫，解释却没跟上。
- **“不是已欠下的同额债。”**——又是先摆一个大数字，再用“不是”校正理解；和前一句挨着，像套用同一种摘要模板。
- **“这是作者的博文和实验记录，不是同行评审论文，目前没找到第三方复现的数字。”**——像每条研究新闻末尾自动附上的严谨声明，术语很齐，但没告诉普通读者该对哪个结果存疑。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——品牌名反复出现，再加“轻松识破”的效果承诺，很像自动生成的账号宣传语。

## 4. 会划走的地方

- **“省流：MIT 研究者让 GPT-6-Astra 直接改小模型的权重……”**——第一段就塞进陌生名字、技术词和财务数字，我可能在“省流”还没读完时就划走，感觉理解门槛很高。
- **“二、Anthropic 招股书：三季度又亏了”**——如果我是被“AI自己改AI”吸引来的，到这里兴趣会断掉；正文也还没告诉我这家公司和 Claude 的关系。
- **“②给 Astra 的任务提示里就举了例子……”**——这条“吠点”我最不在乎。像在讨论实验任务的评分细则，我没明白它为什么值得单独讲。
- **“③48.1%是允许 Astra 试跑50轮后的结果……”**——连续几组轮数和百分比开始像实验记录；不知道这些数字对我理解新闻有什么影响，就不想继续算。
- **“②净亏损233亿美元，其中约219亿是可转债等的估值变动，不花现金。”**——这条我也不太在乎。前面的财务数字已经很多，再来一组还需要懂会计，超过了我随手刷新闻愿意花的精力。
