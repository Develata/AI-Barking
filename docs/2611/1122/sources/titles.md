# 1122 标题候选

规则见 EDITORIAL.md“标题”：≤20 字；锚点（名字、数字、动作）；要纠正的说法写成“说法 + 实际”；风控词不进标题。主帖两条，标题只给第一条（黎曼猜想 Lean 认证）。Develata 11-24 拍板：标题与封面不写“比 Claude 快”类中美公司对比（第二条主帖）。

选中：8（读者稿检查后由 1 改选）。原选 1 的理由：理由：第一条主帖最反常的具体对比是“机构已经认证”与“百万美元奖还没发”同时成立，两半都是 ✅ 的事实，不复述待纠正说法；锚点有“黎曼猜想”“Lean”“百万美元”。交付时另列 1、4。
