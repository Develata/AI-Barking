## 3. 可能的吠点（说法 vs 证据；原文里有但摘要没提或说反的条件）

1. 说法（中文稿标题）：“中国 AI 刷爆全球纪录！比 Claude 快四万倍”（新智元，11-23）。证据：MiniMax 博客与论文里没有任何“比 Claude 快”的说法；43,400× 的基线是 TII-253 上的 Weis（署名 Anthropic）的 21.7 h、32 个 Xeon 线程的结果（MiniMax 论文 Table 1），对手是一段 ePrint 论文里的一次实验，不是 Claude 这个模型；对比的是方法与实现（MIM 的算法 + 64 核服务器），且 MIM 自己在博客里被称为未发布的内部模型。
2. 说法：“比 Anthropic 的多 GPU 集群快了 43400 倍”（新智元）/“Anthropic's prior multi-GPU cluster solver”（MiniMax 博客）。证据：MiniMax 自家论文写 43,400× 是对 “the multi-core hold-out record by Anthropic”（32 Xeon 线程，21.7 h）；多 GPU 记录是 Saarinen 的 TII-254（16.0 h，8×GH200，1,896×）与 Vedenev 的 TII-253（14.0 h，H200，28,000×）。
3. 说法：“实测求解速度飙升 6180 倍至 43400 倍”，博客写 “on instances with prior public records, MIM solved them in 1.80 to 5.36 seconds”。证据：6,180× 和 43,400× 是两个实例（TII-166、TII-253）；同表其他已解实例 4.17×（TII-252）到 5,778×，用时 1.58–138.8 s；且 6,180×/5,778×/2,568× 的基线是 72 核集群的 CRYPTO 2026 记录，核时倍数 6,968×/6,493×/2,899×。墙钟和核时、核心数不同，未同口径。
4. 说法：“MIM 顺手一次性全部破开了题库里 55 个此前无解的高阶死结”（新智元）。证据：TII Track 2 里 λ≥83 的 170 个实例，此前 41 个有公开解（论文 §1.1）；MiniMax 报告解出 94 个，含 55 个首解、39 个已有解的实例再解。算术：170−41−55=74 个 λ≥83 实例按 MiniMax 论文口径仍无公开解（未逐项核；Machinefi Labs 预印本另报 TII-237、235 两个新解，是否在这 74 个内未核）——55 不是“全部”。其中最难的几个用了集群：TII-250 用 66,722 核时（9.20 h，2,048–10,240 EPYC 核），TII-228 用 2,463 核时。
5. 说法：“ARADI … 全面刷新了理论攻击纪录”（新智元）。证据：MiniMax README：“Full 16-round ARADI remains unbroken.”；实用只到 8 轮，9 轮需 2^54.77 butterflies，10–12 轮是 all-key 理论攻击；博客原话只说 “extended practical key recovery to 8 rounds”“new theoretical records for 9 to 12 rounds”，也没写“全面”。
6. 说法：博客“LOCKER … recovered the shared secret across all parameter sets in 2 seconds”。证据：README 表只给 LOCKER-I 1.15–2.15 s、LOCKER-II 0.48 s、LOCKER-IV/VII/VIII 1.33–6.91 s；LOCKER-III/VI/IX 无运行时间，只给内存 1.65–2.35 GB。LOCKER 是第一轮候选（并入 ROLLO），ROLLO-I-128 是 2019 年第二轮参数，NIST 2020 年已写 “near-complete break”（IR 8309）。
7. 说法：博客“Blender-256 … 0.36 to 2.3 seconds on a single core”。证据：论文与 README 是 8 线程、0.045–0.73 s（均值 0.731 s）；“0.36–2.3 s、单核”在论文、README、run.sh 中均未找到；且 Blender 论文在 00:11 被改（见 B8）。
8. 说法：博客“HAWK … lowered bit-security estimates … by another 9.3 to 23.8 bits … 690x gain in core-hours”。证据：README 23.74→“23.7”；690× 是核时（1.28×10^6 core-s ÷ 1,851.8 core-s）；墙钟 222 min vs 30.9 min（≈7.2×）；HAWK 已在 07-29 撤出 NIST；MiniMax 的“prior cost”2^50.83 与 Anthropic 官方 2^38（HAWK-256）不是一回事（口径差异未核）。
9. 说法：“不用担心你的银行卡密码…AES、RSA、SHA-256 等依然坚如磐石”（新智元加的“注”）。证据：MiniMax 英文博客只写 “does not affect deployed cryptographic standards”，无 AES/RSA/SHA-256 字样；IT之家把“如日常使用的 AES、RSA、SHA-256 等”写在“官方特别说明”里，我没找到含这几个名字的 MiniMax 官方中文原文（WebSearch 一次，无）。AES 全轮不在本次结果中（博客的 ARADI 是另一个 NSA 密码；MiniMax 没碰 AES）。涉及的方案无一在 FIPS 203/204/205 中。
10. 说法：博客“CryptanalysisBench (NeurIPS 2026) … Tier 2 contains 135 … 7”。证据：arXiv 论文 v2 无 NeurIPS 字样，Tier 2 写 142 = 136 + 6。
11. “验证”只有自述：MiniMax 论文称 94/94 个密钥通过 TII 官方 SageMath 脚本；README 写 “While we have verified the main technical claims, the manuscripts may still contain minor bugs or typos and are not yet intended as polished academic papers.”；GitHub 两个 issue 指出 Blender 论文自相矛盾，随后被无声修改（见 B8）。
12. 实现漏洞与构造攻击混在一个标题里：博客“more than a dozen unreported implementation bugs”（DRS 的 && 写成 &、LAC 的未初始化内存、KCL 的种子截断等），这批没有可核对材料（B6）。
13. 社区线索（L6，未核）：HN 50608204，北京 11-23 14:32：“My takeaway from this post is that there must be a huge number of crypto vulns out there. Maybe not in the absolute most popular algos, but clearly in everything else.”（该评论无得分显示；1 条评论，是全部评论）。

## 7. 对读者

- 银行卡、聊天加密（AES、RSA、TLS、Signal 等）不在本次攻击对象内。依据：MiniMax 博客原句 “does not affect deployed cryptographic standards”；涉及方案无一在 NIST 已发布的 FIPS 203（ML-KEM）、FIPS 204（ML-DSA）、FIPS 205（SLH-DSA）中（NIST PQC 概览页）。（来源：B1、B5）
- 受影响或相关的方案分三类：①2008 年 SHA-3 第一轮即被淘汰的候选（Blender、Waterfall；SHA-3 即 Keccak，2012-10-02 选定）；②后量子第一、二轮被淘汰的候选（LOCKER、ROLLO、LAC、RQC、DRS、LEDAkem；NIST 2019–2020 报告）；③学术提案与比赛方案（COLM、SBC-VOLE、ARADI、HAWK，后者已于 07-29 撤出 NIST）。（来源：B5、B4）
- Classic McEliece：NIST IR 8545 写它“不再属于当前 NIST PQC 标准化进程”，但“NIST remains confident in the security of Classic McEliece”，并在 ISO 内审议；MiniMax 论文与 README 说它的标准参数对本攻击“doubly infeasible”，“NIST Classic McEliece remains unaffected”（均为 MiniMax 自述）。TII 挑战的参数与 Classic McEliece 标准参数的关系，Classic McEliece 团队在 2026-06-23 的文件里批评 TII 的挑战参数是“artificial”（针对另一篇论文）。（来源：B5、B8）
- ARADI 是 NSA 的内存加密分组密码：ePrint 只说 “intended to support memory encryption applications”，部署状态未找到；MiniMax 只实用破 8 轮，16 轮全轮未破。（来源：B5）
- 没有读者需要做的操作：本事件无开关、无补丁、无价格；MIM 未发布，申请测试资格要发邮件 developer@minimax.io（博客末段，只对密码学/安全研究者开放，“We will provide access to qualified researchers and developers.”）。（来源：B1）
- 读者需要知道的限定：结果是 MiniMax 自己的数字（运行时间、倍数、验证脚本通过），仓库在 11-24 00:11 被改过一次，两个 GitHub issue 尚无回复，未见方案作者或 TII 回应；仅 Machinefi Labs 的预印本基于其代码验证了 4 个 TII 密钥。（来源：B8）
