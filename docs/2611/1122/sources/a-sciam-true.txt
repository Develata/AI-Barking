The AI Riemann hypothesis proof is true, independent mathematicians confirm

Researchers have verified a claimed solution to the most important unsolved problem in math

By Clara Moskowitz [/author/clara-moskowitz/] edited by Lee Billings [/author/lee-billings/]

Mathematicians are now certain the earth-shattering artificial-intelligence-created proof of the Riemann hypothesis is real.

On Friday Anthropic mathematician Levent Alpöge claimed to have used the company’s Claude AI model to solve the Riemann problem [https://www.scientificamerican.com/article/anthropic-mathematician-claims-to-prove-riemann-hypothesis-most-famous-problem-in-all-of-math/], perhaps the most important open quandary in mathematics [https://www.scientificamerican.com/article/the-riemann-hypothesis-is-a-million-dollar-math-problem-hardly-anyone-is-trying-to-solve/]. The hypothesis, first posed in 1859 by mathematician Bernhard Riemann, suggests that a hidden pattern underlies the distribution of the prime numbers—those numbers that are divisible only by themselves and 1.

Now researchers have verified that the proof does do what Alpöge claims.

"We have full confidence that Alpöge's proof of the Riemann Hypothesis is correct, and we congratulate him on this achievement," mathematicians wrote in a joint statement by the Lean and Mathlib communities [https://leanprover-community.github.io/blog/posts/riemann-hypothesis/], which support the Lean mathematics programming language. "We hereby certify that both the statement and the proof of the Riemann Hypothesis are correct."

Alpöge initially checked the work by writing out the proof using Lean; if a Lean-coded proof compiles error-free, this is usually taken as confirmation that the logic and math in each step is correct.

But some questions remained. For instance, does the proof really address the Riemann hypothesis, or does it establish a subtly different point or idea? “The first question which one has to ask when judging a PDF which comes with some Lean code is: ‘what is the statement of the theorem in the Lean code, and does this correspond to the actual theorem statement,’” explained mathematician Kevin Buzzard of Imperial College London in a blog post [https://xenaproject.wordpress.com/2026/11/12/and-the-proof-is-checked-in-lean/].

A second question was whether the Lean code would successfully compile for other mathematicians. Independent researchers, including Andrew Sutherland, a mathematician at the Massachusetts Institute of Technology, have now separately compiled Alpöge’s result in Lean without issues.

“The Lean proof has been compiled and independently rechecked by the Lean kernel with only the three standard axioms,” Sutherland says. “Honestly the chance that anything is fishy here is approximately zero.”

Researchers also made sure that the proof does not include any hack, dodge or shortcut that changed the meaning of the initial hypothesis or any other mathematical rules or truths. This process, called a “comparator run,” typically takes a matter of hours.

“We still await a successful comparator run, which will check that (a) the code does not do anything nefarious like redefine the meaning of any of the symbols in the statement and (b) (assuming it’s run in paranoid mode) the code compiles with several independent kernels (so the code is not just exploiting an as yet unknown bug in Lean’s official kernel,” Buzzard wrote on an online chat server [https://leanprover.zulipchat.com/#narrow/channel/113488-general/topic/Discussion.3A.20Alp.C3.B6ge.20Proves.20the.20Riemann.20Hypothesis/near/642270043] for the Lean community.

That run has now been completed.
