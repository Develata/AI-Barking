Paper 2026/1747

Extending Distinguishing to Key Recovery for Subfield Subcodes of GRS codes [/2026/1747.pdf]

Kirill Vedenev [https://orcid.org/0000-0002-7893-655X], CryptoPro, Southern Federal University

Abstract

The McEliece cryptosystem based on binary Goppa codes has resisted both classical and quantum cryptanalysis for nearly 50 years. Recently, Ghoshal, Ishai, Jain, and Sun proposed an efficient algorithm that distinguishes generator matrices of subcodes of generalized Reed--Solomon (GRS) codes, including Goppa codes, from random ones. From all columns but one, this distinguisher finds a set of multivariate polynomials, called a hold-out kernel, that must vanish at the held-out column if the tested code is indeed a subcode of a GRS code.

In this paper, we propose a full key-recovery attack working essentially from a single run of this distinguisher. The attack takes a relatively small sample of polynomials from the hold-out kernel and recovers a local jet (i.e., a truncated Hasse expansion up to reparametrization and scaling) of the hidden curve associated with the code. This jet can then be used in one of two finishing routes proposed in the paper.
The first route uses the jet to obtain the quadratic forms vanishing on the curve and recover the tangent planes at all columns. From them, it builds a special auxiliary code, called the minor code, which turns out to be a full GRS code with the same secret support, allowing the standard Sidelnikov--Shestakov attack to recover it. The second route seeks two special quadratic forms and recovers the support from them directly. From this support, simple linear algebra recovers the rest of the secret key.

The attack relies on heuristic assumptions, mainly the stated sufficient rank conditions, which we test experimentally. We solved the McEliece challenges TII-173, TII-249, and TII-253, the first two previously unsolved. We also successfully tested the attack on randomly generated small binary Goppa codes, wild Goppa codes, alternant codes, and GRS subcodes. Under these assumptions, the cost of key recovery is dominated by the single distinguisher run (about $2^{90}$ to $2^{101}$ bit operations for Classic McEliece, excluding memory access, depending on the parameter set and the employed sparse solver).

Note: Oct, 7: The revision adds improved attacks, new experimental results, and updated complexity estimates. Under the stated assumptions, key recovery now costs essentially one run of the distinguisher. None of the concerns raised in ePrint 2026/1810 are applicable to this revision.

Nov, 13: The revision adds degree-7 experiments, a detailed comparison with other attacks, and improvements to the exposition throughout.
