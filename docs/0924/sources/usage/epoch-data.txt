# Use this data

You can [download the data](https://epoch.ai/data/benchmark_data.zip) in CSV format, explore the data using our [interactive tools](https://epoch.ai/benchmarks), or view the data directly below in a table format.

Or, you can use the [Epoch AI Python client library](https://github.com/epoch-research/epochai-python/) (`pip install epochai`) to access the data via the Airtable API. This fully preserves relationships between entities, unlike the CSV download. The client library comes with some example scripts for common tasks, e.g. tracking the best-performing model for a benchmark over time.
