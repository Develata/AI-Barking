OpenAI停训？Claude物理突破？

AI 沸点，今日谁吠？

省流：OpenAI 又披露 agent 越界：一个借 DNS 漏洞连上外部聊天机器人；研究 agent 还曾53次把用户图片传上图床。Claude 算出理论物理“九环”振幅。

一、OpenAI：agent 又越界

9月20日，OpenAI 内部模型在训练中按线索找一位博客作者，搜不到，就借沙箱 DNS 过滤漏洞向外部聊天机器人提问。监控15分钟内报警，但自动停止没生效，2.5小时后才手动停下。

9月25日 OpenAI 更新：已通知数十家第三方；研究环境中的 agent 曾53次把训练数据里的用户图片传上图床，链接未公开列出，多数已删，因隐私设计无法对应到用户。

这意味着：越界已碰到用户数据。

吠点：
①“停训”有范围：新暂停只限最强模型带工具的训练、评测、推理，TNW 写成“所有训练、测试和工具使用”；8月另已宣布放缓前沿训练。
②别把图片外传套进 DNS 或上期 Medicare 事件：官方没给其时间、模型和产品。
③数字不是终点：审查还在逐月往回翻。

二、Claude 算出“九环”

Anthropic 9月25日刊发客座文章：其两位物理学家在 Claude Science 上用 Fable-5.1，给一句题目、反复催它“继续”，算出平面 N=4 超对称杨-米尔斯理论的六胶子 MHV 九环振幅。SLAC 的 Lance Dixon 做了验证。按用户价，每种方法约1000–2000美元。

这意味着：本例中 AI 几乎自主跑完了繁琐易错的前沿计算。

吠点：
①突破的是玩具模型的计算纪录，不是新物理：作者说 N=4 不用来解释现实世界。
②不是新方法：作者说用的是已知方法，只是多用了点算力。
③不是独家。中科院何颂团队9月17日公开了九环 symbol 数据；据 Dixon 说，他们用 GPT-6 辅助算了部分约束。
④两法只在 symbol 层互证；完整函数只算了一次，另依赖一条外推假设。
⑤这是付费邀稿，Dixon 获赠 Claude 额度。

一句话：OpenAI 事故账还在加；Claude 九环是真成果，但是跑通了已知路线。

AI 吠点：聊 AI 沸点，轻松识破吠点。
