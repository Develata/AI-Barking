Introduction

This deposit contains a 7z archive encoding the symbols of the six-point BDS-like subtracted MHV amplitudes at two through nine loops in planar N=4 SYM theory.

Archive format and usage

The dataset is distributed as a 7-Zip (.7z) archive for efficient storage, which can be extracted using the free utility 7-Zip (Windows) or p7zip (Linux/macOS). The primary data files are in WXF Format (.wxf) for use with Mathematica/Wolfram Language, and can be imported directly using Import[filename, "WXF"]. For detailed usage instructions, please refer to hexagon_mhv_symbol_weight_18.wl and README.md.
