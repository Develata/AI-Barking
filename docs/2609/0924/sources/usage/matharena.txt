How are expected performance and cost computed?
Expected performance averages normalized scores across all questions from non-deprecated competitions, giving each question equal weight. For each model and question, we use the mean observed score over available runs when results exist, including zeroes and fractional scores. For missing results, we estimate the score with a two-parameter item-response theory model: for model ability $\theta_{m}$ and question difficulty $\beta_{q}$ with discrimination $\alpha_{q}$, we use $p_{m , q} = \sigma \left(\right. \alpha_{q} \left(\right. \theta_{m} - \beta_{q} \left.\right) \left.\right)$. Parameters are fitted on existing data with fractional scores preserved. A model needs to have at least 42 answered questions to be included in the expected performance plots. For confidence intervals, we simulate binary outcomes with the fitted mean scores (a Bernoulli approximation) and refit the full IRT model on each simulated dataset. Each simulated score uses the same averaging rule on the fixed non-deprecated question set: simulated observed means where results exist, and refitted estimates where they are missing. The IRT component is similar to the [Epoch Capability Index](https://arxiv.org/pdf/2512.00193), with parameters $\alpha_{q}$ and $\beta_{q}$ fitted for each question. Our reported average combines observed and estimated scores as described above.

Expected cost is the weighted average per-problem cost over non-deprecated, non-Euler competitions. For missing cost observations, we fit $log ⁡ c_{m b} = \mu_{m} + \beta_{b}$ by least squares on observed per-problem costs and predict missing values with $exp ⁡ \left(\right. \mu_{m} + \beta_{b} \left.\right)$ before averaging by benchmark problem count. Cost confidence intervals are symmetric bootstrap intervals over the benchmark problem mix.

About MathArena

MathArena is a platform for evaluation of LLMs on the latest math competitions and olympiads. Our mission is rigorous evaluation of the reasoning and generalization capabilities of LLMs on new math problems which the models have not seen during training. To show the model performance, we publish a leaderboard for each competition showing the scores of different models individual problems. To evaluate performance, we run each model 4 times on each problem, computing the average score and the cost of the model (in USD) across all runs. The displayed table cost is the average cost of one model run on one problem. Explore the full dataset, evaluation code, and writeups via the links below.
