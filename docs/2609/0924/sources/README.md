## 阅读限制

- 厂商评测与第三方评测的框架、推理强度和回退配置不同，不应把表格中的数字直接视为同条件对照；具体截图与注释见[配图说明](../images/README.md)。
- X 使用帖统计是固定检索窗口中的非随机样本。原记录包含 310 条第一轮纳入编码、73 条直接比较；独立复编码未完成，不能据此推断全部用户偏好。原始帖子采样、编码及运行记录见 [usage/](usage/README.md)，总体取证说明见 [usage-evidence.md](usage-evidence.md)。
- Epoch 的误差栏为标准误，不是 95% 置信区间；未测模型不能用旧版本成绩替代。利益关系说明页是进一步阅读入口，原采集记录未完成对该页全部说明的核对。
- 费马大定理条目描述内部研究模型的形式化工作，不是公开 Opus 5.5 的同设置实测；未独立运行该证明工程。
- 草稿、逐轮核验笔记、完整网页存档、派工记录和未裁剪原图作为工作档案保留；[核验笔记](fact-check.md)与[取证明细](evidence.md)中的状态和限制不能省略。
