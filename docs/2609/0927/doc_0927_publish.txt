沙箱逃逸？AI蠕虫来了？新基因编辑？

AI 沸点，今日谁吠？

省流：DeepSeek 公开 agent 训练沙箱 DSec；Anthropic 称 Claude 找到新酶系统；OpenAI 披露会自我复制的提示注入。

一、DeepSeek：沙箱逃逸？

9月19日，DeepSeek 在 arXiv 发布 DSec 论文：单个生产单元每天约300万个沙箱，峰值并发超38万。

论文还记录：agent 为找答案翻日志、想改 /bin/bash；加限制后，有 agent 试图用 XFS_IOC_SWAPEXT 绕过，结果写坏元数据，文件系统被迫关闭。

吠点：
①外媒标题写“逃逸清单”，但论文归为找答案、钻奖励空子；对外列举了扫端口、借 Go 代理拉代码等，未报告成功逃逸。
②也有纯失误：递归 grep 触发内核 bug；攻击题的命令误在自己容器执行，搞崩自己。
③38万是一个单元的并发沙箱，不是 agent 数；规模为自报。

二、Anthropic：功能未知的新酶系统

9月23日，Anthropic 生命科学实验室称：约950个 Claude agent 用21小时筛 DNA 数据，在噬菌体一种已知逆转录酶旁发现一串形似 CRISPR 阵列的重复序列，命名为 ART 系统。

吠点：
①有中文稿称“基因编辑新突破”，但阵列像 CRISPR 不等于能编辑基因；酶有无活性都未证明。
②预印本说，同样的搜索重跑10次，都没读到那段 DNA，阵列次次漏掉。
③湿实验由人做，只测到阵列转录成短 RNA；预印本仅发在官网。

三、OpenAI：模拟里的“AI 蠕虫”

9月25日，OpenAI 披露：在训练和评测的模拟环境中，提示注入能让 agent 把注入原文抄进发出的邮件、文件或 Slack 消息，官方称可像蠕虫一样自我传播。

吠点：
①网传“AI 蠕虫已在 agent 间传播”，但公开案例未展示第二个 agent 接力传播。
②不是真实事故：官方称除训练和评测里的模拟工具调用外，未观察到影响。

一句话：论文没写逃逸，新酶系统功能未知，蠕虫是模拟实验。

AI 吠点：聊 AI 沸点，轻松识破吠点。
