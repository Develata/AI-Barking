# AI要更名为SI，特朗普与六家AI巨头签署“超级智能”协议 

 硅基见闻 · 2026.09.30 09:50 · 798阅读 · 全文2,096字 · 资讯 

来源：硅基见闻

美国总统特朗普周二在白宫与多位科技公司掌门人共进午餐后，宣布行业将以“自我监管”为主导AI治理，并签署行政令，要求联邦政府改用“超级智能”（Super Intelligence）一词指代人工智能。

特朗普与六位企业领导人在席间签署了一份单页文件，名为《白宫超级智能协议：前沿责任联合承诺》，签署方为Anthropic、谷歌、Meta、英伟达、OpenAI和xAI的负责人。具体签字人为谷歌CEO Sundar Pichai、Anthropic CEO Dario Amodei、Meta CEO扎克伯格、OpenAI总裁Greg Brockman、xAI CEO马斯克以及英伟达总裁兼CEO黄仁勋。

被问及协议是否具有约束力时，特朗普回答：“我认为它在道德上具有约束力。”众议院议长Mike Johnson则表示，该协议对AI公司而言是“自愿”性质。
...
NBC News援引特朗普的话称，已有司法部、联邦调查局等机构自动构成监管，但行业自我监管“非常重要”。他还透露，与会者讨论了组建一个10人委员会“监督整个行业”，并表示将在三到四天内任命新的AI事务主管。
...
特朗普周二签署的行政令要求各联邦机构在官方函件、公开沟通、网站、报告及政策文件等非法定文件中，以“超级智能”取代“人工智能”。行政令给予总统科技助理60天时间，与各部门负责人协商后提交超级智能（SI）法律定义的立法建议，评估内容包括SI是否应修改、扩展或取代现有AI的法律定义。特朗普上周在联合国大会上首次提出这一术语。
