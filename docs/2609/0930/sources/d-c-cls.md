美东时间周二（29日），美国总统特朗普正式签署行政令，下令所有行政部门和机构使用“超级智能”（Super Intelligence，简称SI）一词代替人工智能（AI）。
在特朗普与众多人工智能领袖共进午餐后，白宫宣布了这项行政命令。该命令表明，尽管美国民众对这项快速发展的技术越来越感到担忧，但总统仍试图强行重塑他一直大力支持的行业的品牌形象。
近期多项民调显示，大多数美国民众对人工智能表示担忧，并对特朗普处理该问题的方式表示不满。但这位总统坚称，在人工智能竞赛中保持优势是至关重要的目标，他将各方对这项技术的严峻警告斥为“骗局”，其中包括一些周二与他一同在白宫出席活动的科技高管的警告。
白宫在一份情况说明书中表示，特朗普签署了题为“开启超级智能时代”的行政命令，旨在“认可不断进步的技术前沿及其为美国人民带来的无限希望” 。
该命令规定，行政部门所有机构和部门在官方信函、公共沟通、政策和其他文件中必须使用新术语。“人工智能”和“AI”将不再被使用。
周二下午早些时候，特朗普在白宫西翼外举行的一次不同寻常的新闻发布会上对记者表示，一份确定新名称的文件是由与他共进午餐的科技巨头们签署的。
“我们今天正式更改了名称，”特朗普说道：“这个名称是由全世界最伟大、最聪明、最杰出的人们正式更改的。”
但这些科技公司高管似乎签署了一份单独的两页文件，特朗普在他的“真相社交”账号上分享了这份文件。该文件并未声明要更改名称，只是在其标题中提到了特朗普对人工智能的新称呼：“白宫超级智能协议”。
该协议副标题为“前沿责任联合承诺”，其中表示签署方“认为每家公司都有责任以安全且能建立信任的方式开发自己的技术”。该协议指出，这包括实施“健全的内部流程和控制，以确保其技术按预期运行”，并建议增加四层控制措施。
根据该文件，签署方同意“定期会面”以制定安全标准，文件还补充说，“随着时间的推移，将这些步骤编纂成法律或法规可能是有意义的”。
除了特朗普之外，上述帖子还显示，签署该协议的还有六位科技公司高管：谷歌CEO桑达尔·皮查伊、特斯拉以及SpaceX首席执行官埃隆·马斯克、Anthropic首席执行官达里奥·阿莫代伊（Dario Amodei）、Meta首席执行官马克·扎克伯格、OpenAI总裁兼联合创始人格雷格·布罗克曼以及英伟达CEO黄仁勋。
当被问及该文件是否具有任何约束力时，特朗普在白宫外表示，该文件“具有道德约束力” 。
