## 阅读限制

- “99.7%”的统计单位是账户，公告列出的产品范围不能自动扩展到所有 API 用户；“误判率低于 0.1%”不应当成公开的线上实测结果。
- 门户访问、写入和通知经过按澳方公开说法归因；媒体标题与官方措辞分开阅读。不把调查中的事项写成已经成立的违法结论。
- 截图中的时间可能采用浏览器本地时区；Guardian 截图显示更新时间，未显示指定首发时间。具体条件、裁剪与拼接说明见[配图说明](../images/README.md)。
- 正式配图采用现有交付版本；原始整页截图、整页 HTML、[核验笔记](fact-check.md)与[截图日志](capture-log.md)也作为工作档案保留，不应将原始截图直接当作推荐发布版本。
- 既有横版封面约为 2.54:1；平台裁成 2.35:1 或 1:1 时的限制已记录在配图说明中，本次未改图。
