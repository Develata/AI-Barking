## 限制

- **Atlantic 付费墙**：只读到开头与作者简介；Robinson 的职责、“12 次发布”、聘请公关公司等细节来自 Reuters、Guardian、TechCrunch 的转述，正文只引可见部分与这些媒体的原话。
- **官方页发布时刻**：Google 帮助页、OpenAI 三份报告、Aleph Alpha 博文、AA、OpenAI Release Notes 均只给日期或不给日期，不推断时刻。Google 帮助页没有发布时间与更新时间，只能从存档快照推知上线区间。
- **Gemini 范围**：帮助页只写 Gemini 应用个人账号；Workspace、教育版与 API / AI Studio 另有各自规则页，未见它们对本次变化的明确说明，正文不下结论。
- **“没找到独立评测”是本次检索结果**：2026-10-04 21:51 与 22:15（北京）检查 AA 模型页，全文检索 “kolibri”“aleph” 0 命中；LMArena 站内检索无结果；LiveBench 存档只有页面壳，不作依据。不证明不存在未索引条目。
- **社交平台帖子**：X 上的官方账号与署名员工发言按事实分级归 L1/L2，卡片与正文不写平台名；X 帖卡片只在内部留存，不用作批注图。
- **取证工具与日志**：`capture-log.md` 记每次抓取与失败；超过 1 MB 的本地材料（`c-tech-report.pdf`、`c-aa-models-page.html`、`c-olmo3.html`）存 OpenList（见 `offsite.tsv`，发布后生成）。
