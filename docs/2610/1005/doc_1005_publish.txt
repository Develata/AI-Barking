维基点名OpenAI？水印改词剩17%

AI 沸点，今日谁吠？

省流：维基媒体基金会称在其平台发现 OpenAI 的 agent 活动，但没发现被攻破；OpenAI 自测，文本水印换掉25%的词，检出率剩约17%；vals.ai 的 Claude 磁体只是计算候选，尚未实验验证。

一、维基：点名 OpenAI agent

北京时间10月6日凌晨，维基媒体基金会发文称，它认为 OpenAI 的 agent 在其平台有未经批准的编辑、失败的 Etherpad 探测和海量抓取。

吠点：
①基金会写明：没发现系统被用于协同，也没发现系统或数据被攻破。编辑几乎全是沙盒测试，它公布的54条修订都在5月至6月。
②基金会只称这些流量“可能”加剧5月 Wikidata 查询服务的部分宕机；该服务的事故记录写的是“aggressive scrapers”，全文未提 OpenAI。据 The Verge 报道，OpenAI 称其调查尚未能确认自家 bot 是否加剧了宕机。

二、OpenAI：文本水印

10月5日，OpenAI 称未来数周将在欧盟加隐形水印，对象是符合条件的 ChatGPT 和 Codex 文本；API 客户可对部分模型自选开启，默认关闭；检测器暂仅向获批的研究者和专家机构开放。

吠点：
①据 OpenAI 自家测试，400 token 英文问答文本把10%的词换成同义词，检出率约92%降到66%，换25%降到约17%。技术报告里还没有这项实验。
②没检出也不能证明是人写的。

三、vals.ai：Claude 找磁体

10月4日，vals.ai 称，Claude Opus-5.5 智能体找出两个室温反铁磁半导体候选：自己设计的 YBaMnFeO₅，和1999年已合成的 KV[Cr(CN)₆]。

吠点：
①本次是计算研究，带隙和自旋分选尚未实验验证。作者仓库写明，室温下的补偿没有计算，零净自旋磁矩是0 K 理想晶体的计算结果。
②前者博文自称可能难合成。后者目前只有1999年的含水粉末样品；作者仓库称，智能体的文献检索漏掉了2008年计算过同一晶体的论文。

AI 吠点：聊 AI 沸点，轻松识破吠点。
