嗨，

明天我们将向新订阅者重新开放 Pro $200 订阅，同时我们也将更改其使用量计算方式。实际上，如果你算一算，这将相当于与旧 Pro $200 计划相比，API 支出减少一半的美元金额。

既然已经说到了这里，让我解释一下为什么会出现这种情况，以及为什么你现在能完成的工作量仍将比一个月前使用 Pro $200 订阅时更多。

(a) 我们不想在其他方面妥协，并承诺不再重新引入 5 小时限制，这样你就可以在需要时充分利用每周的使用量。
(b) 在订阅服务中，我们保证随着时间推移，你总能完成更多工作，并且质量水平不断提升。这意味着，由于模型效率的提高以及我们通过降低 API 价格将这些改进传递给你，你将持续获得每美元更高的价值。
(c) 我们不想给自己制造激励，去人为抬高 API 列表价格来制造你获得大量优惠的假象（通过折扣等方式绕过它）。相反，我们希望继续快速降低价格并提升 API 上模型的能力。本周我们以之前价格的 50% 推出了 GPT-6 Sol 和 GPT-6 Luna。随着时间推移，我们看到价格会低到足够，让大多数人选择按需购买使用量，而订阅服务与 API 每美元支出的差距不会太大。
(d) 明天，我们将在订阅中添加更多不消耗使用量的新功能，我暂时不会透露那是什么。

我想在明天所有重大公告之前保持透明。订阅服务即将迎来许多激动人心的新功能，这将让它变得超级吸引人，但我希望提前分享这一变化，让大家都能理解，然后我们再用好消息来“轰炸”你们。
