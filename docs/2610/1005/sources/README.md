## 限制

- **官方页发布时刻**：openai.com 文本水印页与技术报告、vals.ai 博文、Reflection、OpenAI 广告页均只给日期；Nieman Lab 标 “Oct. 5, 2026, 4:01 p.m.” 未注时区。正文只写日期，不推断北京时刻。Wikimedia Diff 元数据为 2026-10-05T17:00:00Z，故写“北京时间10月6日凌晨”。
- **修订清单没有日期列**：“54 条修订都在 5 月至 6 月”由 Claude/Codex 经 9 个域的公共 MediaWiki API 按修订 id 取时间戳得到；不含编辑者、IP 或正文。清单只是基金会公布的“认为来自 OpenAI agent”的修订，不证明之后没有其他活动。
- **Wikimedia 与 OpenAI 的归因**：基金会用 “we believe / likely operated by OpenAI”，未公开取证证据；OpenAI 回应见 Reuters 与 The Verge 当前版（回应加入时刻未核到）。
- **Reuters 旧版**：扫描里“未即时回复置评”的旧句未取到原站历史版本，不引。
- **技术报告未含水印检出实验**：报告 20 页，封面 2026-10-05，页面称之后会补充；正文“还没有”仅指本次读到的版本。
- **vals.ai**：作者身份依据其公开自述与官方帖转发，未确认其与 vals.ai 的雇佣或资助关系；2008 年论文全文订阅墙，其图的结论只来自作者转述，正文不引。
- **Tibo 帖互动数**为抓取时点快照（浏览量约 661 万，随时间变动）；Nieman 报道的 OpenAI 声明只在该报道中找到，未见 OpenAI 自有页面。
- **“没找到”只是本次检索范围**：TechCrunch、404 Media 对 Wikimedia 事件的同日报道、Reuters 对文本水印的报道本轮未找到，不等于没有。
