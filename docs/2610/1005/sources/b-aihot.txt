AI 综述

OpenAI 公布应对欧盟《人工智能法案》的文本溯源方案，推出名为 textGrain 的文本水印技术，做法是在模型逐词选择过程中加入不可见的统计信号。全球 API 客户即日起可对部分模型选择性开启水印，但 API 中水印默认关闭；未来数周，OpenAI 将在欧盟地区为符合条件的 ChatGPT 和 Codex 文本输出添加隐形水印，覆盖所有套餐，且不设为全球默认。

检测水印的工具暂只向获批的研究者和专家机构开放，OpenAI 称这些机构可帮助其评估和改进该技术；据 IT之家报道，该工具只报告是否检测到 OpenAI 水印，不透露用户或对话内容。The Decoder 称，与 Anthropic 对 Claude 的全球强制水印不同，OpenAI 允许全球 API 客户关闭水印。

OpenAI 同时说明该水印不添加可见标记，不识别作者、组织、账号或对话来源，并称测试中未影响模型能力、速度或阅读体验；但 OpenAI 也承认文本水印存在明显局限：短文本中常难以检测，改写或翻译可完全去除水印。X 账号 Testing Catalog 称，OpenAI 官方测试显示 textGrain 效果追平或超过 SynthID 且质量无明显损失，并将开源；该账号同时表示这仍需实际测试验证。
