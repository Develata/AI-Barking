The secure messaging protocol

Unlocking an open, private, and decentralized foundation for secure communication

Quantum-resistant, end-to-end encryption

XMTP uses quantum-resistant hybrid encryption to protect against "Harvest Now, Decrypt Later" attacks and provides perfect forward secrecy and post-compromise security, ensuring messages can never be retroactively decrypted. XMTP's MLS implementation was fully audited [https://www.nccgroup.com/research-blog/public-report-xmtp-mls-implementation-review/] by the same cryptography firm that reviews Signal and WhatsApp.
Learn more about Quantum-resistant, end-to-end encryption [/security]

Any network, any identity, anywhere in the world

XMTP works with any decentralized identifier (DID) or network identity. Developers simply connect their existing identity model to XMTP, allowing users to message securely using passkeys, wallets, social accounts, or custom identities with no platform lock-in.
Learn more about Any network, any identity, anywhere in the world [/identity]

Built for digital money

XMTP supports native integration of digital currencies and assets. Users can send payments securely in conversations, agents can manage transactions, and services can embed payments. As an open protocol, XMTP makes it straightforward to integrate digital assets into messaging experiences.
Learn more about Built for digital money [/digital-money]

Spam protection, built-in

XMTP's network level consent provides end-users with the ability to allow or block anyone across the XMTP network. Everything is opt-in, encrypted and controlled by users. This provides developers with a network level view of allowed/blocked senders, helping to create spam free experiences for users.
Learn more about Spam protection, built-in [/consent]

A messaging network no one can shut down

App and agents builders pay about $5 per 100,000 messages to use XMTP. 100% of that payment goes directly to independent node operators around the world who run the infrastructure and deliver messages across the network—no middleman, no gatekeeper, no permission required.

Nodes are globally distributed so that the network keeps operating even if any country changes its stance on privacy and encryption.

Don't trust, Verify.

Open sourced everything.

XMTP is open source from the ground up, from nodes and smart contracts to SDKs and example apps. Everything is public, auditable, and built together with the community because you shouldn't have to trust one company's word when it comes to the security of your communication.

We fundamentally believe that the most private network is the one where nothing is hidden.

From proposing improvements, or joining the discussion, you have a voice here.
