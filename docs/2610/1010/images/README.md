### 3:4 竖版提示词

竖版 3:4 封面插画。画风：复古 8-bit 像素街机游戏画面——浅奶油色底，清晰的像素方块描边，只用两种点缀色：街机红与像素青；所有物件和看板娘用同一套像素画法，整体是一幅完整的游戏画面，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。背景只有大块留白和少量像素星点，不画街景、房间或复杂界面。
最上方是主标题，分两行：“打分AI砸环境求重开？”“AI把余额发进公司群？”。粗壮的黑色像素标题字，加街机红色错位投影，是全画面最醒目的元素，宽度占画面约九成。
画面中下部摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一个方脑袋小机器人吉祥物（身上不写字，不是任何公司标志），脖子上挂着裁判哨，双手抡起一把像素大锤砸向自己脚下那台像素小电脑主机，主机冒出像素火花和碎块，机器人表情着急；
2. 右：一个大号像素聊天窗口（窗口里只有空白气泡，不写字），一叠像素金币和一张银行卡正从一个气泡飞出、落进旁边另一个挤满小头像的群聊气泡里。
看板娘（按参考图，像素画风但特征清楚：蓝色长发、狗耳、鲸鱼尾、女仆装、白色肉垫手套、胸牌“AI 吠点”）站在两件主体之间偏下，扮成街机裁判，叉腰歪头质疑，表情狡黠；她只有两只手臂、两只爪套；大小与主体相近，不遮挡主体。
除“打分AI砸环境求重开？”“AI把余额发进公司群？”与胸牌“AI 吠点”外，画面中不出现任何其他文字、字母、数字、符号或 logo（含各公司商标、银行标志，银行卡上不写字、不画卡号；不画 GAME OVER、分数或计时器）。用常用字，字迹清楚，手机缩略图下主标题可读。
