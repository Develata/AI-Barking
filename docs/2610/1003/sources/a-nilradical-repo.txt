Kourovka in Lean
Complete, kernel-checked Lean proofs answering selected problems from
The Kourovka Notebook
.
Each entry connects the original question to a precise formal statement,
its proof, and reproducible verification instructions.
The solutions to Problems
21.3 (first question), 21.38, 21.40, 21.44,
21.68 and 21.106
are by
Nilradical v0
.
See the
result and verification record
.
The complex and real projective-linear cases of
16.68
are by
Nilradical v1.0.0
; see their
accepted formal proofs
.
The results for
21.35 and 21.53
are by
Nilradical v1.0.0
; see the
21.35 conditional formalization
and
21.53 accepted proof
.
Problem 21.29 remains credited to Aluna Rizzoli and Adam R. Thomas.
Problem 21.99 is retained as an independent formalized counterexample,
but excluded from the Nilradical discovery catalogue because another
complete solution exists and public priority is unresolved.
Use the results
You are welcome to use the Nilradical results and publish your own
mathematical work. No permission or coauthorship of the agent, its developer,
or its project team is required. Publication credit belongs to the people
doing the mathematical work; cite the results and prior work you build on.
See the
research and credit policy
, including
how to
report missing or mistaken credit
.

Every listed answer has a complete proof checked by Lean. The permitted
foundational axioms are
propext
,
Classical.choice
, and
Quot.sound
.
The
guarded audit
checks the original catalogue endpoints;
16.68 has separate
complex
and
real
audits and a
Lean/Comparator/Nanoda verification record
;
21.53 has its separate
protected Lean/Nanoda verification
.
For 21.35, the complete conditional proof and its
Lean/Nanoda checks
retain exactly Thompson's minimal-simple classification and the stated
quasisimple coprime-commutator theorem as explicit parameters. Their published
proofs are not formalized here; this approved exception is visible at every
public endpoint. External computations do not stand in for proof terms.
Check the proofs
Install
elan
, then clone the repository
and run the build:
git clone https://github.com/alunik/kourovka-lean.git
cd
kourovka-lean
lake exe cache get
lake build
lake env lean Audit.lean
The
Lean toolchain
and
dependencies
are pinned. On a machine with 8 GB of RAM, use
LEAN_NUM_THREADS=1 lake build
; CI uses this setting for the larger finite
checks. Each problem's README also gives a command to build its solution alone.
The normal build uses the committed Lean certificates. To reproduce their
generation separately, see the
certificate guide
.
The
verification record
documents the recorded build,
axiom audit, and source hashes.
Read a solution
Start with the problem README for the question, answer, and scope. Then read
Statement.lean
for the exact quantifiers and
Solution.lean
for the final
theorem. Each
Proof/README.md
maps the supporting argument to its Lean modules.
Kourovka/Problems/P21_03/       # Same entry points for every problem
├── README.md                 # Question, scope, formal statement, proof guide
├── Statement.lean            # Public question, independent of its proof
├── Solution.lean             # Public answer
└── Proof/
    ├── README.md             # Roadmap to supporting modules
    └── …                     # Lemmas and any kernel-checked certificates
Kourovka.lean
imports the original standard-layout solutions.
Problem 16.68 preserves its two independently verified projects in
Kourovka/Problem1668/Complex
and
Kourovka/Problem1668/Real
; run each build
from its own directory, following the
entry's instructions
.
CI builds and audits both projects explicitly.
Problem 21.53 retains its independently reviewed, source-pinned module layout;
build its complete target with
lake build Kourovka.Problem2153.Final
.
Problem 21.35 likewise preserves its verified layout, as a self-contained
project in
Kourovka/Problem2135
; run its build from that directory. The
publication copied its source byte for byte and did not rerun Lean.
docs/
holds longer explanations and verification records;
scripts/
holds repository checks and certificate generators.

contribution guide

credits

CITATION.cff
