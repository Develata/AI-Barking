Overview

What is Mercury 3

Mercury 3 is Inception Labs' flagship diffusion-based language model, released in October 2026. Instead of generating tokens one at a time, it produces and refines them in parallel, reaching 1,000+ tokens per second with a 1M-token context window — built for agents, search, and real-time applications where latency compounds.

Using it anonymously on Venice

On Venice, Mercury 3 runs under the anonymized privacy tier: your prompts are not stored, profiled, or used for training, and there is no personal generation history tied to your account. Access is permissionless — pay per token through the Venice app or the OpenAI-compatible API, no subscription required. That makes the fastest closed model in its price class usable without feeding a Big-Tech data pipeline.

Assessment

Strengths and limitations

Strengths

Speed is the headline: diffusion-based parallel generation delivers 1,000+ tokens per second on NVIDIA hardware by Inception's own measurement, making it well suited to voice pipelines, browser agents, and interactive experiences.

A 1M-token context window with a 128K-token output ceiling gives long documents and extended agent trajectories room to breathe.

Full agentic toolset on Venice: function calling, reasoning mode, web search, and structured output via JSON schema.

Aggressively priced at $0.10 per 1M input and $0.35 per 1M output tokens, with cached input at just $0.01 per 1M — a fraction of comparable frontier-tier models.

Inception claims benchmark wins over Claude Haiku 5.5 and GPT-6 Luna on IFBench, GPQA Diamond, and SWE-Bench Atlas, positioning it as a speed-tier model that doesn't concede quality.

Limitations

Closed and proprietary: no open weights, so it cannot be self-hosted, inspected, or fine-tuned; you rent it, you don't own it.

Text only: no vision, image input, or audio modality, which limits multimodal agent workflows.

The headline speed and benchmark figures are Inception's own measurements and vendor claims, not independently verified.

On Venice it runs under the anonymized tier (prompts not stored) but not inside a TEE with end-to-end encryption, and it is not positioned as an uncensored model.

The launch price is a 50% discount; the standard rate is reportedly $0.20 in / $0.70 out per 1M tokens once it ends.

Prompting

Getting better results

Enable function calling and pass your tool schemas up front — Mercury 3 is built for agentic loops where round-trips dominate latency.

Use structured output with a JSON schema to get parseable results in one shot instead of re-rolling freeform text.

Turn on web search for questions about current events rather than relying on parametric knowledge.

Put stable instructions in a cached prefix — cached input bills at $0.01 per 1M tokens, so repeated system prompts cost almost nothing.

For coding subagents, keep the reasoning setting on for hard steps and off for mechanical ones to trade quality against the already-fast decode.

Stream the output in your UI — at 1,000+ tokens per second, non-streamed responses arrive faster than users can read them anyway.

FAQ

Frequently asked questions

What is Mercury 3?

Mercury 3 is Inception Labs' flagship diffusion-based language model, released in October 2026. It generates text by producing and refining tokens in parallel rather than one at a time, reaching over 1,000 tokens per second with a 1M-token context window and a 128K-token output ceiling.

How much does Mercury 3 cost on Venice?

Venice bills Mercury 3 per token: $0.10 per 1M input tokens, $0.35 per 1M output tokens, and just $0.01 per 1M for cached input. Note that Inception's launch pricing is a 50% discount off a reported standard rate of $0.20 in / $0.70 out per 1M tokens.

Is Mercury 3 free or open source?

Neither. Mercury 3 is a closed, proprietary model — Inception has not published the weights, so it cannot be self-hosted or fine-tuned. On Venice you pay per token with no subscription required, and new accounts include free daily prompts and welcome credits to try it.

Mercury 3 vs Kimi K3 — which should I choose?

They trade on ownership versus speed. Kimi K3 publishes open weights under a Modified MIT licence, so you can download, inspect, and self-host it — but it costs $3.75 in / $18.75 out per 1M tokens. Mercury 3 is closed and rental-only, yet generates at 1,000+ tokens per second for $0.10 in / $0.35 out. Choose Kimi for sovereignty, Mercury 3 for latency and cost.

How fast is Mercury 3?

Inception Labs measures Mercury 3 at 1,068 tokens per second on NVIDIA GPUs, and OpenRouter confirmed 1,000+ tok/s at launch — roughly 4x the throughput of Mercury 2.5. These are vendor and platform figures rather than independent benchmarks, but the diffusion architecture's parallel refinement is the reason for the speed.

Does Mercury 3 support tool use and web search?

Yes. On Venice, Mercury 3 supports function calling, a reasoning mode, web search grounding, and structured output via JSON schema — the full toolkit for agentic workflows. It does not, however, accept image or audio input; it is a text-only model.

How private is Mercury 3 on Venice?

Venice runs Mercury 3 under its anonymized privacy tier: prompts are not stored, profiled, or used for training, and requests carry no personal account history. Unlike some Venice models, it does not run inside a trusted execution environment with end-to-end encryption, but zero retention of prompts still applies.

What is Mercury 3's context window?

Mercury 3 has a 1M-token context window with a 128K-token maximum output, a major expansion from the roughly 260K-token context of its predecessor. That makes it practical for whole-codebase reasoning and very long agent trajectories.

When was Mercury 3 released?

Mercury 3 was released by Inception Labs in October 2026 and went live on Venice the same month. Some listings date the launch to October 16 and others to October 19, 2026; either way, it is available to use on Venice today.
