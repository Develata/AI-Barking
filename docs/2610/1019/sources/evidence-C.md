## 二、可能的吠点（原文里有、线索摘要没提或说反的条件；每条注出处）

1. 对比表三列都标 “(MEDIUM)”，而 Mercury 3 的 API 默认是 low（docs reasoning-efforts）；对手的默认档恰好是 medium（OpenAI 模型页 “reasoning.effort supports none, low, medium (default), high, xhigh, and max.”；Anthropic 模型页 Haiku 5.5 “Default effort medium”）——三家里只有被测方的默认档与表头不一致；博客正文没有“medium”字样，只在图里；联合创始人在 HN 说是 “at matched reasoning effort”。（c-img-YO5…、c-docs-reasoning、HN 50155371）
2. 对比表的 Mercury 3 价格写首发价 $0.10 / $0.35，博客与 docs 的原价是 $0.20 / $0.70；对手列是标准价。原价口径下输入 $0.20 高于两家对手的 $0.10，输出 $0.70 高于 $0.50。（博客、c-docs-models-page、官方价页）
3. 首发半价官方未给截止时间；The Deep View（L4）称 CEO 提到可能让首发价变成永久。（c-m-deepview）
4. Haiku 5.5 官方价按提示长度分档：>10 万 token 的输入 $0.50、输出 $2.50；Luna >272K 输入 token 输入乘 2、输出乘 1.5。表里只写了短提示价。（C3-b、C3-c）
5. 对手速度 ~130 / ~240 无来源无脚注；AA 的 Max 档为 124.2 / 234.1，Medium 档 Haiku 为 178.6，表头却写 MEDIUM。（C2-c、C4-b）

10. 博客 at-a-glance 写 “On par or better than”，开头写 “outperforms”；同一页两种措辞。（C1-a）
