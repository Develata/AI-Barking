Inception Platform

Build with Mercury — the fastest reasoning and code models, served through an OpenAI-compatible API.

Copy pageCopy page

Inception’s Mercury models use diffusion to generate tokens in parallel, delivering high-quality responses with low latency. They’re built for responsive AI applications and agent workflows where speed and quality matter. The API is OpenAI-compatible, so you can be up and running in minutes with the tools you already use.
