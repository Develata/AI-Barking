 [#account-setup]
Account Setup

Create an Inception Platform account or sign in [https://platform.inceptionlabs.ai/auth/login] directly if you already have one. Each new user is initially assigned 100 million free tokens to help get started with the API.

Go to API Keys [https://platform.inceptionlabs.ai/dashboard/api-keys] and create a new API key. You can start using the API immediately with your free tokens!

When your free tokens are running low, navigate to Billing [https://platform.inceptionlabs.ai/dashboard/billing] to add your payment information for continued usage beyond the free tier.

 [#quick-start]
Quick Start

1

Set your API key

Export your API key as an environment variable in your terminal.

macOS / Linux

Windows (Command Prompt)

Windows (PowerShell)

export INCEPTION_API_KEY="your_api_key_here"

set INCEPTION_API_KEY=your_api_key_here

$env:INCEPTION_API_KEY="your_api_key_here"

2

Install the SDK

Python

TypeScript

pip install inceptionai

npm install inceptionai

3

Send your first request

cURL

Python

TypeScript

curl https://api.inceptionlabs.ai/v1/chat/completions \
 -H "Content-Type: application/json" \
 -H "Authorization: Bearer $INCEPTION_API_KEY" \
 -d '{
 "model": "mercury-3",
 "messages": [
 {"role": "user", "content": "What is a diffusion model?"}
 ],
 "reasoning_effort": "medium",
 "temperature": 0.75,
 "max_completion_tokens": 8192
 }'

from inceptionai import Inception

client = Inception() # reads INCEPTION_API_KEY from the environment

completion = client.chat.completions.create(
 model="mercury-3",
 messages=[{"role": "user", "content": "What is a diffusion model?"}],
 reasoning_effort="medium",
 temperature=0.75,
 max_completion_tokens=8192,
)
print(completion.choices[0].message.content)

import Inception from 'inceptionai';

const client = new Inception(); // reads INCEPTION_API_KEY from the environment

const completion = await client.chat.completions.create({
 model: 'mercury-3',
 messages: [{ role: 'user', content: 'What is a diffusion model?' }],
 reasoning_effort: 'medium',
 temperature: 0.75,
 max_completion_tokens: 8192,
});
console.log(completion.choices[0]?.message.content);

 [#using-third-party-libraries]
Using Third-Party Libraries

Inception API is also fully compatible with popular Python libraries:

AISuite

LiteLLM

LangChain

OpenAI Client

VercelAI

import os
import aisuite as ai

client = ai.Client(
 {
 "inception": {"api_key": os.environ["INCEPTION_API_KEY"], "base_url": "https://api.inceptionlabs.ai/v1"},
 }
)

response = client.chat.completions.create(
 model="inception:mercury-3",
 messages=[{"role": "user", "content": "What is a diffusion model?"}],
 max_tokens=8192
)
print(response.choices[0].message.content)

from litellm import completion

# Inception is a native LiteLLM provider; reads INCEPTION_API_KEY from the environment
response = completion(
 model="inception/mercury-3",
 messages=[{"role": "user", "content": "What is a diffusion model?"}],
 max_tokens=8192,
)
print(response.choices[0].message.content)

import os
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

llm = ChatOpenAI(
 model="mercury-3",
 temperature=0.75,
 api_key=os.environ["INCEPTION_API_KEY"],
 base_url="https://api.inceptionlabs.ai/v1"
)
llm.invoke([("user", "What is a diffusion model?")])

import os
from openai import OpenAI

client = OpenAI(
 api_key=os.environ["INCEPTION_API_KEY"],
 base_url="https://api.inceptionlabs.ai/v1"
)

response = client.chat.completions.create(
 model="mercury-3",
 messages=[{"role": "user", "content": "What is a diffusion model?"}],
 max_completion_tokens=8192
)
print(response.choices[0].message.content)

import { createOpenAICompatible } from '@ai-sdk/openai-compatible';
import { generateText } from 'ai';

const provider = createOpenAICompatible({
 name: 'inception',
 apiKey: process.env.INCEPTION_API_KEY,
 baseURL: 'https://api.inceptionlabs.ai/v1',
});

const { text } = await generateText({
 model: provider('mercury-3'),
 prompt: 'What is a diffusion model?',
});
