### 3:4 竖版提示词

竖版 3:4 封面插画。画风：机场安检 X 光扫描屏——深藏青底，物体呈半透明的伪彩色 X 光影像（橙色、青蓝、淡绿三色），屏幕上有细密扫描线和浅色网格，边缘一圈像监视器的圆角屏框；下方是一条安检传送带。所有物件和看板娘统一用这种 X 光屏画面质感，是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。
最上方是主标题，分两行：“DeepSeek全面开源？”“WhatsApp不让AI提监管？”。粗壮的亮白色无衬线大字，带橙色描边，是全画面最醒目的元素，宽度占画面约九成，每个字都清楚可读。不要副标题。
画面中部的传送带上摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一个敞开盖子的大纸箱，X 光透视出箱内分成几格，只有一半格子里有零件，另一半格子是空的（虚线轮廓）；箱子上不写字；
2. 右：一张竖放的大纸页，正常可见的几行用灰色横条表示，X 光照出横条之间还夹着几行发亮的橙色横条（隐藏的字，只画成横条，不写任何可读文字）。
看板娘按参考图（蓝色长发、狗耳、鲸鱼尾巴、女仆装、胸前“AI 吠点”圆牌；双手是正常的人手，不戴肉垫手套）在画面下方右侧出镜，扮成安检员，同样带一点 X 光屏的发光描边（头发保持蓝色、胸牌保持“AI 吠点”）：一手拿着手持安检棒对着那张纸页，一手叉腰，歪头挑眉，表情狐疑。她只有两只手、两只耳朵、一条尾巴，全身入画。
