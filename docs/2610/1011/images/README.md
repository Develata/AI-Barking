副标题修订：初版副标题为“Karpathy粗估”，正文反向核验指出它把“见过真AI”算到 Karpathy 名下（他估的是能在内部使用前沿系统的人数）；Claude 让 Codex 在选定的两张图上只把副标题替换为“Karpathy：内部使用者”（图像编辑，其余画面不变，竖版 1086×1448、横版 1921×819），Claude 逐字核对通过。下方提示词为初版生成时所用。

挑选：同一提示词并行运行 2 次，每种尺寸 2 张候选（第 1 组 Codex 自述对竖版追加了“去除多余色块与颜料桶”的修正）。竖版选第 1 组：漏斗从密到疏层次清楚，底部一小撮红色小人与小门一眼可见，看板娘全身入画（第 2 组看板娘下半身被画面底边截掉，漏斗底部铺了大块红色）。横版选第 2 组：看板娘两只手都戴肉垫手套（第 1 组叉腰的那只手是裸手，与参考图不符）；主标题与看板娘都在居中 1:1 范围（x 约 551–1370）内。竖版、横版各累计 2 张。

本期画风：**复古象形统计图（Isotype 信息图）**——米白纸底、扁平几何小人符号，只用砖红与石板蓝两色点缀；成排小人收成漏斗对应 Karpathy 的“能力认知漏斗”，方脑袋机器人在画板上画修图软件窗口对应 AI 复刻 Photoshop；看板娘举放大镜查看漏斗底部。与 1010 像素街机、1009 黑白侦探漫画、1008 图书馆借阅台、1007 超市特卖传单、1006 教室黑板、1005 档案室证物吊牌区分开。

### 3:4 竖版提示词

竖版 3:4 封面插画。画风：复古“象形统计图”（Isotype 信息图）——米白纸底，扁平几何小人符号、无描边的纯色块，只用两种点缀色：砖红与石板蓝，其余为深炭灰；像 1930 年代科普画报里的统计图，整体是一幅完整画面，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。背景只有大块留白，不画房间、街景或复杂界面。
最上方是主标题，分两行：“只有5000人见过真AI？”“AI造PS？”。粗壮的深炭灰无衬线大字，加砖红色错位投影，是全画面最醒目的元素，宽度占画面约九成。主标题下方一行小号副标题：“Karpathy粗估”，石板蓝色。
画面中下部摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一个由成排象形小人符号组成的大漏斗——顶部很宽、密密麻麻的灰色小人，往下越收越窄，漏斗底部只剩一小撮砖红色小人，挤在一扇小门前；小人身上不写字，不画任何数字；
2. 右：一个方脑袋小机器人吉祥物（身上不写字，不是任何公司标志），握着一支大画笔，正在一块空白大画板上画一个修图软件的窗口轮廓，窗口里只有几个空白的工具图标方块，画板一角贴着一张空白的“测试中”小纸条——纸条上不写字。
看板娘按参考图（蓝色长发、狗耳、鲸鱼尾巴、女仆装、白色肉垫手套、胸前“AI 吠点”圆牌）在右下角出镜，同样用扁平象形风格，一手叉腰，一手举放大镜对着漏斗底部的数字区域，表情狐疑；她有两只手、两只耳朵、一条尾巴。
画面里除了主标题、副标题与胸牌“AI 吠点”，不要出现任何其他文字、数字、logo、品牌标志或真人。
