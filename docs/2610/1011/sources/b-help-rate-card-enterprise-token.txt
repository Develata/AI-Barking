Note: This rate card applies to eligible token-based Enterprise agreements. For a workspace moving from credits, these rates apply only after its billing model changes.

# ChatGPT Work and Codex models

GPT-6.1 Sol, GPT-6 Sol, and GPT-6 Luna are models for ChatGPT Work and Codex. GPT-6 Sol also powers GPT-6 in Chat as it rolls out. GPT-6.1 Sol and GPT-6 Luna remain available only in ChatGPT Work and Codex.

| Model | Input | Cached input | Output |
| GPT-6 Astra | $10.00 | $1.00 | $50.00 |
| GPT-6.1 Sol | $2.00 | $0.10 | $10.00 |
| GPT-6 Sol | $2.00 | $0.20 | $10.00 |
| GPT-6 Luna | $0.10 | $0.01 | $0.50 |
| GPT-5.6 Sol | $4.00 | $0.40 | $20.00 |

Image generation, Voice, web search, long context, fast mode, and regional processing may create separate or additional charges as described below.

# Additional fees and multipliers

The following fees and multipliers may apply in addition to the standard model rate.

| Feature | Rate |
| Long context_>272K input tokens_ | Input: 2x Standard rateCached input: 2x Standard rateOutput: 1.5x Standard rate |
| Fast and Ultrafast modes (Codex and Work modes only) | Fast mode — GPT-6.1 Sol, GPT-6 Astra, GPT-6 Sol, and GPT-6 Luna: 2× Standard USD token rates (Enterprise PAYG), where available. ... GPT-6 Astra Ultrafast and GPT-6.1 Sol Ultrafast: 6× Standard USD token rates ... Compared with Standard mode for the same model, Fast mode uses your included subscription allowance at 2.5× the rate, and Ultrafast for GPT-6 Astra and GPT-6.1 Sol at 8× the rate. These rates describe allowance usage, not speed increases. |

## Note:
- GPT-5.6 and GPT-5.5 support long context in Work and Codex. Long context is not available in the Chat tab.

## GPT-6 Astra — Codex long-context exception

GPT-6 Astra usage in Codex does not incur additional long-context multipliers above 272K input tokens. Codex does not charge for cache writes.
