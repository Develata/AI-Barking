OpenAI Increases GPT-6.1 Sol Default Context to 500K Tokens and Eliminates Long Context Fee for Subscribers

KuCoinFlash

Release Time: 2026/10/12 03:03:32

Share

Summary

OpenAI announced a major update to GPT-6.1 Sol, increasing the default context window to 500,000 tokens—an 80% increase from 272,000. This change reduces automatic context compression during long tasks, helping users retain more details. New token listings and crypto news reflect growing interest in AI-powered tools. The new default is now available, with users able to adjust up to 1,000,000 tokens. OpenAI has also eliminated the long-context fee for ChatGPT subscribers.

ME AI [https://t.me/MEAINEWS] update: OpenAI’s Product and Platform Lead, Thibault Sottiaux, announced Day 7 of the 28-day product sprint. The default context length for GPT-6.1 Sol in Codex and ChatGPT Work has been increased from 272,000 to 500,000 tokens—an increase of approximately 80%. A larger context window reduces the frequency of automatic context compression during long tasks, enabling the model to retain more prior conversation and task details.

Sottiaux noted that this default setting was specifically tested. Users can still manually adjust it higher or lower, with a maximum support of 1 million tokens. While the model has previously supported manually setting larger contexts, this update raises the default value.

Additionally, OpenAI is no longer charging an additional fee for long context usage with GPT-6.1 Sol when using ChatGPT subscription credits.

(Source: BlockBeats)
