Bug

CodexBar 0.72.0 (164), macOS, Codex local session costs enabled: GPT-6.1 Sol requests with 200,001–272,000 input tokens receive long-context pricing, although OpenAI's threshold is more than 272,000 input tokens.

Evidence

The cached models.dev OpenAI entry for gpt-6.1-sol contains these USD-per-million rates:

{"input":2,"cache_read":0.1,"output":10,"cache_write":2.5,"context_over_200k":{"input":4,"cache_read":0.2,"output":15,"cache_write":5}}

ModelsDevPricing.swift [https://github.com/steipete/CodexBar/blob/v0.72.0/Sources/CodexBarCore/Vendored/CostUsage/ModelsDevPricing.swift#L239-L253] translates the presence of context_over_200k into a literal threshold of 200,000.

resolvedCodexPricing [https://github.com/steipete/CodexBar/blob/v0.72.0/Sources/CodexBarCore/Vendored/CostUsage/CostUsagePricing.swift#L562-L615] uses the bundled threshold when available, otherwise this catalog threshold. GPT-6.1 Sol has no bundled threshold override in this version. GPT-6 Astra already has a 272,000 override.

OpenAI's GPT-6.1 Sol pricing [https://developers.openai.com/api/docs/models/gpt-6.1-sol] specifies input $2, cached input $0.10, output $10 per million; full-request long-context multipliers apply only above 272K input tokens.

Minimal calculation example (synthetic)

Standard service tier, one request, no cache writes:

Model: gpt-6.1-sol

Input: 210,000 (includes 200,000 cached)

Output: 1,000

Expected: (10,000 × 2 + 200,000 × 0.1 + 1,000 × 10) / 1,000,000 = $0.050.

With the current 200K threshold: (10,000 × 4 + 200,000 × 0.2 + 1,000 × 15) / 1,000,000 = $0.095.

This example is derived from the v0.72.0 pricing path, not a claim that a Swift test was run. An independent audit of local request records and the app's cost cache found this same threshold error in actual estimates.

Expected fix / regression coverage

Use the documented model threshold rather than inferring it from the legacy catalog field name. Cover input counts 200,000, 200,001, 272,000 and 272,001, including cached input. Reprice affected cached estimates after correction.

This pricing issue is separate from the duplicate ledger/token_count observations tracked in #4289 [https://github.com/steipete/CodexBar/issues/4289]; correcting that duplication alone will leave this pricing error. Private logs and identifiers are intentionally omitted.
