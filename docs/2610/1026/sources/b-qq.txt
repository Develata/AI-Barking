OpenAI 推出 GPT-6.1 Terra：面向日常任务，主打高效计算机操作

超能网
 [https://news.qq.com/omn/author/8QMX235c6YUb]
2026-10-27 10:41发布于广东超能网络科技有限公司官方账号

问AI · 成本减半效率领先会如何改变办公AI格局？

OpenAI 官方博客日前宣布正式推出 GPT-6.1 Terra ，该模型把视觉推理、计算机操作和写作三项能力放进同一个模型，面向起草提案、解读技术图纸、填写表单、剪辑视频这类日常办公任务。它的标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%。在 ChatGPT 工作和 Codex 中，同样的用量额度能完成更多任务。

在Agents' Last Exam 这个计算机操作测试中，中等推理强度下，GPT-6.1 Terra 比 GPT-5.6 Terra 高 15 个百分点，成本约为后者三分之一；表现与 GPT-6 Astra 相当，每个 token 价格只有它的十分之一。最高推理强度下，它的 token 使用效率是 Claude Opus 5.5 的三倍以上，单 token 价格为四分之一，每项任务成本约为九分之一；完成任务的速度是 GPT-6 Astra 和 GPT-6.1 Sol 的三倍以上。视觉推理基准 MMMU-Pro 上，它在所有推理强度下都优于 GPT-5.6 Terra，成绩接近 GPT-6 Astra 和 GPT-6.1 Sol，成本低得多。桌面应用多步骤任务的 OSWorld 2.1 中，推理强度设为中等，它就能超过 GPT-5.6 Terra 的最佳成绩。

OpenAI 称今年在减少幻觉和事实错误上投入了大量资源，内部测试用的是一组容易诱发错误的提示词。低推理强度下错误率从 GPT-5.6 Terra 的 53.6% 降到 16.7%，下降近 37 个百分点；最高推理强度下错误率降 18 个百分点至 4.3%，接近 GPT-6 Astra 和 GPT-6.1 Sol。命令行解题基准 Terminal-Bench 4.0 上，最高推理强度可解决 50.3% 的任务，是 GPT-5.6 Terra 已公布成绩 21.5% 的两倍以上。官方同时说明，最复杂的编程任务仍应交给 GPT-6.1 Sol 和 GPT-6 Astra。

在 OpenAI 的准备框架里，网络安全能力划有风险阈值，GPT-6.1 Terra 这次落在「严重」一档，防护措施沿用了为 GPT-6 Astra 开发的那一套。官方称它比 GPT-5.6 Terra 更倾向于在任务范围内行事，也会如实说明自身局限；在提示词注入测试中，它对试图令其偏离用户任务的恶意指令抵抗力较强。

Plus、Pro、Enterprise 和 Edu 用户即日起就能在 ChatGPT 工作和 Codex 中用到 GPT-6.1 Terra，开发者可通过 API 以 gpt-6.1-terra 调用。标准定价为每百万输入 token 1 美元、缓存输入 0.05 美元、输出 5 美元。
