OpenAI 正式發布平衡型 AI 模型 GPT-6.1 Terra，標準 API 價格比 GPT-5.6 Terra 便宜 50%，同時在電腦操作、視覺推理及編程能力展現顯著突破。Plus、Pro、Enterprise 與 Edu 用戶現時可於 ChatGPT Work 和 Codex 啟用，開發者亦能透過 API 串接。

GPT-6.1 Terra 整體表現直逼旗艦模型 GPT-6 Astra，每個 token 價格僅為後者十分之一，任務處理速度更比 GPT-6 Astra 與 GPT-6.1 Sol 快逾 3 倍。若對比最高推理強度下的 Claude Opus 5.5，Terra 的 token 效率高逾 3 倍，每個 token 價格僅需四分之一，單項任務成本降低約 9 倍。

視覺推理與電腦操作大幅強化

在評估視覺推理能力的 MMMU-Pro 測試中，GPT-6.1 Terra 在所有推理強度皆超越 GPT-5.6 Terra，成績緊追 GPT-6 Astra 及 GPT-6.1 Sol。針對桌面應用程式操作的 OSWorld 2.1 測試，GPT-6.1 Terra 只憑中等推理強度，便打破 GPT-5.6 Terra 最佳紀錄，大幅壓低單項任務成本。

編程表現方面，GPT-6.1 Terra 於 Terminal-Bench 4.0 最高推理強度下成功解決 50.3% 任務，較 GPT-5.6 Terra 的 21.5% 增倍。然而應對極度複雜的編程工作時，GPT-6.1 Sol 與 GPT-6 Astra 依然是能力上限更高的選擇。

▲ AI 基準測試「Agents’ Last Exam v1」結果顯示，多款大語言模型在成本與得分表現各異；其中 GPT-6.1 Terra 在維持低於 1 美元成本下取得接近 60% 得分，Claude Opus 5.5 則以最高得分近 64% 居首，但單次成本接近 9 美元

性價比大幅提升 未知猜測比例減半

獨立評測數據顯示，GPT-6.1 Terra 大幅推高每元智能表現基準。最高推理強度下，其智慧指數比 GPT-5.6 Terra 高 6 分，單項任務成本更由 1.4 美元（約港幣 HK$10.9）驟降至 0.4 美元（約港幣 HK$3.1）。在 Coding Agent Index v2.0 測試，Terra 取得 48 分，落後 GPT-6.1 Sol（54 分）6 分，但比 GPT-6 Luna（31 分）大幅領先 17 分。在 AA-Omniscience 測試中，Terra 面對未知答案胡亂猜測的比例亦由 88% 降至 38%，準確度提升 2 分。

在 ChatGPT Work 與 Codex 運作環境下，相同配額可處理任務量遠超 GPT-5.6 Terra，亦明顯多於 GPT-6.1 Sol 或 GPT-6 Astra。開發者現已能透過模型名稱 gpt-6.1-terra 串接 API。

系統安全評估顯示，Terra 防範間接提示注入攻擊成功率達 98.8%，優於 GPT-5.6 Terra 的 96.2%。面對針對指令層級的直接攻擊，Terra 則與 GPT-6 Astra 及 GPT-6.1 Sol 表現看齊，後兩者在該項目防護率高達 99.99%。

▲ 在「OSWorld 2.1, offline set」基準測試中，Claude Sonnet 5.5 以接近 84% 得分居首，單次成本約 5.7 美元；GPT-6.1 Sol 與 GPT-6.1 Terra 則展現極高性價比，在 1 美元左右成本下取得 74% 至 78% 得分；而 GPT-6 Astra 雖得分破 80%，但成本超過 8 美元。
