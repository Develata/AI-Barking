Abstract

We refute the Exponential Time Hypothesis (ETH) by presenting a deterministic algorithm for 3-SAT on n variables that runs in 2o(n)2^{o(n)}2o(n) time. Our algorithm in fact solves the harder problem #3-SAT, providing a count of the number of satisfying assignments.

The result was discovered by an internal research Claude model and has been formalized in Lean 4.

Provenance statement

The core algorithm was found on October 16 by an internal Claude research model with 14M output tokens and no human input. Anthropic researchers worked with Claude to improve the presentation, resulting in this paper. Independently and concurrently, an internal model at OpenAI claims to have proven a similar result.
