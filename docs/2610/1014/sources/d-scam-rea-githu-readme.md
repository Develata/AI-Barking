## Getting Started
1. Download the x64 zip.
2. Extract. Run `npx rea-agents@latest setup` or the shipped cli.
3. Point Hopper / Ghidra / IDA if you already have one.
4. Ask the agent to inspect a binary or app.
5. Notes in `files/notes/`.

## FAQ

**Source needed?**
No. REA inspects the built app and reports evidence.

**Windows Ghidra?**
Experimental host path. See the CLI guide.

## Requirements
Windows 10/11 x64. Node for npx. Optional Hopper / Ghidra / IDA.
