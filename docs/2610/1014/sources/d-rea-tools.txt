How it works

 Reverse engineering means learning how software works by inspecting
 the program itself. With REA, your agent can follow the code,
 explain a feature and help you rebuild it.

Ask about one feature

Give your agent a program or page and a question.

Inspect the program

REA returns code, references and runtime observations.

Explain it, then try a change

 Your agent uses the findings to explain or rebuild the feature.

Example 02 · Windows Calculator

Rebuild Calculator’s % button.

 The % button does different things after + and ×. Let’s find both
 rules and try them in a small calculator.

1. Ask about the % button

 Example question · Calculator

 Copy

 ›Use REA to inspect Windows Calculator’s % button. Recover
 the rules after + and ×, then build a small calculator that
 uses both.

2. Find both rules

 REA helps the agent read the code behind the % button. It
 applies two different rules:

With +

 Take 10% of the first number.10% of 200 = 20 → 200 + 20 = 220

With ×

 Turn 10% into 0.1.200 × 0.1 = 20

3. Try the % button

 We recreated both rules below. Choose + or ×, press %, then
 press =.

 For this example, previous = 200 and
 current = 10.

 Readable summary of the % handler

if (operation == multiply || operation == divide) {
 percent = current / 100;
} else {
 percent = current * previous / 100;
}
