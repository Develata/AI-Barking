## 二、可能的吠点（L6 线索，进正文前须回到一手核实）

1. Anthropic 原文点名并链接了 Sapling，Mononoke 是 Sapling 的服务端；“Mononoke was not mentioned at all”字面属实，但“未致谢”的框架漏了这一点（Anthropic 原文：“Meta’s Sapling … hard-won lessons”；Mononoke README：“Mononoke is the server built for the Sapling Source Control System”）。Lobsters bakkot（14 分，https://lobste.rs/c/p281xp）：读完博文“angry on the author's behalf”，后发现 Anthropic 其实致谢了 Sapling，转而对博文作者“not stating this up front”不满。simonw（18 分，https://lobste.rs/c/wk6js5）、HN BryantD（https://news.ycombinator.com/item?id=50095356）同样指出。
2. 作者本人立场：反对的是署名而非复制（“I do not have a problem with Anthropic copying Mononoke’s design”）；Mononoke 开源，代码为 GPL-2.0（C4）。“抄袭”一词在作者原文里是“borders on plagiarism”。
3. 作者自己说的更强的话在博文**之外**：HN 评论（https://news.ycombinator.com/item?id=50099795，2026-10-15 06:00 UTC = 14:00 北京时间，截图 29-hn-author-claim.png）：“As I suspected at the time of writing the post (but could not verify) and as was later confirmed in private correspondence to me, Anthropic did not come up with this from first principles. Claude was pointed directly at Mononoke and asked to re-engineer it.”；Lobsters（https://lobste.rs/c/wtwktk，33 分）：“I have since privately received information that this was done in bad faith”。这些均为作者转述的私下信息，对方不明、不公开；读者 mcherm（https://lobste.rs/c/qudpbt，14 分）：“It would certainly change my beliefs if I had any evidence beyond your bare statement.”作者答：“obviously I'm not going to share private correspondence”。博文本身只写“I think the level of imitation goes well beyond…”，并无“被指示照着 Mononoke 做”的内容。正文若写，只能写“作者称”，且不能写成已证实。
4. 博文假设式的 LLM 实验“If you ask Opus 5.5 or GPT-6 Astra…”只证明模型能认出相似，不证明 Anthropic 的设计流程用了 Mononoke；作者同在 HN 称自己起初“assumed Claude came up with it from its training data”（Lobsters https://lobste.rs/c/cdyjhs：“I was charitable when I assumed Claude came up with it from its training data.”）。
5. “derived data / 索引是通用思路”的反驳：HN Mawr（https://news.ycombinator.com/item?id=50099374）：“Coming up with the idea of an index is not a novel thought.” 作者回复（https://news.ycombinator.com/item?id=50099795）：相似之处延伸到整个服务端，核心是 Bonsai changeset ↔ Scion changeset，而不只是 derived data。HN 评论没有显示分数（Algolia 与页面均不给评论分）。
6. “Mononoke 并非可直接用的产品”的反驳：Lobsters mk12（12 分，https://lobste.rs/c/yhtg4n）称“There's a reason no one uses Sapling at scale besides Meta”，并引 README 说 Mononoke 与 EdenFS 为 OSS 不受支持；simonw（16 分，https://lobste.rs/c/ppmvzn）称把大量 AI 生成改动倒进 Sapling 未必受欢迎。（本组已核 Mononoke README 有“The version that we provide on GitHub omits some functions”，但 mk12 引的那句未核。）
7. 另一半：Anthropic 文章署名人员（“Nick G. and the source control team…”）与 Meta 源码管理团队是否重叠，作者称“overlapping group of people”（Lobsters https://lobste.rs/c/ftljxs，41 分，“what I've been told”）。本组未能证实；Anthropic 原文只用名字缩写，不记入。
8. 与 1013 期速览的关系：Anthropic 原文自己写 “Scion is by no means a suitable replacement for git for general use”、“difficult to offer Scion in a form that would be broadly useful”（C6-a）；争议并未涉及 30,000/日等数字。

## 四、扫描说法勘误

- “Scion 不开源、无许可证、无官方仓库”：原文无仓库、无开源表态，且明说难以对外提供（C6-a）；但“无许可证”原文未讨论，只能写“原文未提供源码”。
- “GitHub 上自称 OpenScion 的项目与 Anthropic 无关”：不止一个同名项目；tinyhumansai/openscion README 自述“follows the design Anthropic described”，未写与 Anthropic 无关；bnsd55/open-scion 与 CarterT27/scion 明确写了不隶属 Anthropic（C6-b）。
- “Anthropic 未回应”：截至 17:22 北京时间未见回应，属“未找到”，不是“拒绝回应”（C5）。
- 派工单已知情况中“Anthropic 原文只以 hard-won lessons 致谢 Sapling、全文未提 Mononoke”：属实，但需同时写明点名并链接了 Sapling（C3-a）。
- 派工单写 HN 367 分：17:21 北京时间取为 369 分 / 135 评论（C7）。
- 作者文章里没有“Claude 被直接指向 Mononoke”的说法；该说法出现在 HN 与 Lobsters 评论，且基于未公开的私下通信（见吠点 3）。
- 作者文章里，Anthropic 被称“yesterday”发文，与 Anthropic 页 “Published Oct 13, 2026”相符。
- 作者原句是 “borders on plagiarism”，不是“plagiarism”。
