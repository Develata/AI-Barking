Anthropic's Scion is heavily inspired by Mononoke [https://api.daily.dev/r/CJGzwv5qx]

The creator of Facebook's Mononoke source control server points out that Anthropic's newly announced version control system, Scion, closely mirrors Mononoke's architecture — specifically its use of 'derived data' to speed up operations like blame. The author, who worked on Mononoke and described this same concept in materials from 2022, says the imitation goes beyond shared insight, contrasting it with Cursor's Vicent Marti blog post on git scaling, which has similar goals but different design choices. The author has no issue with the design being copied since Mononoke is open source, but argues that as LLMs trained on open-source code increasingly influence new system designs, giving credit to prior art is both easier and more important than ever — noting that asking Claude Opus or GPT models about prior art immediately surfaces the Mononoke connection.

Questions this post answers

What is the 'derived data' concept used in Mononoke and Anthropic's Scion version control system?

Derived data is a design concept where expensive-to-compute information, such as blame history, is precomputed and cached separately from the raw version control data, making operations like blames much more efficient. Mononoke, the source control server built for Facebook, used this concept as early as 2017-18, and Anthropic's new system Scion reportedly uses a nearly identical approach. Developers evaluating new version control architectures can follow design debates like this one on daily.dev.

Is Anthropic's Scion version control system based on Mononoke's design?

Scion's described use of 'derived data' for efficient operations like blame closely parallels Mononoke's 2017-18 design, according to one of Mononoke's original builders, who argues the similarity goes well beyond coincidental shared insight. The claim is partly based on asking Claude Opus 5.5 and GPT-6 Astra about prior art, both of which immediately identified Mononoke as the precedent. Anyone comparing version control systems and their lineage can track these design disputes on daily.dev.
