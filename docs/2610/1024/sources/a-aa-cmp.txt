AA-Briefcase Elo is a combined metric that aggregates analytical quality Elo, presentation Elo, and rubric pass rate, with rubric performance converted into Elo via synthetic head-to-head matches. Elo and 95% confidence interval bounds are clamped at 0.

AA-Omniscience Index

AA-Omniscience Index (higher is better) measures knowledge reliability and hallucination. It rewards correct answers, penalizes hallucinations, and has no penalty for refusing to answer. Scores range from -100 to 100, where 0 means as many correct as incorrect answers, and negative scores mean more incorrect than correct.

End-to-End Response Time

Seconds to receive a 500 token response. Key components:

Input time: Time to receive the first response token

Thinking time (only for reasoning models): Time reasoning models spend outputting tokens to reason prior to providing an answer. Amount of tokens based on the average reasoning tokens across a diverse set of 60 prompts (methodology details [/methodology/performance-benchmarking]).

Answer time: Time to generate 500 output tokens, based on output speed

Frequently Asked Questions

Which is more intelligent, Kimi K3.1 Pro or Claude Opus 5.5 (Max, Default Fallback)?

Claude Opus 5.5 (Max, Default Fallback) is more intelligent. Claude Opus 5.5 (Max, Default Fallback) scores 58, compared with Kimi K3.1 Pro at 55 on the Artificial Analysis Intelligence Index.

Which is faster, Kimi K3.1 Pro or Claude Opus 5.5 (Max, Default Fallback)?

Claude Opus 5.5 (Max, Default Fallback) is faster. Claude Opus 5.5 (Max, Default Fallback) generates 96.2 tokens per second, compared with Kimi K3.1 Pro at 57.5 tokens per second.

Which is cheaper, Kimi K3.1 Pro or Claude Opus 5.5 (Max, Default Fallback)?

Kimi K3.1 Pro is cheaper. Kimi K3.1 Pro costs $1.54 per 1M tokens, compared with Claude Opus 5.5 (Max, Default Fallback) at $2.94 per 1M tokens (7:2:1 cache hit/input/output ratio).

Which has lower latency, Kimi K3.1 Pro or Claude Opus 5.5 (Max, Default Fallback)?

Kimi K3.1 Pro has lower latency. Kimi K3.1 Pro has a time to first token of 3.07s, compared with Claude Opus 5.5 (Max, Default Fallback) at 652.61s.

Which has a larger context window, Kimi K3.1 Pro or Claude Opus 5.5 (Max, Default Fallback)?

Both models have a context window of 1.0M tokens.
