证明过的软件，就没漏洞？

AI 沸点，今日谁吠？

省流：Claude 写出大规模软件安全证明，证明覆盖什么，比代码有多长更重要。PHP 漏洞让软银暂停灾害警报，这是维护停发，不能说成已经被黑。Canva 推出自研生图模型，宣传里的“第二”说的是实验室，不是模型。

一、AI 写证明，安全有边界

Anthropic 称，Claude 为239个软件测试入口生成约1.8亿行 Rocq 证明代码，由证明检查器检查。它还会先修掉发现的错误，再为修改后的程序证明。

这比“跑很多次没出错”多走了一步：在给定模型和条件下，证明所有符合条件的输入都不会触发规定的错误。

吠点：
①证明的是指定入口，不是整个软件没有漏洞。条件包括小于64 MB 的输入、RISC-V 架构、单线程静态程序、固定内存预算，以及所建模的 Linux 行为；不能直接套到你电脑上的所有运行环境。
②会检查证明，不等于会检查题目有没有出错。规格是否完整、机器模型是否贴合现实，仍是边界。研究方还承认：允许 AI 修改程序，可能诱使它为了过证明而改掉原本功能；团队用惩罚改动、记录和审计补丁等办法约束，不等于风险被消除。

二、漏洞修补，警报先停了

软银公告：为处理 PHP 漏洞，旗下三个品牌暂停紧急灾害警报。涉及 SoftBank、Y!mobile、LINEMO 用户的地震、海啸和灾害避难信息。

暂停始于北京时间10月23日05:47，预计26日完成维护。官方建议临时使用 Yahoo! 防灾速报等服务接收信息。

吠点：停的是公告列明的警报服务，不是全部通信。公告没有确认系统已遭成功入侵；“预计完成”也不能写成已经恢复。

三、Canva 的“第二”是哪种

Canva 发布自研图像模型 Craft，已在 Dream Lab 和公共 API 预览中提供。生成图可通过 Magic Layers 转成可编辑设计元素。

吠点：Canva 援引 DesignArena 排名宣传自己是第二名实验室，同一公告写的模型排名却是第四。别把两个对象混为一谈；也别把生成图片说成直接产出分层设计稿，转换还要靠另一项功能。其 MCP 接入仍标为即将推出。

AI 吠点：聊 AI 沸点，轻松识破吠点。
