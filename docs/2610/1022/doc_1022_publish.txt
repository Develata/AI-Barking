Claude写证明，软件就安全了？

AI 沸点，今日谁吠？

省流：Claude 给软件写安全证明，但不能当成整套软件的无漏洞保证。PHP 漏洞让软银停发灾害警报，维护停发不等于确认被黑。Canva 自研生图模型上线，宣传里的“第二”是实验室排名。

一、AI 写证明，安全有边界

Anthropic 称，Claude 为239个软件测试入口写出约1.8亿行证明代码，由专门的程序检查。发现错误就先修补，再证明改过的版本符合要求。

这和“测了很多遍没出错”不同：它要证明，所有符合条件的输入都不会触发约定的错误。

吠点：
①保证有范围。证明只覆盖指定入口；输入须小于64 MB，程序单线程运行、静态链接、内存预算固定，还限定了 RISC-V 处理器和 Linux 系统模型。换个环境，结论不能直接照搬。
②证明通过，规则也可能没写全，机器模型也可能与现实有差距。还有“改题过关”的风险：AI 获准先改代码再证明，可能为了过关改掉原本功能。研究方承认这点，用惩罚改动、记录和审计补丁等办法约束。

二、漏洞修补，警报先停了

软银公告：为处理 PHP 漏洞，旗下三个品牌暂停紧急灾害警报。涉及 SoftBank、Y!mobile、LINEMO 用户的地震、海啸和灾害避难信息。

暂停始于北京时间10月23日05:47，预计26日完成维护。官方建议临时使用 Yahoo! 防灾速报等服务接收信息。

吠点：警报停发不等于全部通信中断。这份公告说的是漏洞维护，没有确认系统已被攻陷；26日也只是预计完成日期。

三、Canva 的“第二”是哪种

Canva 发布自研图像模型 Craft，已在 Dream Lab 和公共 API 预览中提供。Magic Layers 可把生成图转成可编辑的设计元素；Craft 的 MCP 接入仍待推出。

吠点：官方援引 DesignArena 宣传自己是“第二名实验室”，但 Craft 这个模型排第四。排名对象换了，意思就变了。图层也要分清：生成的是图片，再经另一项功能转换，不能说成模型直接输出分层设计稿。

AI 吠点：聊 AI 沸点，轻松识破吠点。
