# 1030 期标题候选

上限20字（保守口径，标点、字母、数字各算1字）。勾选项：A 读者只看标题能知道出了什么事；B 每个分句有锚点（认得的名字、数字或动作）；C 问号只问确有人这么说的说法；D 无“被曝、被指、疑似、称”等摘要腔；E 无风控词（政府等）。

| # | 候选 | 字数 | 钩子类型 | A | B | C | D | E | 备注 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | Claude取消5小时限制？苹果接千问 | 19 | 切身相关 + 当事人 | ✓ | ✓ | ✓ | ✓ | ✓ | 问号问“取消限制＝不限量”的流行读法（有中文稿写“5 小时限额直接取消”漏了“已验证”）；第二分句是事实，苹果接千问对国内读者最切身。**选用** |
| 2 | Claude为20x道歉？苹果接千问 | 18 | 当事人反差 | ✓ | ✓ | △ | ✓ | ✓ | 最抓人；但道歉的是 Anthropic 订阅产品负责人个人发帖（L2），“Claude 道歉”把员工发言写成公司，且读者不知道 20x 是什么 |
| 3 | Claude删掉20x？苹果接入千问 | 18 | 反常数字 | △ | ✓ | △ | ✓ | ✓ | 改名删掉“20x”是事实；问号问的不是谁的说法，读者不知道 20x 是什么 |
| 4 | 200美元档不限时？iPhone接千问 | 19 | 反常数字 + 切身相关 | △ | ✓ | ✓ | ✓ | ✓ | 两家 200 美元档都覆盖，但第一分句没有主语，看不出是哪家 |
| 5 | iPhone接千问，Siri却没变？ | 18 | 切身相关 | ✓ | ✓ | ✓ | ✓ | ✓ | 只覆盖第二条；“Siri 没变”不准确（Siri 部分请求会接千问，只是不含 Siri AI） |
| 6 | 20x原来只算5小时？ | 11 | 反常数字 | △ | △ | ✓ | ✓ | ✓ | 只覆盖第一条，没有主语 |
| 7 | Claude不限时了？iPhone接千问 | 20 | 动作画面 | ✓ | ✓ | △ | ✓ | ✓ | “不限时”比原文更夸张，周限额仍在，标题先给一个错印象 |

交付终审时列：#1（选用）、#2、#5。
