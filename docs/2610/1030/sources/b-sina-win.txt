ChatGPT Pro 用户这波赢麻了！充多少返多少，Codex 额度再翻倍！

ChatGPT Pro 用户这波赢麻了！充多少返多少，Codex 额度再翻倍！

 2026年10月30日 06:00
 市场资讯 [https://mp.weixin.qq.com/s?__biz=MzkwMzYzMTc5NA==&mid=2247523029&idx=1&sn=5e3c1a53720dd663310f78245b16969b&chksm=c12eca0e5f4f5b274cbb6c3f02bf91b34ba48774b0303d6e92628ef0dfa5fe687ac05eaf71f1&scene=0&xtrack=1]

ChatGPT Pro 用户，这两天赢麻了。

先是 OpenAI 送额度，充多少、返多少。

ChatGPT Pro 100、Pro 200、Pro 500 三个档位，每个月分别送 100、200、500 美元的 API 额度。ChatGPT Business 团队版也有份，一个工作区（Workspace）每月最多能领 500 美元。

送完额度的第二天，就在刚刚，Codex 负责人、重置哥 Tibo 又来加码，额度翻倍。

ChatGPT Pro 100 和 Pro 500 在 ChatGPT Work、Codex 里的额度翻倍，Business 高级席位也一起翻倍；上个月还说要下调额度的 Pro 200，这次也收回成命，原来额度高的保持不变，已经被降过的翻倍补回来。

重置哥立过军令状，28 天里每天要么发布一项改进，要么给所有人重置一次额度。今天是第 25 天，他本人还自嘲了一波，「重置公司升级成 Token 公司了。」

这张得划一会儿

送 API 额度拉拢人心这一招，Anthropic 10 月初刚用过。同样的招式和套路，OpenAI 照搬了一遍。

网友调侃，「这不就是抄 Claude 的作业嘛。」

抄不抄的暂且不谈，羊毛先薅了再说。

领之前，有三个坑最容易踩，第一个月一般拿不到全额；用谷歌 Google Play 订阅的，大多看不到领取入口；领额度时选错了 API 所在的组织，自己改不回来。

来，我们一一细说。

01｜谁能领，领多少

ChatGPT Pro 最好算，充多少返多少。

ChatGPT Business 按席位算。

每个标准席位（Standard）送 20 美元，每个高级席位（Premium）送 100 美元，全工作区合在一起，每月最多送 500 美元。

比如 10 个标准席位加 4 个高级席位，算下来 600 美元，超过上限了，就按 500 美元发放。

年付的 Business 订阅还有个特殊待遇，一次性给你发放全年的额度，最多 6000 美元，到年度账单周期结束才过期。

有网友已经领到了 6000 美元 API 额度。这位才是真大神。

划重点，第一个月一般拿不到全额。

第一笔额度按你当前账单周期剩余的天数折算，从下个周期开始才能全额领取。

计算方法是这样的。档位金额乘以这个账单周期剩下的天数，再除以整个周期的天数。比如 ChatGPT Pro 200 订阅，距离续费还剩 10 天，首月大约只能领 67 美元。

所以别慌，你领少了不是 bug。

有 ChatGPT Pro 500 老哥抱怨「怎么才给 287 美元，这不是误导人吗。」最惨的一位网友第二天订阅就到期，只领到了 6 美元。

领取前，弹窗里会先显示这次能领多少，下个周期发放多少。就像这样。

ChatGPT Plus、免费和赠送的订阅都领不到，企业版、教育版也不在活动范围内。Plus 用户纷纷喊冤，「Plus 不配吗？」

领取前，你还要满足三个条件。

订阅付费满 7 天；

你得是这个订阅（或者 Business 工作区）的所有者，同时是接收额度的那个 API 组织（OpenAI 开发者平台上的账户）的所有者；

ChatGPT 账号和 API 账号要用同一个邮箱。

ChatGPT Business 拼车的朋友注意了，只有工作区所有者才能领这个羊毛，API 额度全部进入工作区所有者绑定的那个 API 组织，成员账号上看不到领取入口。

02｜保姆级领取教程，两种方法

最简单的，在 ChatGPT 里领。

登录 ChatGPT 网页版，打开设置里的账单详情页（Settings → Billing），Business 的所有者打开工作区的账单设置或管理后台（Admin Console）。

此时页面上会多出一张「每月订阅权益」卡片，点击右下角的「Link organization」（绑定组织）领取。

之前没用过 OpenAI API 的，不用先走 API 平台的新手流程，绑定这个个人组织（Personal）就行。名下有好几个组织的，一定要在这一步选准，选错了自己改不回来。

点击「Link & claim」（绑定并领取）。

账单页底部会多出一栏「API 订阅权益」，状态显示「Active」（生效中）。

另一种方法是在 OpenAI 开发者平台领，我就在这儿领的。

用订阅邮箱登录 platform.openai.com，左下角切换到你准备接收额度的组织。

打开账单页（Billing），同样能看到这张卡片，点击「Link organization」，选择你名下的订阅或者 Business 工作区，确认就行。

领完以后，在开发者平台账单页的 Credit grants（额度明细）里，能看到这笔钱和过期日期。

绑定一次就行，之后只要活动还在、订阅还符合条件，额度就会自动到账。

钱到账了，下一步是创建 API Key。

你可以在开发者平台左侧的「API keys」页面新建一个。注意，Key 要创建在绑定了额度的那个组织下面。

更省事的方法在 ChatGPT 或 Codex 里安装 OpenAI Developers 插件，让 Agent 帮你创建。

找不到领取入口？

先检查这四项。套餐对不对、付费订阅满没满 7 天、选择的工作区对不对、登录的邮箱匹不匹配。

用谷歌 Google Play 订阅的用户，大多看不到领取入口。苹果 App Store 内购的，目前没有这个问题。

OpenAI 官方没有解释原因。Anthropic 那边的同款福利，iOS 和安卓 App 里订阅的都能领。

03｜这笔钱，怎么花

这笔 API 赠金，OpenAI 官方点名的用途包括这几类。

Responses API 和 Chat Completions（对话补全）接口，处理文本、代码，也能看懂图片，日常调用模型基本都用这两个

Agents API，运行智能体，OpenAI 托管沙箱的费用也能从额度里扣

Decisions API，不聊天，只做判断，能回答是非题、选择题和打分题

GPT-Live 和 Realtime API，实时语音对话

Images API，生图和改图

内置工具，联网搜索、文件检索、代码解释器，连同它们的调用费和存储费

嵌入模型（Embedding）、语音转写、文字转语音这些服务没被点名，不过它们的用量同样记在组织名下，理论上也能从这笔额度里扣。

例外只有一个，用 API Key 登录 Codex 时产生的用量，不能从这笔额度里扣。

Anthropic 的 API 赠金也一个样，不能用于 Claude Code。

04｜100 美元，能用多少

来粗略一算。

OpenAI API 官方价格，GPT-6.1 Terra 每百万输入 token 1 美元、输出 5 美元；GPT-6.1 Sol 输入 2 美元、输出 10 美元；GPT-6 Astra 输入 10 美元、输出 50 美元；最便宜的 GPT-6 Luna 输入 0.10 美元、输出 0.50 美元。不着急要结果的任务改用 Batch 批量接口，还能打五折。

以 100 美元为例，大致能用出这样的效果。

综合来看，生图和 GPT-Live 实时语音对话还是非常香的。

05｜六个坑，一定要看

额度到期清零。

当前账单周期结束前没用完的，全部作废，也不能顺延到下个周期。

不绑卡，就不会多扣钱。

只要赠送额度还有余额，你的 API 组织就不用绑定支付方式。

扣费顺序是先扣赠金，再扣你自己充值的。什么都不剩了，请求会报 429 错误，错误码 credit_balance_exhausted。如果你之前绑过卡、还开启了自动充值，赠送额度用完就会接着扣你的钱，建议去限额那里设置一个每月消费上限。

送了额度，限速不一定跟着放宽。

OpenAI API 按「用量等级」分档，累计充值越多，限速越宽松。

没充过钱的组织属于免费档，限速比较紧张。好消息是，符合条件的订阅权益也能提升用量等级，你领完额度，API 组织可能就自动升级了。

组织选错了，自己改不回来。

一个订阅只能绑定一个 API 组织，一个 API 组织也只能绑定一个订阅，绑定以后要换，只能联系 OpenAI 的客服，而客服也不保证额度能转移过去。

一位网友用个人账号开通的 Business，额度却绑定到了公司的 API 组织，系统给公司组织里的所有人都发了通知邮件。

订阅一变，额度跟着变。

升级 Pro 档位，当期可能按剩余时间再补发一笔；取消订阅，已经发放的额度照样能用到过期；降级到 ChatGPT Plus、Go 或免费版，本周期结束时自动解绑；从 ChatGPT Pro 换成 Business，原来的绑定自动解除，要等工作区付费满 7 天再重新绑定。

额度别卖。

OpenAI 明令禁止转让、出售、送人或交易额度，一旦发现，额度可能被收回，账号也可能被封，不退款。当然也别把 Key 交给 API 中转站。

充多少、返多少 + 额度翻倍，ChatGPT 这波操作，有点爽。
