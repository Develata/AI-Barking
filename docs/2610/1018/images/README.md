### 3:4 竖版提示词

竖版 3:4 封面插画。画风：19 世纪雕版股票凭证与老钞票——米白色厚纸底，墨绿色与酒红色两种油墨，细密的雕版排线与扭索纹（guilloche）花边，像一张老式股票凭证的版面；所有物件和看板娘用同一套雕版线条画法，整体是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。
最上方是主标题，分两行：“Anthropic要捐3200亿？”“DeepSeek开源第一？”。粗壮的酒红色无衬线大字，带米白描边，是全画面最醒目的元素，宽度占画面约九成，每个字都清楚可读。不要副标题。
画面中下部摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一张带扭索纹花边的大股票凭证，凭证一角被一把大剪刀剪下一小块三角，三角上写“5%”；剪下的三角用一根细绳仍然系在凭证上，没有真正离开；凭证上除了“5%”不写任何字；
2. 右：一座奖杯，左半边是金色、右半边是银色，像被从中间拼起来的两半；奖杯上不写字、不写数字。
看板娘按参考图（蓝色长发、狗耳、鲸鱼尾巴、女仆装、胸前“AI 吠点”圆牌；双手是正常的人手，不戴肉垫手套）在画面下方居中出镜，同样用雕版线条画风（头发保持蓝色、胸牌保持“AI 吠点”）：一手举着放大镜对着那根系住三角的细绳，一手叉腰，歪头挑眉，表情狐疑。她只有两只手、两只耳朵、一条尾巴，全身入画。
画面里除了主标题、“5%”与胸牌“AI 吠点”，不要出现任何其他文字、数字、国旗、logo、品牌标志或真人。
