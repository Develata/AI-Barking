成本砍掉90%！DeepSeek-V4.1-Flash 重磅升级：逆袭成为 WebDev 榜首开源模型

 2026-10-19 10:29
 ·

 来源： AIbase基地 [https://www.aibase.com/news/31712]

开源大模型领域再次迎来技术爆破!根据 Arena 官方最新发布的评测榜单，DeepSeek 团队推出的最新模型迭代版本 DeepSeek-V4.1-Flash-20261017（Max） 正式登顶 Code Arena: WebDev 榜单，成功摘得“第一开源模型”的桂冠。

值得关注的是，在本次 WebDev 前沿代码与网页开发基准评测中，DeepSeek-V4.1-Flash-1017不仅成功超越了此前备受关注的 Kimi K3（Max），更在推理成本上实现了数量级的突破——其调用开销仅为后者的十分之一左右。在性能与性价比之间，再次刷新了行业认可的帕累托最优边界。

在总榜表现方面，该模型以1670分的成绩位列总榜第12名。在这一高位区，它不仅领先于封闭源领军模型 Claude Opus5（High），并且与顶尖模型 GPT-6Sol (Max) 的差距已缩小至10分以内。

根据官方介绍，本次推出的1017版本作为深度优化迭代，相较于一个月前发布的上一版（20260910），榜单得分大幅提升了52分。模型在保持极低定价策略(每百万输入 token0.3美元，输出 token1.2美元)的同时，进一步加快了复杂任务的完成速度，并显著精简了冗余输出，帮助开发者在实际调用中进一步节省算力和时间成本。

目前，DeepSeek-V4.1-Flash-1017已同步在 DeepSeek 网页端、移动端 App 以及 API 接口上线。针对开发者生态，官方已对 DeepSeek Harness、腾讯 CodeBuddy 以及 WorkBuddy 等多款主流 AI 编程与 Agent 辅助工具进行了专项适配优化。开发者只需将框架升级至 DeepSeek Harness v0.2.1-rc.1或更高版本，即可无缝解锁该模型的最高性能体验。
