## 二、可能的吠点

每条原文在上表或存档中可回溯。

1. “开放模型第一”只在 **Arena WebDev 一个榜**成立，且按 Arena 自己的许可标签（含 “Kimi K3 license”“qwen-community-1.0” 等）分；在 AA 的开放权重榜 MiMo-V2.6-Pro（46）高于 1017（45），在 LiveBench 的 “open” 行里 1017 最高（79.2）。三个榜三种口径，结论互不相同（出处：B2b、B6、B7a）。
2. “超过 Kimi K3”：分差 1664 对 1655，置信区间 1649.1–1678.9 与 1648.8–1660.8 重叠，Rank Spread 8–16 与 11–16 重叠，按 Arena 自己的定义两者“并列”（Arena 博客：“two models are tied if their rank spreads overlap”）。1017 的票数只有 1,830（Kimi K3 19,481），区间 ±15。
3. “10x lower cost”：Arena 帖里写的是 $0.3/$1.2 对 Kimi K3 $3/$15 的**每百万 token 挂牌价**（散点图横轴也是 “Blended price per 1M tokens”），不是完成同一任务的花费。AA 的每任务成本是 $0.26 对 $2.00（同表可查）；两个口径是不同的东西。TokenPost 把输入/输出分别算成 10% 和 8%。

7. 啰嗦：AA 自己写 “very verbose”，210M token 对中位数 140M，Verbosity #39 / 47；每任务输出 token 柱高 89k，旧版也是 89k（图 21）。
8. AA 的 “Max” 是最高思考档；HN 有用户称 max 档 token 用量远大于 high、收益很小（见下评论），AA 页面目前只给 1017 (max) 一档。

10. OpenRouter 1017 页 “Benchmarks” 区挂的是旧版 AA 分数（Intelligence Index 39.5），且页首价格 $0.05/$0.15 是最便宜提供商的价，不是 DeepSeek 自家价 $0.30/$1.20。
11. AA 的 “Cost per Task” 含缓存命中价（“Cache Discount 98%”），缓存命中比例会影响任务成本（页面说明：“Each evaluation’s cost is calculated from input, cache hit, cache write, reasoning, and answer token prices”）。1017 与旧版的 Cache Discount 同为 98%，页面未给两版的实际缓存命中率。
12. 总参数：AA 现页 552B，AA 9 月原帖 763B，OpenRouter 文字 “552B-parameter backbone”；1016 已记 HF 卡约 763B。口径不同（见 1016 存档）。
