TL;DR

HybridAgent reports a 10.4% average performance gain over frontier LLM agents across 11 benchmarks at three model scales.

The paper claims 35.5%-54.7% fewer tokens, 1.8x-2.6x faster inference, and 2.7x-3.7x cost savings versus text-based baselines.

A lightweight 'HybridLink' toggles between latent reasoning and text, letting the agent think silently then surface into text to call tools.

An agent that switches mid-generation between text and silent 'latent' reasoning posts a 10.4% average performance gain over frontier LLM agents while using 35.5% to 54.7% fewer tokens, running 1.8x to 2.6x faster, and costing 2.7x to 3.7x less across 11 benchmarks at three model scales, according to a new arXiv preprint titled 'Hybrid Reasoning Agents' [https://arxiv.org/abs/2610.18861].

The pitch is a toggle. The authors describe a 'lightweight HybridLink' that 'enables seamless transitions between text and latent modes', paired with a 'continuous working memory' preserving 'lossless hybrid context across multiple turns'. The agent reasons silently in latent space when internal thinking is cheaper and surfaces into text when it needs to invoke a tool, which standard latent-reasoning setups cannot do natively.

Training is split into two post-training stages. 'HybridSFT stabilizes tool-integrated hybrid generation by teaching the backbone to coordinate with HybridLink', the paper says, and 'HybridRL scales reasoning by learning when to think in latent space and when to act through text'. The 11 benchmarks span mathematics, science, medicine, search, and agentic reasoning.

Code and data are posted at github.com/togethercomputer/HybridAgent [https://github.com/togethercomputer/HybridAgent]. The abstract publishes ranges rather than per-benchmark figures, does not name the specific frontier baselines, and does not identify the three model scales it evaluates.

 Editor's note

Latent-reasoning agents have lacked native tool access; if HybridAgent's toggle holds up outside its benchmarks, the inference math for agent products changes, since tokens and latency are what make agent runs expensive.
