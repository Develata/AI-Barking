# 1015 期 C 组取证：ARC-AGI-3 上 Gemini-4-Argon 换 harness 分数翻倍

执行：Sonnet 5.5（claude-sonnet-5-5），取证时段 2026-10-16 19:39–20:10（北京时间）。只取证，不下结论。时间一律北京时间（UTC+8），括号内为原时区。存档文件均在 `docs/2610/1015/sources/`，前缀 `c-`；截图在 `docs/2610/1015/images/25–32`。

## 一句话结论（事实层面）

- ARC Prize 结果页与官方推文都写明：Argon 在 ARC-AGI-3 上 Provider Adapter harness 得 97.5%（Low reasoning，成本 $4,770），标准（Standard）harness 得 49.8%（Low reasoning，成本 $5,821），两种成绩分开列、各自标注 harness。
- 标准 harness 没有跑完：Low 档 55 题中完成 42 题，Medium 46 题，High 19 题（High 不发布分数）；“Reported scores include all 55 tasks, retaining partial credit earned on incomplete runs.”
- ARC Prize 自己的定义：Provider Adapter harness = “provider-designed context-management features”；标准 harness = “minimal, provider-neutral interface”。ARC Prize 在 GPT-6 Astra 博客里说“We believe a future AGI should be able to solve ARC-AGI-3 under these conditions”（指标准 harness），同时把两者说成“answer different evaluation questions”，并称两种分数“Both are state-of-the-art scores”。**没有**找到“标准 harness 才是更有意义的门槛”这种直接表述（见“扫描说法勘误”）。
- GPT-6 Astra 的 99.9% 是 Provider Adapter harness、high reasoning、$18,817（博客写 $19K）；同一模型标准 harness 最好 62.7%（max，$26,098）。所以“仅次于 Astra 的 99.9%”是同口径（adapter）比较。

## 可能的吠点（线索摘要没提或说反的条件，每条注出处）

1. 标准 harness 分数是**未跑完**的：Low 42/55、Medium 46/55、High 19/55，且“retaining partial credit”；页面没说未完成题怎么计。因此 49.8% 不是完整评测下的标准 harness 成绩（结果页，C2）。
2. 97.5% 与 49.8% 都在 **Low** reasoning；High 档标准无分数、Adapter 为 97.3%。扫描摘要常只写 97.5% 与 49.8%（结果页表）。
3. 两种 harness 是 ARC Prize **分开报告**的两种条件：“These harnesses answer different evaluation questions.”；同时 ARC Prize 对标准 harness 的话更重：“We believe a future AGI should be able to solve ARC-AGI-3 under these conditions.”（政策页；Astra 博客）。
4. Adapter 用到提供方不可见的推理状态：“preserving the opaque reasoning state (which we don’t see) between requests and using compaction to manage longer conversations”（Astra 博客）。Astra 博客另有带代码沙箱的 PRO-LONG harness，与 Adapter 是两回事，不要混用。
5. 成本按 Google 的 “introductory pricing of $2 per million input tokens and $10 per million output tokens” 计算，不是长期价格（结果页）。
6. 页面与推文给的是 ARC Prize 的 **Verified**（Semi-Private）成绩；“62% fewer actions than the human baseline”则明说是 “across the 25 ARC-AGI-3 public games”（推文第 2 条）。两个口径不要写成同一个集合。
7. “第二家超过 95%”与“仅次于 Astra 的 99.9%”都以 Provider Adapter harness 为口径；标准 harness 下 Astra 最好 62.7%，Argon 49.8%（未跑完）。同一句里不带 harness 就会被读成同条件。
8. 结果页摘要写 “91.2% on v2”，表格与推文写 91.3%。内嵌数据值为 0.9125，是四舍五入差异；两处都记，不取舍。
9. ARC Prize 仍强调：Astra 博客 “we are not claiming that it is AGI”，且 “ARC-AGI-3 has a tightly bounded scope and format… It does not represent the complexity and open-endedness of the real world.”（Astra 博客；对 Argon 无单独声明，仅是 ARC Prize 对饱和该基准的一贯口径）。
10. 社区质疑：HN 与 Reddit 上没有找到关于该成绩的独立讨论（见 C8），因此没有可摘的高赞评论（L6 线索：无）。

## 扫描说法勘误

1. “ARC Prize 称 Argon 是第二个在 ARC-AGI-3 超过 95% 的前沿实验室，仅次于 GPT-6-Astra 的 99.9%”：推文第 1 条只有 “second frontier AI lab to score above 95%”，**Astra 与 99.9% 出现在第 2 条**（同秒发出的串内回复）。事实本身属实，且仅在 Provider Adapter 口径下成立。
2. “WorkBuddy 称：ARC Prize 自己说过标准 harness 才是更有意义的门槛”：未找到原句。能找到的是 ARC Prize 说标准 harness 提供“apples-to-apples comparison”并“We believe a future AGI should be able to solve ARC-AGI-3 under these conditions”，同时称 Adapter 是“a separate question”，并称两者都是“state-of-the-art scores”。该说法属于二手转述（OfficeChai 有类似转述句）。状态：部分支持。
3. “provider adapter harness 来自 Google”：未找到一手表述。ARC Prize 仅称其使用“provider-designed context-management features”，Gemini adapter 代码在 ARC Prize 开源仓库里，由名为 `mattm` 的 GitHub 用户提交，隶属未核实。
4. “97.5% / 49.8% / 成本 $4.8K / $5.8K”：与结果页一致（4770.148614 / 5820.531006）。
5. “Low 55 题完成 42、Medium 46、High 19”：与页面一致；High 标准 harness 不发布分数（扫描说“High 无分数”，属实）。
6. “页面摘要写 91.2% 与表格 91.3% 矛盾”：属实，内嵌数据 0.9125，四舍五入差异。
7. 结果页日期 “Oct 13, 2026” 是 Google 发布日，不是 ARC 结果的发布时间；成绩推文 2026-10-16 00:22:30 北京时间（10-15 16:22:30 UTC）。
8. 摘要里的“GPT-6-Astra 的 99.9%”：Provider Adapter、high reasoning、$18,817（博客写 $19K），2026-09-03 博客发布；同一模型标准 harness 62.7%（max，$26,098）。
