ARC-AGI-3 Quickstart

Copy pageCopy page

ARC-AGI-3 is an Interactive Reasoning Benchmark designed to measure an AI Agent’s ability to generalize in novel, unseen environments.

Copy pageCopy page

Traditionally, to measure AI, static benchmarks have been the yardstick.
These work well for evaluating LLMs and AI reasoning systems. However, to evaluate frontier AI agent systems, we
need new tools that measure:

Exploration

Percept → Plan → Action

Memory

Goal Acquisition

Alignment

By building agents that can play ARC-AGI-3, you’re directly contributing
to the frontier of AI research. 

 Learn more about
ARC-AGI-3 [https://arcprize.org/arc-agi/3].

Can you build an agent to beat
this game [https://arcprize.org/tasks/ls20]?

​

 [#play-your-first-arc-agi-3-environment]
Play your first ARC-AGI-3 environment

​

 [#1-install-the-arc-agi-toolkit]
1. Install the ARC-AGI Toolkit [https://github.com/arcprize/arc-agi]

uv init
uv add arc-agi
# or
pip install arc-agi

​

 [#2-set-your-arc_api_key]
2. Set your ARC_API_KEY

Optionally set your ARC_API_KEY. If no key is provided, an anonymous key will be used. However, registering for an API key will give you access to public games at release. Get an ARC_API_KEY [/api-keys]

export ARC_API_KEY="your-api-key-here"
# or
echo 'ARC_API_KEY=your-api-key-here' > .env

​

 [#3-play-your-first-game]
3. Play your first game

Create a file called play.py:

import arc_agi
from arcengine import GameAction

arc = arc_agi.Arcade()
env = arc.make("ls20", render_mode="terminal")

# Take a few actions
for _ in range(10):
 env.step(GameAction.ACTION1)

print(arc.get_scorecard())

Run it:

python play.py

You should see the game render in your terminal and a scorecard with your results.
🎉 Congratulations! You just played your first ARC-AGI-3 environment programmatically.
Do you feel the AGI yet?

​

 [#next-steps]
Next Steps

After running your first environment:

Make it fast - Use env = arc.make("ls20") without render_mode to hit +2K FPS

Try a different game - Run env = arc.make("ft09", render_mode="terminal") to play another game. See a list of games available at arcprize.org/tasks [https://arcprize.org/tasks] or via the ARC-AGI Toolkit [/toolkit/list-games]

Use an agent - Explore agent templates [/llm_agents] or create your own agent [/agents-quickstart].

Explore the ARC-AGI Toolkit - The ARC-AGI Toolkit [/toolkit/overview] allows quick and easy integration with ARC-AGI Environments.
