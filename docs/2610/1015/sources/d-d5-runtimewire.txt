Tencent's WorkBuddy faces a Claude Code copying allegation over internal prompts

An October 16th post claims 224 identical text segments in WorkBuddy's bundled CodeBuddy CLI; Tencent's docs confirm Claude plugin compatibility, complicating the comparison.

 By Ryan Merket [/author/ryan-merket]
 · Published Oct 16th, 2026, 12:20am CT

Primary source: X [https://x.com/0xLogicrw/status/2110953344579846187]

Why it matters

The allegation concerns agent memory instructions, prompts and tool conventions. Tencent documents Claude plugin compatibility, which may explain some shared identifiers, but the claimed identical internal prompt text has not been independently verified.

Tencent's WorkBuddy is facing an allegation that its international desktop app reused internal text from Anthropic's Claude Code, after an X post reported matching passages in the products' command-line tools. The claim comes from an October 16th post by @0xLogicrw [https://x.com/0xLogicrw/status/2110953344579846187], which says its author unpacked WorkBuddy and compared the bundled CodeBuddy CLI with Claude Code source code that leaked in March. The reported matches have not been independently verified.…
