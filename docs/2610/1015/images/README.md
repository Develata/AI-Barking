### 3:4 竖版提示词

竖版 3:4 封面插画。画风：复古报关单与橡皮图章——米黄色旧纸张底，纸面有淡淡的横格线与打孔边，物件用粗线条扁平插画，主色是图章红与墨蓝，少量牛皮纸棕点缀；所有物件和看板娘用同一套线条与上色，整体是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。背景只有大块平涂纸色，不画复杂场景。
最上方是主标题，分两行：“AI技术出口要登记？”“Meta最强带限定”。粗壮的墨蓝色无衬线大字，像盖在报关单上的大号铅字，是全画面最醒目的元素，宽度占画面约九成，每个字都清楚可读。不要副标题。
画面中下部摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一个牛皮纸快递箱，箱子侧面贴着一张空白标签，上方悬着一枚巨大的红色橡皮图章正要盖下去，图章印面空白、不写字；箱子和标签上不写字；
2. 右：一座金色奖杯，奖杯底座右上角挂着一个特别小的星号形吊牌（只有一个星形符号，不写字），奖杯上不写字。
看板娘按参考图（蓝色长发、狗耳、鲸鱼尾巴、女仆装、胸前“AI 吠点”圆牌；双手是正常的人手，不戴肉垫手套）在画面下方居中出镜，同样用这套扁平画风：一手举着一个大放大镜对准奖杯上的小星号吊牌，一手叉腰，眯眼挑眉，表情狐疑。她只有两只手、两只耳朵、一条尾巴，全身完整入画。
画面里除了主标题与胸牌“AI 吠点”，不要出现任何其他文字、数字、国旗、logo、品牌标志或真人。
