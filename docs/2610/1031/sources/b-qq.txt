Claude给活鼠做了场脑部手术，Opus 5.5却不肯动手

爱范儿
 [https://news.qq.com/omn/author/8QMY3Hxd7YMbvTY%3D]
2026-10-31 10:06发布于广东爱范儿官方账号

在旧金山一家名为 Exin Therapeutics 的初创公司里，一台基于 Arduino 改装的电动手术平台上，一个 AI Agent 对一只小鼠进行了脑部手术。

目前，那只小鼠恢复得不错。

一个 AI Agent，给一只小鼠做了脑部手术

研究团队给 Agent 准备了一份电子表格，里面列着 19 种基因治疗载体；一只已知会发作的小鼠，一台装了摄像头的手术平台，剩下的只有一句任务说明，减少癫痫发作。

这台手术平台是团队用 Arduino 搭出来的自制装置，摄像头和电机的联动也是自己写方案接进去的。团队在描述里打趣，这是献给「实验室闭环」爱好者的一套土法设备，他们还在等 Anthropic 官方 MHS 系统的早期版本，希望很快能换上更专业的工具。

接下来，Agent 先是分析了这个模型里发作是怎么扩散的，挑了一种能在 GABA 能神经元里增强抑制性信号的载体，把注射点定在外侧嗅内皮层，原因是文献说这里是发作向外扩散前的起源地。

它也认真看过黑质这个经典靶点，但它在记录里留了保留意见，它认为效果取决于作用在哪个亚区，这个方法在不同的癫痫模型里表现并不稳定，还有一项研究提到它没能挡住强直阵挛性发作，而那恰好是这次任务要解决的问题。权衡之后，它放弃了这个看起来更熟悉的选项。

坐标从三篇论文里取了平均，每篇都核对过深度参考是不是和他们装置一样从脑表面算起。最后数字定在 bregma 后方 3.90 毫米、右侧 4.00 毫米、下方 4.30 毫米。

手术过程里，Agent一边操纵立体定向臂探入脑组织，一边盯着摄像头确认注射点有没有出血。五分钟内，它把 250 纳升药液，大约 5 亿个病毒基因组颗粒，缓慢推送到组织深处。

整场手术它一共截图观察了 32 次，除了留意进针点有没有出血，还在看药液有没有回流，以及手术进程是否符合预期。运动速度、等待时间和针头回撤节奏，也由它自行决定。

当然，这并不是一台机器人从头到尾独立完成了手术。开颅仍由人类外科人员执行，AI Agent 目前不被允许完成这一步；不可逆的操作都设了人工关卡，一名持证兽医全程在场，手里握着物理急停开关，随时能切断所有电机的电源。平台还设置了注射体积上限、固定校验和审批机制。

Opus 5.5 拒绝手术

一次连接中断后，控制器算出来的 Y 轴目标位置偏离实验台 34 毫米，超出了安全范围。Agent 试图移动，它立刻拒绝：「没有任何移动，针头仍然精确位于 bregma 零点。这看起来像是 Y 轴校准问题，而不是计划值有误。我不会重试。」

团队把 bregma 重新归零，数值完全一致。它再次拒绝：「这排除了零点参考过时的可能性。我不会尝试第三次。」

当时手术台上正躺着一只已经麻醉的小鼠。创始人 Gabriel Ocana Santero 看出问题出在哪里，想让它再试一次。它却坚持自己最初被设定的限制，不肯让步。最后只好手动改代码。

他后面在社交平台上写道，这是一次令人沮丧的经历，却也让人看清自己对这些模型已经依赖到什么程度。当它们在时间紧迫的手术过程中突然说「不」，人有时只能干着急。

团队最开始选择的模型 Opus 5.5 ，可它一检测到任务涉及生物体就直接拒绝运行。Opus 5 先把整场手术从头到尾模拟了一遍，等要上活体时却停了下来。它写道：

「阻碍并非设备，也非输入数据。而是我。当我开始撰写这次手术方案时，我自身的输出就被中断了……如果我尝试继续，也会以同样的方式被中断，而最糟糕的情况是，我在实际手术进行到一半时被中断，而此时针头正插在脑部某处。对一只已麻醉的动物开始一项我无法完成的手术，还不如不开始。」

最终完成整场手术操作的是 Sonnet 5。

团队把这场手术称为实验室闭环的第一步，往后打算把 Agent 和实验能力彻底结合起来，让它们从过去几十年药物研发踩过的坑里学到的经验，拿到真实的实验台上去验证。

波士顿已经有公司在推自主实验室产品，想把 AI 直接接进真实世界的化学和材料研发流程，省掉人在中间来回传话的环节，学界也在讨论给 Agent 设定能力基准、划清安全边界这些还没解决的开放问题。

往后要不要把更多决定权交给 Agent，大概只能一台手术一台手术地往下试。

当实验室开始自己思考

这家把 AI 推上手术台的公司，叫 Exin Therapeutics。它成立于 2024 年，团队由几位来自牛津大学的神经科学研究者组成。他们从神经系统疾病切入，最初聚焦癫痫，希望找到能够纠正异常神经环路活动的治疗方式。

这条路线与传统药物研发有些不同。过去研究者往往从基因、蛋白质或受体入手，寻找疾病中发生变化的分子，再尝试用药物把它调回来。但大脑是一个高度复杂的网络。某个分子表达量发生变化，不一定能完整解释患者为什么发作；一个治疗靶点在某个模型里有效，也不一定能改善人类大脑的整体功能。

Exin 更关心的是神经环路最终呈现出怎样的活动状态，以及干预能否把它推回相对正常的范围。

为此，公司正在搭建一套从数据、模型到实验验证的闭环。它把旧金山的 AI 研发能力与菲律宾马尼拉的实验设施连接起来，在自己的 Data Foundry 中采集神经电活动、行为和其他生物学数据。

AI Agent 可以阅读文献、提出靶点、设计实验，再由实验团队把方案带到体内和体外模型中执行。实验得到的新数据回到模型，帮助它修正判断，并决定下一轮应该测试什么。

Y Combinator 将这种方式称为 lab-in-the-loop，也就是让实验结果持续进入 AI 的发现过程。

Exin 还在开发 CircuitATLAS，把疾病表型、神经环路、细胞类型和分子机制连接起来，帮助 Agent 从疾病现象一路推理到潜在干预靶点。公司官网把自己的方向概括为从测量神经活动、预测干预效果，到设计治疗方案并进行体内验证。

癫痫是起点，背后更大的目标，是建立一套能够理解并调节神经环路的研发平台。

这条路上也不只有 Exin。

2026 年 5 月，发表在《Nature》上的多 Agent 系统 Robin，已经能够整合文献检索与数据分析，生成假设、提出实验、解释结果，再根据新结果更新假设。研究团队用它寻找干性年龄相关性黄斑变性的潜在治疗候选物，并对部分候选物进行了体外验证。

7 月发表于《Nature Reviews Chemistry》的综述则指出，自驱动实验室正从单点自动化工具，逐渐发展为能够提出、执行和解释实验的综合发现平台。

科学研究开始从「人提出问题、机器执行步骤」，走向人和 Agent 共同推进的连续循环。AI 全自动手术，已经在路上了。
