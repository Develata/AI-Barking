DeepSeek has released a prototype of a more autonomous coding agent as it seeks to challenge Anthropic PBC [https://www.bloomberg.com/quote/ANT:US]’s popular Claude Code. 

The new open-source offering, dubbed “Super-Agent,” can proactively monitor group chats among developers for feedback on coding issues and suggest solutions without being summoned, the DeepSeek Harness team said [https://mp.weixin.qq.com/s/zoS7GlReWPhfCjENGxXCdg] in a post on WeChat on Saturday.
