xAI to Add Invisible Watermarks to Grok API Text Output by Default Starting November 7

PA一线·1 min read [/contributors/166]Follow

PANews, November 1: According to xAI's official documentation, the company plans to add invisible watermarks by default to the API text output of models such as Grok 4.7 and 4.6 starting November 7, covering plain text, structured outputs and tool-call parameters. The watermark is used to identify model-generated content and applies to global and regional API endpoints; team administrators can disable the feature on a per-model basis.

Original link [https://docs.x.ai/developers/advanced-api-usage/watermarking]
