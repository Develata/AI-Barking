## 1. 标题

我会点的前三：

1. **“AI给活鼠打针，没开颅？”**——“活鼠”和“没开颅”让我好奇，到底怎么把针打进脑子里。
2. **“ChatGPT聊天要扣额度？”**——我可能用得到，想知道以后聊天是不是聊几句就不能用了。
3. **“AI做脑手术？Claude先拒了”**——AI 怎么做手术、又为什么拒绝，这两个问题让我想点进去。

看不出具体在说什么事：

- **“AI给鼠脑打针？ChatGPT额度合并”**——前后像两件完全不相干的事，“额度合并”也没说跟谁合并。
- **“DeepSeek超级智能体，只是原型？”**——不知道“超级智能体”能干什么，也不明白“只是原型”跟我有什么关系。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁乱讲吗？还没开始读，就得先猜这个栏目名。
- **“一家公司让 Claude 智能体给一只癫痫模型小鼠往脑内注射基因疗法，开颅仍由兽医做。”**——“智能体”“癫痫模型小鼠”“基因疗法”三个词挤在一起；“模型小鼠”是真老鼠还是模拟出来的老鼠？
- **“12月起，ChatGPT 和 Codex 共用额度，Instant 聊天不扣。”**——不知道 Codex 和 Instant 是什么，也不知道“额度”是消息条数、钱，还是使用时长。
- **“DeepSeek 公开的‘超级智能体’自称研究原型。”**——“自称”读着像是 AI 自己说的，不知道实际是谁在介绍它。
- **“Exin Therapeutics 公司 CEO 北京时间10月28日晚发帖称，他们让 AI 智能体操控自制的电动手术台，给一只癫痫模型小鼠往脑内注射基因疗法，药和脑区都由它选；切口、开颅和缝合由兽医做，兽医还握着急停开关。”**——一句话太长，要回头分清 AI 和兽医分别干了什么；“电动手术台”怎么完成打针，我也想象不出来。
- **“①最先试的 Opus-5.5 一发现涉及生物就拒绝，动手的是官方已标为旧版的 Sonnet-5。”**——这两个英文名字跟前面的 Claude 是什么关系？是两个 AI，还是同一个 AI 的不同版本？
- **“③随后三家模型各做一只，选的疗法、脑区都不同；疗效未知，没有论文，CEO 说别当正式评测。”**——“三家模型”是哪三家？前面的小鼠也叫“模型”，这里要反应一下；“各做一只”是各给一只老鼠做手术吗？
- **“OpenAI 帮助页北京时间11月1日凌晨更新：12月起，Plus、Pro 和 Business 套餐的额度由 ChatGPT 和 Codex 共用，按 token 计；Instant 聊天不扣。”**——一串套餐和功能名看不懂，“token”更不知道怎么对应到我聊了多少句话。
- **“②Business 帮助页写明 Instant 是‘几乎不限’，仍防滥用；选着 Instant，自动推理也可能扣推理额度。”**——刚说不扣，怎么又可能扣？“自动推理”什么时候发生，“推理额度”跟前面的额度是不是同一个？
- **“④免费版、Go、企业版和教育版，帮助页都没提。”**——Go 是什么版本？如果我用免费版，看到这里还是不知道自己会不会受影响。
- **“北京时间10月31日，DeepSeek 在 GitHub 公开 dsh-superagent：它盯着一个仓库，有人派活，就在独立会话里干完，再回原对话答复。”**——不知道 GitHub 和“仓库”是什么；谁给它派什么活，又为什么要换一个会话？
- **“②默认是‘观察’模式，只记下本来会接的活；要它主动干活，得切 auto 模式、自己写规则。”**——“本来会接的活”具体是什么？“自己写规则”是打几句话，还是要写程序？
- **“④部署文档写明，它以完全访问权限、用运营者自己的系统账号运行，能读其主目录。”**——“部署”“运营者”“主目录”都不熟，不知道是在说它能看我电脑里的文件，还是别的事情。

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**——为了把“沸”和“吠”凑成梗，硬造了一个平时不会说的问句，像让 AI 想一个有记忆点的栏目口号。
- **“省流：一家公司让 Claude 智能体给一只癫痫模型小鼠往脑内注射基因疗法，开颅仍由兽医做。12月起，ChatGPT 和 Codex 共用额度，Instant 聊天不扣。DeepSeek 公开的‘超级智能体’自称研究原型。”**——像自动摘要把三条新闻各压成一句，名字和术语都留下了，却没顾上我能不能看懂。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——“轻松识破”像宣传文案，结尾又重复绕“沸点／吠点”，像生成出来的品牌标语。

## 4. 会划走的地方

- **“OpenAI 帮助页北京时间11月1日凌晨更新：12月起，Plus、Pro 和 Business 套餐的额度由 ChatGPT 和 Codex 共用，按 token 计；Instant 聊天不扣。”**——我大概会在这里划走。第一条还有老鼠手术的具体画面，到了这里全是我不认识的名字，也看不出自己受什么影响。
- **“②CEO 首帖和 IT 之家标题都说 AI 做了‘脑部手术’。”**——这条“吠点”我不在乎：前面确实描述了脑内打针，我没看懂这里要指出什么问题。
- **“③爱范儿稿文末称‘无限畅聊的时代要结束了’，开头却写 Instant 不扣额度。”**——我更想知道自己还能不能免费聊，不太关心另一篇稿子前后怎么写。
- **“③新浪上一篇自媒体稿称它‘7x24 小时在线’，DeepSeek 的仓库和文章里都没有这个说法。”**——我连这个东西能帮我干什么都没弄明白，暂时不在乎别人有没有夸大它的在线时间。
