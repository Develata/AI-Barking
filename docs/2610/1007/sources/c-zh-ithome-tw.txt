# Anthropic擴大資安Claude存取計畫，Glasswing半年找到逾12萬漏洞

Anthropic放寬資安團隊使用Claude進行漏洞研究與紅隊測試的限制，並將Project Glasswing併入Cyber Verification Program

  文/陳曉莉|2026-10-07發表

 Anthropic彙整33個Project Glasswing合作夥伴提供的部分資料，以及自家掃描開源軟體的結果，共確認13.56萬個漏洞，其中逾3.3萬個屬重大或高嚴重度；由於合作夥伴資料並不完整，Anthropic表示這些數據僅反映目前已知的部分成果。（圖片來源／Anthropic）

Anthropic周二（10/6）宣布擴大Cyber Verification Program（CVP），整合原本分開運作的Project Glasswing，並重新分為3個資安存取層級，讓通過驗證的資安團隊可依工作需求，取得限制較少的Claude模型能力。Anthropic同時公布Project Glasswing成果，指出合作夥伴自今年4月至7月間已發現至少12.9萬個經驗證的軟體漏洞。

Anthropic於今年4月先後推出Project Glasswing與Cyber Verification Program（CVP），但兩者定位不同。Project Glasswing鎖定負責保護關鍵軟體與基礎設施的組織，提供資安能力更強的Claude Mythos，協助主動掃描程式碼並尋找高風險漏洞；CVP則面向從事漏洞研究、滲透測試與紅隊作業的資安專業人士及團隊，讓通過驗證者使用降低部分安全限制的Claude模型。前者偏向特定關鍵系統的防禦，後者則是較廣泛的專業資安存取機制。

整併了Project Glasswing的新版CVP分為Defense Access、Red Team Access與Specialized Access三個層級。其中，Defense Access主要供資安營運、事件回應、惡意程式逆向工程及漏洞分析等防禦工作使用；Red Team Access則進一步開放經授權的滲透測試與紅隊作業；限制最少的Specialized Access僅提供少數經深入驗證的組織，用於測試飛航系統、電網、電信網路及銀行間轉帳基礎設施等高風險系統。既有的Project Glasswing成員則直接轉入Specialized Access。

Anthropic也以CyScenarioBench測試不同存取層級的限制效果。在未取得CVP權限時，Claude Opus 5.5在50次測試中全部於第一個提示詞即遭封鎖；Defense Access有46次在執行過程中被阻擋；Red Team Access則沒有任何一次遭封鎖，最終完成50項中的34項，表現接近完全不套用安全防護時的67.6％成功率。

不過上述測試並未涵蓋Red Team Access仍會封鎖的高風險操作，例如可能造成實體傷害、大規模中斷，或針對高風險安全系統的測試；這類操作只有Specialized Access才會放行。

而自今年4月到7月間，Project Glasswing的合作夥伴已發現至少12.9萬個經過驗證的軟體漏洞，Anthropic也以相同的Claude資安能力掃描開源專案，於4月至10月額外找出5,500個安全漏洞。在這些漏洞中，有超過3.3萬個被評為重大或高嚴重度漏洞。

新版CVP採申請制，Anthropic會依不同存取層級審核申請者資格。服務目前可透過Claude Platform、Google Cloud Vertex AI及Microsoft Foundry使用，Amazon Bedrock則僅開放符合特定安全條件的客戶。
