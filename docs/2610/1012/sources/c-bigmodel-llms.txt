- [对话补全](https://docs.bigmodel.cn/api-reference/模型-api/对话补全.md): 和 [指定模型](/cn/guide/start/model-overview) 对话，模型根据请求给出响应。支持多种模型，支持多模态（文本、图片、音频、视频、文件），流式和非流式输出，可配置采样，温度，最大令牌数，工具调用等。点击 **Try it** 按钮可快速试用。
- [对话补全(异步)](https://docs.bigmodel.cn/api-reference/模型-api/对话补全异步.md): 和 [指定模型](/cn/guide/start/model-overview) 对话，通过查询异步结果获取模型响应。支持多种模型，支持多模态（文本、图片、音频、视频、文件），可配置采样，温度，最大令牌数，工具调用等。注意此为异步接口，通过 [查询异步结果](/api-reference/%E6%A8%A1%E5%9E%8B-api/%E6%9F%A5%E8%AF%A2%E5%BC%82%E6%AD%A5%E7%BB%93%E6%9E%9C) 获取生成结果。点击 **Try it** 按钮可快速试用。
- [查询异步结果](https://docs.bigmodel.cn/api-reference/模型-api/查询异步结果.md): 查询对话补全和视频生成异步请求的处理结果和状态。点击 **Try it** 按钮可快速试用。
- [创建 Response](https://docs.bigmodel.cn/api-reference/response/创建-response.md): 创建一次模型响应。`input` 支持文本、图片和文件，可选流式、工具与多轮。详见 [Response API](/cn/guide/develop/responses/introduction)。点击 **Try it** 可试用。
- [查询 Response](https://docs.bigmodel.cn/api-reference/response/查询-response.md): 按 `id` 检索已保存的 Response。创建时须 `store=true`。点击 **Try it** 可试用。
- [查询输入项列表](https://docs.bigmodel.cn/api-reference/response/查询输入项列表.md): 分页列出某次 Response 的输入项。创建时须 `store=true`。点击 **Try it** 可试用。
- [删除 Response](https://docs.bigmodel.cn/api-reference/response/删除-response.md): 删除已保存的 Response。创建时须 `store=true`。点击 **Try it** 可试用。
- [图像生成](https://docs.bigmodel.cn/api-reference/模型-api/图像生成.md): 使用 [GLM-Image](/cn/guide/models/image-generation/glm-image) 等系列模型从文本提示生成高质量图像。通过对用户文字描述快速、精准的理解，让 `AI` 的图像表达更加精确和个性化。点击 **Try it** 按钮可快速试用。
- [图像生成(异步)](https://docs.bigmodel.cn/api-reference/模型-api/图像生成异步.md): 使用 [GLM-Image](/cn/guide/models/image-generation/glm-image) 系列模型从文本提示生成高质量图像。通过对用户文字描述快速、精准的理解，让 `AI` 的图像表达更加精确和个性化。仅支持 `GLM-Image` 模型。点击 **Try it** 按钮可快速试用。
- [视频生成(异步)](https://docs.bigmodel.cn/api-reference/模型-api/视频生成异步.md): 通过调用 [视频模型](/cn/guide/models/video-generation/cogvideox-3) 能力生成视频内容。支持多种视频生成方式，包括文本转视频、图像转视频等。注意此为异步接口，通过 [查询异步结果](/api-reference/%E6%A8%A1%E5%9E%8B-api/%E6%9F%A5%E8%AF%A2%E5%BC%82%E6%AD%A5%E7%BB%93%E6%9E%9C) 获取生成视频结果。点击 **Try it** 按钮可快速试用。
- [语音转文本](https://docs.bigmodel.cn/api-reference/模型-api/语音转文本.md): 使用 [GLM-ASR-2512](/cn/guide/models/sound-and-video/glm-asr-2512) 模型将音频文件转录为文本，支持多语言和实时流式转录。点击 **Try it** 按钮可快速试用。
- [文本转语音](https://docs.bigmodel.cn/api-reference/模型-api/文本转语音.md): 使用 `GLM-TTS` 将文本转换为自然语音，支持多种声音、情感控制和语调调整。点击 **Try it** 按钮可快速试用。
- [音色复刻](https://docs.bigmodel.cn/api-reference/模型-api/音色复刻.md): 使用音色复刻技术，基于示例音频生成指定音色、文本内容的语音合成。点击 **Try it** 按钮可快速试用。
- [音色列表](https://docs.bigmodel.cn/api-reference/模型-api/音色列表.md): 获取音色列表，支持按音色名称模糊搜索、按音色类型过滤。点击 **Try it** 按钮可快速试用。
- [删除音色](https://docs.bigmodel.cn/api-reference/模型-api/删除音色.md): 删除指定的音色。点击 **Try it** 按钮可快速试用。
- [文本嵌入](https://docs.bigmodel.cn/api-reference/模型-api/文本嵌入.md): 使用 [GLM Embedding](/cn/guide/models/embedding/embedding-3) 系列模型将文本转换为高维向量表示，用于语义相似性和搜索。点击 **Try it** 按钮可快速试用。
- [文本重排序](https://docs.bigmodel.cn/api-reference/模型-api/文本重排序.md): `Rerank` 用于文本重排序，通过接收用户的查询文本及候选文本列表，使用模型计算候选文本与查询文本的相关性得分并返回分数。适用于智能问答、信息检索等场景。点击 **Try it** 按钮可快速试用。
- [文本分词器](https://docs.bigmodel.cn/api-reference/模型-api/文本分词器.md): `Tokenizer` 用于将文本切分为模型可识别的 `token` 并计算数量。它接收用户输入的文本，通过模型进行分词处理，最终返回对应的 `token` 数量。适用于文本长度评估、模型输入预估、对话上下文截断、费用计算等。点击 **Try it** 按钮可快速试用。
- [文档解析](https://docs.bigmodel.cn/api-reference/模型-api/文档解析.md): 使用 [GLM-OCR](/cn/guide/models/vlm/glm-ocr) 模型解析文档和图片的布局并提取文本内容。支持图片和`PDF`文档的`OCR`识别，返回详细的布局信息和可视化结果。点击 **Try it** 按钮可快速试用。
- [网络搜索](https://docs.bigmodel.cn/api-reference/工具-api/网络搜索.md): `Web Search API` 是一个专给大模型用的搜索引擎，在传统搜索引擎网页读取、排序的能力基础上，增强了意图识别能力，返回更适合大模型处理的结果（网页标题、`URL`、摘要、名称、图标等）。支持意图增强检索、结构化输出和多引擎支持。见 [网络搜索服务](/cn/guide/tools/web-search)。点击 **Try it** 按钮可快速试用。
- [网页阅读](https://docs.bigmodel.cn/api-reference/工具-api/网页阅读.md): 读取并解析指定 `URL` 的网页内容，可选择返回格式、支持控制缓存、图片保留与摘要选项等。点击 **Try it** 按钮可快速试用。
- [内容安全](https://docs.bigmodel.cn/api-reference/工具-api/内容安全.md): 可对文本、图片、音频、视频格式类型的内容进行检测，精准识别涉黄、涉暴、违法违规等风险内容，并输出结构化审核结果（包括内容类型、风险类型及具体风险内容片段），快速定位和处理违规信息。点击 **Try it** 按钮可快速试用。
- [文件解析(同步)](https://docs.bigmodel.cn/api-reference/工具-api/文件解析同步.md): 创建文件解析任务，支持多种文件格式和解析工具。见 [文件解析服务](/cn/guide/tools/file-parser)。点击 **Try it** 按钮可快速试用。
- [文件解析](https://docs.bigmodel.cn/api-reference/工具-api/文件解析.md): 创建文件解析任务，支持多种文件格式和解析工具。见 [文件解析服务](/cn/guide/tools/file-parser)。点击 **Try it** 按钮可快速试用。
- [解析结果](https://docs.bigmodel.cn/api-reference/工具-api/解析结果.md): 异步获取文件解析任务的结果，支持返回纯文本或下载链接格式。见 [文件解析服务](/cn/guide/tools/file-parser)。点击 **Try it** 按钮可快速试用。
- [OCR 服务](https://docs.bigmodel.cn/api-reference/工具-api/ocr-服务.md): 上传图片文件，使用指定工具类型进行 OCR（光学字符识别），支持手写体、文字等识别模式，见 [OCR 服务](/cn/guide/tools/zhipu-ocr)。点击 **Try it** 按钮可快速试用。
- [列出 Agent](https://docs.bigmodel.cn/api-reference/managed-agents--agent/列出-agent.md): 分页列出当前身份可读取的 Agent，包括本人创建以及通过访问桥授权的 Agent。支持通过 `limit`、`order` 和 `page` 游标翻页。点击 **Try it** 按钮可快速试用。
- [创建 Agent](https://docs.bigmodel.cn/api-reference/managed-agents--agent/创建-agent.md): 创建 Agent 及其首个不可变版本。可配置模型、系统提示词、内置或自定义工具、Skill 和 MCP Server；配置 MCP Server 时必须同时提供引用同名服务器的 `mcp_toolset`，不使用 MCP 时请省略这两个字段。点击 **Try it** 按钮可快速试用。
- [获取 Agent](https://docs.bigmodel.cn/api-reference/managed-agents--agent/获取-agent.md): 获取指定 Agent 的当前版本及完整配置，包括模型、系统提示词、工具、Skill、MCP Server、元数据和归档时间。无读取权限时与资源不存在时均返回 404。点击 **Try it** 按钮可快速试用。
- [更新 Agent](https://docs.bigmodel.cn/api-reference/managed-agents--agent/更新-agent.md): 更新指定 Agent 并生成新的不可变版本。可带当前 `version`；不一致时返回 409，避免覆盖刚发生的改动。仅所有者可更新，已归档 Agent 不可更新。MCP Server 与 `mcp_toolset` 必须按名称一一对应。点击 **Try it** 按钮可快速试用。
- [列出 Agent 版本](https://docs.bigmodel.cn/api-reference/managed-agents--agent/列出-agent-版本.md): 分页列出指定 Agent 的历史版本。每条记录都是该版本的完整 Agent 配置快照，而不是仅包含版本号的摘要。点击 **Try it** 按钮可快速试用。
- [归档 Agent](https://docs.bigmodel.cn/api-reference/managed-agents--agent/归档-agent.md): 归档指定 Agent。该操作仅限所有者且幂等，并会同时归档其仍在运行的 Deployment；归档是 Agent 的终止操作。点击 **Try it** 按钮可快速试用。
- [列出 Environment](https://docs.bigmodel.cn/api-reference/managed-agents--environment/列出-environment.md): 分页列出当前身份可访问的 Environment，可使用游标控制顺序和分页大小。点击 **Try it** 按钮可快速试用。
- [创建 Environment](https://docs.bigmodel.cn/api-reference/managed-agents--environment/创建-environment.md): 创建供 Managed Session 和 Deployment 使用的云端 Environment。可配置预装软件包和网络策略；省略配置时使用平台默认设置。点击 **Try it** 按钮可快速试用。
- [获取 Environment](https://docs.bigmodel.cn/api-reference/managed-agents--environment/获取-environment.md): 获取指定 Environment 的名称、配置、元数据、状态及归档信息。不可见或不存在时返回 404。点击 **Try it** 按钮可快速试用。
- [更新 Environment](https://docs.bigmodel.cn/api-reference/managed-agents--environment/更新-environment.md): 更新指定 Environment 的名称、说明、元数据或云端配置。未提供的字段保持不变；归档后的 Environment 不能再绑定到新的 Session 或 Deployment。点击 **Try it** 按钮可快速试用。
- [删除 Environment](https://docs.bigmodel.cn/api-reference/managed-agents--environment/删除-environment.md): 永久删除指定 Environment。删除后不能再用于 Session 或 Deployment；不存在或无权限时返回 404。点击 **Try it** 按钮可快速试用。
- [归档 Environment](https://docs.bigmodel.cn/api-reference/managed-agents--environment/归档-environment.md): 归档指定 Environment。归档后保留资源记录，但不能再绑定到新的 Session 或 Deployment。点击 **Try it** 按钮可快速试用。
- [列出 Session](https://docs.bigmodel.cn/api-reference/managed-agents--session/列出-session.md): 分页列出当前身份可读取的 Session，并可按 Agent、状态和创建时间等条件筛选。点击 **Try it** 按钮可快速试用。
- [创建 Session](https://docs.bigmodel.cn/api-reference/managed-agents--session/创建-session.md): 基于指定 Agent 和 Environment 创建 Session。可选择固定 Agent 版本或提供会话级覆盖，并可附带初始用户消息、File 或 Memory Store 资源及 Vault。点击 **Try it** 按钮可快速试用。
- [获取 Session](https://docs.bigmodel.cn/api-reference/managed-agents--session/获取-session.md): 获取指定 Session 的配置、状态、关联 Agent 与 Environment，以及归档和错误信息。无读取权限时与资源不存在时均返回 404。点击 **Try it** 按钮可快速试用。
- [更新 Session](https://docs.bigmodel.cn/api-reference/managed-agents--session/更新-session.md): 更新 Session 的标题、元数据或 Agent 工具配置。仅允许更新接口声明的字段，已归档 Session 不可修改。点击 **Try it** 按钮可快速试用。
- [删除 Session](https://docs.bigmodel.cn/api-reference/managed-agents--session/删除-session.md): 删除指定 API Session。运行中的 Session 不能删除；成功后写入删除事件，并尽力清理文件投影和 Checkpoint 等外部运行资源。不存在或无权限时返回 404。点击 **Try it** 按钮可快速试用。
- [归档 Session](https://docs.bigmodel.cn/api-reference/managed-agents--session/归档-session.md): 归档指定 API Session，并将其终止后保留历史数据。运行中的 Session 不能归档，已归档 Session 再次归档会返回冲突；归档后不可再追加事件或修改资源。点击 **Try it** 按钮可快速试用。
- [列出 Session Resource](https://docs.bigmodel.cn/api-reference/managed-agents--session/列出-session-resource.md): 分页列出 Session 挂载的 File 与 Memory Store Resource，结果按创建时间稳定排序。点击 **Try it** 按钮可快速试用。
- [新增 Session File Resource](https://docs.bigmodel.cn/api-reference/managed-agents--session/新增-session-file-resource.md): 向未归档的 Session 新增一个 File Resource。`file_id` 必须属于该 Agent 所有者，`mount_path` 必须有效且不能与现有挂载路径重叠。点击 **Try it** 按钮可快速试用。
- [获取 Session File Resource](https://docs.bigmodel.cn/api-reference/managed-agents--session/获取-session-file-resource.md): 获取 Session 中指定 File Resource 的挂载信息。Memory Store Resource 通过列表接口返回，不通过该资源详情接口读取。点击 **Try it** 按钮可快速试用。
- [删除 Session File Resource](https://docs.bigmodel.cn/api-reference/managed-agents--session/删除-session-file-resource.md): 从未归档的 Session 删除指定 File Resource。该操作只解除 Session 挂载，不删除源 File。点击 **Try it** 按钮可快速试用。
- [列出事件](https://docs.bigmodel.cn/api-reference/managed-agents--session/列出事件.md): 分页读取指定 Session 已持久化的历史事件。可使用游标继续读取，适合在实时流断开后补齐事件。点击 **Try it** 按钮可快速试用。
- [发送事件](https://docs.bigmodel.cn/api-reference/managed-agents--session/发送事件.md): 向指定 Session 追加事件并触发后续处理。一次可发送 1 至 10 个受支持事件；已归档 Session 不接受新事件。点击 **Try it** 按钮可快速试用。
- [订阅实时事件](https://docs.bigmodel.cn/api-reference/managed-agents--session/订阅实时事件.md): 通过 Server-Sent Events 订阅指定 Session 的实时事件。该流只推送连接后的新事件；重连时应先调用事件列表接口补齐历史并按事件 ID 去重。
- [列出 File](https://docs.bigmodel.cn/api-reference/managed-agents--file/列出-file.md): 分页列出当前身份可读取的 Managed File，并返回文件元数据和游标。点击 **Try it** 按钮可快速试用。
- [上传 File](https://docs.bigmodel.cn/api-reference/managed-agents--file/上传-file.md): 通过 `multipart/form-data` 上传一个 File，供 Session 或 Deployment 作为文件资源挂载。请求必须包含 `file` 字段，并受平台文件大小限制。点击 **Try it** 按钮可快速试用。
- [获取 File](https://docs.bigmodel.cn/api-reference/managed-agents--file/获取-file.md): 获取指定 File 的元数据，不返回文件二进制内容。无读取权限时与文件不存在时均返回 404。点击 **Try it** 按钮可快速试用。
- [删除 File](https://docs.bigmodel.cn/api-reference/managed-agents--file/删除-file.md): 删除指定 File。已被引用或不满足删除条件时会返回相应错误；不存在或无权限时返回 404。点击 **Try it** 按钮可快速试用。
- [下载 File 内容](https://docs.bigmodel.cn/api-reference/managed-agents--file/下载-file-内容.md): 下载指定 File 的原始二进制内容。响应媒体类型和文件名由已保存的文件元数据决定。点击 **Try it** 按钮可快速试用。

- [创建 Memory Store](https://docs.bigmodel.cn/api-reference/managed-agents--memory/创建-memory-store.md): 创建一个用于跨 Session 保存长期记忆的 Memory Store。可设置名称、说明和自定义元数据。点击 **Try it** 按钮可快速试用。
- [获取 Memory Store](https://docs.bigmodel.cn/api-reference/managed-agents--memory/获取-memory-store.md): 获取指定 Memory Store 的配置、状态、容量和归档信息。不可见或不存在时返回 404。点击 **Try it** 按钮可快速试用。
- [更新 Memory Store](https://docs.bigmodel.cn/api-reference/managed-agents--memory/更新-memory-store.md): 更新指定 Memory Store 的名称、说明或元数据。元数据使用补丁语义，值为 `null` 时删除对应键。点击 **Try it** 按钮可快速试用。
- [删除 Memory Store](https://docs.bigmodel.cn/api-reference/managed-agents--memory/删除-memory-store.md): 删除指定 Memory Store，解除活动的 Session 挂载并删除其中的 Memory；版本审计记录会保留但不再可通过已删除的 Store 访问。Store 正在被操作时不能删除。点击 **Try it** 按钮可快速试用。
- [归档 Memory Store](https://docs.bigmodel.cn/api-reference/managed-agents--memory/归档-memory-store.md): 归档指定 Memory Store。归档后保留历史内容，但不能再作为活动资源挂载或写入。点击 **Try it** 按钮可快速试用。
- [列出 Memory](https://docs.bigmodel.cn/api-reference/managed-agents--memory/列出-memory.md): 分页列出指定 Memory Store 中的 Memory 条目，可使用游标继续读取。点击 **Try it** 按钮可快速试用。
- [创建 Memory](https://docs.bigmodel.cn/api-reference/managed-agents--memory/创建-memory.md): 在指定 Memory Store 中创建 Memory。`path` 必须以 `/` 开头且不能包含空、`.` 或 `..` 路径段，内容受平台字节数限制。点击 **Try it** 按钮可快速试用。
- [获取 Memory](https://docs.bigmodel.cn/api-reference/managed-agents--memory/获取-memory.md): 获取指定 Memory 的当前内容、路径、版本及时间信息。点击 **Try it** 按钮可快速试用。
- [更新 Memory](https://docs.bigmodel.cn/api-reference/managed-agents--memory/更新-memory.md): 更新指定 Memory 的路径或内容。可选 `content_sha256` 前置条件用于避免覆盖并发修改；未提供或为 `null` 的字段保持不变。点击 **Try it** 按钮可快速试用。
- [删除 Memory](https://docs.bigmodel.cn/api-reference/managed-agents--memory/删除-memory.md): 删除指定 Memory。删除操作会形成可审计的版本记录，资源不存在或无权限时返回 404。点击 **Try it** 按钮可快速试用。
- [列出 Memory Version](https://docs.bigmodel.cn/api-reference/managed-agents--memory/列出-memory-version.md): 分页列出指定 Memory Store 的版本历史，包括创建、更新、删除和脱敏产生的版本。点击 **Try it** 按钮可快速试用。
- [获取 Memory Version](https://docs.bigmodel.cn/api-reference/managed-agents--memory/获取-memory-version.md): 获取指定 Memory Version 的不可变历史快照。点击 **Try it** 按钮可快速试用。
- [脱敏 Memory Version](https://docs.bigmodel.cn/api-reference/managed-agents--memory/脱敏-memory-version.md): 对指定 Memory Version 执行脱敏，使敏感历史内容不再可读取。该操作针对版本记录，不修改当前 Memory 的业务路径。不能对当前 head 版本脱敏（409）。点击 **Try it** 按钮可快速试用。
- [列出 Vault](https://docs.bigmodel.cn/api-reference/managed-agents--vault/列出-vault.md): 分页列出当前身份拥有的 Vault。Vault 用于集中管理 Session、Deployment 和 MCP 访问所需的凭据。点击 **Try it** 按钮可快速试用。
- [创建 Vault](https://docs.bigmodel.cn/api-reference/managed-agents--vault/创建-vault.md): 创建一个 Vault，用于保存和组织受保护的 Credential。可设置展示名和自定义元数据。点击 **Try it** 按钮可快速试用。
- [获取 Vault](https://docs.bigmodel.cn/api-reference/managed-agents--vault/获取-vault.md): 获取指定 Vault 的元数据和状态；响应不返回任何凭据明文。点击 **Try it** 按钮可快速试用。
- [更新 Vault](https://docs.bigmodel.cn/api-reference/managed-agents--vault/更新-vault.md): 更新指定 Vault 的展示名或元数据。元数据使用补丁语义，值为 `null` 时删除对应键。点击 **Try it** 按钮可快速试用。

- [归档 Vault](https://docs.bigmodel.cn/api-reference/managed-agents--vault/归档-vault.md): 归档指定 Vault。归档后保留记录，但其中 Credential 不能再用于新的运行时注入。点击 **Try it** 按钮可快速试用。
- [列出 Credential](https://docs.bigmodel.cn/api-reference/managed-agents--vault/列出-credential.md): 分页列出指定 Vault 中的 Credential 元数据和认证类型。密钥、Token 等敏感值不会在响应中返回。点击 **Try it** 按钮可快速试用。
- [创建 Credential](https://docs.bigmodel.cn/api-reference/managed-agents--vault/创建-credential.md): 在指定 Vault 中创建 Credential。支持 MCP OAuth、静态 Bearer、通用 OAuth、Bearer 和环境变量凭据；敏感字段只写不回显。点击 **Try it** 按钮可快速试用。
- [获取 Credential](https://docs.bigmodel.cn/api-reference/managed-agents--vault/获取-credential.md): 获取指定 Credential 的元数据、认证类型和状态；响应不会返回密钥、Token 或 Secret 明文。点击 **Try it** 按钮可快速试用。
- [更新 Credential](https://docs.bigmodel.cn/api-reference/managed-agents--vault/更新-credential.md): 更新指定 Credential 的展示信息或认证材料，可用于轮换 Token、Secret 和 OAuth 刷新配置；敏感值只写不回显。点击 **Try it** 按钮可快速试用。
- [删除 Credential](https://docs.bigmodel.cn/api-reference/managed-agents--vault/删除-credential.md): 永久删除指定 Credential。删除后相关运行时不能再使用该凭据。点击 **Try it** 按钮可快速试用。
- [验证 MCP OAuth](https://docs.bigmodel.cn/api-reference/managed-agents--vault/验证-mcp-oauth.md): 验证指定 MCP OAuth Credential 当前是否能访问其 MCP Server。该操作只执行连通性与认证校验，不返回敏感 Token。点击 **Try it** 按钮可快速试用。
- [归档 Credential](https://docs.bigmodel.cn/api-reference/managed-agents--vault/归档-credential.md): 归档指定 Credential。归档后保留记录，但不能再注入到新的 Session 或 Deployment 运行。点击 **Try it** 按钮可快速试用。

- [创建 Skill](https://docs.bigmodel.cn/api-reference/managed-agents--skill/创建-skill.md): 通过 `multipart/form-data` 上传一个完整 Skill 目录并创建首个版本。上传内容必须包含顶层目录中的 `SKILL.md`，字段名使用 Skill 内相对路径。点击 **Try it** 按钮可快速试用。
- [获取 Skill](https://docs.bigmodel.cn/api-reference/managed-agents--skill/获取-skill.md): 获取指定 Skill 的元数据和当前版本信息。不可见或不存在时返回 404。点击 **Try it** 按钮可快速试用。
- [删除 Skill](https://docs.bigmodel.cn/api-reference/managed-agents--skill/删除-skill.md): 删除指定 Skill 及其版本。被活动配置引用或不满足删除条件时会返回相应错误。点击 **Try it** 按钮可快速试用。
- [列出 Skill Version](https://docs.bigmodel.cn/api-reference/managed-agents--skill/列出-skill-version.md): 分页列出指定 Skill 的历史版本，可使用游标继续读取。点击 **Try it** 按钮可快速试用。
