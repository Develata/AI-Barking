02/Highlights

Image editor

What's inside.

01

Familiar by design

The menus, shortcuts, panels and tools your hands already know. Productive on day one, no retraining.

02

Native GPU canvas

Renders on Metal, Vulkan, DirectX 12 and WebGPU. No Electron and no web view, just a fast native compositor.

03

Real layered files

Opens and saves layered PSD and PSB documents. 134 of 135 real-world test files round-trip byte for byte.

04

Non-destructive editing

16 adjustment layers, 70+ live-preview filters, smart objects with smart filters, and a full set of layer styles.

05

On-device selection

Select subjects and objects and refine masks with tools that run on your machine, not someone else's server.

06

Serious color

8, 16 and 32-bit documents in RGB, CMYK, Lab and Grayscale, with ICC color management and soft proofing.

Build from source

Run it today.

Needs Rust 1.90 or newer. New to Rust? Install it with rustup [https://rustup.rs], then run:

TerminalCopy

git clone https://github.com/storytold/photocraft.git
cd photocraft
cargo run --release -p photocraft
