OPENAI 🔥: GPT-6.1 Sol now has 500k default context length for Codex and ChatGPT Work.

Earlier, default context length was set to 272k.

OpenAI also plans to increase this default value in the future even further.

Default bump 👀

引用Tibo@thsottiauxDay 7/

We have increased default context length for GPT-6.1 Sol to 500k when used through Codex & Work, up from 272k or an ~ 80% increase.

We will go higher in the future, but it helps reduce occurrence of compactions and with tasks that require keeping a lot of context and nuance over periods of time. It was carefully tested and is the new sweet spot for most of our users.
