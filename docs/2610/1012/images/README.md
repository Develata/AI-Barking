### 3:4 竖版提示词

竖版 3:4 封面插画。画风：1950 年代 B 级科幻怪兽电影海报——做旧的米黄色纸底，粗网点印刷质感，深墨蓝色线条，只用两种点缀色：荧光绿与警示橙；所有物件和看板娘用同一套线条与上色，整体是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力，但怪物是可爱的卡通形象，不血腥、不恐怖。背景只有大块留白和几道放射状光束，不画房间、街景或复杂界面。
最上方是主标题，分两行：“Codex关窗仍在跑？”“AI蠕虫进电视盒？”。粗壮的复古电影海报无衬线大字，深墨蓝字加警示橙色错位投影，是全画面最醒目的元素，宽度占画面约九成，每个字都清楚可读。不要副标题。
画面中下部摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一台合上盖子的笔记本电脑，盖缝里透出荧光绿的光；一个圆滚滚、长着两只小角的卡通小怪物（身上不写字）正从盖缝里钻出来，手里拎着一个鼓鼓的行李箱（行李箱上不写字），一脸得意；
2. 右：一个巴掌大的黑色电视机顶盒，罩在一个透明的实验室玻璃罩里；一条胖乎乎的荧光绿卡通小蠕虫从机顶盒的接口里探出半个身子，好奇地贴着玻璃往外看。机顶盒和玻璃罩上不写字。
看板娘按参考图（蓝色长发、狗耳、鲸鱼尾巴、女仆装、胸前“AI 吠点”圆牌；双手是正常的人手，不戴肉垫手套）在画面下方居中偏右出镜，同样用这套海报画风，扮成电影里起疑的女主角：一手举着手电筒把光照向两只小怪物，一手叉腰，歪头挑眉，表情狐疑；她只有两只手、两只耳朵、一条尾巴，全身完整入画。
