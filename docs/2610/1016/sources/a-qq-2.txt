DeepSeek V4.1 Flash-1017版正式发布

 [https://news.qq.com/omn/author/8QMd3XlZ74AYsDbY]
2026-10-17 17:09发布于河北

问AI · 新版本如何借自反馈学习提升从零构建能力？

IT时代网10月17日消息，国产大模型厂商 DeepSeek 旗下 V4.1 Flash 模型已更新至 V4.1-Flash-1017 版本，官方网页端、APP 与 API 模型同步变更为新模型，API 调用方式与价格保持不变，仍使用 deepseek-flash 即可访问最新模型。

据官方介绍，此次更新在性能与成本之间实现了帕累托改进。各项基准测试中，新版本模型能力较上一版 V4.1 Flash 有明显提升，同时任务运行时间与输出长度均有缩短，使单次调用的综合成本下降。

具体数据方面，新版本 HLE（不含工具）成绩为 42.6，Terminal-Bench 4.0 为 42.3，DeepSWE v1.1 为 77.0，ProgramBench 为 29.1，NL2Repo-Bench 为 68.2，Automation-Bench v1.0.6 为 60.5，Agents’ Last Exam 为 35.4，Apex Bench v1.1 为 72.1，Chartography（含工具）为 83.0，BabyVision（含工具）为 92.5，ZeroBench-main（含工具）为 51.0。

官方表示，新模型在提升性能的同时缩短了任务运行时间与输出长度，让用户能够以更低成本、更快速度完成任务，在多个 Harness 下达到新的性能-费用帕累托最优。

此次更新针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等平台做了适配优化，官方建议将 DeepSeek Harness 升级至 0.2.1-rc.1 或更高版本以获取完整适配。

在能力维度上，V4.1-Flash-1017 通过基于自反馈的强化学习训练，增强了模型从零构建完整项目的能力，覆盖游戏开发、3D 建模等场景。官方称这一改进使模型能够承接更多许愿式编程请求，即在提示词和素材参考极为有限的条件下直接生成可运行的项目成果。

官方演示案例显示，在 DeepSeek Harness 环境中，新版本以极短的交互轮次完成了完整项目的搭建。

此外，V4.1-Flash-1017 的模型权重已同步开放下载，在 HuggingFace 和 ModelScope 上均提供权重文件，延续了 V4.1 Flash 以 MIT 许可证开源的策略。

此前，本站曾报道过 DeepSeek 新模型短暂上架后撤下，此次为该模型的正式发布。
