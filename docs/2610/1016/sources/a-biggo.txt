DeepSeek Releases V4.1 Flash Update: Cheaper Inference, Stronger Coding, and First-Ever Public Access to Its Proprietary Search API

Add preferred source [https://www.google.com/preferences/source?q=finance.biggo.com]

DeepSeek updated its V4.1 Flash model to V4.1-Flash-1017 on October 17, rolling out the new version simultaneously across web, app, and API channels. The new version achieved top scores on multiple benchmarks including DeepSWE, Automation-Bench, and others, outperforming Claude Opus 5, GPT-5.6-Sol, Kimi K3, and GLM 5.3. Notably, it delivered these gains while reducing task runtime and output length—a dual optimization of performance and cost. On DeepSWE v1.1, the top tier achieved a 77.0% pass rate at roughly 1.3 yuan (approximately $0.19) per task, down sharply from 3.3 yuan (approximately $0.49) for the prior version. DeepSeek also opened its proprietary search API to the public for the first time, adding Search and Fetch endpoints priced at 5 yuan (approximately $0.75) per 1,000 calls. The search engine handles hundreds of millions of requests daily, indexes hundreds of billions of web pages globally, and filters for SEO spam, GEO manipulation, and low-quality AI-generated content. Model weights are open-sourced on HuggingFace and ModelScope under the MIT license, with 763B total parameters and a 1M-token context window.

Barely a month after its last model release, DeepSeek is iterating again. On the afternoon of October 17, DeepSeek officially announced the update of its V4.1 Flash model to V4.1-Flash-1017, with the web, app, and API endpoints switched over simultaneously. Unlike a routine minor version bump, this release also saw DeepSeek open up the API for its proprietary search engine—putting the underlying search capability that handles hundreds of millions of requests daily on public display for the first time.

V4.1 Flash was only formally released by DeepSeek on September 10, making the 1017 version just over a month removed from its predecessor. The official technical report describes this update as "a minor update," but the published evaluation data suggests the capability gains far exceed what the word "minor" implies.

Capability Gains and Cost Reductions in Tandem

In the official test data, V4.1-Flash-1017 achieved top scores across multiple domains including DeepSWE v1.1 (an AI coding benchmark), Automation-Bench (an agent business-task benchmark), Agents' Last Exam, and Apex Bench v1.1 (a multimodal agent benchmark), outperforming Claude Opus 5, GPT-5.6-Sol, as well as China's Kimi K3 and Zhipu GLM 5.3.

Compared with the prior version, 1017 improved across all 11 benchmarks. More notably, the new model achieved these performance gains while actually reducing task runtime and output length. DeepSeek describes this as a "Pareto improvement in performance versus cost." Taking DeepSWE v1.1 as an example, V4.1-Flash-1017 achieved a 77.0% pass rate at the highest tier with an average cost of roughly 1.3 yuan (approximately $0.19) per task; at the lowest tier, the pass rate was 72.6% with per-task cost under 0.8 yuan (approximately $0.12). By comparison, the prior version posted a 74.2% pass rate at the highest tier at roughly 3.3 yuan (approximately $0.49) per task, while Claude Opus 5 at its highest tier costs nearly 80 yuan (approximately $12) per task.

API unit pricing remains unchanged, with the model name still listed as deepseek-flash. Because outputs are shorter and runtimes lower, developers' actual token consumption should decline, reducing the real cost per task.

The official pricing page also specifies: 1M context length, 384K maximum output tokens, concurrency limit of 2,500, and thinking mode enabled by default with the option to switch to non-thinking mode.

For developers in overseas markets such as Japan, the API offers both OpenAI-format (https://api.deepseek.com [https://api.deepseek.com]) and Anthropic-format (https://api.deepseek.com/anthropic [https://api.deepseek.com/anthropic]) endpoints, allowing tools like Claude Code and Codex to work with existing configurations. The official English pricing page lists the three tiers above at $0.003/$0.006 per million tokens (cache hit), $0.15/$0.30 (cache miss), and $0.60/$1.20 (output), respectively.

From "Typing in a Chat Box" to "Wish-Based Programming"

The experiential improvement in agentic coding scenarios is particularly striking with this update. DeepSeek says V4.1-Flash-1017, trained with self-feedback reinforcement learning techniques, has enhanced its ability to build complete projects from scratch in areas like game development and 3D modeling, supporting more "wish-based" programming tasks and project development requests.

"Wish-based programming" refers to a workflow where the user states a goal, and the model autonomously analyzes code structure, invokes the terminal, modifies programs, runs tests, and continues debugging based on error messages—minimizing human intervention until the task is complete. This shift from "supervisor-style interaction" to "autonomous delivery of results" is the core experiential change in agentic scenarios with this upgrade.

DeepSeek's update also focused on optimizing for three platform frameworks: its own DeepSeek Harness, plus Tencent's CodeBuddy and WorkBuddy. The official DeepSeek Harness account simultaneously released version 0.2.1 to support the new model, noting that the model received targeted optimization for this framework during training, improving task performance while reducing runtime, output consumption, and token costs.

Proprietary Search API Opens Up: From Backstage to Center Stage

If model performance iteration was expected, the opening of the proprietary search engine API was a move that exceeded expectations.

According to the official introduction, DeepSeek's search capabilities on both the web and API sides are powered by its in-house search engine, which stably handles hundreds of millions of search requests daily from around the world. The engine indexes hundreds of billions of web pages globally, supports multilingual search, and has built identification and filtering mechanisms targeting SEO spam, GEO manipulation, and low-quality AI-generated content to ensure authoritative and trustworthy information is presented to users and large models.

Starting October 17, this battle-tested underlying search capability—validated by massive traffic—is formally available to developers via API. DeepSeek API has added support for two new endpoints: Search and Fetch, both priced at 5 yuan (approximately $0.75) per 1,000 calls. Developers can use these endpoints to integrate DeepSeek's search capabilities directly into their own AI applications, completing the puzzle of real-time information retrieval.

For users who have already connected DeepSeek API through DeepSeek Harness, Claude Code, or Codex, server-side tool calls will automatically access these two endpoints. Before 00:00 on November 1, Search and Fetch calls within these tools are free; after that, they will be billed per call.

Search returns 1–50 results per call (default 10), with query support for site:, lang:, after:, before: and other search syntax. Each result carries a rerank_score of 0–3 (1.5 or above indicates a quality result) and an authority rating of 0–4 (3 or above indicates highly authoritative). Failed, empty, or timed-out requests are not billed. Rate limits for Search and Fetch are calculated independently per account, and Fetch has additional restrictions per target domain.

Open Source and Deployment Information

V4.1-Flash-1017 model weights are now available on HuggingFace and ModelScope under the repository name DeepSeek-V4.1-Flash-1017. The model has 763B total parameters, is released under the MIT open-source license, supports interleaved image-text input, and features a 1M-token context window. Official recommended parameters are temperature 1.0 and top_p 1.0, with max_tokens no lower than 256K.

From a strategic standpoint, DeepSeek's approach with this update is clear: rather than making noise about version numbers or model size, the company is emphasizing practical efficiency and engineering deployment across the board. More precise reasoning compresses task time and token consumption; stronger agent capabilities support the "wish-based programming" experience; and the open proprietary search API fills in the real-time information gap. For developers and users alike, the ability to actually complete complex tasks with fewer resources and greater speed carries more practical value than benchmark scores alone.
