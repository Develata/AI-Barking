快科技10月17日消息，据DeepSeek官方公众号今日消息，DeepSeek V4.1 Flash现已更新至V4.1-Flash-1017版本，官方网页端、APP与API模型已同步变更为新模型。

据官方介绍，DeepSeek V4.1 Flash 1017通过基于自反馈的强化学习（RL）训练技术，提升了在游戏开发、3D建模等方面从零开始构建完整项目的能力，能够支持实现更多“许愿式”编程任务及项目开发请求。

不仅如此，本次新版本发布 DeepSeek API 新增对 Search 与 Fetch 接口的支持，相关能力正式向公众开放。

据了解，两个接口价格均为5元 / 千次，详细使用方法请参考官方API文档：API 指南 - 网页搜索与抓取。

官方同时提醒：当前用户在DeepSeek Harness / Claude Code / Codex 中使用 DeepSeek API时，已经会通过Server端工具调用访问到 Search/Fetch 接口。

据介绍，这部分 Search/Fetch 接口调用目前未计费，并将在两周后（北京时间2026年11月1日00:00）开始按次收取调用费用。

DeepSeek V4.1 Flash新版本上线后，评论区网友怒赞刷屏，有网友调侃“我就是知道，你那天挂机就是背着我们偷偷进步。太上进了”，还有网友直呼，“ x x什么超级斩杀线”。

关于新版本的真实性能表现，快科技将持续跟进、带来后续报道。
