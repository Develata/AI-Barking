DeepSeek 刚刚发布了 DeepSeek-V4.1-Flash-1017，这是其 V4.1-Flash 模型的新检查点。它已在 DeepSeek 网站、应用和 API 上线 [https://x.com/deepseek_ai/status/2111375640717033777]。DeepSeek 声称，相比 9 月发布的 V4.1-Flash [https://api-docs.deepseek.com/updates]，它的分数更高、任务完成更快、输出更短。该公司称其在性能与成本上实现了帕累托改进。与此同时，DeepSeek 向所有开发者开放了其 Search 和 Fetch API [https://api-docs.deepseek.com/guides/search]。对于智能体构建者来说，这意味着一个更便宜的编码模型，加上一个第一方网络层，都通过同一个 API 密钥提供。

TL;aDR

规模：552B 骨干参数加 196B Engram 参数。预填充阶段每 token 激活 8B 参数，解码阶段激活 16B。上下文为 1M token，最多可输出 384K token。

运行于：DeepSeek API，即 deepseek-flash。9 月 V4.1-Flash 权重（763B 参数，FP8）以 MIT 许可证在 Hugging Face 上发布。硬件要求和 1017 权重：未披露。

性能：在 DeepSeek 报告的全部 11 项基准上均超过此前的 V4.1-Flash，提升 2.0 至 11.1 分。

最佳：DeepSWE v1.1 上为 77.0，在 DeepSeek 的表格中高于 Claude Opus 5（74.0）。

最差：无工具 HLE 上为 42.6，而 Claude Opus 5 为 56.3。

什么是 DeepSeek-V4.1-Flash-1017？

DeepSeek-V4.1-Flash-1017 是 DeepSeek-V4.1-Flash 的更新后训练检查点，通过 deepseek-flash 模型名提供服务。以下架构细节来自 V4.1-Flash 技术报告 [https://arxiv.org/abs/2609.19969]。

DeepSeek 团队表示，DeepSeek-V4.1-Flash-1017 使用带自我反馈的强化学习来完成端到端项目工作。其示例从游戏创作到 3D 建模。它针对 DeepSeek Harness [https://deepseek-harness.github.io/deepseek-harness/en/guide/quickstart]、腾讯 CodeBuddy 和 WorkBuddy 进行了调优。DeepSeek 建议使用 DeepSeek Harness v0.2.1-rc.1 或更高版本。

V4.1-Flash 架构如何工作？

V4.1-Flash 是一个 多模态混合专家模型 [https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash]，有 40 层 Transformer。它们分为 20 层因果编码器和 20 层解码器。

因果编码器-解码器（CED）：解码器全局 KV 由最终编码器隐藏状态投影而来。这几乎将预填充计算减半。

压缩稀疏注意力 2（CSA2）：各层以 Full、Reindex 或 Reuse 模式运行。它们跨层共享主 KV 和索引器键。

FP4 主 KV 缓存：全局 KV 降至每 token 890 字节，约为 V4-Flash 的 1/4。

SWA 有界重放：持久 KV 缓存缩减至约 V4-Flash 的 1/8。

推理力度：1 到 100 的标量。API 的 low、high 和 max 档分别映射到 50、75 和 100。

DeepSeek 的 Search 和 Fetch API 是什么？

Search API [https://api-docs.deepseek.com/guides/search] 返回按排名排序的网页结果。Fetch API 以 Markdown 形式返回单个页面。DeepSeek 表示其自研引擎每天处理数亿次请求。

端点： POST /v1/tools/search 和 POST /v1/tools/fetch 位于 api.deepseek.com。

搜索选项： 1 到 50 条结果，可选页面内容，以及 site:、lang:、after: 和 before: 等运算符。

结果字段： 每条结果都有 0 到 3 的重排分数和 0 到 4 的权威等级。

价格： 每个端点每 1,000 次成功请求 $0.75 [https://api-docs.deepseek.com/quick_start/pricing]。空结果和失败免费。

速率限制： 每个 API 每账户 5 QPS。

免费窗口： 通过 DeepSeek Harness、Claude Code 或 Codex 发起的服务端调用在 2026 年 11 月 1 日前保持免费。

部署与定价

通过 OpenAI 或 Anthropic 格式端点使用 deepseek-flash 调用该模型。高峰定价 [https://api-docs.deepseek.com/quick_start/pricing]为每 1M 缓存未命中输入 token $0.30，每 1M 输出 token $1.20。非高峰费率为半价。
