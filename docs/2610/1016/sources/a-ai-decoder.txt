Deepseek V4.1 Flash 1017 beats larger rivals in agentic tasks while once again massively cutting per-task costs

中国 AI 公司 Deepseek 已发布其 Flash 模型的更新版本，在智能体任务和编程任务上取得大幅提升。该公司还首次向外部开发者开放其内部搜索引擎。

Deepseek-V4.1-Flash-1017 现已通过公司网站、应用和 API 提供。Deepseek 还在 Hugging Face [https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017] 和 ModelScope [https://modelscope.cn/models/deepseek-ai/DeepSeek-V4.1-Flash-1017] 上以开源形式发布了模型权重。与其直接前代相比，该模型基准测试得分更高、完成任务更快、输出更短。公司称此次更新是在性能与成本权衡上的帕累托改进。

对于从零构建完整软件项目，Deepseek 采用带自我反馈的强化学习（RLSF）。这种后训练方法让模型使用自身内部置信度分数或自我生成的批评作为奖励信号。这消除了对人类评估者或外部奖励模型的需求。Deepseek 表示，该方法改善了从游戏编程到 3D 建模 [https://x.com/deepseek_ai/status/2111375646223933650]和设计工作等任务的端到端项目开发。该模型还能制作简洁的讲解视频动画，与最近发布的 Opus 5.5 类似 [https://the-decoder.com/claude-opus-5-5-matches-fable-5-1-at-40-percent-lower-cost-as-anthropic-promises-to-fix-claudish-writing/]。

视频来自 FeiZ [https://x.com/Fei2411/status/2111339332405719137]

该模型针对 Deepseek Harness [https://www.deepseek.com/en/harness/]（建议使用 v0.2.1-rc.1 或更高版本）、腾讯 CodeBuddy 和 WorkBuddy 等开发环境进行了调优。

更小的 Flash 模型在编程和智能体任务上击败更大的竞争对手

在 Deepseek 自己的基准测试中，V4.1-Flash-1017 优于其前代 V4.1-Flash。它还在多个编程和 AI 智能体类别中击败了 Claude Opus 5、GPT 5.6-Sol、Kimi K3 和 GLM 5.3 等更大的竞争模型。

Deepseek V4.1-Flash-1017 在所有测试类别中均优于其前代。| 图片：Deepseek

DeepSWE 基准测试的成本图表显示了更短的输出对效率的重要性。V4.1-Flash-1017 以每任务略低于 0.20 美元的平均成本达到 77.0% 的最高分。在低设置下，它仍能以约 0.10 美元的成本超过 72%。前代得分为 74.2%，但每次运行成本约为 0.50 美元。

在智能体编程任务的平均成本上，Flash 模型以大幅优势低于竞争对手。| 图片：Deepseek

GPT-6 Astra、Gemini 3.8 Flash 和 Claude Opus 5 等竞争模型在此图表中每任务成本介于 2 美元到超过 10 美元之间，且没有一个能达到更小的 Deepseek 模型的准确率。独立基准测试尚未出炉，而且基准测试无论如何也只能说明一半的情况。例如，开发者对代码质量的印象可能与基准测试结果大相径庭。

Deepseek 将其内部搜索引擎转变为公共 API

除语言模型外，Deepseek 还向所有开发者开放其网络搜索工具（Search & Fetch API）。该公司表示，这些服务运行在其内部构建的搜索引擎上，该引擎每天已在全球处理数亿次查询。设置详情见 API 文档 [https://api-docs.deepseek.com/guides/search]。

每个端点每 1,000 次调用收费 0.75 美元。Deepseek API 用户可在 2026 年 10 月 31 日（UTC 16:00）之前，通过 Deepseek Harness、Claude Code 和 Codex 中的服务器端工具免费使用这些功能。

不过，昨天将中国 AI 模型深度整合进工作流程这件事确实变得没那么有吸引力了。据报道，中国政府计划 [https://the-decoder.com/china-plans-to-tighten-export-controls-on-open-weight-models-and-23-key-ai-technologies/]收紧开放权重模型的发布规则，甚至可能完全禁止其发布。一个决定性因素是某个系统是否跻身能力最强的十大模型之列。
