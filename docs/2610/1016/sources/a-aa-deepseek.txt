DeepSeek offers 9 models, each with different intelligence, performance, and pricing characteristics. Below is a comparison of the key metrics across models.

For intelligence, the top models on DeepSeek are DeepSeek V4.1 Flash (max) (39), DeepSeek V4 Pro 0813 (max) (36), and DeepSeek V4 Flash Vision (max) (35).

For output speed, the fastest models are DeepSeek V4.1 Flash (max) (176 t/s), DeepSeek V4 Flash Vision (max) (173 t/s), and DeepSeek V4 Flash 0731 (max) (173 t/s). Speed varies significantly across models, with a 109% difference between the fastest and slowest.

For latency, DeepSeek V4.1 Flash (non-reasoning) (1.27s), DeepSeek V4 Pro 0813 (non-reasoning) (1.68s), and DeepSeek V4 Pro (non-reasoning) (1.68s) offer the lowest time to first answer token.

For pricing, DeepSeek V4 Pro (max) ($0.18), DeepSeek V4 Pro (high) ($0.18), and DeepSeek V4 Pro (non-reasoning) ($0.18) offer the lowest blended prices per 1M tokens.

For context window size, DeepSeek V4 Pro 0813 (max) (1M), DeepSeek V4.1 Flash (max) (1M), and DeepSeek V4 Flash Vision (max) (1M) support the largest context windows on DeepSeek.

DeepSeek V4.1 Flash (max) offers the best combination of intelligence and speed. For cost optimization, DeepSeek V4 Pro (max) provides the most competitive pricing.

What Cache Hit Rate Shows

The share of cacheable input tokens served from the provider's prompt cache, measured during multi-turn agentic coding sessions. We regularly measure each endpoint and report a representative rate based on recent measurements. Higher values mean more of the input is billed at the cheaper cache-hit price, where the provider offers one, which lowers the effective cost of agentic workloads. For further details, see our methodology page [/methodology/performance-benchmarking].

Common questions about DeepSeek

What models does DeepSeek offer?

What is the most intelligent model on DeepSeek?

The most intelligent model available on DeepSeek is DeepSeek V4.1 Flash (max) [/models/deepseek-v4-1-flash] with an Intelligence Index score of 39.

What is the fastest model on DeepSeek?

The fastest model on DeepSeek by output speed is DeepSeek V4.1 Flash (max) [/models/deepseek-v4-1-flash] at 175.9 tokens per second.

Which model has the lowest latency on DeepSeek?

The model with the lowest time to first answer token on DeepSeek is DeepSeek V4.1 Flash (non-reasoning) [/models/deepseek-v4-1-flash-non-reasoning] at 1.27s. Lower latency means faster initial response time.

What is the cheapest model on DeepSeek?

The most affordable model on DeepSeek by blended price is DeepSeek V4 Pro (max) [/models/deepseek-v4-pro-0424] at $0.18 per 1M tokens (7:2:1 cache hit/input/output ratio).

How much do prices vary across models on DeepSeek?

Prices on DeepSeek vary up to 4x across models, from $0.18 per 1M tokens for DeepSeek V4 Pro (max) [/models/deepseek-v4-pro-0424] to $0.69 per 1M tokens for DeepSeek V4 Pro 0813 (non-reasoning) [/models/deepseek-v4-pro-non-reasoning].

Is DeepSeek OpenAI compatible?

Yes, DeepSeek offers an OpenAI-compatible API, making it easy to switch from OpenAI or use existing OpenAI SDK integrations.

Does DeepSeek support JSON mode?

Yes, all 9 models on DeepSeek support JSON mode for structured output.

Does DeepSeek support function calling?

Yes, all 9 models on DeepSeek support function calling (tool use).

Does DeepSeek offer reasoning models?

Yes, DeepSeek offers 6 reasoning models: DeepSeek V4.1 Flash (max) [/models/deepseek-v4-1-flash], DeepSeek V4 Pro 0813 (max) [/models/deepseek-v4-pro], DeepSeek V4 Flash Vision (max) [/models/deepseek-v4-flash-vision], DeepSeek V4 Flash 0731 (max) [/models/deepseek-v4-flash], DeepSeek V4 Pro (max) [/models/deepseek-v4-pro-0424], and DeepSeek V4 Pro (high) [/models/deepseek-v4-pro-0424-high]. Reasoning models use extended thinking to work through complex problems before providing an answer.

Does DeepSeek offer open weight models?

Does DeepSeek's performance change over time?

Yes, provider performance can vary over time due to infrastructure changes, load balancing, and updates. We continuously benchmark all providers and display historical performance trends in the "Over Time" charts.

How do I choose a model on DeepSeek?

When choosing a model on DeepSeek, consider: intelligence (for quality-sensitive tasks), output speed (for throughput-intensive tasks), latency (for interactive applications requiring quick first responses), pricing (for cost-sensitive workloads), and features like context window size, JSON mode, or function calling support.
