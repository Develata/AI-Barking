DeepSeek搜索收费？NSA种子身世

AI 沸点，今日谁吠？

省流：DeepSeek 搜索接口按次收费，Claude Code 等客户端经 DeepSeek API 的服务端搜索11月起也收费。Anthropic 称 Claude 不到半小时找出 NIST 曲线种子的来历，不是破解。Anthropic 技术岗新招聘中初级占比从27%降到9%，降的是招聘占比，不能推出裁员。

一、DeepSeek 搜索要收钱？

DeepSeek 10月17日把 deepseek-flash 升级为 V4.1-Flash-1017 并开放权重，API 价格不变；同日开放自研搜索 API，Search、Fetch 各按每千次成功请求5元计费。

吠点：
①在 DeepSeek Harness、Claude Code、Codex 里用 DeepSeek API 时，服务端工具已在调用搜索，目前不计费，北京时间11月1日起按次收。据文档，Claude Code 里搜不搜由模型判断。
②官方对比表里的美国模型是 GPT-5.6-Sol 和 Opus-5，不是9月下旬发布的 GPT-6-Sol、Opus-5.5；11项里 Opus-5 仍有6项最高。表为官方公布。

二、NSA 曲线种子的身世

北京时间17日凌晨，Anthropic 称 Claude 不到半小时找出 P-256 等5条 NIST 椭圆曲线种子的来历：1997–1998年用时间戳初始化的随机数生成器的输出。这些种子由美国国家安全局提供，当年没附说明。

吠点：
①不是破解：Anthropic 写明这不算攻破或新弱点；悬赏发起人、密码学家 Valsorda 称，即便放宽到任选当年时间戳和前16个素数阶候选，余地也仅约30比特，不够埋“只有设计者能用”的后门。
②没全解开：Valsorda 称可用种子约是公布数的两倍，跳过原因找不到合适解释；四条曲线的基点也仍未解释。

三、AI 公司少招新人？

Anthropic 发布内部用工研究：技术岗新招聘中初级占比从27%降到9%，技术招聘绝对数仍在增长。

吠点：
IT 之家标题写“AI 工时已是人类6倍”：这是8月数据，只算员工发起的交互式会话，分子是 agent 运行时长（不含超30分钟的等待），分母按人头乘每周40小时算。

AI 吠点：聊 AI 沸点，轻松识破吠点。
