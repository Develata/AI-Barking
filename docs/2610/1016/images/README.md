竖版 3:4 封面插画。画风：1990 年代复古电脑杂志封面——深藏青底色，荧光绿与洋红为主色，少量米白；物件用粗轮廓扁平插画，边缘带一点像素点阵质感，像老式 CRT 屏幕上的图形；所有物件和看板娘用同一套线条与上色，整体是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。背景只有大块平涂深色与稀疏的扫描线，不画复杂场景。
最上方是主标题，分两行：“DeepSeek搜索收费？”“NSA种子身世”。粗壮的荧光绿无衬线大字，带一点像素描边，是全画面最醒目的元素，宽度占画面约九成，每个字都清楚可读。不要副标题。
