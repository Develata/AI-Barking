## 二、可能的吠点（原文里有、线索摘要没提或说反的条件）

1. AUP 条文只有一句 “Engage in sustained and needless abusive or cruel behavior toward our models”，没有任何定义、例子或豁免。“extreme cases”“no discernible purpose”“does not apply to… user frustration, pushback, dark creative themes, or model testing and research” 只写在 2026-10-08 的公告里，不在 AUP 正文（来源：b-aup.txt 第 175 行；b-announce.txt）。公告是博客，AUP 是合同性文本，两者效力不同——未核对 Consumer Terms 等如何引用 AUP，此点为推断。
2. “结束对话是主要执行手段”是公告的话。AUP 开头的通用后果条款列的是 “warn… or throttle, limit, suspend, or terminate”，其中没有“结束对话”。官方没有说明本条在什么情形升级到封号；The Verge、Newser、Dexerto、Gizmodo 都写 Anthropic 没回应这一点。
3. 新条款 2026-11-12 才生效（公告与 AUP 页顶 “Effective November 12, 2026”）。“已禁止”“now”类说法在此之前不准确。
4. 结束对话工具的覆盖范围比 AUP 窄：研究页（2025-08-15）只写 Claude Opus 4 与 4.1、“consumer chat interfaces”；Claude Code 文档写需 v2.1.213+、Opus 4.8 / Sonnet 5 / Fable 5 或其后继、仅交互终端，`-p`、Agent SDK、VS Code 扩展、GitHub Actions、云端会话、Bedrock/Foundry 等均不含；Opus 4.7 系统卡（2026-04-16）写 “no models have the ability to end conversations in Claude Code or the API”。而 AUP 适用于 API 与云厂商用户。因此对 API/SDK/非交互场景，“结束对话为主要手段”在一手文字里没有对应的机制（推断，未见 Anthropic 对 API 的说明）。
5. Claude Code 的触发条件比公告更窄：文档写 “after attempts to redirect the conversation have failed and after a clear warning in an earlier message”，并明说 “General frustration, profanity… don’t qualify”。变更日志（2026-07-18）却写 “highly abusive users or jailbreak attempts”，多了“越狱”——公告没提。
6. 研究页的理由不只是“福利”：“developed primarily as part of our exploratory work on potential AI welfare, though it has broader relevance to model alignment and safeguards.” 同页：“We remain highly uncertain about the potential moral status of Claude and other LLMs”。2026-10 公告本身没有出现 “welfare” 一词，也没有解释为什么要禁（AFP 与 HN 评论也指出这点）。
7. 公告说 “We’ve added a prohibition”，同时开头说 “Most of the updates… are intended to clarify existing rules”：虐待模型是新增，不是澄清。
8. 研究页的结束对话还包括“用户明确要求结束”，用户主动叫停也算。
9. 36氪/新智元引了“Anthropic 透明度报告”称 2026 年上半年封号 1140 万、申诉 39.8 万、翻案 4.2 万；该数字本组未核（未找原报告），不要用。
10. Verge 页面 `datePublished` 与公告同为 17:00:00Z，页面可见时间 “1:00 PM EDT” 与之一致；HN 上 Verge 帖提交于 17:08:02Z。发布时刻以 17:00Z 为准，HN 时刻可作上界。
