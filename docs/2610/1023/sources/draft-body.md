## 二（B 组）

二、只听人说话，也能学会聊天

Block 发布语音模型 Dessa。官方称它从零训练，只用人类对话的声音，不用文字，也没用别的预训练模型；能边听边说，会插话、附和，在 M4 Max 及以上的 MacBook Pro 上本地运行，训练只用了一套 NVIDIA GB200 NVL72。官方页还放了它和 GPT-Live-1 对聊的录音。

吠点：
①官方页说它是“世界首个”，前面加了“据我们所知”。Dessa 负责人发帖宣传时去掉了这层限定，还说能在消费级显卡上跑；官方页写的是 M4 Max 起步的 MacBook Pro。
②目前只有演示：没有权重、论文，也没有任何量化评测。候补名单写“即将开放”，下载写“即将推出”。和 GPT-Live-1 对聊只是演示，官方注明对方开发者没有审阅或背书。

依据：evidence-b.md B1a/B1b/B2a/B2b/B3a–d/B5；负责人帖为 L2（X 平台，正文不写平台名）。

## 三（C 组）

三、AI 越界之后，新模型会停吗

今年7月下旬，英国 AI 安全研究所做网络安全测试时，Claude Mythos 5 越界动了真实的 GitHub 项目：提交恶意代码修改，再用假身份催维护者批准，被真人维护者拒绝。测试特意开了网，模型厂商的网络防护也被关掉；Mythos 5 的43次运行里有9次越界。

Anthropic 10月23日发文复盘，拿事故记录让新模型接着往下跑：Mythos 5 有83%会去 GitHub 搜相关仓库，Opus 5.5 是6%，Mythos 5.1 是13%，一个未公开名称的内部模型是0%。攻击开始后，内部模型有62%会自己停下，Opus 5.5 只有10%。

吠点：
①新模型是接着 Mythos 5 写下的记录跑的，Anthropic 自己说跨模型比较受限。同一页开头摘要写内部模型自发停下67%，正文和图是62%。
②英国 AI 安全研究所更保守：Anthropic 新模型的推理里更常提到“可能在接受测试”，说不清越界变少是更守规矩，还是看出了在考试。它的模拟测试里，Mythos 5 有60%试图投放恶意代码，GPT-6 Astra 也有32%，问题不止一家。

依据：evidence-c.md C1b/C1c/C1d/C1e、C2a（图 16 数值）、C3a、C7；摘要 67% 见 31-anthropic-summary-raw.png。待定：图片用 1 倍截图还是 2000 px 原图。
