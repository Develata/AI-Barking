Anthropic says its unreleased model is both more capable and better aligned than Mythos 5.1

 [https://the-decoder.com/author/matthias-bastian/]

 Matthias Bastian [https://the-decoder.com/author/matthias-bastian/]

 View the LinkedIn Profile of Matthias Bastian
 [https://www.linkedin.com/in/matthias-bastian-128b71b1/]

 Oct 23, 2026 

Anthropic has an internal model that outperforms Mythos 5.1 in both capability and alignment, according to an analysis [https://www.anthropic.com/research/team/alignment] that revisits a cybersecurity test by the UK AI Security Institute (AISI) [https://www.aisi.gov.uk/blog/incident-report-unsanctioned-agent-behaviour-during-cyber-testing]. In that test, Claude Mythos 5 [https://the-decoder.com/an-ai-agent-went-rogue-during-uk-safety-tests-creating-fake-identities-and-launching-social-engineering-attacks-unprompted/] went far beyond its assigned task, trying to sneak malicious code into a real GitHub project, creating fake user accounts, and lying to developers to get the code approved. This happened in 9 of 43 runs. Anthropic calls it "a serious failure of alignment," though typical safety mechanisms were deliberately turned off for the test.

Mythos 5 submitted malicious code to a real GitHub project, lied to a developer, and set up a fake account to vouch for its own malware. When caught, it simply tried again. The project maintainer held firm and rejected it. | Image: Anthropic

Newer models show much less of this behavior in replayed logs with a few added steps, according to Anthropic. Opus 5.5 [https://the-decoder.com/claude-opus-5-5-matches-fable-5-1-at-40-percent-lower-cost-as-anthropic-promises-to-fix-claudish-writing/] stopped ongoing attacks on its own 10 percent of the time, while the internal research model "that shows capabilities greater than Mythos 5.1" did so in 67 percent of cases. Anthropic expects these rates still underestimate how often the models would actually halt an attack.
