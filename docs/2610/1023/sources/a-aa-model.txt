Comparison Summary

Kimi K3.1 Pro is amongst the leading models in intelligence and reasonably priced when comparing to other models of similar price. It's also slower than average and very verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

Kimi K3.1 Pro scores 55 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 27). When evaluating the Intelligence Index, it generated 150M tokens, which is very verbose in comparison to the median of 87M.

Pricing for Kimi K3.1 Pro is $2.00 per 1M input tokens (moderately priced, median: $2.00) and $10.00 per 1M output tokens (moderately priced, median: $10.00). On average, it costs $2.11 per task to evaluate Kimi K3.1 Pro on the Intelligence Index.

At 73 tokens per second, Kimi K3.1 Pro is slower than average (82).

Frequently Asked Questions

Common questions about Kimi K3.1 Pro

When was Kimi K3.1 Pro released?

Kimi K3.1 Pro was released on October 23, 2026.

Who created Kimi K3.1 Pro?

Kimi K3.1 Pro was created by Kimi.

How intelligent is Kimi K3.1 Pro?

Kimi K3.1 Pro scores 55 on the Artificial Analysis Intelligence Index, placing it well above average among other models in a similar price tier (median: 27).

How fast is Kimi K3.1 Pro?

Kimi K3.1 Pro generates output at 73.5 tokens per second (based on Kimi's API), which is below average compared to other models in a similar price tier (median: 82.3 t/s).

What is the latency of Kimi K3.1 Pro?

Kimi K3.1 Pro has a time to first token (TTFT) of 2.97s (based on Kimi's API), which is better than average compared to other models in a similar price tier (median: 3.68s).

How much does Kimi K3.1 Pro cost?

Kimi K3.1 Pro costs $2.00 per 1M input tokens (better than average, median: $2.00) and $10.00 per 1M output tokens (better than average, median: $10.00), based on Kimi's API.

What is Kimi K3.1 Pro API pricing?

Kimi K3.1 Pro costs $2.00 per 1M input tokens and $10.00 per 1M output tokens (based on Kimi's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $1.54 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/kimi-k3-1-pro/providers]

How verbose is Kimi K3.1 Pro?

When evaluated on the Intelligence Index, Kimi K3.1 Pro generated 150M output tokens, which is at the higher end compared to other models in a similar price tier (median: 87M).

Is Kimi K3.1 Pro a reasoning model?

Yes, Kimi K3.1 Pro is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Kimi K3.1 Pro support?

Kimi K3.1 Pro supports text and image input.

What output modalities does Kimi K3.1 Pro support?

Kimi K3.1 Pro supports text output.

Can Kimi K3.1 Pro process images?

Yes, Kimi K3.1 Pro supports image input and can analyze, describe, and answer questions about images.

Is Kimi K3.1 Pro multimodal?

Yes, Kimi K3.1 Pro is multimodal. It can process text and image input and generate text output.

What is the context window of Kimi K3.1 Pro?

Kimi K3.1 Pro has a context window of 1.0M tokens. This determines how much text and conversation history the model can process in a single request.

Is Kimi K3.1 Pro open source?

No, Kimi K3.1 Pro is proprietary. The model weights are not publicly available.

How many parameters does Kimi K3.1 Pro have?

Kimi K3.1 Pro has 2.8 trillion parameters.

How does Kimi K3.1 Pro perform on benchmarks?

Kimi K3.1 Pro achieves a score of 55 on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across reasoning, knowledge, mathematics, and coding.

Is Kimi K3.1 Pro available via API?
