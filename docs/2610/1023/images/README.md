## 封面

画风：复古丝网印刷体育海报（三色套印、网点），跳高横杆前三个玩具机器人——最高的虚线“幽灵”是假想对照版，中间实体比它矮却远高于右边小号旧机器人，呼应“压低是跟谁比”；看板娘当裁判拿卷尺量。本期首次用此画风（1021–1022 为纸艺）。主标题「“压低”了，跟谁比？」为问句，不含品牌名与“攻击”，不宣称任何数字。

生成方式：Codex CLI 内置图像生成（gpt-6-astra medium），参考仓库通用看板娘全身设定图。竖横各2候选，横版另做1次局部编辑：
- 竖版选候选1：主标题逐字正确，胸牌放大4倍为「AI／吠点」，两只正常人手（一手持卷尺、一手指向旧机器人），无多余文字。候选2文字也正确，但构图更挤，落选。
- 横版：候选1与2的胸牌文字均糊成乱码，淘汰原图；以候选1为底，用 Codex 编辑只修胸牌，得到采用版。放大4倍胸牌为「AI／吠点」（“点”笔画略软，缩略图下可辨）；两只正常人手（一手持卷尺、一手叉腰）；居中820×820方形裁切后标题与看板娘完整。

尺寸：竖版1086×1448（精确3:4），横版1918×820（约2.34:1）。候选与编辑稿留在会话草稿目录，不入库。发布时声明封面为AI生成。
