最新动态 ​ [#最新动态]

记录 Kimi Code 各产品的新功能与核心修复，重点介绍最值得关注的变化。

最新模型发布
K3.1 Pro 系列上线 2026 年 10 月 23 日 ​ [#k3-1-pro-系列上线-2026-年-10-月-23-日]

🎉 K3.1 Pro 现已全量上线 Kimi Code，这是全新 K3.1 系列的第一个模型，也是我们迄今能力最强的三万亿级参数模型，支持 100 万上下文，在代码、3D 创作、金融研究和其他长程 Agent 能力上的提升尤为显著。我们还同步推出了 K3.1 Pro Highspeed，在相同的模型效果下，其速度是 K3.1 Pro 的约 2–3 倍。→ 技术报告 [https://www.kimi.com/en/blog/kimi-k3-1-pro]

会员权限说明 ​ [#会员权限说明]

K3.1 Pro：Plus / Moderato 及以上可用，Pro / Allegretto 及以上解锁最高 1M 上下文。

K3.1 Pro Highspeed：Pro / Allegretto 及以上可用。

更多权益对比见 模型配置 [/code/docs/kimi-code/models.html]

使用建议 ​ [#使用建议]

保持思考开启：K3.1 Pro 系列仅支持思考模式，提供 low / high / max 三档，默认 high；关闭思考会返回 400。

新建会话后再使用：不要在 K3 系列、K2.8 Preview、K2.7 Code Highspeed 的历史会话中切换到新模型，以免效果异常并降低缓存命中。

使用原生接口协议：推荐使用 Kimi Coding Plan 原生 Responses、chat completion、message 接口协议，以获得最佳效果稳定性，代理协议转换可能引起效果波动。

Kimi Code Desktop
v1.1.1 2026 年 10 月 21 日 ​ [#v1-1-1-2026-年-10-月-21-日]

工作区信任确认 ​ [#工作区信任确认]

打开未信任的文件夹时会提示是否信任该工作区，选择不信任则无法发送消息。→ 工作区管理 [/code/docs/kimi-code-desktop/project-and-session-management.html#工作区管理]

切换模型确认 ​ [#切换模型确认]

会话中切换模型时会确认下一步：新建会话、压缩当前上下文后继续，或直接继续。→ 界面导览 [/code/docs/kimi-code-desktop/interface-and-sessions.html#主要区域]

会话重新加载 ​ [#会话重新加载]

在应用外修改 AGENTS.md、技能或配置后，输入 /reload 或从会话菜单选择“重新加载会话”即可立即应用，无需重启桌面端。→ 会话管理 [/code/docs/kimi-code-desktop/project-and-session-management.html#会话管理]

此外：/compact 可在 Agent 运行期间排队，轮到它时自动执行；修复长对话流式输出时界面卡顿、电脑发热的问题。→ 常用命令 [/code/docs/kimi-code-desktop/input-and-context.html#常用命令] · 变更记录 [/code/docs/kimi-code-desktop/changelog.html]

Kimi Code CLI
v2.3.0 2026 年 10 月 21 日 ​ [#v2-3-0-2026-年-10-月-21-日]

插件技能改用限定名 ​ [#插件技能改用限定名]

插件 Skill 以 <插件ID>:<技能名> 列出和调用，不同插件的同名技能不再互相遮挡；裸名调用不再生效，需改用限定名。→ Skills 与会话启动 [/code/docs/kimi-code-cli/customization/plugins.html#skills-与会话启动]

切换模型确认 ​ [#切换模型确认-1]

会话中切换模型时弹出确认：新建会话、压缩上下文后继续，或直接继续。→ /model [/code/docs/kimi-code-cli/reference/slash-commands.html]

远程控制流式传输 ​ [#远程控制流式传输]

远程控制支持流式传输请求与响应，传输上限从 10 MiB 提升至 100 MiB。→ 远程控制 [/code/docs/kimi-code-cli/guides/remote-control.html]

此外：同一会话在多个客户端打开时会显示占用提示，可重试或取消；首轮对话后自动生成会话标题，并显示为终端窗口标题。→ 变更记录 [/code/docs/kimi-code-cli/changelog.html]

Kimi Code Desktop
v1.1.0 2026 年 10 月 14 日 ​ [#v1-1-0-2026-年-10-月-14-日]

Linux 版本 ​ [#linux-版本]

桌面端新增 Linux 支持，可在 x86_64 架构的 Linux 上通过 AppImage、deb 或 RPM 安装。→ 安装与启动 [/code/docs/kimi-code-desktop/getting-started.html#安装与启动]

远程控制 ​ [#远程控制]

在“设置 → 远程控制”中开启后，可通过链接或二维码从手机、平板或另一台电脑控制本机 Agent，任务和本地工具仍在运行桌面端的电脑上执行。→ 远程控制 [/code/docs/kimi-code-desktop/remote-control.html]

文件树面板 ​ [#文件树面板]

右侧栏新增文件树，可浏览、搜索和刷新工作区文件，点击即可预览；也可以按 Cmd + Shift + E（macOS）或 Ctrl + Shift + E（Windows / Linux）快速开关。→ 右侧面板 [/code/docs/kimi-code-desktop/interface-and-sessions.html#右侧面板]

此外：新增实验性进展更新，可在“设置 → 实验室”中为之后新建的会话开启；新增 kimi app 命令，从终端在当前或指定目录打开桌面端新会话。→ 实验室 [/code/docs/kimi-code-desktop/settings-and-extensions.html#实验室] · 从终端打开工作区 [/code/docs/kimi-code-desktop/getting-started.html#从终端打开工作区]

Kimi Code CLI
v2.2.0 2026 年 10 月 14 日 ​ [#v2-2-0-2026-年-10-月-14-日]

从终端打开 Desktop 新会话 ​ [#从终端打开-desktop-新会话]

新增 kimi app [path]：在当前或指定目录唤起桌面端并打开新草稿，适合从 CLI 直接切到图形界面继续任务。→ kimi app [/code/docs/kimi-code-cli/reference/kimi-command.html#kimi-app]

实验性进展更新 ​ [#实验性进展更新]

NotifyUser 让 Agent 在回合内发布简短进展；默认关闭，可在 TUI /experiments 或 Web / Desktop 设置的实验室中开启，仅影响之后新建的会话。→ 协作类工具 [/code/docs/kimi-code-cli/reference/tools.html#协作类]

后台等待可被消息打断 ​ [#后台等待可被消息打断]

WaitFor 最长等待 90 秒；等待期间按 Enter 或 Ctrl-S 可把消息注入当前轮次并提前结束等待，后台任务继续运行。→ 流式输出期间 [/code/docs/kimi-code-cli/guides/interaction.html#流式输出期间]

此外：全屏模式为用户消息保留一行摘要，点击可跳回原消息；用户技能卡片改为高亮提示词，并支持 Ctrl-S 发送。

Kimi Code CLI
v2.1.0 2026 年 9 月 23 日 ​ [#v2-1-0-2026-年-9-月-23-日]

全屏模式（实验性） ​ [#全屏模式-实验性]

新增实验性全屏界面：transcript 独立滚动、支持鼠标选择，点击折叠块即可展开或收起，底部还有可点击的 "Jump to bottom" 指示器。在 /settings 的 TUI mode 中开启，或在 ~/.kimi-code/tui.toml 中设置 tui_mode = "fullscreen"，重启 Kimi Code 后生效。→ tui.toml [/code/docs/kimi-code-cli/configuration/config-files.html#tui-toml]

启动更快、占用更低 ​ [#启动更快、占用更低]

缩短 CLI 启动时间并降低内存占用，大项目下的首屏等待明显变短。

文件监听默认关闭 ​ [#文件监听默认关闭]

对配置文件和工作区文件的监听默认不再开启；如需热更新 AGENTS.md、skills 或 MCP 配置，将 [watch] enabled 设为 true 或设置 KIMI_CODE_WATCH=1。→ watch [/code/docs/kimi-code-cli/configuration/config-files.html#watch]

此外：加强工作区安全限制——文件工具无法再通过符号链接访问工作目录外的文件，项目本地配置仅在工作区受信任后生效；新增 auto_session_title 配置，可关闭客户端自动生成会话标题。→ 配置文件 [/code/docs/kimi-code-cli/configuration/config-files.html#顶层字段]

Kimi Code Desktop
Kimi Code Desktop 正式发布 2026 年 9 月 17 日 ​ [#kimi-code-desktop-正式发布-2026-年-9-月-17-日]

Kimi Code 桌面客户端正式上线：延续 Kimi Code CLI 的 Agent 核心能力，在图形界面中打开项目、与 Agent 对话并交付改动。现已支持 macOS（Apple Silicon / Intel）和 Windows。→ 快速开始 [/code/docs/kimi-code-desktop/getting-started.html]

每一步都清晰可见 ​ [#每一步都清晰可见]

工具调用、思考过程和每轮修改的文件都在界面中呈现；敏感操作会弹出审批提示，始终询问 / 必要时询问 / 完全自动三档权限模式由你掌控。→ 处理审批 [/code/docs/kimi-code-desktop/task-execution-and-review.html#审批与权限]

从对话到交付的完整工作流 ​ [#从对话到交付的完整工作流]

目标模式持续推进长任务，可暂停、恢复或取消；计划模式先出方案再动手，计划可评审、可反馈；长任务还可转入后台继续运行，随时查看进度。→ 选择任务模式 [/code/docs/kimi-code-desktop/task-execution-and-review.html#任务模式]

内置浏览器与可视化标注 ​ [#内置浏览器与可视化标注]

浏览器进驻右侧面板，标签页随会话常驻，页面信息与 Agent 共享；截图标注、划词评论、@ 提及文件、网页元素点选，让 Agent 准确定位要修改的位置。→ 验证修改 [/code/docs/kimi-code-desktop/built-in-browser.html#标注并反馈]

下载：macOS · Apple Silicon [https://code.kimi.com/kimi-code/desktop/download/KimiCode-mac-arm64.dmg] · macOS · Intel [https://code.kimi.com/kimi-code/desktop/download/KimiCode-mac-x64.dmg] · Windows [https://code.kimi.com/kimi-code/desktop/download/KimiCode-win-x64.exe]

新增 /desktop 斜杠命令（别名 /install-desktop）与 kimi install-desktop 子命令，在浏览器中打开桌面端页面，从终端直达桌面端下载安装。→ kimi install-desktop [/code/docs/kimi-code-cli/reference/kimi-command.html#kimi-install-desktop]

v0.1.0 2026 年 5 月 ​ [#v0-1-0-2026-年-5-月]

Kimi Code CLI 新版首发，底层从 Python / uv 完整重写为 TypeScript / Node.js。这不是一次渐进式更新，而是一个新起点——核心架构、安装方式、配置格式全面升级。

与旧版 kimi-cli 的主要区别：

对比项旧版 kimi-cli新版 Kimi Code CLI

运行时Python + uvNode.js（无 Python 依赖）

安装uv tool install一行 curl 脚本或 npm install -g

配置文件~/.kimi/config.toml~/.kimi-code/config.toml（格式不兼容）

终端界面基础文本输出全功能 TUI（对话视图 + 状态栏 + 审批面板）

启动速度较慢（Python 冷启动）更快（Node.js 原生二进制）

多供应商支持有限内置 Anthropic / OpenAI / Gemini / Vertex 等

Agent 子任务不支持内置 coder / explore / plan 三种子 Agent

Plugin 系统不支持支持（v0.4.0 起）

定时任务不支持支持（v0.5.0 起）

已有 kimi-cli 数据（配置、会话、MCP 声明）可通过 kimi migrate 一键迁移。→ 版本升级 [/code/docs/kimi-code-cli/guides/migration.html]
