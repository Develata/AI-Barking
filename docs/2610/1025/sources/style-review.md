## 1. 标题

我会点的前三：

1. **“拍照问AI皮肤病？老网络比GPT准”**：拍照问病是我能想到的使用场景，我想知道这样问到底靠不靠谱。
2. **“10年前的AI比GPT准，却漏18个癌”**：“更准”和“漏癌”让我觉得矛盾，想点进去看怎么回事。
3. **“Kimi偷吃额度？官方道歉回拨25%”**：“偷吃”让我觉得付的钱可能白花了，想看看自己有没有吃亏，不过“回拨”不太懂。

看不清在说什么事的：

- **“老AI胜GPT却漏癌？Kimi认错补额度”**：前后像两件完全无关的事，我不知道为什么放在一个标题里。
- **“10年前AI胜GPT，Kimi道歉回拨额度”**：“胜GPT”没说比什么，“回拨额度”也不直观，读完只知道有两条新闻。
- **“皮肤科医生考AI：老网络赢了GPT”**：“老网络”让我先想到以前的互联网，不知道它也是一种 AI。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**：“谁吠”是在说谁说了假话，还是今天要批评谁？不明白栏目意思。
- **“Kimi 为订阅额度被白白耗掉道歉，补偿是回拨已用量，不是另发。”**：“回拨已用量”要读两遍，我得自己翻译成“把已经扣掉的额度退回来”。
- **“一、老网络认得准，却放走18个黑色素瘤”**：不知道黑色素瘤是什么、是否就是标题里的癌；“放走”也让我以为真的有病人被放回家了。
- **“盖伊医院皮肤科医生 Magnus Lynch 从公开数据集抽了200个活检确诊的皮肤病变，每个配一张近照、一张皮肤镜图，交给 GPT-6-Astra、Claude-Fable-5.1 和谷歌2015年发表的 Inception-v3 网络。”**：“公开数据集”“活检”“皮肤病变”“皮肤镜图”连续出现，后面又跟三个英文型号，到句末已经忘了前面在说什么。
- **“三者都要判断是六种病里的哪种、能否放病人回家。”**：只看图片就决定能不能回家吗？这里是在模拟答题，还是真的参与了看病，我没分清。
- **“诊断题，老网络对了125个，两个大模型分别对84、85个。”**：“大模型”是不是前面那两个聊天 AI？84、85 分别是谁，要回头找。
- **“能不能放回家，结果反过来：30个黑色素瘤里，老网络按预设阈值放走18个，GPT-6-Astra 放走3个，Claude 放走4个。”**：“预设阈值”不懂，也不明白为什么认病更准，却更容易放走癌症。
- **“①大模型漏得少，靠的是几乎都留下：100个良性病变，它们只放回家32、22个，老网络放回76个。”**：“留下”是住院还是继续检查？32、22 又得对应前面的两个名字。
- **“作者称把老网络的阈值调到与大模型看齐，只放走1到2个，但没给调后多留了多少良性病变。”**：“作者”是不是那位医生？“阈值调到与大模型看齐”是什么意思、为什么调一下就能从18变成1到2，我卡在这里。
- **“有海外科技站把它写成老网络‘漏得更少’，表里正相反。”**：“表”是哪个表？当前文字里没有表，我不知道该看哪里。
- **“所选病变都切过活检，比门诊常见的难认。”**：不懂“切过活检”和“难认”之间是什么关系。
- **“Kimi-K3.1-Pro 上线后，有付费用户称5小时额度几分钟就用完。”**：“5小时额度”是本来能用5小时，还是每5小时重新给一次？这两种理解差很多。
- **“北京25日晚，Kimi 开发者账号先更新了编程工具：默认不再自己派子 Agent 分头干活，要用得用户开口或打开集群模式。”**：“子 Agent”“集群模式”都不认识；“要用得用户开口”还得重新断句。
- **“26日凌晨，Kimi 致歉，承认限流和‘不必要的额度消耗’。”**：“限流”具体是不给用、变慢，还是限制使用次数？
- **“官方称所有档位订阅会员一次性回拨月度总额的25%，相当于一周用量；已用不足25%的直接清零。”**：“清零”第一眼像把剩余额度清掉了，要回头确认清掉的是已用量。
- **“官方称还在减少不必要的子 Agent 调用和输出长度。”**：“调用”不懂，“输出长度”是在说回答字数吗？

## 3. 像 AI 写的

- **“省流：皮肤科医生实测，十年前的老网络认皮肤病比 GPT 和 Claude 准，却放走了更多黑色素瘤。Kimi 为订阅额度被白白耗掉道歉，补偿是回拨已用量，不是另发。”**：两条完全不同的新闻都被压成“先说一件事，再纠正你的理解”，像自动生成的摘要。
- **“①这是把已用量往回拨，不是另发25%。”**：前面已经说过“回拨已用量，不是另发”，这里又重复一次同样的纠正式句型，有种模板在反复强调重点的感觉。
- **“②公告没说多少人受影响、多扣了多少，也没给修复后同样任务省多少额度。”**：三个“多少”排得很齐，像新闻总结末尾固定补上的“信息仍不充分”评价，读起来有套模板的感觉。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**：“沸点／吠点”来回押词，加上“轻松识破”的承诺，像让 AI 写栏目宣传口号的产物。

## 4. 会划走的地方

- **“盖伊医院皮肤科医生 Magnus Lynch 从公开数据集抽了200个活检确诊的皮肤病变……”**：这是我第一次想划走的地方。刚被“漏癌”吸引进来，马上碰到一长串医学词和英文型号，阅读门槛突然高了。
- **“作者称把老网络的阈值调到与大模型看齐，只放走1到2个，但没给调后多留了多少良性病变。”**：到这里我很可能真的划走。前面刚理解18、3、4，接着又有32、22、76，现在再来1到2，我已经跟不上比较。
- **“有海外科技站把它写成老网络‘漏得更少’，表里正相反。”**：这条吠点我不太在乎。我想知道拍照问 AI 能不能信，不太关心一个没名字的网站怎么写错了。
- **“北京25日晚，Kimi 开发者账号先更新了编程工具……”**：如果我是为了皮肤病点进来的，读到这里会觉得后半篇和我没关系；编程工具也不像是给我用的。
- **“有新浪数码标题写成‘发放25%月会员额度’。”**：这一句我不太在乎。前面解释清楚能退多少就够了，媒体标题用哪个词没有让我继续读的动力。
- **“②公告没说多少人受影响、多扣了多少，也没给修复后同样任务省多少额度。”**：这条吠点没有给我新的答案；读到结尾，我仍不知道现在用 Kimi 还会不会很快耗完额度。
