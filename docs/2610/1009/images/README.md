### 3:4 竖版提示词

竖版 3:4 封面插画。画风：黑白侦探漫画（noir comic）——米白色纸底，粗黑墨线，网点与斜线阴影，只用警灯红一种点缀色；所有物件和看板娘用同一套线条与上色，整体是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。背景只有大块留白与少量网点，不画街景或房间细节。
最上方是主标题，分两行：“Claude编命案线索？”“谷歌买员工邮件？”。粗壮的黑色漫画标题字，加警灯红色错位投影，是全画面最醒目的元素，宽度占画面约九成。
画面中下部摆三件主体，体量大，彼此留出空隙，不堆小物件：
1. 左上：一个圆脑袋小机器人吉祥物（身上不写字，不是任何公司标志），踮着脚往一个红色报案信箱的投信口里塞一张纸条，表情一本正经；信箱上不写任何字；
2. 右：一大捆用麻绳扎起的白色信封堆，上面斜压着一把木质拍卖锤；
3. 左下：一块椭圆形的星空画框（深色夜空里点点白星），右侧约三分之一面积是用虚线勾出的补丁，补丁里的星星画得更淡。
看板娘（按参考图）站在画面中间偏右下，扮成侦探：戴猎鹿帽，一手举放大镜对着信箱，歪头质疑，表情狡黠；大小与主体相近，不遮挡三件主体。
