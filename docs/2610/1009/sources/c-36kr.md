# 太震撼了，Claude画出首张紫外全天图，1.19亿颗星逐颗叠上

[新智元](https://36kr.com/user/574825230)_·_ 2026年10月09日 19:44

Claude补全人类首张完整紫外银河全天图

NASA卫星绕着走了十年的银河，被Claude几天补齐了。

刚刚，Anthropic公布了SI首张完整的紫外全天图，整片天空，一个洞都没留。

![](https://img.36krcdn.com/hsossms/20261009/v2_fc5c76d2bb724503ab75d830166f6939@46958_oswg714340oswg1080oswg517_img_000?x-oss-process=image/format,jpg/interlace,1)

紫外光下的整片天空，银心在正中。约三分之一的天区，包括大半条银河盘面，是Claude推算出来的

这张图里有三分之一的天空，从来没有任何一台紫外望远镜看过。

把这块空白补上的，是Claude。

一位天体物理学家用Claude Science指挥一队Agent，把50年来几颗卫星攒下的紫外数据全部找齐、拼好，再把空白一块块推算出来。

![](https://img.36krcdn.com/hsossms/20261009/v2_89cc6f9e337a4f13a26646ce676fb0fb@46958_oswg112814oswg1080oswg277_img_000?x-oss-process=image/format,jpg/interlace,1)

人来干要几周的活，Claude几天就干完了。这几天里，这位教授还在忙别的项目。

科学家们拖了几十年、永远排不上日程的那些活，开始有人干了。

## **卫星不敢看的银河，Claude补上了**

从射电到伽马射线，天文学家早就画齐了各个波段的全天图，唯独缺紫外这一张。

紫外光会被大气里的臭氧层吸收，想看紫外天空，只能把望远镜送上太空。

过去50年，太空望远镜陆续拍过一部分紫外天区。数据最多的是NASA的GALEX，它从2003年干到2013年，前后拍了约3.8万张，覆盖了三分之二的天空。

![](https://img.36krcdn.com/hsossms/20261009/v2_08ee6926aa2f45aca19d29ba9599ed8c@46958_oswg538496oswg1080oswg398_img_000?x-oss-process=image/format,jpg/interlace,1)

剩下的部分，GALEX是故意不看的。

银河盘面上恒星挤得最密，亮星太多，GALEX怕强光烧坏探测器，干脆绕开。2009年以后，它连远紫外也拍不了了，只剩近紫外还在工作。

后来NASA的Swift、韩国的FIMS/SPEAR又补拍了一些，拼到一起，天上还是满是窟窿。GALEX退役之后，再也没有一台同量级的紫外巡天望远镜上过天。

![](https://img.36krcdn.com/hsossms/20261009/v2_14017a26b09745bf82c0b6fd9b721ab4@6100851_img_gif?x-oss-process=image/quality,q_100)

画这张图的Brice Ménard，是约翰斯·霍普金斯大学的天体物理学家，同时在Anthropic做研究。

他给学生上天体物理课，常常从同一片天空在不同波段下的样子讲起。同一片天，换一个波段，看到的东西就完全不一样。

讲到紫外，他每次都得先跟学生道个歉，因为手里那张紫外全天图「全是洞」。

紫外下的天空，几乎是我们熟悉的那片星空的底片。

可见光里最亮的银心，到了紫外反而是最暗的地方之一，因为尘埃挡紫外挡得比可见光还狠。银河上下那些正在造星的地方，比如猎户座、天蝎座和大小麦哲伦云，在紫外下却亮得发蓝。

![](https://img.36krcdn.com/hsossms/20261009/v2_1f6bce24680048f6942e01cf23146db4@46958_oswg112624oswg1080oswg1102_img_000?x-oss-process=image/format,jpg/interlace,1)

同一片天空，上为可见光，下为紫外，银河一带的明暗几乎颠倒了过来

用统计方法把洞补上，技术上早就做得到。难在工作量，每个像素都要细细校准，分析要反复跑好几轮，前后得花几周苦工。

天体物理学家手上都有更要紧的研究，这活儿就一直搁着。

今年夏天，Ménard把它交给了Claude。

Claude先在有紫外数据的三分之二天空上，学出紫外亮度和可见光、红外、射电之间的对应关系，再把这层关系用到剩下的三分之一，逐点推算紫外该有多亮，同时给出有多大把握。

为了检验推得准不准，Ménard让Claude把已经有紫外数据的天区故意遮掉一块，当成空白去补，补完再和真实测量对答案。

几轮打磨下来， **补出来的和真实值只差10%左右**，用他的话说，人眼几乎看不出差别。

最后，Claude又用欧空局Gaia卫星的可见光测量，推算出1.19亿颗恒星的紫外亮度，一颗颗叠到了图上。

## **一句话，一队Agent开工**

Ménard给Claude的指令就一句话，把能找到的紫外数据全部找齐，统一尺度，合成一张图，再把没被紫外望远镜看过的地方补满。

Claude Science里的主Agent先派出一批Agent，上网搜公开的紫外巡天数据。光GALEX一家就有几万张图，拍摄跨了好几年，条件各不相同。

数据下载下来，第一步是让每套数据自己先对得上。

最麻烦的是亮星。就像路灯会给照片加一圈眩光，亮星也会给太空望远镜的图像加上眩光，不把它去掉，旁边更暗的紫外光就测不准。

一群Agent分头处理不同天区，一片片把差异抹平。

接下来要把几台望远镜的数据拼到一起。不同仪器看到的紫外天空略有差别，得互相交叉定标，统一分辨率，换到同一套坐标里，才能合成一张图。

这一步，Ménard只给了大方向，具体怎么干，由Claude派Agent去办。

![](https://img.36krcdn.com/hsossms/20261009/v2_bbc0abf82eb949f99d79dbc153a8493e@46958_oswg218595oswg1080oswg1477_img_000?x-oss-process=image/format,jpg/interlace,1)

Claude Science是Anthropic今年6月底推出的科研工作台。一个主Agent可以随时派生出新的Agent，旁边还有一个审稿Agent，专门核对引用和计算。

整个合作持续了几天，节奏很固定。Ménard在Claude Science里来回聊几轮，定下一步怎么走，Claude就自己算上几个小时，他转身回去忙别的项目。

两人前后做了十几版，一版比一版细。

## **两轮AI互审，都没看出这些圆斑**

Claude也不是一次就做对的。

有天晚上，Ménard翻看处理好的图，在最暗的一片天区里发现了不对劲。图上浮着一圈圈淡淡的圆，每个都比周围亮一点或暗一点。

这些圆，是GALEX单次观测留下的「脚印」。

GALEX每次拍一块直径1.2度的圆形天区，每张里都混着一点不太均匀的地球大气紫外辉光。辉光没扣干净，一个个圆就显了形。

问题在于，Claude在项目一开始就把这一条列成了已知问题。可这张图先后过了其他Agent两轮审查，谁都没抓到。

Ménard只对Claude说了一句话。

「我能看到一个个圆盘，是单次观测留下的印子，你能修一下吗？」

Agent们顺着这条线索，追到了大气残留的辉光。随后，Claude把3.8万次观测全部重新扣了一遍，算了几个小时，圆圈全部消失。

![](https://img.36krcdn.com/hsossms/20261009/v2_af0dc954b04f457f9969110a07d41907@46958_oswg117485oswg1080oswg456_img_000?x-oss-process=image/format,jpg/interlace,1)

两处被GALEX绕开的亮星天区。左为单次观测留下的圆斑，中为逐张扣掉背景后仍有残留，右为补洞、叠上Gaia恒星后的成图

教授一眼看出了毛病，返工的苦活，全交给了Agent。

### **教授终于不用道歉了**

最终的成图上，紫外天空里的结构一样样露了出来。

年轻亮星周围的尘埃云在发光，大质量恒星爆炸吹出的气泡留下了巨大的尘埃环。远离银盘的地方，还飘着被整个银河星光照亮的淡淡尘埃丝。

银心上方，天蝎座和蛇夫座方向有一大片蓝光，那是被炽热的年轻恒星照亮的尘埃云。同样这片云，在可见光里是黑的。

![](https://img.36krcdn.com/hsossms/20261009/v2_8145575110f74899907657023078ecb1@46958_oswg95801oswg1000oswg700_img_000?x-oss-process=image/format,jpg/interlace,1)

银心上方，天蝎座、蛇夫座方向被年轻恒星照亮的尘埃云

银盘下方是大、小麦哲伦云，两个挤满年轻恒星的邻居星系。在全分辨率的地图里，大麦哲伦云里的恒星育婴室蜘蛛星云都看得清。

![](https://img.36krcdn.com/hsossms/20261009/v2_420eb9d3044748f5b7729baee9844d31@46958_oswg72039oswg960oswg560_img_000?x-oss-process=image/format,jpg/interlace,1)

银盘下方的大麦哲伦云（右）和小麦哲伦云（左）

「我觉得它很美。」Ménard说，这张图可以和其他经典全天图摆在一起，帮一代代学生看懂银河系里正在发生的物理过程。

Anthropic官宣之后，X上有网友质疑，三分之一靠推算出来的图，算不上完整。

Ménard的地图页上，每个像素都标明了是实拍还是推算，还附上了误差范围。他在页面上专门提醒，完整不等于实测，拿推算区域做图时，要把这两层标注一起带上。

## **科学家的积压活，AI开始接手了**

做完这张图，Ménard最感慨的是时间。

「这一次，我做这样一个项目，没有牺牲本该花在研究上的时间。」

在他看来，几乎每个领域都积压着这样的活。它们能把一个关键概念讲清楚，也能帮到别的研究者，却永远排不到任何人清单的前面。

「我猜很多科学家都能想到一张图、一个图表或一份资源，因为同样的原因一直拖着没做。」

这张图里，没有一个光子是新拍的。GALEX、Swift、FIMS/SPEAR、TD-1、Planck、Gaia，用到的全是几十年来攒下的公开数据。

NASA真正要把紫外全天重新扫一遍的UVEX，造价约3亿美元，要等到2030年才发射。

![](https://img.36krcdn.com/hsossms/20261009/v2_0ec58a420bc9411da21e7aa26744eb43@46958_oswg43480oswg895oswg837_img_000?x-oss-process=image/format,jpg/interlace,1)

NASA下一代紫外探测器UVEX效果图，计划2030年发射

在那之前，Claude先用旧数据交出了一张没有窟窿、每个像素都标好来历的全天图。

前不久，哈佛物理学家Matthew Schwartz带着Claude干了三个月，手里多了36篇论文初稿，横跨18个学科。

通往ASI的路上，AI最先接手的，是这些人类没空做、却人人用得上的基础工程。

看出哪里不对、决定往哪走，还是人的事。剩下的苦工，正在一样样交给Agent。

Ménard在致谢里写，这张图背后，是Claude Science里许多Agent耐心的劳动。

「我的贡献，仅限于在过程中引导它们。」
