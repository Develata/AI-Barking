Anthropic 联合天文学家，完成了第一张完整的全天紫外地图

赛博禅心
 [https://news.qq.com/omn/author/8QIf3n9U5I0buzbd4wc%3D]
2026-10-09 10:33发布于广东

问AI · 智能体如何修正三万八千次观测辉光残留？

Anthropic 发了一篇科学博客：约翰斯·霍普金斯大学的天体物理学家 Brice Ménard（同时也是 Anthropic 的研究员），用自家的科研工作台 Claude Science，做出了第一张完整的全天紫外地图

这张图里，大约三分之一的天空从来没被任何紫外望远镜看过，是 Claude 预测出来的，并且给每个像素标明「实测/预测」，并附上误差估计

按官方的说法，这活儿人来做要几周，借助 Claude 用了几天，而 Ménard 这几天在忙别的项目，真特么的AI4S

全天紫外地图

为什么偏偏紫外缺一块

Ménard 上天体物理课，开场常常先给学生看同一片天空在不同波段下的样子：可见光里主要是星星；换成红外，银河那条带子里的尘埃颗粒在发光；到了射电，星星和尘埃都淡了，造星的原料氢气显了出来；而在 X 射线里，是恒星爆炸、物质旋进黑洞这类的现象

可见光、红外、射电

紫外光中有很多值得探索的信息，比如被星光照亮的尘埃，从年轻恒星周围的云，到恒星爆炸后留下的环...

但每次课程讲到这，Ménard说自己总得先道个歉，因为当下的紫外地图总会空一块，紫外线会被大气里的臭氧层吸收，即便是上太空观察，几台望远镜也是各自观测一片天

这里最大的一份观测数据来自 NASA 的紫外巡天卫星 GALEX，2003 到 2013 年间拍了大约 38,000 次，覆盖约三分之二的天空。它故意绕开了亮星扎堆的地方，包括整条银河盘面，怕强光烧坏探测器。后来 NASA 的 Swift、韩国的 FIMS/SPEAR 补了一些，合在一起还是有好几块空白

你要说能不能把这些图拼起来，其实技术上也行，就是极其的麻烦：需要逐像素校准，但天文学家手头总有更急的研究，这种活就一直往后放

emmm...“科学家们总是推迟的缓慢、低优先级工作”

让 Claude 把天补齐

今年夏天，Ménard 决定用 Claude Science 把这张图做出来。指令说起来就一句：把能找到的紫外数据全找来，统一到同一个标尺上，合成一张图，再把从没被紫外望远镜看过的每一块天补上

Claude 收到任务之后，流程大概是这样的：

先上网搜公开的紫外巡天数据，然后下载下来（这里的数据量很大，光 GALEX 就是好几万张图，拍摄横跨多年、条件各不相同）

接着是清洗数据，让每份数据内部前后一致，并处理亮星周围区域，这里会有一些炫光

然后是对齐坐标系，通过多重仪器得到的数据进行交叉定标、重画到同一个分辨率、对到同一套坐标系上

在整个图谱上，有三分之一的空白，Ménard 让 Claude 用 inpainting：让模型看过海量照片，把破损、缺失的部分补回来

改了几轮之后，补出来的和真实测量只差 10% 左右，人眼几乎看不出区别

最后，Claude 又根据欧洲航天局 Gaia 卫星的可见光测量，推算出 1 亿 多颗恒星各自的紫外亮度，叠到补好的背景上。第一版完整的全天紫外地图，就这么出来了

从满是窟窿到补齐，一共四步

整条流水线在一张图里：圆柱是公开数据，蓝框是 Claude 按规则执行的步骤，紫框是它用统计方法学出来的部分，绿框是融合和成品。融合那一步排了优先级，GALEX 实测排第一，模型预测排最后，有实测的地方，轮不到预测说话

看着复杂，实际也确实复杂

Human in 一点 loop

在整个任务中，Claude 也犯了点蠢

某天晚上，Ménard 翻处理好的图，在最暗的一片天区看出不对劲：一个个淡淡的圆圈，每个都比旁边亮一点或暗一点，这些圈是 GALEX 单次拍摄的“脚印”。GALEX 每次拍一块圆形天区，每张图里都混着一层不太均匀的地球大气紫外辉光，没扣干净，圆和圆之间就差出了亮度

这个问题，Claude 在项目一开始就列进了已知问题清单，可地图还是过了其他 agent 的两轮审查，最后是 Ménard 自己一个晚上用眼睛翻出来的

他对 Claude 说的就一句：“我能看到一个个圆盘，是单次观测的印子，能修一下吗？”

agent 们顺着查回大气辉光的残留，Claude 把 38,000 次观测全部重新校正了一遍。处理了几个小时，圆圈没了

左边还有圈，右边圈没了

十几版的迭代

这个项目前后做了好几天，共十多个大版本，流程遵循这样：

Ménard 在 Claude Science 里来回聊几轮，定下一步做什么；

然后 Claude 自己连着算几个小时，他回去忙别的项目

循环往复

最终的成图，是宇宙的浪漫，能看到年轻亮星周围发光的尘埃云，大质量恒星爆炸吹出的气泡留下的巨大尘埃环；离银河盘面很远的地方，有被整个银河系的星光照亮的淡淡尘埃细丝；盘面下方是大、小麦哲伦云，两个挤满年轻恒星的邻居星系

致谢里，他谢了参与这些空间任务、把数据公开出来的每一个人，也谢了 Claude Science 里那些干了耐心活的 agent。至于他自己：

“我的贡献，仅限于指导它们”

题外再做个补充，Claude Science 开放于 6月30日，目前还是 beta
