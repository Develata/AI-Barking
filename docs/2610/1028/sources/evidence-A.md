## 0. 先给 Claude 的结论（按对正文影响排序）

1. **A1 成立，但领先只有 1 分且档位不同**：Google 表、AA 模型页、AA 榜单都写 Carbon（High）59 排第 1；第 2 名是 Claude Opus 5.5（Max，Default Fallback）58，第 3 是 Opus 5.5（Xhigh）57 与 GPT-6 Astra（Max）57。Carbon 跑的是 high，Opus 跑的是 max。AA 自己的文章写明：Carbon 在 9 项评测里只拿 4 项第一，“not leading in coding and knowledge work”。
2. **Carbon 不是公开可用**：AA 模型页写 “No publicly available API”，AA 文章写 “being rolled out to selected users and is not yet publicly available”；Gemini API 的模型页、价格页、更新日志与 Vertex 模型文档都只有 Argon、没有 Carbon（我在 2026-10-29 20:0x–20:1x 北京时间核对）。Argon 发布当天 API 全面可用，Carbon 不是。
3. **价格脚注给了期满价，没给截止日**：Google 博文脚注 1 全文：“After the introductory period expires, the price of $4 per 1M input tokens and $20 per 1M output tokens will apply.” 没有 Carbon 的截止日期。对照：Argon 的博文脚注与 Gemini API 价格页都写明 2026-11-30（含）前 $2/$10，2026-12-01 起 $4/$20。AA 的图表一律用 $4/$20 标准价，并写 “Google is offering a 50% launch discount, with no confirmed end date.”
4. **“firm lead”与“10X”的依据都弱于正文措辞**：三项安全基准里 SEC-bench Pro、ExploitGym 是 Google 自己跑的（竞品数字取自对手自己的 system card / 技术报告），CWE-bench 由第三方 Collinear 跑但每个模型用各自的 harness；ExploitGym 的 54.8% 是 10 小时上限，6 小时上限是 53.5%，对手的上限各不相同。“Chrome 团队称 10 倍”没有点名对手、没有基线数字、找不到 Chrome 侧一手材料。
5. **Google 自家对比表里 Carbon 不领先的有两行**：FrontierSWE 2（Astra 65.5%、Opus 5.5 62.3% 都高于 Carbon 61.2%）与 OSWorld-2.1 离线子集（Opus 5.5 87.2% > Carbon 81.5%）。17 行里 Carbon 领先 15 行，其中 AA 指数、Vals、SWE-sweep 三行领先幅度分别只有 1 分、0.2 个百分点、0.1 个百分点。

## 2. 可能的吠点（L6 线索；进正文前必须回到一手来源）

每条先写原文里有的事实，再写出处。

1. **AA 第一只领先 1 分，档位不同**。A1c：Carbon（High）59 对 Opus 5.5（Max）58；A1d：9 项评测里 Carbon 只领先 4 项（HLE-Diamond、Terminal-Bench-Science、AA-Omniscience、AutomationBench-AA），“not leading in coding and knowledge work”。AA 的 Coding Agent Index 上 Carbon 59、Opus 5.5 62。
2. **榜单为一个公众拿不到的模型排名**。AA 模型页 “No publicly available API”；AA 文章 “not yet publicly available”；Google 博文只面向 “a subset of cyber defenders”；Gemini API 与 Vertex 文档只有 Argon。Argon 当天 API 全面可用（Argon 博文）。
3. **“Without guardrails” 的成绩 ≠ 将来对外开放版**。博文写外部基准 “(evaluated without guardrails)”，同时写 “continuing to gather feedback and iterate on guardrails before making Carbon available”。方法页另写 ALE/OSWorld 是 “with safety filters enabled”。博文没有说明对外版本的表现是否变化（原文未说，不能推断）。
4. **“firm lead” 的口径**：SEC-bench Pro、ExploitGym 都是 Google 自跑（A2b、A2c）；竞品数字来自各自 system card；ExploitGym 的 54.8% 是 10 小时上限，6 小时是 53.5%，对手有的无上限（Astra）、有的 6 小时（Opus 5.5）；CWE-bench 是 Collinear 跑的，但各模型 harness 不同（Antigravity、Codex、Claude Code、opencode），Carbon 领先 3 个百分点。Opus 5.5 在 SEC-bench Pro 上没有数字。
5. **“10X”无法核对**：未点名对手，未给基线，没有 Chrome 侧材料（A3）；9 月 Flash Cyber 的同类说法是 “2.6 times more correct patches … than the best commercial models that are much larger”，措辞和口径都比这次具体。
6. **价格是限时价，期满价翻倍，Carbon 没给截止日**（A6）。AA 的成本图按 $4/$20；AA 估算的 Carbon 每任务成本 $7.76，比 Opus 5.5 的 $10.04 低约 23%（标准价口径，AA 明说图表不含 50% 折扣）。
7. **幻觉率上升**：AA-Omniscience v1.1 上 Carbon 的 hallucination rate 从 Argon 的 4% 升到 11%，仍是第二低（Opus 5.5 与 Astra 均 50%）；博文里“reduced misalignment and fabrication rates”指 “in live coding environments with our own teams”，是 Google 内部团队的数字，两者不是同一口径。
8. **对比表里不领先的两行**：OSWorld-2.1、FrontierSWE 2（A7）。
9. **WebDev “#4” 带 Preliminary**：2 分之差、秩区间 2–6（A4b）。
10. **AA 指数 v5 一天前才发布**：AA v5 公告 2026-10-27，Carbon 的 AA 文章 2026-10-28。v5 公告里 Opus 5.5 以 58 领先；Carbon 的第一发生在 v5 上线第二天。这是时间事实，不含对动机的判断。
