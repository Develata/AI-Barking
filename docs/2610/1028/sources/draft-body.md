## A Gemini 4 Carbon

一、谷歌新模型登顶，你却用不上？

Google 北京29日凌晨发布 Gemini-4-Carbon，称它网络安全和长时任务能力最强，在 Artificial Analysis 新版综合指数上以59分排第一。目前只给一部分网络安全防御者用，再逐步扩到受信任伙伴；开发者、企业和普通用户“尽快”开放，没给日期。首发价同 Argon：每百万 token 输入2美元、输出10美元。

吠点：
①第一只领先1分，档位还不同：AA 榜上 Carbon（high 档）59，Claude-Opus-5.5（max 档）58；AA 自己写，9项测试里 Carbon 拿了4项第一，编程和知识工作没领先。
②谷歌自家对比表17行，两行没领先：电脑操作测试 OSWorld 上 Opus-5.5 87.2%，Carbon 81.5%。
③首发价没写截止日，只写期满后涨到输入4美元、输出20美元；Argon 写明首发价到11月30日。
④三项网络安全成绩是不开安全护栏测的，两项是谷歌自己跑的；“Chrome 团队称比另一家实验室的大模型强10倍以上”，没说是哪家、怎么比。

A 备忘：原文提到参与美国政府自愿预发布测试，正文不写；36氪“只允许国家级安全防御者”“全面碾压”为夸大实例；AA 幻觉率 4%→11% 可备用。

## B 指纹脚本

二、网页脚本藏“危险词”，专拦 AI？

安全研究者 veritas 10月28日发文：他爬网页时发现，一个反机器人指纹脚本里，函数起了吓人的名字，还藏着一段肉眼看不见的“越狱提示”。他猜这是给 AI 下的套：让 AI 助手一看就触发安全拦截，不肯帮人拆解代码。他让 Astra 分析，被拦；换 GLM-5.3，照做了。

吠点：
①标题说脚本“制造生物武器”，只是钩子：作者自己拆完写，除了这些诱饵，它就是普通的反机器人脚本，收集浏览器和显卡信息。
②“专拦 AI”是作者的推断，他用的是“会不会是”“说得通”；本号没找到脚本提供方的说法。
③测试很少：作者只写了三种设置的结果，没给次数，也没给提示词全文。
④开了 OpenAI 的 Daybreak Blue 照样被拦，不算诱饵更强：OpenAI 文档写明，这一档里 Astra 保留标准安全限制。

## C Claude Code 后台摘要

三、Claude Code 写状态栏，吃掉一成多花费？

Flamerix AI 公司发文称：Claude Code 每个正在干活的后台 agent，约每30秒就把整段对话发给模型，让它写一行三五个字的状态。他们一周的用量里，这项占 Claude Code 估算花费的16.4%、请求的19.7%。一位自称在 Claude Code 工作的 Anthropic 员工在技术论坛回应：上周所有上报遥测的用户里，这项约占按 API 标价算的花费2%，终端用户约6%。

吠点：
①16.4%和2%分母不同：一个是一家公司一周的用量，员工认为像主要跑后台 agent 的团队；一个是全部上报遥测的用户。谁也推翻不了谁。
②16.4%是 Claude Code 自带的花费估算，不是账单；Flamerix 也写明，订阅用户损失的是额度余量。
③Flamerix 的标题说“烧掉15–20%的 token”，可它测的是花费和请求次数，不是 token。
④员工称2.1.311版起修掉了最贵的情况（没命中提示缓存），更省的方案还在做；本号在更新日志里没找到对应条目。

C 备忘：员工身份只有本人自述（另有公开简介写 Anthropic 产品与社区沟通负责人，平台名不进正文）；Flamerix 自卖 DRIM，异常由 DRIM 发现；issue #86879 多组口径各异，正文不用。
