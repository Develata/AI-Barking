## 1. 标题

我会点的前三：

1. **“网页藏吓人词，专坑AI助手？”**——我能想象成网页故意吓唬 AI，好奇它怎么就会上当。
2. **“谷歌新模型登顶，你却用不上？”**——能看懂是谷歌出了很厉害的新 AI，想知道为什么不给我用。
3. **“AI评测第一只赢1分，你还用不上？”**——“只赢1分”让我好奇这个第一到底有多厉害，但我不知道一分差距算不算小。

看不出具体在说什么事的：

- **“Claude Code状态栏吃16%花费？”**——不认识 Claude Code，也不明白状态栏怎么会花钱，更不知道是总费用的16%还是某项费用的16%。
- **“谷歌AI登顶只赢1分？网页专坑AI？”**——前后像两条新闻，不知道有什么关系。
- **“谷歌新AI登顶，网页却在坑AI？”**——“却”让我以为网页正在坑谷歌这个新 AI，究竟是不是这件事，看不出来。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁胡说八道吗？不知道接下来是新闻还是吐槽。
- **“省流：谷歌 Carbon 评测登顶只领先1分，还只给少数人用。”**——Carbon 是什么产品？评测满分多少？只领先一分意味着差距很小吗？
- **“Claude Code 状态栏占花费16.4%是一家公司的数，员工称全体约2%。”**——是哪家的员工？“全体”指那家公司全体，还是所有使用者？两组数要读到后面才知道大概在比什么。
- **“Google 29日凌晨发布 Gemini-4-Carbon，在 Artificial Analysis 新版综合指数上以59分排第一，目前只给部分网络安全防御者，大众开放没给日期。”**——英文名字一下太多；不知道这是什么榜，也不知道“网络安全防御者”具体是什么人。
- **“首发价每百万 token 输入2美元、输出10美元。”**——不知道 token 是什么，也不懂输入和输出为什么分别收费，更换算不出我用一次要多少钱。
- **“①只领先1分，档位还不同：Carbon（high 档）59，Opus-5.5（max 档）58；该机构称它编程和知识工作没领先。”**——两个档位是什么？Opus 又是谁？“知识工作”包括什么？既然这两项没领先，它靠什么排第一？
- **“②首发价没写截止日，只写期满涨到4美元、20美元；Argon 写明到11月30日。”**——Argon 突然出现，不知道它和 Carbon 什么关系；两个价格也需要回头找对应项。
- **“③安全成绩不开护栏测，两项谷歌自己跑；‘Chrome 团队称比另一家实验室的大模型强10倍以上’，没说是谁。”**——“护栏”是什么？“两项”是哪两项？“强10倍”是更安全、答题更准，还是速度更快？
- **“研究者 veritas 发现，一个反机器人指纹脚本把函数起成吓人的名字，还藏了段隐形‘越狱提示’。”**——“反机器人指纹脚本”“函数”“越狱提示”都不懂；“隐形”的东西 AI 怎么能看见？
- **“他猜是诱饵，让 AI 触发安全拦截、不肯帮人拆代码；试 Astra 被拦，GLM-5.3 照做。”**——不知道是谁拦谁，也不知道“拆代码”是在做什么；Astra 和 GLM-5.3 是两个 AI 吗？
- **“①标题说脚本‘制造生物武器’只是钩子：作者拆完说，它就是普通反机器人脚本。”**——前面给的标题没有“制造生物武器”，这里说的是谁的标题？“作者”是研究者还是这篇文章作者？
- **“②‘专拦 AI’是作者推断，本号没找到脚本方说法；测试只写三种设置，没给次数。”**——“脚本方”是谁？“三种设置”又是什么设置？
- **“③开了 OpenAI 的 Daybreak Blue 仍被拦不奇怪：文档写明这一档 Astra 保留标准限制。”**——不认识 Daybreak Blue，也不知道它和 Astra 的关系，整句话抓不到意思。
- **“Flamerix AI 公司称，Claude Code 干活中的后台 agent 约每30秒把整段对话发给模型写状态，他们一周里这项占估算花费16.4%。”**——“后台 agent”是什么？“写状态”就是更新状态栏上的字吗？“他们”指这家公司，还是那些 agent？
- **“一位自称在 Claude Code 工作的 Anthropic 员工称，上周全体上报遥测的用户约2%，终端约6%。”**——不知道 Anthropic 和 Claude Code 什么关系；“上报遥测”“终端”都不懂，2%和6%各自在算什么也没写明白。
- **“①分母不同：一家公司一周对全体用户，员工认为前者像主要跑后台 agent 的团队。”**——“一家公司一周对全体用户”读着像少了几个字；还是没弄清这两组数为什么不能直接比。
- **“②16.4%是工具自带估算，不是账单；标题说‘烧掉15–20%的 token’，测的却是花费和请求。”**——这里又是哪个标题？token、花费、请求之间有什么区别，我分不清。
- **“③员工称2.1.311版起修了最贵的缓存未命中情况；本号在更新日志里没找到。”**——“缓存未命中”完全不懂，也不知道修好后是不是就不会多花这笔钱了。

## 3. 像 AI 写的

- **“省流：谷歌 Carbon 评测登顶只领先1分，还只给少数人用。网页脚本藏‘危险词’专拦 AI，是研究者推测。Claude Code 状态栏占花费16.4%是一家公司的数，员工称全体约2%。”**——三条都像把长文机械压缩成“结论＋限定条件”，名字和数字塞满，省了字却没让我更容易理解。
- **“一、Carbon 登顶，你用不上？”**——“你用不上”像套用吸引点击的句式，还没告诉我它能干什么，就先拿“你”制造遗憾。
- **“②16.4%是工具自带估算，不是账单；标题说‘烧掉15–20%的 token’，测的却是花费和请求。”**——连续用“是……不是……”“说……却是……”纠正别人，像 AI 常写的辨析模板，我还没懂事情就先被上了一课。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——“沸点／吠点”反复押字，加上“轻松识破”的承诺，很像自动生成的品牌口号；正文其实一点也不轻松。

## 4. 会划走的地方

- **“省流：谷歌 Carbon 评测登顶只领先1分……员工称全体约2%。”**——这里就第一次想划走：三个新闻、几个陌生名字和三组数字挤在一起，没有哪件事让我立刻明白和自己有什么关系。
- **“①只领先1分，档位还不同：Carbon（high 档）59，Opus-5.5（max 档）58……”**——如果继续读，到这里大概率划走。我还不知道这两个 AI 能帮我做什么，已经开始比较档位和榜单分数了。
- **“②首发价没写截止日，只写期满涨到4美元、20美元；Argon 写明到11月30日。”**——这条吠点我不在乎：前面说了我暂时用不上，价格什么时候涨很难吸引我。
- **“③开了 OpenAI 的 Daybreak Blue 仍被拦不奇怪：文档写明这一档 Astra 保留标准限制。”**——这条吠点我也不在乎：原本想看网页怎么骗 AI，读到这里却变成陌生产品的档位说明。
- **“①分母不同：一家公司一周对全体用户，员工认为前者像主要跑后台 agent 的团队。”**——到这里感觉在看两拨人对数字口径，我更想知道多花钱这件事会不会发生在普通人身上。
- **“③员工称2.1.311版起修了最贵的缓存未命中情况；本号在更新日志里没找到。”**——具体版本号和更新日志我不在乎，而且读完仍不知道这个问题现在到底解决没有，有点白读了的感觉。
## 采纳（Claude）

- 标题：读者排序 #4 网页藏吓人词 > #1 谷歌新模型登顶 > #6；#3（Claude Code）与双问句看不懂。主帖顺序不变，标题暂留 #1，#4 作候选交 Develata。
- 省流“员工称全体约2%”：采纳，改“Anthropic 员工称上报数据的全体用户约2%”。
- A 节价格段与吠点②（首发价无截止日）：读者不在乎，且正文超字数，删；事实留在 fact-check 与批注图。
- A“护栏”“两项是哪两项”：采纳，改“关掉安全限制测的，三项里两项谷歌自己跑”；Opus 补全为 Claude-Opus-5.5。
- B“标题说……谁的标题”“作者是谁”：采纳，改“博文标题问脚本为何……”“他”；Astra/GLM 补“他试了两个 AI”。
- B③ Daybreak Blue 看不懂：采纳，改“OpenAI 给安全人员的放宽权限”。
- C①“少了几个字”：采纳，改“16.4%只是一家公司一周的账”。C②补主语 Flamerix。C③“缓存未命中”改“最费钱的一种情况”。“上报遥测”“终端”改“上报数据”“命令行里”。
- 不采纳：开场与 Slogan 为固定格式；token、agent、反机器人指纹脚本等术语在千字上限内无法逐个解释，靠事件卡与批注图补；“你用不上”小标题保留（是事实：只给部分防御者）。
