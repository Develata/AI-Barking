谷歌新模型登顶，你却用不上？

AI 沸点，今日谁吠？

省流：谷歌 Carbon 评测登顶只领先1分，本周起将只先给少数人。网页脚本藏“危险词”专拦 AI，是研究者推测。Claude Code 状态栏占估算花费16.4%是一家公司的数，Anthropic 员工称上报数据的全体用户按 API 标价约2%。

一、Carbon 登顶，你用不上？

Google 29日凌晨发布 Gemini-4-Carbon，在 Artificial Analysis 新版综合指数上以59分排第一，称本周起将先向部分网络安全防御者开放，没给大众开放日期。

吠点：
①只领先1分，档位还不同：Carbon（high 档）59，Claude-Opus-5.5（max 档，带 fallback）58；Artificial Analysis 称它编程和知识工作没领先。
②网络安全成绩是关安全限制测的，三项里两项谷歌自己跑；Chrome 团队称它生成高质量补丁比另一家实验室的大模型强10倍以上，没说是谁。

二、网页脚本专拦 AI？

研究者 veritas 发现，一个反机器人指纹脚本把函数起成吓人的名字，还藏了隐形“越狱提示”。他猜是诱饵，让 AI 触发安全拦截、不肯帮人拆代码；试 Astra 被拦，GLM-5.3 照做。

吠点：
①博文标题问脚本为何“制造生物武器”，只是钩子：veritas 拆完说，除了这些混淆，它看起来就是普通反机器人脚本。
②“专拦 AI”是 veritas 的推断，本号没找到脚本方回应；测试只写三种设置，没给次数。

三、状态栏吃掉一成多花费？

Flamerix 公司称，Claude Code 工作中的后台 agent 约每30秒把整段对话发给模型写状态，他们一周里这项占估算花费16.4%。一位自称在 Claude Code 工作的 Anthropic 员工称，上周上报数据的全体用户里，这项按 API 标价约占2%。

吠点：
①分母不同：16.4%只是一家公司一周的账，自称员工的回复者认为它像主要跑后台 agent 的团队。
②16.4%是工具估算，不是账单；Flamerix 标题说“烧掉15–20%的 token”，测的却是花费和请求。
③此人还称2.1.311版起修了最费钱的情况，本号在更新日志里没找到。

AI 吠点：聊 AI 沸点，轻松识破吠点。
