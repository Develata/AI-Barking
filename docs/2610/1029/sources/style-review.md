# 1029 期读者稿检查

检查方：Codex gpt-6-astra（medium），只给旧稿正文与标题候选（标题当时为“Claude插件藏后门？换语言贵17倍？”），不带本期上下文。

## 1. 标题

我会点的前三：

1. **“装个Claude插件，电脑被埋后门？”**——装个东西就可能危及电脑，后果很具体，我想知道自己有没有碰上。
2. **“说中文用AI更贵？”**——直接关系到我的使用习惯，我会想知道中文是不是让我多花钱。
3. **“5000人装到假Claude插件？”**——人数让我觉得这事离普通用户不远，想看看怎么分辨真假。

看不出具体在说什么事的：

- **“Cursor混进假Claude插件？”**——我不知道 Cursor 是什么，也不知道它跟 Claude 是什么关系。
- **“Anthropic被黑？假插件埋后门”**——不认识 Anthropic，“被黑”是被骂还是被攻击也不明确，和后面的假插件怎么关联看不出来。
- **“Claude插件藏后门？换语言贵17倍？”**——两个问句放在一起，我不知道是两条新闻，还是同一个插件换语言就会变贵。

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁乱讲话吗？我还没看正文，就得先猜这个栏目的意思。
- **“Cursor 扩展市场混进被篡改的 Claude Code 扩展”**——Cursor、Claude Code、扩展市场全都不熟；标题叫“插件”，这里叫“扩展”，我也不确定是不是同一种东西。
- **“多数模型里最省 token 的就是英文或简体中文。”**——不知道 token 是什么，“省 token”是省钱、省字还是省时间？
- **“它的扩展市场里 Claude Code 扩展2.1.313版被恶意篡改，不是 Anthropic 开发的。”**——要读两遍：是这个扩展原本就不是官方开发的，还是被篡改的这个版本不是官方发布的？
- **“它会把攻击者的 SSH 钥匙加进电脑、装开机自启的脚本，再把主机信息发给攻击者。”**——“SSH 钥匙”“脚本”“主机信息”都卡住了，只能大概看出电脑里被塞了东西。
- **“要求受影响用户查这把钥匙、用官方脚本清理并轮换凭据”**——不知道去哪查钥匙，“轮换凭据”更完全不知道要做什么；“官方”是哪家公司也不清楚。
- **“不是‘Anthropic 被黑’：有安全研究者的标题这么写”**——“这么写”指研究者写了“Anthropic 被黑”，还是写了“不是 Anthropic 被黑”？需要回头确认。
- **“没说是安装还是下载，也没说多少台电脑真被埋了后门。”**——前面说“最多5000人”，这里又区分安装、下载和电脑数量，我不知道这5000到底数的是什么。
- **“Cursor 说恶意代码出错、‘这一步会失败’，指的只是多数 Mac 和 Windows 上开不了远程登录，攻击者登不进来；加钥匙、装脚本、发信息照样成功。”**——一句话塞了太多转折；读完还是不明白，攻击者登不进来，那留下的东西具体还能造成什么影响。
- **“用约200种语言的同一批句子，测19组模型的分词器，看同一模型里最费 token 的语言比最省的多几倍。”**——“分词器”不懂，“19组模型”也不知道一组包含什么；200种语言和19组模型挤在一起，我得慢下来理清在比什么。
- **“按 token 计费，token 多就多花钱。”**——知道它关系到钱了，但还是不知道 token 是什么，也不知道我平时按月付会员费算不算这种计费。
- **“最差的 Falcon-3 是17倍，Gemini 一组5.1倍，GPT-5 一组13.8倍。”**——不知道每个倍数具体是哪两种语言在比；“最差”也容易让我以为是在说回答水平最差。
- **“比的不是英文：报告称多数模型里最省的就是英文或简体中文”**——前面不是说最费的跟最省的比吗？最省的又常常是英文，为什么这里说“比的不是英文”？
- **“前20种常用语言之间只差1.5到3.1倍”**——不知道这20种语言包括哪些，也不知道为什么前面GPT-5还是13.8倍，这里就变成最多3.1倍。
- **“报告只数了 token，没换算成钱，也没测回答质量。”**——前面已经说“token 多就多花钱”，这里又说没换算成钱，我不确定标题里的“贵17倍”到底能不能这样理解。

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**——“沸”和“吠”硬凑谐音，再配一句口号式问句，像让 AI 给栏目设计开场白。
- **“②‘最多5000人’是上限”**——“最多”本来就是上限，又单独总结一次，像 AI 为了凑出一个纠错要点，把同一个意思说两遍。
- **“②比的不是英文”**——先摆出一句纠正读者的判断，但我此前并没认定是在跟英文比，像套用了“先否定误解，再解释”的固定格式。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——谐音重复加“轻松识破”的效果承诺，很像自动生成的品牌宣传语；读完没有多得到任何信息。

## 4. 会划走的地方

- **“省流：Cursor 扩展市场混进被篡改的 Claude Code 扩展……”**——第一句话就连着出现几个陌生名字。如果我没用过这些东西，很可能在省流这段就划走，觉得是写给程序员看的。
- **“Cursor 称，北京时间29日17:27到30日04:35，它的扩展市场里 Claude Code 扩展2.1.313版……”**——看到精确到分钟的时间和版本号，我会开始跳读；我还不知道自己跟这件事有没有关系。
- **“语言公平研究联盟 CLEAR 9月29日发报告：用约200种语言的同一批句子，测19组模型的分词器……”**——这是第二个明显想划走的位置。我想看“中文到底贵不贵”，这里却先进入研究方法和一串数字。

不太在乎的“吠点”：

- **“①不是‘Anthropic 被黑’……”**——我不认识这家公司，也没看过那个研究者的标题；谁的说法该被纠正，对我不如“我会不会中招”有吸引力。
- **“②‘最多5000人’是上限……”**——我更想知道哪些人需要担心，对这个数字该怎么严格表述兴趣不大。
- **“①17倍只出自 Falcon-3，开发方称它只支持英、法、西、葡4种语言。”**——没听说过这个模型，看起来也不是我会用的，读到这里会觉得17倍跟我没关系。
- **“③……转载的‘1.5至5倍’是外媒写法。”**——我没看过那篇转载，不在乎外媒和转载之间这点数字表述差异，感觉在旁观一场与我无关的纠错。
## 采纳

- 标题：采纳。双问句“Claude插件藏后门？换语言贵17倍？”被读成同一件事；读者前三为 #2“装个Claude插件，电脑被埋后门？”、#6“说中文用AI更贵？”、#7。新标题“假Claude插件埋后门？说中文更贵？”取两者钩子，“假”字避免读成官方插件有后门；“说中文更贵？”问的是 Rest of World 标题 “AI models cost more when you don't use English” 与中文转载的说法。
- “扩展”与“插件”混用：采纳，全文统一为“插件”。
- Cursor 是什么：采纳，省流补“编程软件 Cursor”。
- SSH 钥匙、轮换凭据：采纳，改“远程登录钥匙”“换掉密码和密钥”。
- 吠点①“这么写”指代不清：采纳，改为先写研究者标题原话、再写员工说法。
- 吠点③一句塞太多转折：采纳，拆成两句。
- token、分词器：采纳，第二条开头补一句 token 的解释，删去“分词器”。
- “比的不是英文”令人困惑：采纳（同时是反向核验 BLOCKER），改为先回答读者关心的“说中文贵不贵”。
- “报告只数了 token，没换算成钱”与前文矛盾：采纳，删去“没换算成钱”。
- “转载的‘1.5至5倍’是外媒写法”读者不在乎：采纳，删去。
- 固定开场与 Slogan 像 AI：不采纳，品牌固定格式。
- “5000人”吠点读者兴趣不大：不采纳，它纠正的是“5000人中招”的读法；措辞改为“Cursor 给的上限”。
- 精确到分钟的时间让人跳读：采纳，正文改“29日下午到30日凌晨”。
