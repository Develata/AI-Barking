假Claude插件混进Cursor？

AI 沸点，今日谁吠？

省流：编程软件 Cursor 的插件市场混进被篡改的 Claude Code 插件，会往电脑埋后门，Cursor 称最多5000人受影响。“换种语言用 AI 贵17倍”只出自 Falcon-3 一个模型，多数模型里最省的就是英文或简体中文。

一、Cursor 里的假 Claude 插件

Cursor 称，北京时间29日下午到30日凌晨，它插件市场里的 Claude Code 插件2.1.313版遭恶意篡改，不是 Anthropic 开发的。装上后，它会替攻击者在电脑上留一把远程登录钥匙、装自启脚本，并把电脑信息发出去。

Cursor 已下架这个版本，攻击者服务器也已下线。受影响用户要查钥匙、用官方脚本清理、换掉密码和密钥，只卸载插件可能不够。

吠点：
①有安全研究者的博文标题写“Anthropic 被黑”；Anthropic 员工 Felix Rieseberg 称公司系统没被攻破，官方渠道不受影响。恶意版本怎么上的架，Cursor 没说。
②5000人是 Cursor 给的上限，没说按安装还是下载算，也没说多少台电脑真中招。
③Cursor 说恶意代码出错，“这一步会失败”，又说多数 Mac 和 Windows 电脑上插件没权限开启远程登录，攻击者登不进来，但钥匙和脚本照样装上，服务器下线前电脑信息也照样外发。

二、换种语言，AI 贵17倍？

大模型接口通常按 token 计费，token 是文字被切成的小块，同一句话切得越碎越贵。研究联盟 CLEAR 9月29日发报告，用约200种语言的同一批句子测19组模型，看每个模型里最费 token 的语言是最省的几倍：最差的 Falcon-3 是17倍，Gemini 一组5.1倍，GPT-5 一组13.8倍。

吠点：
①报告称多数模型里最省 token 的语言就是英文或简体中文，吃亏最多的是缅甸文、藏文这类少见文字。
②17倍只出自 Falcon-3 一个模型，开发方发布时列出的语言只有英、法、西、葡4种。
③只看网上最常见的20种语言，各模型里最费比最省只差1.5到3.1倍，唯一例外也是 Falcon-3。
④报告只数了 token，没测回答质量。

AI 吠点：聊 AI 沸点，轻松识破吠点。
