Notes
Agentic video understanding: When using agentic video understanding,
token usage is variable based on the content loaded by the model rather than
full video length. This typically results in up to 88% fewer input tokens for
long-form video, though token counts depend on query complexity and dynamic
sampling depth (which may exceed 1 FPS for detailed visual segments). See [https://ai.google.dev/gemini-api/docs/video-understanding#agentic-video-understanding] Agentic video understanding .
Document token billing: Tokens for the DOCUMENT modality (for example, PDFs) are billed at the image token rate. In API responses, these tokens appear under the DOCUMENT modality within promptTokensDetails .
