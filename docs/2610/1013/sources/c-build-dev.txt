Gemini 4 Argon is now available for developers.

Oct 13, 2026

Starting today, developers can build with Gemini 4 Argon [https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/], our frontier model for complex workflows across real-world software engineering, enterprise knowledge work, and cybersecurity defense.

Gemini 4 Argon is designed for those long-horizon workflows that require deep reasoning and structural precision, including code migrations and frontier research. By handling the multi-step problems with ease, it lets you focus on building and shipping great products.

Start building using the paid tier of the Gemini API in Google AI Studio and Android Studio, and Google AI Ultra subscribers can try it in AI Studio, and our agent-first development platform, Google Antigravity.

To get started:

Check out the Gemini API Developer Guide [https://aistudio.google.com/learn/gemini-4-argon-developer-guide] for model details and setup instructions.

Read the Google Antigravity blog [https://antigravity.google/blog/gemini-4-argon-in-google-antigravity] for details on using Argon in our agent-first development platform.

Read the Android Studio blog [http://android-developers.googleblog.com/2026/10/bringing-gemini-4-argon-to-android-agentic-engineering-antigravity-cli.html] to see how Android Developers can start building.

See how you can use Gemini 4 Argon for robotics [https://developers.googleblog.com/gemini-4-argon-for-robotics].
