### 3:4 竖版提示词

竖版 3:4 封面插画。画风：法庭速写——米白色素描纸底，炭笔线条加彩色粉笔淡彩，笔触松快、有现场速写感，只用两种点缀色：法院木色（暖棕）与砖红；所有物件和看板娘用同一套线条与上色，整体是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人，不画法官、律师、被告或任何真实人物；搞怪、有冲击力。背景只有大块留白和几笔木质法庭栏杆的轮廓，不画复杂场景。
最上方是主标题，分两行：“AI陪聊破产怪算力？”“窃听案靠AI破？”。粗壮的手写感黑色马克笔大字，加砖红色投影，是全画面最醒目的元素，宽度占画面约九成，每个字都清楚可读。不要副标题。
画面中下部摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一架大号黄铜法庭天平，一边托盘里压着一块沉甸甸的显卡芯片（往下沉），另一边托盘里只有一个瘪瘪的小钱袋（往上翘）；天平底座边上坐着一个圆滚滚的白色对话气泡卡通小人，抱着膝盖一脸发愁。芯片、钱袋、气泡小人身上都不写字；
2. 右：一个木质证物台上放着一台老式小电视，电视背后的接口上插着一个用卫生纸裹起来的小设备，旁边立着一块空白的三角证物牌（牌上不写字）。电视屏幕是空白雪花，不写字。
看板娘按参考图（蓝色长发、狗耳、鲸鱼尾巴、女仆装、胸前“AI 吠点”圆牌；双手是正常的人手，不戴肉垫手套）在画面下方居中出镜，同样用这套速写画风，扮成法庭速写画师：一手托着打开的速写本，一手捏着炭笔指向两件主体，歪头挑眉，表情狐疑；速写本页面上只有几道潦草线条，不写字。她只有两只手、两只耳朵、一条尾巴，全身完整入画。
画面里除了主标题与胸牌“AI 吠点”，不要出现任何其他文字、数字、logo、品牌标志或真人。
