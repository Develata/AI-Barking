### 3:4 竖版提示词

竖版 3:4 封面插画。画风：工程蓝图——普鲁士蓝底色，白色与浅青色细线条，带淡淡的网格、尺寸标注线和箭头（尺寸线上不写数字），像一张建筑或机械蓝图；只在关键处点一点亮橙色；所有物件和看板娘用同一套线条画法，整体是一幅完整的画，不要贴纸拼贴感，不要写实，不要真人；搞怪、有冲击力。背景只有大块蓝底和稀疏网格，不画复杂场景。
最上方是主标题，分两行：“OpenCode泄露谁？”“GDP涨五成？”。粗壮的白色无衬线大字，带一点亮橙色描边，是全画面最醒目的元素，宽度占画面约九成，每个字都清楚可读。不要副标题。
画面中下部摆两件主体，体量大，彼此留出空隙，不堆小物件：
1. 左：一朵蓝图线条画成的云，云底裂开一道口子，三四把亮橙色的钥匙正从裂口往下掉（钥匙上不写字）；
2. 右：一根很高的柱子（柱状图的一根柱），柱子下面约四分之一用虚线框出一截，表示“本来就有的那一截”，上面四分之三是实线；柱子上不写字、不写数字。
看板娘按参考图（蓝色长发、狗耳、鲸鱼尾巴、女仆装、胸前“AI 吠点”圆牌；双手是正常的人手，不戴肉垫手套）在画面下方居中出镜，同样用蓝图线条画风（头发保持蓝色、胸牌保持“AI 吠点”）：一手拉着一卷测量用的卷尺贴在柱子上量高度，一手挠头，歪头挑眉，表情狐疑。她只有两只手、两只耳朵、一条尾巴，全身完整入画。
画面里除了主标题与胸牌“AI 吠点”，不要出现任何其他文字、数字、国旗、logo、品牌标志或真人。
