Comparison Summary

Beam 1.0 is amongst the leading models in intelligence, but somewhat expensive when comparing to other open weight models of similar size. It's also notably fast and highly concise. The model supports text input, outputs text, and has a 1M tokens context window.

Beam 1.0 scores 30 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 19). When evaluating the Intelligence Index, it generated 79M tokens, which is very concise in comparison to the median of 130M.

Pricing for Beam 1.0 is $0.70 per 1M input tokens (somewhat expensive, median: $0.43) and $2.10 per 1M output tokens (somewhat expensive, median: $1.68). On average, it costs $0.57 per task to evaluate Beam 1.0 on the Intelligence Index.

At 303 tokens per second, Beam 1.0 is notably fast (74).

Total Parameters

The total number of trainable weights and biases in the model, expressed in billions. These parameters are learned during training and determine the model's ability to process and generate responses.

Active Parameters at Inference Time

The number of parameters actually executed during each inference forward pass, expressed in billions. For Mixture of Experts (MoE) models, a routing mechanism selects a subset of experts per token, resulting in fewer active than total parameters. Dense models use all parameters, so active equals total.

Frequently Asked Questions

Common questions about Beam 1.0

When was Beam 1.0 released?

Beam 1.0 was released on October 16, 2026.

Who created Beam 1.0?

Beam 1.0 was created by Reflection.

How intelligent is Beam 1.0?

Beam 1.0 scores 30 on the Artificial Analysis Intelligence Index, placing it well above average among other open weight models of similar size (median: 19).

How fast is Beam 1.0?

Beam 1.0 generates output at 302.6 tokens per second (based on the median across providers serving the model), which is well above average compared to other open weight models of similar size (median: 73.7 t/s).

What is the latency of Beam 1.0?

Beam 1.0 has a time to first token (TTFT) of 0.90s (based on the median across providers serving the model), which is very competitive compared to other open weight models of similar size (median: 1.70s).

How much does Beam 1.0 cost?

Beam 1.0 costs $0.70 per 1M input tokens (somewhat higher than average, median: $0.43) and $2.10 per 1M output tokens (somewhat higher than average, median: $1.68), based on the median across providers serving the model.

What is Beam 1.0 API pricing?

Beam 1.0 costs $0.70 per 1M input tokens and $2.10 per 1M output tokens (based on the median across providers serving the model). For a blended rate (7:2:1 cache hit/input/output ratio), this is $0.43 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/reflection-beam/providers]

How verbose is Beam 1.0?

When evaluated on the Intelligence Index, Beam 1.0 generated 79M output tokens, which is very competitive compared to other open weight models of similar size (median: 130M).

Is Beam 1.0 a reasoning model?

Yes, Beam 1.0 is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does Beam 1.0 support?

Beam 1.0 supports text input.

What output modalities does Beam 1.0 support?

Beam 1.0 supports text output.

Can Beam 1.0 process images?

No, Beam 1.0 does not support image input. It can only process text.

Is Beam 1.0 multimodal?

No, Beam 1.0 is not multimodal. It only supports text input.

What is the context window of Beam 1.0?

Beam 1.0 has a context window of 1.0M tokens. This determines how much text and conversation history the model can process in a single request.

Is Beam 1.0 open source?

Yes, Beam 1.0 is open weights. The model weights are publicly available and can be downloaded for self-hosting.

How many parameters does Beam 1.0 have?

Beam 1.0 has 501 billion parameters (23 billion active).

What are the active parameters of Beam 1.0?

Beam 1.0 is a Mixture of Experts (MoE) model with 501 billion total parameters, but only 23 billion active parameters are used during inference.

What is the license for Beam 1.0?

Beam 1.0 is released under the Apache 2.0 license. This license allows commercial use. View license [https://www.apache.org/licenses/LICENSE-2.0]

How does Beam 1.0 perform on benchmarks?

Beam 1.0 achieves a score of 30 on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across reasoning, knowledge, mathematics, and coding.

Is Beam 1.0 available via API?

Yes, Beam 1.0 is available via API through 4 providers. Compare API providers [/models/reflection-beam/providers]

Where can I use Beam 1.0?

Beam 1.0 is available through 4 API providers. Compare providers [/models/reflection-beam/providers]
