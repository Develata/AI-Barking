🔔 New article published

Announcing Artificial Analysis Intelligence Index v5

Index v5 features 2 new benchmarks and 3 upgrades. For the first time, the majority of the Index is built on private datasets

 [/articles/artificial-analysis-intelligence-index-v5]

Artificial Analysis Intelligence Index methodology

Artificial Analysis Intelligence Index v5.0

New to the Intelligence Index:

➤ FrontierCode 2.0: Cognition’s private benchmark of real-world coding tasks, graded on whether a repository maintainer would merge the agent’s change

➤ Terminal-Bench-Science: 70 agentic scientific research tasks, run in a terminal environment

Upgraded:

➤ HLE-Diamond (replacing Humanity’s Last Exam): a refined 1,000-question version of Humanity’s Last Exam, split evenly between reasoning and knowledge questions

➤ AA-Omniscience v1.1: an updated dataset with saturated questions and all public set questions removed, new questions added, and ambiguous or erroneous questions revised

➤ CritPt v2 (Hard Subset): a private 40-question hard subset of CritPt v2, revised by the CritPt authors and run with a code-execution tool

Staying in the Index: AA-Briefcase, AutomationBench-AA, GDP.pdf and Terminal-Bench 4.0

Removed from the Index: GDPval-AA v2, SciCode and AA-LCR
