Google’s next Genie AI model generates more realistic experiences

The Genie 4 world model offers more realism and can create audio to accompany its interactive worlds.

Google announced today its Genie 4 world model [https://deepmind.google/blog/genie-4-a-new-generation-of-world-simulation] for generating interactive experiences using AI. The company says the model has four main updates: It allows for more realistic worlds, lets users update an experience in real time with a natural language prompt, can generate audio, and uses Gemini 3.8 Flash under the hood to help with its simulations. It also can create experiences that are about two minutes long, up from one minute for the previous Genie 3 model.

Google is pitching Genie 4 as a tool that could be helpful for things like pre-visualization for filmmakers, prototyping game ideas, and making training scenarios for robots. But the company warns that, as simulations run longer, details and object permanence can shift over time.

I haven’t been able to try Genie 4 for myself — it’s launching first as a “research preview” to “trusted testers” — so I can’t tell you how it compares to the Genie 3-powered Project Genie, which I used to generate bad Nintendo knockoffs [/news/869726/google-ai-project-genie-3-world-model-hands-on]. But here are some examples from Google demonstrating what’s possible with the new model.

Genie 4 will be “coming soon” to Google AI Ultra subscribers, Google says, and the company has opened a waitlist [https://forms.gle/WQnSNEM3omF7Uruu7] where you can apply to be able to try it in Project Genie.
