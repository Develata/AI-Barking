# 1027 读者稿检查

检查者：Codex gpt-6-astra（medium，只读沙箱、无仓库与事实清单；Windows 主机 full-access 被权限拦截，改 -s read-only），北京 10/28 晚。输入：标题候选 #1–#5 与当时正文。

## 1. 标题

我会点的前三：

1. **“AI暗设立场，专家86%跟着选？”**——我能看懂是 AI 偷偷带偏专家，会好奇专家怎么也没发现。
2. **“游戏引擎已死？谷歌AI世界撑两分钟？”**——“撑两分钟”很具体，我想看看这个世界到底长什么样、两分钟后会怎样。
3. **“谷歌AI造世界能玩多久？86%跟AI选？”**——前半句让我想到可以进去玩的游戏，但后半句突然换了件事，有点打断兴趣。

看不出具体在说什么的：

- **“游戏引擎已死？专家86%跟着AI选？”**——不知道游戏引擎和专家做选择有什么关系，也不知道专家选什么。
- **“专家86%跟AI选？谷歌世界撑两分钟？”**——两边都缺信息：“选”什么，“谷歌世界”又是什么？

## 2. 读不懂

- **“AI 沸点，今日谁吠？”**——“谁吠”是在说谁乱讲吗？我不知道你要介绍新闻还是骂人。
- **“Google 发布实时 AI 世界 Genie-4，媒体报的‘两分钟’是上限，研究员说跑满也不保证一致。”**——“一致”指什么？人物不变、地图不变，还是画面不会出错？
- **“Anthropic 实验里，分析师的分项选择86%跟着 AI 被暗设的倾向走，最终建议的差距按预先登记的算法不显著。”**——“分项选择”“预先登记”“不显著”都让我停下来；“跟着 AI 被暗设的倾向走”也要读两遍才明白是谁被设了倾向。
- **“AA 综合指数换了考卷，Kimi 从55分变46分。”**——AA 是谁？满分多少？“换了考卷”是真的换题，还是换了评分方法？
- **“Google DeepMind 27日发布世界模型 Genie-4”**——“世界模型”是什么？后面的一句话生成世界能帮助理解，但我仍不知道它是游戏还是视频。
- **“Google 书面只写能连续玩‘几分钟’。”**——“连续玩”和前面的“场景保持一致”是同一件事吗？为什么这两种说法放在一起？
- **“50名职业分析师用 Claude Code 做同一项分析”**——Claude Code 是什么工具？他们分析的是股票、公司经营，还是别的？
- **“研究者抛硬币给 AI 暗设倾向，没告诉分析师。”**——是随机让 AI 支持或反对某件事吗？这里没说倾向的具体内容。
- **“四个分析选择里，分析师86%选了 AI 偏向的那个，不受影响应约50%。”**——是86%的分析师，还是全部选择次数中的86%？“四个分析选择”是四道题吗？为什么不受影响就是50%？
- **“86%是中间步骤。”**——百分比怎么会是“步骤”？要往后读才猜到是在说中间环节的选择结果。
- **“到‘要不要推广’的最终建议，AI 偏向推广时54%的人建议推广，反之36%；按论文预先登记的主要算法，差距不显著。”**——推广什么？“反之36%”是谁做了什么选择？54%和36%看起来有差距，为什么叫“不显著”？
- **“‘60%改口’只有38个案例，Anthropic 称估计不精确。”**——前面没提过60%，突然出现不知道在接什么。谁改口，从什么改成什么，38又是哪一批人？
- **“AI 的倾向是故意加强的。”**——“加强”到什么程度？是反复劝人，还是偷偷改分析结果？
- **“六成权重来自不公开的题目或答案。”**——“权重”不懂；是在说总分的六成来自这些题吗？
- **“本号1023期写的 Kimi-K3.1-Pro 旧版55分，新版46分。”**——“旧版”“新版”是模型版本还是考卷版本？我得回头确认。
- **“AA 方法页写，各版分数不用于跨版本长期比较；它的公告却拿新版12分差距对比旧版3分。”**——12分和3分分别是谁跟谁的差距？前面只有55分和46分，这里接不上。
- **“公告称 Kimi-K3.1-Pro 是开放权重最高分，但它权重未公开，AA 模型页归为闭源。”**——“开放权重”“闭源”都不懂；这里的“权重”和前面“六成权重”是一个意思吗？

## 3. 像 AI 写的

- **“AI 沸点，今日谁吠？”**——像为了栏目口号硬凑的谐音，“今日谁吠”也不像普通人介绍新闻时会说的话。
- **“Google 发布实时 AI 世界 Genie-4……Anthropic 实验里……AA 综合指数换了考卷……”**——“省流”里连续塞进三个机构、几组数字和专业限定，像把三篇摘要机械压成一段，没有照顾我能不能跟上。
- **“一、Genie-4 能玩两分钟？”“二、分析师86%跟着 AI 选？”“三、Kimi 从55分变46分？换了考卷”**——连续用“名字＋数字＋问号”做标题，下面再统一套“吠点”，模板感比较明显。
- **“AI 吠点：聊 AI 沸点，轻松识破吠点。”**——“沸点／吠点”反复绕口，最后再加“轻松识破”的效果承诺，很像自动生成的品牌宣传语。

## 4. 会划走的地方

- **“最终建议的差距按预先登记的算法不显著。”**——第一段“省流”到这里，我就可能划走：还没知道分析师在做什么，就先要理解统计结论。
- **“‘60%改口’只有38个案例，Anthropic 称估计不精确。”**——如果坚持读到第二部分，这里会再次让我想走：突然又加一组没有来由的数字，我不想继续补上下文。
- **“三、Kimi 从55分变46分？换了考卷”**——这一段我大概率跳过。我更想知道 Kimi 用起来有什么变化，单看分数和考卷变化，不知道跟我有什么关系。

不太在乎的“吠点”：

- **“官方演示视频注明‘片段已缩短’。”**——单独看这句，我只觉得视频剪短了，不知道它为什么值得专门指出。
- **“AA 方法页写，各版分数不用于跨版本长期比较；它的公告却拿新版12分差距对比旧版3分。”**——像在查评测公告前后是否一致，我没有看过这个榜单，对这场争论没兴趣。
- **“公告称 Kimi-K3.1-Pro 是开放权重最高分，但它权重未公开，AA 模型页归为闭源。”**——我不知道这些分类会影响我什么，读起来像行业内部在争一个称号。
## 采纳

- 标题：采纳。读者看不懂“游戏引擎已死？专家86%跟着AI选？”两半的关系；改选读者排第二的“游戏引擎已死？谷歌AI世界撑两分钟？”（只钩第一条主帖，但两个分句都有锚点）。读者排第一的“AI暗设立场，专家86%跟着选？”不采纳：读者自己把它读成“AI 偷偷带偏专家”，实为研究者给 AI 设的倾向；作为备选列给 Develata 时改为“AI被暗设立场……”。
- 省流太挤、术语多（分项选择、预先登记、不显著）：采纳。改成“研究者暗中让 AI 偏向某个选项，分析师的中间选择86%跟着走，最终建议的差别按论文主算法算不上显著”；“主算法”保留，因为未调整估计是显著的，删掉会改变含义。
- “一致”指什么：采纳，改“场景前后一致”。
- “Google 书面只写……”与前句关系不清：采纳，改“Google 自己的页面没写两分钟，只说能连续玩‘几分钟’”。
- B 段“做同一项分析”“暗设倾向”“四个分析选择”“86%是中间步骤”“反之36%”“60%改口没来由”：采纳，补主语与对象（评估同一个农场项目；抛硬币决定 AI 偏向哪边；86%的情况下；偏向反面时；分析师先表态、AI 再反对时）。
- “故意加强到什么程度”：部分采纳，改“特意加强的”；程度细节字数不够，留在事实清单。
- C 段“权重”歧义、旧版新版不清、12分与3分接不上：采纳，改“总分六成”“旧版指数”“开放模型最好的落后榜首12分，旧版只差3分”“权重还没公开下载”。
- “官方演示视频注明‘片段已缩短’”不在乎：采纳，删（同时为字数）。
- C 整段可能跳过、两条吠点像行业内部争称号：不采纳。C 是对本号 1023 期数字的跟进，必须交代；已尽量换成人话。
- 固定开场与 Slogan 像 AI 宣传语：不采纳，品牌固定格式。
- 小标题“名字＋数字＋问号”模板感：不采纳，符合“谁 + 出了什么事”的小标题规则；第三条已带“换了考卷”。
