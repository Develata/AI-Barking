实测 Kimi K3.1 Pro，国模终于继续卷旗舰

爱范儿
 [https://news.qq.com/omn/author/8QMY3Hxd7YMbvTY%3D]
2026-10-24 10:04发布于广东爱范儿官方账号

问AI · 各家卷模型速度价格，Kimi续推旗舰背后动因何在？

刚刚，Kimi 正式发布了新一代旗舰模型 K3.1 Pro。在国产大模型纷纷卷起速度和价格的当下，Kimi 又把竞争带回了性能天花板之争。

前两天，大模型竞技场上一款叫 Kibitz 的神秘模型，就已经引起了大家的关注。社交媒体的信息流里，都是用这款模型生成的各种惊艳的案例。

图｜提示词：编写一个骑自行车的鹈鹕的 SVG，尽可能详细

这个骑自行车的鹈鹕，一行提示词已经进化到在不同的环境背景里面骑行，还能调节步频。不少网友认为，效果已经足以媲美 GPT-6 Astra 和 Opus 等前沿闭源模型。

现在 Kibitz 的真实身份也揭晓了，它就是 Kimi K3.1 Pro。一起公开的，还有这款新模型在竞技场上的盲测成绩。

在代码、Agent 和知识类基准上，K31. Pro 都紧追最强闭源模型，在 Artificial Analysis 「智能指数」直接跃升到全球第四，开源第一。

除了保持 benchmark 的领先，K3.1 Pro 一如既往地没有选择走两三个月来国模的 Flash 路线，它继续用旗舰大模型来占据国产模型 Pro 档位的第一。

K3.1 Pro 拥有3 万亿级参数模型，支持 100 万上下文，并计划 11 月 4 日前开放完整模型权重。这次 Kimi 还同步推出了 K3.1 Pro Highspeed 高速版本，在保持相同的智能水平的前提下，输出速度能做到普通版的 2-3 倍。

图｜全新 Kimi K3.1 Pro 已经在 Kimi 官方网页和 App、Kimi Code、CLI，以及 API 上线

我们连夜测试了 K3.1 Pro 在代码、3D 创作、金融研究与建模等方面的能力，只能说那个「大而美」的 Kimi 时隔100天又回来了。

各种 3D 大场面，全部都能做

这段时间最「大」的场面莫过于「特斯拉能飞」了，我们也是安排 K3.1 Pro 复刻一下特斯拉的空中特技。

模型利用 Three.js 和 SVG 制作了一段汽车短片，白色的 Roadster 冲上巨大的 C 形轨道，在最高处倒挂一秒，随后脱离轨道，喷出冷气，在半空翻回正面，最后四轮落地。

图｜提示词来源：X@my189 预览链接：https://q6tpvtie4twcu.kimi.page/

回到地面， 再让 K3.1 Pro 用一句话就造出一个 3D版「一剑冰封整座城」。

生成的雨夜古城里，玩家蓄力拔剑后，寒潮沿街巷向远处推进，把城楼、屋顶、树木和河面依次冻成透亮的冰晶。

K3.1 Pro 真正做到了「一句话就生成可玩特效」，场景的视觉冲击力、材质、灯光、空间层次和动作节奏做到了像正式游戏的大招展示。

古城之后，画面再转进墨西哥高地的蝴蝶森林，以帝王蝶的越冬栖息地为主题，生成一个虚拟的 3D 场景。

图｜预览链接：https://6f7tb5wqi4f5m.kimi.page/

蝴蝶给画面带来了几种不同的尺度，远处是压满枝头的色块，靠近以后是层叠的翅膀，再近一些，才看清单只蝴蝶的纹样。透过翅膀的光，也让这个 3D 案例有了和古城不同的质感。

除了让 K3.1 Pro 生成这些 3D 大场面，Kimi 这次还同步上线了一个挺有意思的新功能：3D Make。我们可以直接在线预览、编辑 3D 模型，调整好之后，模型文件还能下载下来，拿去 3D 打印。

图｜可以直接把「骑自行车的鹈鹕」下载为 blend 或 glb 等 3D 资产的文件格式

如果不打算打印，3D Make 也支持把作品导出为视频或实况照片，直接分享到社交平台，可太适合 AI 玩家了。

从审美到工程，Kimi 的另一面

从 3D 项目成为今年大模型的必测项目以来，能看到模型在 3D 效果上的表现都越来越好，更多的细节表现，渲染也更高效，能体现不同模型区别的，更多的还是在模型的审美上，或者说模型的「品味」。

网页，这项曾经是 Kimi 最具优势的项目，随着 K3.1 Pro 的能力提升，现在我们用更简单的方式，更快得到一个真正有设计感的网页。

图｜https://s4l7pmwerocje.kimi.page

类似的能力，给 K3.1 Pro 一张房间照片，它能把照片里的空间变成一个可以旋转浏览的 3D 网页。

桌子、椅子、书架和摆件先从原位分离，桌板和桌腿、椅背和座面、屏幕和支架再逐步展开。最后，所有物件像拆机摄影那样，整齐铺成一个矩形。

图｜https://zoqnbv5ocsizg.kimi.page/

又或者让 K3.1 Pro 用 Blender 脚本生成一个 3D 机器人资产，然后再为这款掌心大小的桌面陪伴机器人做一场可交互的 3D 发布会。

K3.1 Pro 生成的网页，把材质、镜头和排版都做到了尽可能精致，同一套模型在这里既能演示，也能继续交给设计师修改。

最近用大模型做出来比较好玩的还有解释机器，我们丢给它一个「XX 是怎么工作的」问题，它就把答案做成一台可以点的互动机器，用一个独立的 HTML 页面，把真实的部件、可以按步骤点亮的按钮、以及能剖开看内部运作的窗口都囊括进来。

发送提示词「冰箱是怎么制冷的」让 K3.1 Pro 做一个网页，生成的效果很适合用来做简单的科普。

图｜https://kvqmkfuf2q7lg.kimi.page

还有前段时间有个做插画的 Skill 很火，当时的教程推荐使用 Claude Code 的模型和工具。我们也把它安装到 Kimi 里，看看它能不能也生成像 Opus 5.5 一样高水准的动效插画网页。

Anatomy 这个 Skill 的特点也是把技术概念做成一台「真的机器」来解释，它几乎不会使用画方框和箭头的方式，而是发明一个物理装置，让它的工作原理本身就是那个概念。

然后我们在测试 K3.1 Pro 的时候，给它上了点难度，要求它来解释一下海底光缆是怎么连接全球互联网。

事实证明，在处理这类有专门 Skill 的创作任务时，K3.1 Pro 完全可以用来替代 GPT-6 Astra 或 Opus 5.5 等前沿旗舰模型，我们可以花更少的钱就得到同样好的效果。

除了 3D 能力的提升，我们还发现，K3.1 Pro 经过大规模强化学习之后，长程编码能力也有了明显增强。

比如在测试中，我们顺手让它做了一段动态图形视频。提示词只有一句话：「制作一段充满动感的 15 秒动态图形视频，展现你是一位多么出色的动态设计师，就像这是你简历用的作品集短片一样。」

最终生成的成品，已经有了比较完整的节奏、转场和视觉语言。

Kimi 在通用编程和长程调试上的增强，不只体现在创意生成任务里，也体现在更复杂的软件理解和复现任务上。

刚好 Arc 将在 12 月关闭，我们就想着安装好 REA 后，让 K3.1 Pro 复刻一个同款的 Arc 浏览器。

能看到 K3.1 Pro 对安装包进行了完整的检查，提取了详细的应用信息。而复刻的版本，我们也能像用 Arc 一样，使用标签页拆分、侧边栏、全局搜索以及空间等功能。

除了好看，还很专业

3D、网页和动效这些案例，最容易让我们看到模型的进步。但对于真正需要用 AI 干活的企业来说，模型能否正确处理复杂数据、完成专业任务，可能比做出一个漂亮的网页更重要。

金融就是一个很好的例子，如果让 AI 总结一份财报很简单，但要同时读取多份金融文件，交叉核对数据，再建立一份包含大量公式的财务模型，难度就高了不少。

根据 Kimi 公布的成绩，这次 K3.1 Pro 在金融领域的表现也有明显提升。在 Office QA Pro v2 和 SpreadsheetBench 2 两项外部基准测试中，K3.1 Pro 均超过了 GPT-6 Astra、Opus 5.5 等前沿闭源模型。

前者考察模型对真实金融文档的分析能力，后者则要求 AI 真正操作电子表格，包括建立财务模型、处理跨表公式和诊断错误。

国产模型终于继续卷 Pro 了

下半年大模型更新基本收缩成两条主线，卷智价比的「斩杀线」，以及顶尖的前沿能力。

从 DeepSeek V4 Flash 开始，大家不约而同地把重点放在了卷成本和速度的 Flash 上。

另一边，Claude Opus 5.5、GPT-6 Astra 等前沿模型接连更新，尤其是在编程、3D 创作和复杂 Agent 任务上，表现一次比一次惊艳。

Kimi K3 在今年 7 月发布时，把国产开源模型的规模提升到了 2.8 万亿参数。当时它最受关注的一点，是让开源模型的整体能力进一步逼近了美国顶级闭源模型。

但模型的迭代速度实在太快，短短两个月，很多 Flash 模型已经达到甚至超越之前的旗舰模型，「斩杀线」不断刷新，而 Claude 则稳稳占据着前沿模型的头把交椅。

现在，Kimi 终于带着 K3.1 Pro 回来了，它当然还没有全面超过这些闭源旗舰，但从这次的实测来看，至少国产模型这一边，终于又有选手能和它们正面较量了。

某种程度上，Kimi K3.1 Pro 也代表着一条「大而美」的技术路线。

过去一段时间，大模型行业热衷于证明一件事，小模型也能办大事。通过技术工程，更少的参数、更低的推理成本，也能在 Benchmark 上交出接近旗舰模型的成绩单。

但 Benchmark 上分数接近，不代表现实世界里的能力就完全相同。

类似的差异在开放式任务中尤其明显。两款模型即便跑分相差无几，真正拿来写文章、做创意策划或者分析复杂问题时，较大模型仍然可能展现出更敏锐的洞察力、更丰富的想象力，以及更细腻的语言表达能力。

参数规模并不能直接等同于智能水平，但在架构、训练质量和推理条件相近的情况下，更充足的模型容量，会带来知识储备和综合能力上的优势。

面对大型代码工程、复杂 Agent 工作流等现实任务，模型还需要持续规划、调用工具、应对突发状况，并在漫长的执行过程中始终理解自己究竟要完成什么。相比标准化测试，真实世界对模型的要求显然更加复杂。

说到底，模型可以越来越便宜，简单任务也可以交给越来越小的模型，但真到了需要干大活儿的时候，用户依然需要一个能力上限足够高的 Pro。

从这个角度来看，Kimi K3.1 Pro 的意义也正在于此。当行业都忙着把模型做得更快、更省时，仍然有人愿意继续探索大模型的能力上限，让国产模型有机会参与全球最顶尖的能力竞争。

说实话，能重新对一款国产旗舰模型有这样的期待，还是挺让人兴奋的。
