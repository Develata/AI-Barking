Comparison Summary

GPT-6.1 Terra (Max) is amongst the leading models in intelligence and well priced when comparing to other models of similar price. It's also faster than average, however somewhat verbose. The model supports text and image input, outputs text, and has a 1M tokens context window.

GPT-6.1 Terra (Max) scores 51 on the Artificial Analysis Intelligence Index, placing it well above average among comparable models (median: 41). When evaluating the Intelligence Index, it generated 99M tokens, which is somewhat verbose in comparison to the median of 63M.

Pricing for GPT-6.1 Terra (Max) is $1.00 per 1M input tokens (competitively priced, median: $2.00) and $5.00 per 1M output tokens (moderately priced, median: $10.00). On average, it costs $0.96 per task to evaluate GPT-6.1 Terra (Max) on the Intelligence Index.

At 91 tokens per second, GPT-6.1 Terra (Max) is faster than average (86).

Frequently Asked Questions

Common questions about GPT-6.1 Terra (Max)

When was GPT-6.1 Terra (Max) released?

GPT-6.1 Terra (Max) was released on October 26, 2026.

Who created GPT-6.1 Terra (Max)?

GPT-6.1 Terra (Max) was created by OpenAI.

How intelligent is GPT-6.1 Terra (Max)?

GPT-6.1 Terra (Max) scores 51 on the Artificial Analysis Intelligence Index, placing it well above average among other models in a similar price tier (median: 41).

How fast is GPT-6.1 Terra (Max)?

GPT-6.1 Terra (Max) generates output at 90.9 tokens per second (based on OpenAI's API), which is above average compared to other models in a similar price tier (median: 86.4 t/s).

What is the latency of GPT-6.1 Terra (Max)?

GPT-6.1 Terra (Max) has a time to first token (TTFT) of 77.96s (based on OpenAI's API), which is at the higher end compared to other models in a similar price tier (median: 3.69s).

How much does GPT-6.1 Terra (Max) cost?

GPT-6.1 Terra (Max) costs $1.00 per 1M input tokens (very competitive, median: $2.00) and $5.00 per 1M output tokens (better than average, median: $10.00), based on OpenAI's API.

What is GPT-6.1 Terra (Max) API pricing?

GPT-6.1 Terra (Max) costs $1.00 per 1M input tokens and $5.00 per 1M output tokens (based on OpenAI's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $0.73 per 1M tokens. Pricing may vary by provider. Compare provider pricing [/models/gpt-6-1-terra/providers]

How verbose is GPT-6.1 Terra (Max)?

When evaluated on the Intelligence Index, GPT-6.1 Terra (Max) generated 99M output tokens, which is somewhat higher than average compared to other models in a similar price tier (median: 63M).

Is GPT-6.1 Terra (Max) a reasoning model?

Yes, GPT-6.1 Terra (Max) is a reasoning model. It uses extended thinking or chain-of-thought reasoning to work through complex problems before providing an answer.

What input modalities does GPT-6.1 Terra (Max) support?

GPT-6.1 Terra (Max) supports text and image input.

What output modalities does GPT-6.1 Terra (Max) support?

GPT-6.1 Terra (Max) supports text output.

Can GPT-6.1 Terra (Max) process images?

Yes, GPT-6.1 Terra (Max) supports image input and can analyze, describe, and answer questions about images.

Is GPT-6.1 Terra (Max) multimodal?

Yes, GPT-6.1 Terra (Max) is multimodal. It can process text and image input and generate text output.

What is the context window of GPT-6.1 Terra (Max)?

GPT-6.1 Terra (Max) has a context window of 1.0M tokens. This determines how much text and conversation history the model can process in a single request.

Is GPT-6.1 Terra (Max) open source?

No, GPT-6.1 Terra (Max) is proprietary. The model weights are not publicly available.

How many parameters does GPT-6.1 Terra (Max) have?

GPT-6.1 Terra (Max) is a proprietary model and OpenAI has not disclosed the model size or parameter count.

How does GPT-6.1 Terra (Max) perform on benchmarks?

GPT-6.1 Terra (Max) achieves a score of 51 on the Artificial Analysis Intelligence Index. This composite benchmark evaluates models across reasoning, knowledge, mathematics, and coding.
