## 一、结论先行（仅事实核对，不是正文结论）

1. **官方两处写的时长都没有数字**：博文只写“短会话”（short sessions），官方模型页写“a few minutes of continuous interaction, rather than extended sessions”。博文与模型页都没有分辨率、帧率、延迟、参数量，也没有技术报告或 model card 链接。
2. **“两分钟”不在 Google 官方页面里**，出自发布会（press briefing）转述：TechCrunch、The Verge、Bloomberg（经 Bloomberg Línea 西语稿、财联社转述）、第一财经、爱范儿等都写“两分钟”，且多数写成“比 Genie 3 翻倍”。Google 官方的 Genie 3 页写的是“a few minutes”（24 帧每秒、720p），“一分钟”是 Genie 3 的视觉记忆（visual memory）回看距离，以及 Project Genie 产品把每次生成限制在 60 秒——媒体的“翻倍”把三个不同口径当成了同一个。
3. **开放范围**：研究预览，仅限受信任测试者（trusted testers）；Google AI Ultra 订阅者（Project Genie）与 Gemini API / AI Studio 早期合作伙伴“coming soon”，另有等待名单。无发售日、无价格。
4. 流行说法“人人可玩 / 无限世界 / 游戏引擎已死”的原文依据：官方博文用了 “infinitely variable simulations”，模型页用了 “infinite playground for robotics simulations”“unlimited range of realistic environments”，都是在说训练环境多样、不是“可无限连续游玩”；官方同时写 “a few minutes”“short sessions”。

## 三、可能的吠点（线索，进正文前须回一手核实）

1. “能连续玩多久”：官方书面只有“a few minutes”（模型页）与“short sessions”（博文），“两分钟”来自发布会口头与媒体转述；Hang Qi 在发布会上说达到两分钟上限也不等于全程完全一致（财联社/Bloomberg Línea）。
2. “比 Genie 3 翻倍”不是 Google 书面口径：Genie 3 官方页同样写 “a few minutes”，一分钟指视觉记忆回看，Project Genie 产品壳另限制 60 秒（Project Genie 博客）。
3. 谁能玩：目前只有受信任测试者；Ultra 订阅者与 API 合作伙伴是“coming soon”；另有等待名单（官方博文、Google 博客）。Ars 称 Ultra 档起价 $100 每月、API 价格未公布（L4）。
4. 官方只有“演示视频”，且写明 “Sequences shortened”“Results for illustrative purposes”（博文视频叠层、模型页 Disclaimer）；没有给出分辨率、帧率、延迟、参数量，也无技术报告。
5. 官方自己把“物体恒存、细节漂移、物理交互、音频准确、文字、空间精度、长期一致性、多主体、真实地点”列为局限（模型页、博文）。
6. “连贯”有一部分靠 Gemini 3.8 Flash 实时监看与改写提示（博文），不是纯 Genie 单模型；机器人演示用的是 Gemini 4 Argon，实际实时体验用 Gemini 3.8 Flash（财联社转述 Bloomberg，L4）。

## 五、扫描说法勘误

- “官方模型页只写 a few minutes”：属实（模型页 Limitations：“The model can support a few minutes of continuous interaction, rather than extended sessions.”）。但**博文**写的是 “short sessions”，没有 “a few minutes”。
- “‘两分钟连贯时长’的口径问题此前已有人拆过”：“两分钟”**不在**官方书面页面；出自发布会，由 TechCrunch、The Verge、Bloomberg 等转述，并被写成“比 Genie 3 翻倍”。Genie 3 官方页写 “a few minutes”，Project Genie 产品限制 60 秒。
- ChatGPT 扫描说“受限研究预览；用户可用键盘进入生成的世界，实时改天气与场景，有原生音频”：与原文相符，但“用户”只指受信任测试者；公众访问是 “coming soon”。
- “场景规划等借助其他 Gemini 模型”：原文是 Gemini 3.8 Flash 作 “guiding agent”（观察画面、拆目标、核对每步是否成功）与 Gemini Omni “anchors” 外观与行为，另有 Gemini 4 Argon 用于机器人演示。
