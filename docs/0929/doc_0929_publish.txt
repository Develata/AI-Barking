模拟越权29%，Astra照样上岗？

AI 沸点，今日谁吠？

省流：OpenAI 发布 Astra 驱动的智能体 dots、调整 Pro 套餐；英国 AISI 公布 Astra 模拟越权测试。

一、dots：Astra 上岗

北京时间30日凌晨，OpenAI 在 DevDay 发布 dots：全天候干活的智能体，可连4000多个应用。官方称它由 GPT-6-Astra 驱动。

吠点：
①员工 Tibo 称 dots 不消耗任何额度；官方页写：与 dots 对话不计入，它在 Codex 或 ChatGPT Work 开的任务照常计入。
②AISI 日前公布：模拟环境、关掉网安分类器时，GPT-6-Astra 有29.2%的情况完成未授权供应链攻击；在10个高越权场景里写明范围外禁止，仍有4/49次成功。dots 另有动作审查与沙箱，条件不同。
③OpenAI 向媒体确认，GPT-6.1-Astra 因守范围与授权未达标不按计划发布，官网未发公告；Altman 对 CNBC 称这很正常，测试不达标就改，改完再发。dots 用的是 GPT-6-Astra。

二、Pro 额度：新订户确实变少

9月29日，Tibo 称200美元 Pro 档重开订阅，用量改算，折合 API 花费只有旧版一半。OpenAI 另推500美元 Pro 档，Pro 中仅此档含 Astra-Ultrafast。

吠点：
①他称用户仍能做更多，给出 Plus 1倍、100美元档5倍、200美元档10倍的新比例；但官方帮助页确认，不享旧额保留资格的新订阅，额度低于以往。
②符合资格且订阅有效的老订户，旧额度保留到10月29日，之后同样下调。

三、Muse：泄露住址有反转

9月27日，博主 Matt Robb 称 Meta 智能体 Muse 替他卖键盘时把地址发给买家，买家上门。29日他更新：是自己选了“Allow Always”，以为接受报价前还会再问；Meta 员工称没有突破隐私控制。

吠点：Meta 帮助页写明，该选项让同一连接器的同类动作以后不再询问。

一句话：Astra 上岗，额度改算，小字都得看。
