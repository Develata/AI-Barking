DevDay 2026 回顾

在 DevDay 2026，我们为人们提供更多方式来挑战更有雄心的工作，并带来开创未来的工具

分享

DevDay 2026 是我们迄今规模最大的一届，带来了超过 20 项重大更新，涵盖 ChatGPT、Codex、我们的模型，以及与 AI 协作的全新方式。

我们相信，AI 能助力创造与探索迎来新一轮繁荣。它应当让人们有更多时间投入自己重视的事，更自由地追求自己的想法，并有能力做到曾经认为不可能的事。

今天，我们推出了能够持续承担职责的智能体，以及人与 AI 协作的新方式。我们也进一步践行了对开放生态系统的承诺，将 ChatGPT 开放为人与智能体协作的共享平台，让开发者能够直接面向我们合计 12 亿用户推出全新的原生体验。

dots

这些能力出众、全天候运行的智能体能够持续承担职责，让你有更多时间和精力专注于自己重视的事。dots 由我们最智能、最符合对齐目标的模型 GPT‑6 Astra 驱动，拥有各自的云端计算机，并能在你选择连接的各类应用中开展工作。给它一个目标，明确它可以自主执行的操作，它就会主动为你开展工作。我们设想，未来多个 dot 将组成团队，协同为你工作。

适用于 Pro、Business Premium 和 Enterprise。了解更多⁠

GPT-6.1 Sol

我们推出了 GPT‑6.1 Sol，这是 GPT‑6 Sol 的一次重大升级，在智能体编程、计算机使用和专业工作方面均表现尤为出色。它让 Sol 在高难度任务上的表现更接近 GPT‑6 Astra，而输入和输出 Token 价格仅为 Astra 标准价格的四分之一，让开发者在相同预算下有更大空间运行智能体，用于探索代码库、迭代解决方案和执行复杂工作流。

Astra Ultrafast

Astra Ultrafast 是 GPT‑6 Astra 的高端速度档位，可在 API、“ChatGPT 工作”和 Codex 中使用。其速度在 API 中最高可达标准版 Astra 的 6 倍，在 Codex 和“ChatGPT 工作”中最高可达 8 倍。Ultrafast 专为注重低延迟的工作而设计，无论是通过更快生成代码帮助开发者保持心流状态，还是提供更好的用户体验，都能发挥作用。

Codex Cloud

按需运行 Codex：在电脑上运行、通过手机远程操作，或从任意设备在云端运行。可复用的开发环境让任务快速启动，并为团队提供采用已批准设置和权限的共享配置。适用于 Plus、Pro、Business、医疗保健版、Education 和 Enterprise。

焕新升级的 Codex CLI

Codex CLI 现已支持语音对话，你可以直接与 Codex 对话来启动任务并引导任务推进。借助全新的 /agents 视图，你可以将工作分配给多个智能体，并轻松跟踪多项任务的进度。我们还改进了日常工作流程，包括编辑提示词、恢复会话以及新增内置工作树支持，同时更新了终端界面，让界面更简洁、长会话更易读。

适用于所有套餐。了解更多

代码审查

ChatGPT 桌面应用中的全新代码审查体验，帮助你快速把握各个项目中需要关注的重点。在提供反馈前，你可以浏览摘要、深入查看差异，并向 Codex 询问潜在问题；借助自动审查，还可以让 Codex 在你不在时于云端完成初审。代码审查支持 GitHub Pull Request 和 GitLab 合并请求。

适用于所有套餐。了解更多

Codex Security Cloud

我们正在将 Defense Factory⁠ 的持续防御方法引入 Codex Security Cloud，并提供对 Daybreak Blue 所提供模型的访问，无需另行申请 Daybreak。现在，团队既可以持续检查新提交，也可以按需或定时扫描整个 GitHub 代码仓库。调查、自动去重和修复均在云端运行，即使合上笔记本电脑，工作也会继续。以插件形式提供，可在 Codex 桌面端和网页版中使用。

面向所有 Codex 用户开放。了解更多⁠

Decisions API

Decisions API 将 Luna 的智能集中用于一组由用户定义的问题，每个问题都设有有限的预定义答案，从而实现实时决策。开发者通过文本或图像提供上下文，获得的答案可用于对内容分类、路由请求，或选择智能体的下一步操作。

今日起限量开放预览版，计划在未来几天内广泛发布。了解更多

Agents API 中的计算机使用功能

Agents API⁠ 现已支持开发者以托管方式使用 Codex 执行框架。你的应用负责定义任务、连接工具和数据，以及展示进度。OpenAI 负责运行底层系统，加快智能体开发，并减少团队需要构建和维护的智能体基础设施。Agents API 支持 Codex 的出色功能，包括多智能体、工具搜索、工具调用、压缩，以及新增的计算机使用功能。

可通过 API 使用，500 美元 Pro 套餐订阅用户和符合条件的 Enterprise 客户也可在 Codex 和“ChatGPT 工作”中使用。了解更多⁠

人与 AI 协作的更好方式
ChatGPT 资料空间

与 AI 和团队一起完成工作的全新空间。将团队加入专属空间，让包括 ChatGPT 在内的所有成员都能结合共同目标和过往工作，在已有协作成果上继续推进。让 ChatGPT 将对话转化为页面或幻灯片，它会先提问以明确需求，再在你面前起草内容。你可以亲自编辑、让 ChatGPT 再修改一轮，或邀请团队加入，全程无需将工作转移到其他工具。

Pro、Business 和 Enterprise 套餐用户可在 ChatGPT 桌面应用和网页版中使用，移动端即将推出。了解更多⁠

动态页面

一种全新的文档类型，专为你与智能体及团队成员共同完成工作而设计，适用于项目计划、报告、视觉概念等多种内容。凡是能用 ChatGPT 完成的事，都可以在页面上完成。与 ChatGPT 或你的 Dot 协作，生成图表、交互式仪表板和图像，并用标题、项目符号和表格来组织内容。邀请团队通过评论或直接编辑提出想法和反馈，再提及你的 Dot 或 ChatGPT，让它修改内容或执行后续步骤。设置页面从已连接的工具自动更新，例如随最新工作变化的待办事项清单，或根据已连接数据源的更新保持最新的产品团队跟踪表。

适用于 Pro、Business 和 Enterprise 套餐。了解更多

协作式幻灯片

全新且功能强大的演示文稿编辑器，让团队与 ChatGPT 共同打造专业演示文稿。无论是准备财务评审还是客户演示，它都提供了生动呈现内容所需的工具，包括原生可编辑图表，以及文本、形状和图像。将对话转化为幻灯片，或从自己的模板开始，并在 ChatGPT 制作过程中向它提供反馈。邀请多位团队成员同时直接编辑演示文稿、发表评论，或标注希望 ChatGPT 修改的地方。准备就绪后，可以直接在 ChatGPT 中演示，也可以导出到 PowerPoint 或 Google Slides，保留原有格式并继续编辑。

适用于 Pro、Business 和 Enterprise 套餐。了解更多

创建团队，共享任务

在 ChatGPT 中将同事加入团队，即可与所有成员共享页面、演示文稿、电子表格等内容。你还可以创建团队任务，将每周项目进展汇报等重复性工作交给 ChatGPT。描述你的需求，ChatGPT 就能使用已连接的工具收集信息并执行操作，既可以定时运行，也可以在出现变化时触发，例如收到新的电子邮件或 Slack 消息时。团队成员可以共同更新指令，让任务随着工作重点的变化持续发挥作用。

适用于 Business 和 Enterprise 套餐。了解更多

Slack 和 Microsoft Teams 中的 @ChatGPT

在频道、消息串或私信中提及 @ChatGPT，即可将讨论转化为项目简报、排查缺陷并准备修复方案供审核，或每天早上发布客户动态。它可以使用管理员已连接的工具，也可以在你的授权范围内使用你的工具。即使没有个人 ChatGPT 许可，团队成员也能在同一对话中补充上下文并完善工作成果。

会议插件

使用会议插件录制会议音频，并将会议纪要保存在 ChatGPT 资料空间中。你可以将纪要设为私密，也可以与团队共享。ChatGPT 可以结合你们此前合作的上下文，总结与你最相关的要点、决策和后续步骤。让它协助处理行动事项。例如，在团队站会后，让 ChatGPT 根据已作出的决策、遇到的阻碍和发生的变化更新项目计划。

已向 Pro 和 Business 用户开放测试版，即将向 Enterprise 用户开放。了解更多⁠

可分享的个人资料页让用户能够展示自己的站点和插件，供他人发现和复用。个人资料页将这些作品汇集起来，方便你集中分享。团队成员还可以发现共享的技能，技能共享仅限于工作空间内。
