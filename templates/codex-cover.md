# Codex 封面生成模板

规则见 EDITORIAL.md“封面”。流程：抽签 → 按 A、B 两组各写提示词 → 各跑一次 Codex（每次出竖版、横版各 1 张）→ 挑一组 → 记录。每种尺寸累计最多 5 张。

## 1. 抽签

```bash
cargo run --release --manifest-path tools/barking/Cargo.toml -- cover-draw docs/<YYMM>/<MMDD>
```

输出 A、B 两组取值（画风、底色、标题、看板娘、动作）、每个值的提示，以及两行现成的 `封面抽签：…`。两组都配不上当期内容时可以重抽一次（再跑一遍），把理由写进 `images/README.md`。不要在两组之间拼取值。

## 2. 写提示词

每组写一段竖版、一段横版。提示词分两部分：

- **画面**：每组从头写，不从上一期或另一组复制句子。先定主体：当期新闻里的具体物件或场景（不是通用玩具机器人）。然后把抽到的五个值逐个落到画面上：画风在桶里挑最贴主题的细分；底色；标题放在哪里、写成什么字；看板娘怎么出镜、在干什么。
- **硬性要求**：下面这段逐字照抄，只填 `{…}`。

> 画面里只允许出现这些文字：主标题，逐字为「{主标题}」；{副标题，逐字为「…」；关键数字，逐字为「…」；——按 EDITORIAL.md 封面“文字”一条决定加不加，不加就删掉这半句}看板娘胸前圆牌上的「AI 吠点」。不要其他文字、数字、字母、logo、国旗、品牌标志或真人。附带的参考图只用来认人：蓝色长发、狗耳、鲸鱼尾巴、女仆装、胸前「AI 吠点」圆牌、两只正常的人手（不戴手套）。不要沿用参考图的日系动漫上色和画法，按本画面的画风重新画她，线条、上色、头身比例都跟画面一致。她只有两只手、两只耳朵、一条尾巴。主标题在手机缩略图下清楚可读。{竖版：3:4 竖版，1080×1440 或同等比例。｜横版：2.35:1 横版，约 1920×816，独立横构图；主标题与看板娘完整落在画面正中的方形区域内，便于再裁出 1:1 缩略图。}

两组的四段提示词都记进 `images/README.md`（选中组在前，落选组注明“落选”）。

## 3. 运行

`{OUT}` 为草稿目录下的新子目录（如 `cover-A/`、`cover-B/`），候选图不放进仓库。两组可以同时在后台跑：

```bash
codex exec -m gpt-6-astra -c 'model_reasoning_effort="medium"' -s danger-full-access --skip-git-repo-check --ephemeral -C "E:/gitclone/AI-Barking" -i "E:/gitclone/AI-Barking/common_images/mascot-reference.png" -o "{OUT}/report.md" - < "{OUT}/prompt.md"
```

约 3 分钟。`image_generation` 是 Codex CLI 的内置功能（0.156 起为 stable，默认开启）。本机拦下 `danger-full-access` 时改用 `-s workspace-write`，并以 `{OUT}` 为工作区（1024 期如此）。

### prompt.md

---

你是图像生成执行者。用你的图像生成能力生成两张封面图。

输出：
- `{OUT}/00-cover.png`（竖版 3:4）与 `{OUT}/00-cover-wide.png`（横版 2.35:1，不支持则取最接近的横版比例并说明）。
- 生成工具若存到别处，复制到上述路径。只写入 `{OUT}/`，不改动其他文件，不 commit。
- 回报两张图的实际像素尺寸与保存路径。

=== 图 1：3:4 竖版 ===
{竖版提示词}
=== 图 2：2.35:1 横版 ===
{横版提示词}

---

## 4. 挑选与验收（Claude）

1. 逐字核对画面里的每个字与数字：必须与提示词引号内文字、正文一致；多字、漏字、错字、乱码、logo、真人脸即淘汰。小字裁出放大约 4 倍再看。
2. 看板娘：数手、耳朵、尾巴；看她是不是按本期画风重画了，而不是参考图原样贴进来。
3. 与前几期比：用 Read 打开前 3 期的 `images/00-cover.png`，和候选一起看。缩略图一眼像同一系列（同样的底色、同样的标题字和位置、同样的看板娘姿势）就淘汰。
4. 横版：按居中 1:1（宽 = 图高）裁切检查，主标题与看板娘必须完整留在框内。竖版：手机缩略图下主标题可读，主体不拥挤。
5. 选中的图复制为本期 `images/00-cover.png`、`images/00-cover-wide.png`。在 `images/README.md` 封面节记录：`封面抽签：…` 一行（选中组，整行照抄）、抽签种子、生成方式、候选数、选中哪组及理由、落选原因、逐字核对结果。
